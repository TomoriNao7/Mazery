# 日式剧本风格设计思路（playstyle 技能）

> **说明**：本文档是从 RAG 背景知识 `rag/background/bg_日式推理.md` 的「五、日式剧本风格设计思路（风格专属）」章节拆出的**风格技能**，供创作 Agent 在创作日式推理本时作为风格约束加载。对应背景知识（诡计库/案例/专业速查）见 `bg_日式推理.md`。

### 5.1 时代设定决策五档

日式本先定"时代档位"，档位决定家制度形态、证据体系与逻辑要求，且**选定后必须守约**：

| 档位         | 时间范围              | 家制度/社会                                    | 逻辑要求                                                   |
| ------------ | --------------------- | ---------------------------------------------- | ---------------------------------------------------------- |
| **明治·大正** | 1868–1926            | 家督制、士族/华族/町人、近代化碰撞              | 旧民法家制度；无DNA/监控/手机；铁路初兴（时刻表可用）      |
| **战前昭和** | 1926–1945            | 军国、镇压、秘密警察                            | 身份审查严；家名至上；情报/密探要素                        |
| **战后昭和** | 1945–1989            | 经济起飞、宗族瓦解、城乡迁徙                    | 新民法均分继承；指纹库建立；录像带/大哥大后期出现           |
| **平成**     | 1989–2019            | 泡沫崩溃、失业、地方凋敝                        | 监控/DNA/手机普及；社会派主题黄金期                        |
| **令和/现代** | 2019–                | SNS时代、心理健康、阶层固化                     | 智能监控/定位/网络痕迹；须处理监控盲区                     |

**设定一致性检验**：大正本出现"手机定位破案"或"DNA鉴定"是硬伤；战后本沿用"长子继承制度"而无家元/老铺理由也是硬伤（§2.7铁律3）。

### 5.2 日式元素如何服务诡计（而非纯氛围）

**原则：日式元素应成为推理的证据体系与诡计载体，而非装饰。** 反面例子：只有"和服/榻榻米/鞠躬描写"而无"日式证据运用"的剧本，是换了皮的现代本格。

| 日式元素       | 推理/诡计用途                                 |
| -------------- | ---------------------------------------------- |
| 妖怪/怨灵/诅咒 | 误导源、设定系规则、民俗暗号系统（§3.7）       |
| 温泉旅馆/宿帐  | 封闭集合花名册、入浴在场性、钥匙管理（§3.5）   |
| 时刻表/列车    | 不在场证明、不可能往返、时间错位（§3.2）       |
| 家制度/系图/家纹 | 动机分布、身份识别锚点、继承之争（§3.3、§5.3） |
| 和室建筑（障子/押入れ/檐廊） | 密室、藏身处、听觉证据（§3.1、§5.5） |
| 敬语/称谓/座次 | 身份、行为权限、关系亲疏的证据                 |
| 社会结构（会社/官僚/媒体） | 系统性动机、共犯链、冤案反转（§3.8） |

### 5.3 人物身份与关系网（家族制度核心）

- **家族结构即嫌疑网**：本家/分家、嫡系/旁支、长子/次子/养子——每个人的继承顺位与处境决定动机分布（§3.8）。画一张**家系图**作为核心线索卡。
- **家元/老铺传承**：传统艺能（茶道/花道/剑道/歌舞伎）的"家元"制度让"继承"不仅是财产更是"名号"——名号断承比财产更致命，动机更强。
- **养子制度的推理价值**：婿养子（改姓入赘）、相续养子——养子的"血缘与名分错位"是身份诡计的温床（§3.3、§附录C）。
- **家纹/印章/和服纹样**：家纹是家族标识，可作"不可伪造"的身份识别锚点（§附录C）。
- **关系网≥3条**：血缘/姻亲/主仆（员工体系）/师徒/旧怨/利益/职场——人物关系本身就是线索网。

### 5.4 妖怪元素的三档处理

| 档位       | 妖怪定位                     | 逻辑要求                                     | 适用场景           |
| ---------- | ---------------------------- | -------------------------------------------- | ------------------ |
| **写实民俗** | 妖怪是当地信仰/传说背景      | 妖怪不参与作案；证据体系完全写实             | 硬核本格、社会派   |
| **都市传说** | 妖怪叙事作为误导源           | 每个灵异线索有非灵异解释且可搜证证伪（§3.7） | 本格+氛围、变格向  |
| **设定系变格** | 妖怪真实存在但能力有规则     | 立规则并明示（§3.7规则模板），设定内可推理    | 变格、新本格、怪谈 |

**选型建议**：多数日式剧本建议走"**写实民俗/都市传说**"档——妖怪作为氛围与误导，真相归位到人。设定系变格本对规则自洽要求极高（§3.7），谨慎选择。

**妖怪与线索的绑定原则**：每个妖怪元素都必须"**绑定至少一条可搜证的物理线索**"（雪地足迹、尸温、药物、藏匿空间、录音）——妖怪负责迷惑，物理线索负责归位。

### 5.5 温泉旅馆场景设计（封闭空间 + 日式细节）

温泉旅馆是日式暴风雪山庄的黄金舞台。设计时注意：

**空间结构**（可作地图线索卡）：

| 空间           | 逻辑用途                                       |
| -------------- | ---------------------------------------------- |
| 本馆/别馆/离れ | 距离与移动时间成为时间线要素                   |
| 大浴场/内汤/露天风吕/贷切 | 入浴时段与在场性（§3.5风吕要素）     |
| 帐场（前台）   | 宿帐、钥匙、电话——证据枢纽                     |
| 厨房/储物间    | 凶器来源（刀具）与藏匿点                       |
| 押入れ/阁楼    | 藏身处/藏尸处——须交代空间真实性（§3.1）      |
| 檐廊（縁側）   | 外部通道——密室破解路径之一                     |

**日式细节的推理化**：
- **宿帐**：入住登记簿——人数核对、身份登记、时间记录的硬证据。
- **和服/浴衣/纹样**：衣物的湿、乱、损毁状态；家纹/纹样泄露身份。
- **暖炉/电热毯**：尸温诡计载体（§3.6）。
- **隔音差的和室**："听到什么"是证据也是误导（§3.5）。
- **餐食时间**：仲居送餐/板前备餐记录是时间线交叉验证点。

### 5.6 社会派主题设计（动机社会学）

| 设计要点     | 说明                                                         |
| ------------ | ------------------------------------------------------------ |
| **选题**     | 从阶层、家族压迫、官僚、校园、职场、战争遗留中选一个核心主题（§3.8动机库） |
| **触发事件** | 设计"最后一根稻草"——迫使凶手"现在"动手的具体事件            |
| **证据化处境** | 角色困境以旧照/日记/档案/病历/账目等可搜证书证呈现            |
| **共犯链**   | 设计体制内外的知情者/沉默者/帮凶，信息边界清楚                 |
| **反转层次** | "表面凶手"→"幕后系统之恶"两层结构，忌"为反转而反转"         |
| **道德基调** | 让玩家理解动机、不认同手段——避免"洗白凶手的价值观问题"       |

### 5.7 氛围营造（为推理服务）

| 维度         | 建议                                                         |
| ------------ | ------------------------------------------------------------ |
| **场景描写** | 注重日式细节（障子光影、露天风吕水汽、雪景、挂轴、香炉、暖帘）——建筑细节可埋密室/藏匿线索 |
| **服饰描写** | 和服/浴衣/洋服的时代混搭体现时代；衣物状态（湿/乱/损）埋证据 |
| **器物描写** | 茶具、灯火、香炉、刀具、怀表、提灯、旧照片——器物可埋机关/毒药/身份线索 |
| **称谓礼节** | 敬语、称呼、座次、上座下座——关系亲疏与行为权限的映射       |
| **声音设计** | 和室隔音差的脚步声、障子滑轨声、雪落声——听觉线索与误导       |

### 5.8 公平性特殊考量：知识自包含

**核心规范**：剧本内所有推理所需的关键日式知识，必须以**设定说明/知识线索卡**形式在游戏内给出，**不得依赖玩家自带日式知识**——否则违反公平（§1.3原则2）。

**知识线索卡示例**：
- **妖怪民俗手册**：本剧涉及的妖怪传说与"都市传说档案"（§附录A内容可化作线索卡）
- **温泉旅馆房型与规矩**：宿帐、风吕时段、员工体系、钥匙管理（§附录B）
- **家系图/遗嘱**：家族结构、继承顺位、养子关系（§附录C）
- **列车时刻表/巴士时刻表**：班次、换乘、停运（§3.2）
- **法医报告/尸检记录**：死因、伤痕、胃内容物（按时代档位取舍）

> **自检问题**：如果一名完全不懂日式知识的玩家，仅凭剧本内线索能否完成全部推理？若不能，缺的那块知识必须写进剧本。

### 5.9 日式本常见误区

| 误区               | 后果                                       |
| ------------------ | ------------------------------------------ |
| **妖怪作祟成解答** | 用灵异解释本可物理验证的现场，逻辑崩塌    |
| **有和风无和法**   | 证据体系仍是现代思维，日式沦为皮囊        |
| **家制度悬浮**     | 家族/继承只作背景板，不做动机与身份线索    |
| **温泉只当布景**   | 旅馆细节不做推理要素（宿帐/风吕/钥匙）     |
| **时代科技混用**   | 大正本靠DNA破案、现代本监控"恰好全坏"     |
| **设定系无规则**   | 妖怪万能，变成纯玄学（§3.7反面）           |
| **社会派空喊**     | 批判宏大却无证据化处境与触发事件          |
| **知识依赖玩家**   | 玩家不懂日式知识即卡关，违反公平（§5.8）  |
