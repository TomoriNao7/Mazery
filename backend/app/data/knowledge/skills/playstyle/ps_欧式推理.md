# 欧式剧本风格设计思路（playstyle 技能）

> **说明**：本文档是从 RAG 背景知识 `rag/background/bg_欧式推理.md` 的「五、欧式剧本风格设计思路（风格专属）」章节拆出的**风格技能**，供创作 Agent 在创作欧式推理本时作为风格约束加载。对应背景知识（诡计库/案例/专业速查）见 `bg_欧式推理.md`。

### 5.1 时代设定决策三档

欧式本先定"时代档位"，档位决定证据体系与逻辑要求，且**选定后必须守约**：

| 档位         | 说明                                 | 逻辑要求                                                   | 适用场景               |
| ------------ | ------------------------------------ | ---------------------------------------------------------- | ---------------------- |
| **写实中世纪** | 真实历史分期、制度、器物、称谓       | 器物/制度/称谓符合史实；证据体系严格按该时期（§2.7）       | 硬核推理、历史爱好者   |
| **架空欧陆** | 脱离史实自由构建世界观               | 世界规则须自洽且**明示**（有无火器/有无教会魔法/通讯方式）；证据体系自行定义并告知玩家 | 变格、设定系、权谋、欢乐 |
| **戏说历史** | 历史框架下的艺术加工                 | 允许适度夸张，但"现实向"部分仍须自洽；注明戏说成分         | 融合向、氛围向         |

**中世纪分期参考**（写实档需守约）：**中世纪早期**（约500–1000，诺曼征服前）、**中世纪盛期**（约1000–1300，城堡/骑士/大教堂全盛）、**中世纪晚期**（约1300–1500，黑死病、百年战争、火药萌芽）。**火器在14世纪中叶后才出现**，写实档需注意——13世纪剧本出现火枪是硬伤。

**设定一致性检验**：写实本出现"化学验毒破案"或"13世纪有火枪"是硬伤；架空本不说明"本世界有教会魔法"就使用魔法也是硬伤（§2.7铁律3）。

### 5.2 欧式元素如何服务诡计（而非纯氛围）

**原则：欧式元素应成为推理的证据体系与诡计载体，而非装饰。** 反面例子：只有"城堡/骑士/纹章描写"而无"欧式证据运用"的剧本，是换了皮的现代本格。

| 欧式元素       | 推理/诡计用途                                 |
| -------------- | ---------------------------------------------- |
| 钟声/祷时/烛台/沙漏 | 时间诡计、不在场证明、目击时间                 |
| 粗糙检视/试毒人  | 死因判定、身份识别、验毒局限                   |
| 纹章/封印/族谱/洗礼 | 身份诡计、私生子冒认、继承权                   |
| 城门/吊桥/城墙/守卫 | 密室、机会排查、封闭性验证                     |
| 密道/暗格/塔楼   | 密室、藏身处、建筑诡计（须有建造者与用途）     |
| 信使/快马/文书蜡封 | 不在场证明、通讯诡计、书证伪造                 |
| 毒药/炼金术      | 手段与延时、毒物来源推理                       |
| 继承/教会/王权   | 动机、阻力（谁能查/敢不敢查）、行为权限        |

### 5.3 人物身份与关系网（贵族/教士/骑士/平民/仆人）

- **身份等级决定行为权限**：谁能进内廷、谁能见领主、谁掌钥匙、谁有佩剑/骑马权——这既是氛围，也是推理要素（机会×身份互检）。
- **社会阶层**：国王/贵族（爵位递降）→ 骑士 → 教士 → 自由民/商人 → 农奴/仆从——**每个阶层带来一种行为权限与证据视角**（领主→文书/账册、管家→钥匙/仆从调度、马夫→行程/马匹、厨房→饮食/毒药、神父→忏悔/告解记录、铁匠→凶器制作）。
- **家族/领地关系网**：血缘/姻亲/封臣/主仆/师徒/仇怨/婚约/领地——人物关系本身就是线索网（§附录B）。
- **称谓规范**：国王/殿下/大人（Lord）/小姐（Lady）/修士/修女——称谓混乱是时代硬伤，称谓本身也能泄露身份。

### 5.4 城堡场景设计（建筑诡计 + 封闭空间）

城堡是欧式本的灵魂舞台。设计时注意：

**空间结构**（可作地图线索卡）：

| 空间             | 逻辑用途                                       |
| ---------------- | ---------------------------------------------- |
| 主堡/塔楼        | 密室、坠亡、封闭空间                           |
| 大厅/宴会厅      | 全员目击、公开对峙、毒杀舞台                   |
| 礼拜堂/祈祷室    | 避难权、告解、密道入口（暗格）                 |
| 地牢/地窖        | 藏尸、禁锢、隐藏密道                           |
| 厨房/酒窖        | 凶器（刀具）与毒药（食物/酒）来源              |
| 密道/暗格        | 密室破解、藏身处——须有建造者与用途交代         |
| 城墙/吊桥/城门   | 封闭性验证、进出记录                           |
| 马厩/驿站        | 行程、马匹、换马——不在场证明的破绽点           |
| 图书馆/文书房    | 书证（遗嘱/契约/族谱）枢纽                     |

**建筑细节的推理化**：
- **密道/暗格三要素**：建造者（谁挖的）、用途（为何而建）、启用痕迹（灰尘/划痕/机关磨损）——三要素缺一即"凭空通道"硬伤。
- **塔楼/楼梯**：螺旋楼梯上行方向、壁炉烟道可攀爬、塔高与坠亡时间的物理约束。
- **吊桥/城门**：何时升降、谁掌管——进出记录与封闭性验证的硬证据。
- **蜡烛/壁炉**：照明来源与烛火计时——目击可信度与延时装置。

### 5.5 宗教与信仰要素（氛围 + 行为权限）

| 设计要点     | 说明                                                         |
| ------------ | ------------------------------------------------------------ |
| **法庭体系** | 教会法庭 vs 世俗法庭并行——教士的司法豁免是行为权限的戏剧张力 |
| **忏悔保密** | "唯一知情人"的沉默——可作信息封锁、反转钥匙、凶手藏身的保护伞 |
| **避难权**   | 教堂庇护=追捕盲区——可作凶手藏身/关键证人躲藏的设计          |
| **异端/圣物** | 异端审判、圣物之争——嫁祸、销毁证据、制造恐慌的动机来源      |
| **圣迹/预言** | 超常叙事的误导源（§3.9）——必须归位到物理证据                |

### 5.6 公平性特殊考量：知识自包含

**核心规范**：剧本内所有推理所需的关键欧式知识，必须以**设定说明/知识线索卡**形式在游戏内给出，**不得依赖玩家自带中世纪知识**——否则违反公平（§1.3原则2）。

**知识线索卡示例**：
- **城堡布局图**：密道、暗格、城门/吊桥、塔楼落锁情况（§5.4）
- **纹章/族谱手册**：家族纹章、血缘关系、继承顺位、私生子传闻（§附录B）
- **祷时/计时对照表**：教会祷时与现代时间换算（§2.2）
- **毒药/症状说明**：中世纪毒物与死状对应、来源渠道（§3.7）
- **领地文书/遗嘱/契约**：封地归属、遗嘱真伪、蜡封印记（§附录B）

> **自检问题**：如果一名完全不懂中世纪知识的现代玩家，仅凭剧本内线索能否完成全部推理？若不能，缺的那块知识必须写进剧本。

### 5.7 欧式本常见误区

| 误区               | 后果                                       |
| ------------------ | ------------------------------------------ |
| **有欧风无欧法**   | 证据体系仍是现代思维，欧式沦为皮囊        |
| **密道凭空出现**   | 建筑诡计无建造者与用途，逻辑崩塌          |
| **巫术解案**       | 用恶魔/巫术/圣迹解释本可物理验证的现场    |
| **验毒现代化**     | 中世纪用化学验毒破案，时代硬伤            |
| **为诡计乱改时代** | 写实与架空混淆，设定自相矛盾              |
| **知识依赖玩家**   | 玩家不懂中世纪知识即卡关，违反公平（§5.6）|
