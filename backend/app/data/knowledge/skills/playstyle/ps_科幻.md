# 科幻剧本风格设计思路（playstyle 技能）

> **说明**：本文档是从 RAG 背景知识 `rag/background/bg_科幻.md` 的「五、科幻剧本风格设计思路（风格专属）」章节拆出的**风格技能**，供创作 Agent 在创作科幻本时作为风格约束加载。对应背景知识（诡计库/案例/专业速查）见 `bg_科幻.md`。

### 5.1 科技设定决策三档

科幻本先定"科技档位"，档位决定证据体系与逻辑要求，且**选定后必须守约**：

| 档位           | 说明                                 | 逻辑要求                                                   | 适用场景               |
| -------------- | ------------------------------------ | ---------------------------------------------------------- | ---------------------- |
| **硬科幻近未来** | 基于现实科技外推（AI、基因、义体、网络） | 科技须符合"可外推的现实"——AI受算力权限、基因受生物学、黑客留痕迹 | 硬核推理、科技爱好者   |
| **软科幻架空**   | 脱离现实科技自由构建世界观           | 世界规则须自洽且**明示**（有无意识上传/有无虚拟世界/通讯方式）；证据体系自行定义并告知玩家 | 设定系、变格、欢乐     |
| **赛博朋克反乌托邦** | 近未来的资本/公司垄断、阶层割裂、义体与AI失控氛围 | 允许适度夸张（霓虹都市/巨型公司），但"现实向"部分仍须自洽；技术与社会规则互锁 | 融合向、氛围向、阵营   |

**设定一致性检验**：近未来本出现"无条件意识上传"或"DNA一锤定音"而无技术交代是硬伤；架空本不说明"本世界有意识上传"就使用意识诡计也是硬伤（§2.7铁律3）。

### 5.2 科幻元素如何服务诡计（而非纯氛围）

**原则：科幻元素应成为推理的证据体系与诡计载体，而非装饰。** 反面例子：只有"霓虹/义体/全息描写"而无"科幻证据运用"的剧本，是换了皮的现代本格。

| 科幻元素         | 推理/诡计用途                                     |
| ---------------- | -------------------------------------------------- |
| 时间戳/链上记录  | 时间诡计、不在场证明、证据可信度锚点             |
| 法医扫描/基因检测 | 死因判定、身份识别、样本可信度                   |
| 基因档案/神经签名 | 身份诡计、冒名顶替、克隆替身                     |
| 门禁/安保AI      | 密室、机会排查、权限归属                         |
| 通讯/神经链接    | 不在场证明、通讯诡计、身份伪装                   |
| AI/程序/黑客     | 手段与延时、凶手/目击者/替罪羊三角色             |
| 基因毒/纳米/义体 | 手段与延时、身份识别、生物学约束                 |
| 资本/公司/阶层   | 动机、阻力（谁能查/敢不敢查/受益者是谁）         |

### 5.3 人物身份与关系网

- **身份权限决定行为边界**：谁能进安全区、谁能访问神经数据、谁有AI控制权、谁有武器授权——这既是氛围，也是推理要素（机会×身份互检）。
- **身份层级**：公司高管/警务/黑客/义体医师/基因工程师/底层义体工人/全息主播——每个职能带来一种证据获取渠道（医师→医疗记录、工程师→系统日志、黑客→暗网痕迹、警务→验尸报告）。
- **人与非人**：人类/克隆体/仿生人/义体人/意识体/强AI——"是不是人"本身就是推理素材（§3.3、§3.7）。
- **关系网≥3条**：血缘/公司隶属/资本利益/情感/师徒/交易/仇怨/生存绑定——人物关系本身就是线索网。

### 5.4 科幻特色诡计选型

| 科幻特色诡计       | 选型要点                                     | 逻辑约束                                   |
| ------------------ | -------------------------------------------- | ------------------------------------------ |
| **克隆替身**       | 提前铺垫克隆工厂/双份档案/行为差异          | 置换后行为一致；识别锚点（§3.3）          |
| **意识/记忆诡计**  | 记忆可篡改、可植入、可重放                  | 记忆是数据可编辑；交叉验证（§3.6）        |
| **AI/程序诡计**    | AI作为凶手/目击者/替罪羊三角色              | 知识/物理/动机三边界（§3.7）              |
| **基因毒/纳米**    | 按发作时间与检测局限选型                    | 生物学约束；来源渠道；急/慢性定在场性（§3.8）|
| **密室（逻辑/物理）** | 交代门禁/安保系统的权限归属与日志          | 进/出/闭三向验证（§3.1）                  |
| **数字证据伪造**   | 监控/日志/时间戳/神经记录可伪造             | 篡改留痕+独立时钟源交叉验证（§2.4）       |
| **身份置换（克隆/义体/网络）** | 提前暗示；置换后行为一致              | 识别锚点；两角不同时在场（§3.3）          |
| **时间诡计**       | 系统性偏差（时钟被改/监控循环/日志重写）    | 偏差来源+计时源交叉验证（§2.2）           |

### 5.5 氛围营造（为推理服务）

| 维度         | 建议                                                         |
| ------------ | ------------------------------------------------------------ |
| **场景描写** | 注重建筑细节（赛博都市霓虹、地下城、实验舱、数据舱）、气候（酸雨、雾霾、电磁暴）——建筑细节可埋设夹层/维护通道/安全系统布线线索 |
| **义体描写** | 区分人类/义体人/仿生人的体态与痕迹——义体描写可埋身份/替换线索（"此人从不摘手套"） |
| **器物描写** | 全息屏、终端、植入物、神经接口、药品与基因试剂——器物可埋AI/毒剂/篡改线索（终端访问记录、试剂瓶残留） |
| **权限层级** | 门禁卡/权限等级/授权代码——权限层级是行为边界与机会的映射 |
| **时间表达** | 系统时间戳、公司内网时间、生理日志时间——统一时间基准，服务时间诡计 |

### 5.6 公平性特殊考量：知识自包含

**核心规范**：剧本内所有推理所需的关键科幻知识，必须以**设定说明/知识线索卡**形式在游戏内给出，**不得依赖玩家自带科幻知识**——否则违反公平（§1.3原则2）。

**知识线索卡示例**：
- **世界设定卡**：本世界的科技档位、AI权限、克隆合法性、意识上传技术、义体普及度（§5.1）
- **法医鉴定手册**：验尸流程、检测手段、代谢窗口（§八内容可化作线索卡）
- **系统权限图**：谁有哪级权限、门禁/安保系统的控制者
- **时空基准说明**：系统时钟源、哪些记录不可篡改、哪些可被改
- **医疗/基因档案**：克隆记录、改造记录、体检数据、用药史

> **自检问题**：如果一名对科幻只有影视刻板印象的现代玩家，仅凭剧本内线索能否完成全部推理？若不能，缺的那块知识必须写进剧本。

### 5.7 科幻本常见误区

| 误区               | 后果                                       |
| ------------------ | ------------------------------------------ |
| **有科幻无科学**   | 证据体系仍是现代思维，科幻沦为皮囊        |
| **为诡计乱改科技** | 硬科幻与软科幻混淆，设定自相矛盾          |
| **设定系无规则**   | AI/意识万能，变成纯玄学（§3.7反面）        |
| **DNA/时间戳万能** | 证据被当作全知工具，忽视可伪造性（§2.4）   |
| **黑科技凭空**     | 物理/科技可行性被破坏（§2.3）              |
| **知识依赖玩家**   | 玩家不懂科幻设定即卡关，违反公平（§5.6）   |
