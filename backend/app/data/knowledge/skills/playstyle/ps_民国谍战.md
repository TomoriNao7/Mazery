# 民国谍战剧本风格设计思路（playstyle 技能）

> **说明**：本文档是从 RAG 背景知识 `rag/background/bg_民国谍战.md` 的「五、民国谍战剧本风格设计思路（风格专属）」章节拆出的**风格技能**，供创作 Agent 在创作民国谍战本时作为风格约束加载。对应背景知识（诡计库/案例/专业速查）见 `bg_民国谍战.md`。

### 5.1 时代设定决策三档

民国谍战本先定"时代档位"，档位决定证据体系与逻辑要求，且**选定后必须守约**：

| 档位         | 说明                                 | 逻辑要求                                                   | 适用场景               |
| ------------ | ------------------------------------ | ---------------------------------------------------------- | ---------------------- |
| **写实历史** | 真实事件/年代/城市/机构（如1937年孤岛上海、珍珠港前的军统破译） | 机构、器物、制度、时间线符合史实；证据体系严格按民国（§2.7） | 硬核推理、历史爱好者   |
| **虚构城市** | 民国背景下的虚构都会/机构/人物（"沪上""临江"类） | 世界规则须自洽且**明示**（机构名、租界划分、科技水平）；证据体系自行定义并告知玩家 | 架空、阵营、融合       |
| **戏说历史** | 真实框架下的艺术加工（"改写历史""平行时空"） | 允许适度夸张与历史改写，但"现实向"部分仍须自洽；注明戏说成分 | 欢乐、反转、大格局     |

**设定一致性检验**：写实本出现"1940年上海租界有监控"或"军统办案如现代警方"是硬伤；虚构城市不说明"本世界无租界"就用租界诡计也是硬伤（§2.7铁律3）。

### 5.2 民国元素如何服务诡计（而非纯氛围）

**原则：民国元素应成为推理的证据体系与诡计载体，而非装饰。** 反面例子：只有"旗袍/黄包车/十里洋场描写"而无"电报破译/身份核验/管辖真空运用"的剧本，是换了皮的现代本格。

| 民国元素       | 推理/诡计用途                                 |
| -------------- | ---------------------------------------------- |
| 电报/密码本/电台 | 情报流转、电文破译、时间戳、测向窗口（§3.7）  |
| 密写/死信箱/接头 | 传递诡计、身份暴露、交接留痕（§3.7）          |
| 卧底/双面/化名 | 身份诡计、动机计算、排除法（§3.3）            |
| 租界/华界/管辖 | 管辖真空、跨区诡计、引渡窗口（§3.8）          |
| 帮派/堂口/码头 | 机会排查、动机、眼线（§3.8）                  |
| 军统/中统/76号/地下党 | 机构权限、档案、审讯、暗杀（§3.8）      |
| 法医/仵作     | 死因判定、验尸局限、身份锚点（附录D）         |
| 钟表/时刻表/报纸 | 时间诡计、不在场证明、时间源交叉（§2.2）      |
| 枪械/炸弹     | 手段、弹道、军火来源（§2.3）                  |

### 5.3 人物身份与关系网

- **身份等级与权限**：军统要员、76号特工、巡捕房探长、帮派堂主、地下党交通员、舞女、记者、医生、买办——每个身份带来一种证据获取渠道（探长→巡捕房档案、报务员→电文、账房→票据、堂口眼线→街面见闻）。
- **多重身份是特色**：一人可同时是"公开职业+隐藏组织身份+私下利益"——身份层越多，推理维度越深（§3.3）。
- **称谓与行话**：特工行话（上线/下线、接应、锄奸、钉子、白手套）、帮派切口（香堂、拜师、摆平）、时代称谓（先生/太太/同志/长官/少爷）——行话自洽既防穿越，行话本身也能泄露身份。
- **关系网≥3条**：血缘/夫妻/主仆/同僚/上下线/帮派辈分/政商同盟/旧识——人物关系本身就是线索网（§4.3《潜伏》启示）。

### 5.4 民国特色诡计选型

| 民国特色诡计       | 选型要点                                     | 逻辑约束                                   |
| ------------------ | -------------------------------------------- | ------------------------------------------ |
| **密码破译**       | 截获+密码本/密钥+语言特征，破译可重现        | 破译过程需线索支撑（§3.7）                |
| **密写/隐写**      | 米汤/柠檬汁/夹层/书页隐写，显影是线索        | 显影手段+试剂来源线索（§3.7）             |
| **卧底/双面**      | 提前铺垫身世疑点、旧识"认不出"              | 身份识别锚点+行为一致（§3.3）             |
| **管辖真空**       | 跨区尸体、交界案、引渡窗口                   | 管辖归属+跨区手续明确（§3.8）             |
| **电台测向**       | 开机时间窗+三角定位                           | 发报时段内在场者排查（§3.7）              |
| **暗杀/锄奸**      | 行动窗口+撤退通道+军火来源                   | 工具三问+机会×时机（§2.3）                |
| **假情报栽赃**     | 放料人+放料渠道+收料人完整链条               | 反向排查即破绽（§3.8）                    |
| **帮派/机构斗争**  | 帮规/权限/机构争抢作为动机与阻力             | 行为有规则、权限可查（§3.8）              |
| **过渡科技诡计**   | 人工总机窃听、暗房底片、电车时刻表           | "半可用"科技的双刃剑（§2.7）              |

### 5.5 氛围营造（为推理服务）

| 维度         | 建议                                                         |
| ------------ | ------------------------------------------------------------ |
| **场景描写** | 外滩钟声、电车叮当、舞厅霓虹、洋房吊灯、烟馆氤氲、码头汽笛——场景细节可埋管辖/交通/盲区线索（跨区地界、后门、防火梯） |
| **服饰描写** | 西装/旗袍/制服（军警/巡捕/学生装）/礼帽——服饰区分身份，可埋易容/乔装线索（"此人从不摘帽"） |
| **器物描写** | 怀表、钢笔、名片、打火机、烟斗、相机、留声机、电台——器物可埋时间/身份/密写线索（怀表停摆、名片真伪、表壳夹层） |
| **语言风格** | 特工行话、帮派切口、时代称谓——行话自洽防穿越，行话泄露身份 |
| **时间表达** | 阳历/阴历、钟点/时辰混用、报纸日期、电报时间戳——统一换算，服务时间诡计 |

### 5.6 公平性特殊考量：知识自包含

**核心规范**：剧本内所有推理所需的关键民国知识（密码学、机构、帮派、租界制度、民国器物），必须以**设定说明/知识线索卡**形式在游戏内给出，**不得依赖玩家自带民国知识**——否则违反公平（§1.3原则2）。

**知识线索卡示例**：
- **密码学入门卡**：电报码、密码本、密写原理、显影方法（附录A内容可化作线索卡）
- **机构关系卡**：军统/中统/76号/地下党/巡捕房的权限与关系（附录B）
- **租界地图卡**：公共租界/法租界/华界界限、管辖归属
- **电讯记录卡**：电报底稿、电台监听记录、时间戳
- **法医检验卡**：死因判定、弹道、身份锚点（附录D）
- **时代器物卡**：交通工具时刻表、票证真伪、枪械口径

> **自检问题**：如果一名完全不懂民国谍战知识的现代玩家，仅凭剧本内线索能否完成全部推理？若不能，缺的那块知识必须写进剧本。

### 5.7 民国谍战本常见误区

| 误区               | 后果                                       |
| ------------------ | ------------------------------------------ |
| **有民国无谍战**   | 只是民国服饰背景，无密码/身份/情报运用    |
| **现代思维办案**   | 像现代警方一样跨区查案、用DNA/监控         |
| **卧底完美无破绽** | 身份诡计无提前暗示、无法核验（§3.3反面）   |
| **破译天降**       | 电文内容直接给，无破译过程（§3.7反面）     |
| **密码学错用**     | 把现代密码体系/加密手段硬套民国            |
| **机构权限混乱**   | 军统/巡捕房/76号行为逻辑不真实             |
| **知识依赖玩家**   | 玩家不懂民国谍战知识即卡关，违反公平（§5.6） |
