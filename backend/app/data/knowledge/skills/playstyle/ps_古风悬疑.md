# 古风剧本风格设计思路（playstyle 技能）

> **说明**：本文档是从 RAG 背景知识 `rag/background/bg_古风悬疑.md` 的「五、古风剧本风格设计思路（风格专属）」章节拆出的**风格技能**，供创作 Agent 在创作古风本时作为风格约束加载。对应背景知识（诡计库/案例/专业速查）见 `bg_古风悬疑.md`。

### 5.1 时代设定决策三档

古风本先定"时代档位"，档位决定证据体系与逻辑要求，且**选定后必须守约**：

| 档位         | 说明                                 | 逻辑要求                                                   | 适用场景               |
| ------------ | ------------------------------------ | ---------------------------------------------------------- | ---------------------- |
| **写实历史** | 真实朝代、制度、器物、称谓           | 器物/制度/称谓符合史实；证据体系严格按该朝代（§2.7）       | 硬核推理、历史爱好者   |
| **架空世界** | 脱离史实自由构建世界观               | 世界规则须自洽且**明示**（有无铁器/有无巫术/通讯方式）；证据体系自行定义并告知玩家 | 变格、设定系、权谋、欢乐 |
| **戏说历史** | 历史框架下的艺术加工                 | 允许适度夸张，但"现实向"部分仍须自洽；注明戏说成分         | 融合向、氛围向         |

**设定一致性检验**：写实本出现"银钗验出乌头毒"或"宋代有锦衣卫"是硬伤；架空本不说明"本世界有魂术"就使用魂术也是硬伤（§2.7铁律3）。

### 5.2 古风元素如何服务诡计（而非纯氛围）

**原则：古风元素应成为推理的证据体系与诡计载体，而非装饰。** 反面例子：只有"古风服饰/器物描写"而无"古风证据运用"的剧本，是换了皮的现代本格。

| 古风元素       | 推理/诡计用途                                 |
| -------------- | ---------------------------------------------- |
| 时辰/更漏/更夫 | 时间诡计、不在场证明、目击时辰                 |
| 仵作验尸/银钗  | 死因判定、身份识别、验毒局限                   |
| 户籍/族谱/路引 | 身份诡计、冒名顶替、家族继承                   |
| 门户/院墙/仆从 | 密室、机会排查、钥匙归属                       |
| 书信/驿站/信鸽 | 不在场证明、通讯诡计、书证伪造                 |
| 毒药/暗器/机关 | 手段与延时                                     |
| 权谋/门第/等级 | 动机、阻力（谁能查/敢不敢查）、行为权限        |

### 5.3 人物身份与关系网

- **身份等级决定行为权限**：谁能进书房、谁能见到主上、谁掌钥匙、谁有自由出入权——这既是氛围，也是推理要素（机会×身份互检）。
- **称谓规范**：陛下/殿下/大人/公子/姑娘/草民/奴才——称谓混乱是时代硬伤，称谓本身也能泄露身份（称"草民"者非官身）。
- **职能分工**：仵作、捕快、师爷、郎中、管家、账房、丫鬟、车夫——每个职能带来一种证据获取渠道（仵作→验状、账房→账册、郎中→药方、更夫→巡夜记录）。
- **关系网≥3条**：血缘/主仆/师徒/同门/仇怨/婚约/财产/政治同盟——人物关系本身就是线索网（《麻衣神探》的启示）。

### 5.4 古风特色诡计选型

| 古风特色诡计       | 选型要点                                     | 逻辑约束                                   |
| ------------------ | -------------------------------------------- | ------------------------------------------ |
| **易容术**         | 提前铺垫易容工具/技艺/门派传说              | 置换后行为一致；识别锚点（§3.3）          |
| **毒杀**           | 按发作时间与验毒局限选毒                    | 银钗局限；来源渠道；急/慢性定在场性（§3.7）|
| **暗器/机关**      | 发射痕迹、匠人制作、机括寿命                | 物理可行性；工具三问（§2.3）              |
| **密室（夹壁/暗道）** | 交代夹壁/暗道的建造者与用途                | 进/出/闭三向验证（§3.1）                  |
| **权谋栽赃**       | 栽赃通道线索（如何取得凶器/信物）           | 动机可查证；书证可验（§3.8）              |
| **身份置换（双生/男装）** | 提前暗示；置换后行为一致                   | 识别锚点；两角不同时在场（§3.3）          |
| **时辰诡计**       | 系统性偏差（更漏被调/更夫买通）             | 偏差来源+计时源交叉验证（§2.2）           |

### 5.5 氛围营造（为推理服务）

| 维度         | 建议                                                         |
| ------------ | ------------------------------------------------------------ |
| **场景描写** | 注重建筑细节（飞檐、青砖、雕花、回廊、夹壁）、自然元素（竹影、月光、雨声、雪）——建筑细节可埋设夹壁/暗道线索 |
| **服饰描写** | 区分官服、常服、江湖装束，体现身份差异——服饰可埋易容/身份线索（"此人从不宽衣"） |
| **器物描写** | 茶具、文房四宝、灯具（烛台/灯笼）、乐器、兵器架——器物可埋机关/毒药线索（熏香炉、杯沿） |
| **称谓规范** | 陛下/殿下/大人/公子/姑娘/草民——等级差异是行为权限的映射 |
| **时间表达** | 时辰制（子丑寅卯）、年号纪年、五更——统一换算，服务时间诡计 |

### 5.6 公平性特殊考量：知识自包含

**核心规范**：剧本内所有推理所需的关键古风知识，必须以**设定说明/知识线索卡**形式在游戏内给出，**不得依赖玩家自带古代知识**——否则违反公平（§1.3原则2）。

**知识线索卡示例**：
- **仵作验尸手册**：介绍验状流程、常见死因特征（§八内容可化作线索卡）
- **药铺账册/药方**：毒药购买记录、药性说明
- **更夫巡夜记录**：打更时辰与所见
- **府邸布局图**：夹壁、暗道、门户落锁情况
- **驿站文书/行程记录**：人员往来与日程

> **自检问题**：如果一名完全不懂古代知识的现代玩家，仅凭剧本内线索能否完成全部推理？若不能，缺的那块知识必须写进剧本。

### 5.7 古风本常见误区

| 误区               | 后果                                       |
| ------------------ | ------------------------------------------ |
| **有古装无古法**   | 证据体系仍是现代思维，古风沦为皮囊        |
| **为诡计乱改时代** | 写实与架空混淆，设定自相矛盾              |
| **设定系无规则**   | 巫术/魂术万能，变成纯玄学（§3.4反面）      |
| **银钗万能**       | 毒药诡计失真，验毒方法被误用（§3.7）       |
| **轻功飞天**       | 物理可行性被破坏（§2.3）                   |
| **知识依赖玩家**   | 玩家不懂古风知识即卡关，违反公平（§5.6）  |
