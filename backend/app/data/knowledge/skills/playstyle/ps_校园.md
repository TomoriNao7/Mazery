# 校园剧本风格设计思路（playstyle 技能）

> **说明**：本文档是从 RAG 背景知识 `rag/background/bg_校园.md` 的「五、校园剧本风格设计思路（风格专属）」章节拆出的**风格技能**，供创作 Agent 在创作校园本时作为风格约束加载。对应背景知识（诡计库/案例/专业速查）见 `bg_校园.md`。

### 5.1 制度设定决策三档

校园本先定"制度档位"，档位决定证据体系与逻辑要求，且**选定后必须守约**：

| 档位         | 说明                                 | 逻辑要求                                                   | 适用场景               |
| ------------ | ------------------------------------ | ---------------------------------------------------------- | ---------------------- |
| **写实校园** | 真实的教育制度（公立/私立、寄宿/走读、初高中/大学） | 作息、监控、取证、学生权限符合现实；证据体系严格按该制度（§2.7） | 硬核推理、现实题材     |
| **架空校园** | 脱离现实教育制度自由构建世界观       | 世界规则须自洽且**明示**（有无手机/有无晚自习/学生自由程度）；证据体系自行定义并告知玩家 | 变格、设定系、欢乐     |
| **戏说校园** | 现实校园框架下的艺术加工             | 允许适度夸张（偶像剧化/热血化），但"现实向"部分仍须自洽；注明戏说成分 | 融合向、氛围向、情感   |

**设定一致性检验**：写实本出现"学生随意查监控"或"走读制却晚自习后全员封闭"而无交代是硬伤；架空本不说明"本世界无手机"就使用手机线索也是硬伤（§2.7铁律3）。

### 5.2 校园元素如何服务诡计（而非纯氛围）

**原则：校园元素应成为推理的证据体系与诡计载体，而非装饰。** 反面例子：只有"校服/教室/青春描写"而无"校园制度运用"的剧本，是换了皮的成人本格。

| 校园元素       | 推理/诡计用途                                 |
| -------------- | ---------------------------------------------- |
| 课表/上课铃/查寝 | 时间诡计、不在场证明、目击时间                 |
| 校医务室/体检  | 死因判定、身份识别、药物渠道                   |
| 学籍/学生证/点名 | 身份诡计、冒名顶替、查寝漏洞                   |
| 教室/宿舍/钥匙 | 密室、机会排查、钥匙归属                       |
| 班级群/手机/纸条 | 不在场证明、通讯诡计、网络霸凌                 |
| 药品/刀具/实验室 | 手段与延时                                     |
| 霸凌生态/人设/升学 | 动机、阻力（谁在霸凌、谁在维护人设、谁不敢说） |

### 5.3 人物身份与关系网

- **身份层级决定行为权限**：学生/班干部/学生会长/老师/宿管/校医/门卫——谁能自由行动、谁能看档案、谁有钥匙，这既是氛围，也是推理要素（机会×身份互检）。
- **角色职能**：同桌、室友、班长、社团社长、学霸、体育生、转学生、被霸凌者、霸凌者、旁观者——每个职能带来一种证据获取渠道（班长→点名、同桌→位置、室友→查寝、老师→档案）。
- **关系网≥3条**：同学/室友/师生/社团/家庭/情感/霸凌关系——人物关系本身就是线索网（《少年的你》的启示）。
- **人与人的"标签"**：学霸/校花/富二代/转学生/孤僻者——校园标签本身是人设，人设背后是真实与谎言的裂缝（§3.3、§3.8）。

### 5.4 校园特色诡计选型

| 校园特色诡计     | 选型要点                                     | 逻辑约束                                   |
| ------------------ | -------------------------------------------- | ------------------------------------------ |
| **制度密室**     | 查寝/钥匙/监控构成密室要件                  | 进/出/闭三向验证；钥匙归属（§3.1）        |
| **查寝/点名漏洞** | 代答到/不查寝/时间差                         | 漏洞有机制性交代（§2.2法则2）             |
| **人设伪装**     | 学霸/乖乖女人设与真实的裂缝                  | 置换后行为一致；人设矛盾即线索（§3.3）    |
| **霸凌动机**     | 被霸凌者复仇/霸凌者灭口/保护他人             | 霸凌史与求助失败铺垫（§3.7、§3.8）        |
| **双胞胎/顶替**  | 提前暗示双胞胎传闻/转学生                   | 识别锚点；两角不同时在场（§3.3）          |
| **慢性药物延时** | 安眠药/处方药累积，制造不在场证明            | 药物来源渠道；急/慢性定在场性（§3.6）     |
| **网络霸凌诡计** | 匿名网暴/人肉/威胁曝光                       | 发布记录/匿名溯源/威胁物证（§3.7）        |
| **时间诡计**     | 课表/查寝/下课铃的系统性偏差                 | 偏差来源+计时源交叉验证（§2.2）           |

### 5.5 氛围营造（为推理服务）

| 维度         | 建议                                                         |
| ------------ | ------------------------------------------------------------ |
| **场景描写** | 注重校园细节（教学楼走廊、宿舍楼、天台、操场、废弃活动室、图书馆）——建筑细节可埋设密室/藏身/监控死角线索 |
| **服饰描写** | 校服、私服、配饰的差异——服饰可埋身份/人设线索（"此人从不穿短袖"掩盖旧伤/疤痕） |
| **器物描写** | 手机、日记、纸条、奖状、成绩单、药瓶、刀具——器物可埋药物/网络/人设线索 |
| **时间表达** | 课表、上课铃、查寝时间、放学时间——统一作息表，服务时间诡计 |
| **氛围元素** | 午后的教室、深夜的宿舍、雨中的天台、静校后的走廊——青春的孤独与压抑为心理悬疑服务 |

### 5.6 公平性特殊考量：知识自包含

**核心规范**：剧本内所有推理所需的关键校园知识，必须以**设定说明/知识线索卡**形式在游戏内给出，**不得依赖玩家自带校园知识**——否则违反公平（§1.3原则2）。

**知识线索卡示例**：
- **校园作息表**：课表、上课铃、查寝时间、静校时间（§5.1）
- **校规与权限说明**：谁能自由行动、谁有钥匙、谁能看档案、监控覆盖范围（§2.7）
- **校医务室/体检档案**：体检记录、用药史、心理测评（§八内容可化作线索卡）
- **班级/社团人员表**：点名、签到、人员关系（§5.3）
- **霸凌与心理档案**：被霸凌史、求助记录、心理测评变化（§3.7）

> **自检问题**：如果一名已离开校园多年、不懂现行校园规则的现代玩家，仅凭剧本内线索能否完成全部推理？若不能，缺的那块知识必须写进剧本。

### 5.7 校园本常见误区

| 误区               | 后果                                       |
| ------------------ | ------------------------------------------ |
| **有校园无制度**   | 证据体系仍是成人思维，校园沦为皮囊        |
| **为诡计乱改制度** | 写实与架空混淆，设定自相矛盾              |
| **设定系无规则**   | 灵异/超能力万能，变成纯玄学（§3.4反面）    |
| **成人动机**       | 用钱权动机忽略青春期心理逻辑（§3.8）      |
| **成人身手**       | 未成年人完成超体力手法（§2.3）            |
| **知识依赖玩家**   | 玩家不懂校园规则即卡关，违反公平（§5.6）  |
