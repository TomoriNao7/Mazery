# 角色设计方法论

> **说明**：本文档规范了剧本杀中 NPC 角色（含玩家角色和 AI 角色）的设计标准，包括角色信息分层、动机设计、关系网构建、声音指纹规范等。Character Designer Agent 在设计角色时必须严格遵循本文档的约束，Reviewer Agent 将据此进行审查。


## 一、角色的基本概念

### 1.1 角色的定义

角色是剧本杀故事中的参与者。每个角色都是一个独立的人格实体，拥有自己的身份、性格、秘密、动机和人际关系。角色不仅是案件的“嫌疑人”，更是故事的“人物”。

### 1.2 角色的功能

| 功能         | 说明                                                   |
| ------------ | ------------------------------------------------------ |
| **承载案件** | 每个角色都可能是凶手、受害者或证人，与案件核心紧密关联 |
| **提供线索** | 角色通过对话、行为、物品等向玩家传递信息               |
| **制造冲突** | 角色之间的利益冲突、情感纠葛、秘密交换推动剧情发展     |
| **营造迷雾** | 每个角色都有自己的秘密和嫌疑，增加推理难度             |
| **情感锚点** | 在情感本中，角色是玩家情感投射的对象                   |


## 二、角色信息分层结构

每个 NPC 在设计时必须包含以下 **五层信息**：

|  层级  | 名称       | 说明                                                       |   玩家可见性   | 何时可见          |
| :----: | ---------- | ---------------------------------------------------------- | :------------: | ----------------- |
| **L1** | 公共层     | 姓名、年龄、职业、外貌、公开身份、公开性格                 |  所有玩家可见  | 剧本开始时        |
| **L2** | 关系层     | 与其他角色的血缘/利益/情感关系、在案发时间线中的公开位置   |  所有玩家可见  | 部分需探索发现    |
| **L3** | 秘密层     | 不可告人的隐私（出轨、债务、私生子、犯罪前科等）           |   需玩家挖掘   | 通过搜证/对话发现 |
| **L4** | 动机层     | 与案件直接相关的深层动机（为何可能杀人、为何可能包庇他人） |   需玩家推理   | 通过综合推断得出  |
| **L5** | 核心真相层 | 该角色与案件核心的最终关系（是否为真凶/帮凶/关键证人）     | 仅在揭晓时公开 | 真相揭晓/复盘阶段 |

### 2.1 公共层（L1）——角色基础卡

每个角色必须包含以下基础信息：

| 字段      | 必填 | 说明                     | 示例                                               |
| --------- | :--: | ------------------------ | -------------------------------------------------- |
| 姓名      |  是  | 角色的全名               | 张承志                                             |
| 性别      |  是  | 男/女                    | 男                                                 |
| 年龄      |  是  | 具体年龄或年龄段         | 45岁                                               |
| 职业/身份 |  是  | 角色的公开社会身份       | 山庄管家                                           |
| 外貌特征  |  是  | 显著的外貌特点           | 中等身材，灰白短发，右眼角有一道旧疤               |
| 公开性格  |  是  | 角色在公众面前展现的性格 | 沉默寡言，冷静，对主人极度忠诚                     |
| 公开背景  |  是  | 角色公开的履历/身世      | 在这座山庄工作了20年，据说是老主人从战场上救回来的 |

### 2.2 关系层（L2）——人际关系网络

每个角色必须与其他至少 **2 个角色** 存在明确的关系：

| 关系类型         | 说明                | 示例                           |
| ---------------- | ------------------- | ------------------------------ |
| 血缘关系         | 亲属关系            | 父子、兄弟、表亲               |
| 情感关系（爱）   | 爱情/友情/亲情      | 前恋人、挚友、青梅竹马         |
| 情感关系（恨）   | 敌意/仇恨           | 宿敌、仇人、竞争者             |
| 利益关系（重大） | 金钱/权力的深度绑定 | 债主-债务人、合伙人、继承人    |
| 利益关系（一般） | 普通的职业/经济关联 | 雇主-雇员、房东-租客           |
| 秘密关系         | 不为公众所知的关系  | 私生子关系、地下情人、隐秘同盟 |
| 相识关系         | 仅认识但不密切      | 同村、同校、曾有一面之缘       |

**角色关系网示例**：

```
张管家（45岁，山庄管家）
├──主人-老主人（死者）
├──同僚-王厨娘（厨师）
├──秘密关系-char_02（前战友）
├──同乡-char_04
```

### 2.3 秘密层（L3）——角色隐藏面

每个角色必须拥有 **至少 1 个、至多 3 个** 隐藏秘密：

| 秘密类型 | 说明                   | 示例                                       |
| -------- | ---------------------- | ------------------------------------------ |
| 私德秘密 | 不道德但不违法的隐私   | 出轨、私生子、赌债、私吞钱财               |
| 犯罪秘密 | 违法但非本案的事       | 盗窃前科、诈骗记录、过失杀人未遂           |
| 关系秘密 | 隐藏的人际关系         | 和某人是亲兄弟、曾是恋人、其实是仇人       |
| 身份秘密 | 真实身份与公开身份不符 | 其实是卧底、其实是替身、其实是改名换姓     |
| 知情秘密 | 知道某件事但未公开     | 目击了某件事但没说出来、知道某人的真实身份 |
| 恐惧秘密 | 角色内心最害怕的东西   | 怕鬼、怕被抛弃、怕暴露自己的无能           |

**秘密设计原则**：
- 秘密必须与案件有一定关联（直接或间接）
- 秘密的暴露应产生剧情影响（增加嫌疑、改变关系、提供动机）
- 真凶的核心秘密（杀人动机）不能与其表面秘密完全相同
- 秘密的发现难度应与其重要性成正比

### 2.4 动机层（L4）——行为驱动力

每个角色必须拥有 **至少 1 个** 与案件相关的动机：

| 动机分类       | 说明                         | 示例                                       |
| -------------- | ---------------------------- | ------------------------------------------ |
| 复仇           | 因过去的伤害而想要报复       | 死者在战争中害死了他的全家                 |
| 保护           | 为了保护自己或所爱之人而行动 | 死者知道他的真实身份，一旦暴露全家遭殃     |
| 贪婪           | 因利益驱使                   | 继承巨额遗产、免除巨额债务、获得公司控制权 |
| 恐惧           | 因被威胁/被控制而行动        | 死者掌握着他犯罪的证据、死者要揭发他的秘密 |
| 情杀           | 因情感纠葛                   | 死者抢走了他的未婚妻、死者背叛了多年的感情 |
| 偏执/疯狂      | 因极端心理状态               | 认为死者背叛了他们的约定、坚信死者是恶魔   |
| 正义（扭曲的） | 自认为在执行正义             | 死者罪大恶极却逃脱了法律制裁               |
| 信仰           | 因宗教或理念冲突             | 死者亵渎了其信仰的神明                     |

### 2.5 核心真相层（L5）——案件定位

每个角色在案件中的最终定位：

| 定位             | 说明                   | 剧本中占比（6人本） |
| ---------------- | ---------------------- | :-----------------: |
| 真凶             | 实施致命一击的角色     |         1人         |
| 帮凶             | 协助真凶作案或事后包庇 |        0-1人        |
| 关键证人         | 目击了重要信息但未公开 |        0-1人        |
| 无辜者（有秘密） | 有嫌疑但未参与案件     |        3-4人        |


## 三、动机设计原则

### 3.1 动机的深度层次

|     层次     | 名称 | 说明                               | 示例                                                 |
| :----------: | ---- | ---------------------------------- | ---------------------------------------------------- |
| **表层动机** |      | 角色自己意识到的、愿意承认的动机   | "我需要钱还债"                                       |
| **中层动机** |      | 角色意识到的但不愿承认的动机       | "我嫉妒他拥有的一切"                                 |
| **深层动机** |      | 角色自己可能都没有完全意识到的动机 | "我恨他是因为他是我一直渴望却得不到的父亲形象的化身" |

**要求**：真凶的动机必须至少包含 **表层 + 深层** 两个层次。

### 3.2 合格动机的标准

| 标准         | 说明                                                         |
| ------------ | ------------------------------------------------------------ |
| **个性化**   | 动机必须与角色的独特背景绑定，不能是任何角色都适用的通用动机 |
| **充分性**   | 动机必须足够支撑"杀人"这一极端行为                           |
| **逻辑性**   | 动机必须符合角色的性格设定和所处环境                         |
| **可发现性** | 动机必须通过线索（日记、信件、对话等）可以被玩家发现         |
| **共鸣性**   | 动机应能引发玩家的理解或共情（即使是反派）                   |

### 3.3 禁止的动机

| 禁止项         | 说明                             |
| -------------- | -------------------------------- |
| "一时冲动"     | 没有铺垫的情绪爆发，偷懒设计     |
| "他就是个疯子" | 精神疾病作为逃避动机解释的挡箭牌 |
| "纯粹缺钱"     | 除非有独特的、令人同情的缺钱原因 |
| "替天行道"     | 将凶手塑造成正义使者，弱化罪责感 |
| "为了好玩"     | 反社会人格作为唯一动机，缺乏深度 |

### 3.4 合格与不合格示例

####  **合格动机**

**角色**：张管家（45岁，山庄管家）

**表层动机**：我需要钱来治好女儿的病。
**中层动机**：老主人（死者）上周透露将修改遗嘱，要把我赶出山庄。
**深层动机**：老主人是我在战场上救下的仇人，当年他背叛了我的部队，我是来复仇的。20年的隐忍和忠诚都是伪装。

**为什么合格**：

- 个性化（女儿的病、战场往事）
- 充分性（20年隐忍 + 遗产被夺 + 国仇家恨）
- 逻辑性（符合其'沉默寡言'的性格）
- 可发现性（通过女儿的信件、老主人的日记、战场纪念品等线索可发掘）
- 共鸣性（读者能理解"为了女儿"和"报国仇"的动机）

####  **不合格动机**

**角色**：张管家（45岁，山庄管家）

**动机**：老主人要开除他，他一时冲动就杀人了。

**为什么不合格**：

- "一时冲动"——缺乏铺垫
- 任何人被开除都可能冲动，这是通用动机
- 没有深层层次，角色扁平
- 无法让玩家产生共鸣或理解

### 3.5 动机与案件类型的对应

| 案件类型    | 推荐动机方向                 | 说明                     |
| ----------- | ---------------------------- | ------------------------ |
| 本格硬核    | 财产继承、仇恨复仇           | 逻辑清晰，证据链明确     |
| 情感本      | 情杀、保护所爱、亲情羁绊     | 以情感冲突为核心         |
| 社会派      | 阶级压迫、体制不公、社会歧视 | 反映社会问题             |
| 变格/设定系 | 世界观规则驱动的动机         | 需要理解特定设定         |
| 欢乐本      | 荒诞且夸张的动机             | 可以不合常理，但要有笑点 |
| 恐怖本      | 恐惧驱动的动机               | 源自角色内心的深层恐惧   |


## 四、角色关系网设计

### 4.1 关系网密度要求

| 人数 | 最少关系连接数 | 说明                          |
| :--: | :------------: | ----------------------------- |
| 4人  |      4 条      | 每个角色至少连接 2 个其他角色 |
| 5人  |      6 条      | 每个角色至少连接 2 个其他角色 |
| 6人  |      9 条      | 每个角色至少连接 3 个其他角色 |
| 7人  |     12 条      | 每个角色至少连接 3 个其他角色 |

### 4.2 关系类型权重

| 关系类型         | 权重  | 说明                           |
| ---------------- | :---: | ------------------------------ |
| 血缘关系         | ★★★★★ | 最强连接，通常涉及家族秘密     |
| 情感关系（爱）   | ★★★★★ | 最强情感驱动                   |
| 情感关系（恨）   | ★★★★★ | 最强冲突驱动                   |
| 利益关系（重大） | ★★★★  | 金钱/权力的深度绑定            |
| 利益关系（一般） |  ★★★  | 普通的职业/经济关联            |
| 秘密关系         | ★★★★  | 需要被隐藏的关系，有揭露价值   |
| 相识关系         |  ★★   | 仅认识但不密切，提供基础社交网 |

### 4.3 关系网构建原则

| 原则             | 说明                                             |
| ---------------- | ------------------------------------------------ |
| **连接密度适中** | 关系不能太少（角色孤立）也不能太多（关系网混乱） |
| **关系有张力**   | 角色之间应存在潜在的冲突或秘密，而非纯粹和睦     |
| **关系有层次**   | 公开关系 + 隐藏关系并存                          |
| **关系有影响**   | 角色之间的互动应能影响玩家的判断                 |

### 4.4 关系网示例

```
6人角色关系网（冰锥山庄示例）

老主人（死者）
│
├── 张管家（45岁）—— 主仆关系 + 战场旧仇（秘密）
│
├── 王厨娘（52岁）—— 主仆关系 + 从小一起长大的同乡
│
├── char_02（30岁）—— 父女关系（私生女，秘密）
│
└── char_03（28岁）—— 雇佣关系 + 债务关系（欠老主人钱）

张管家（45岁）
├── 王厨娘（52岁）—— 同僚 + 互相知道对方的秘密
│
└── char_02（30岁）—— 她不知道自己的身世，但管家知道（保护/威胁）

王厨娘（52岁）
├── char_03（28岁）—— 同乡 + 看着长大的
│
└── char_04（35岁）—— 姐妹关系（亲姐妹，秘密）

char_02（30岁）
├── char_03（28岁）—— 前恋人 + 现在互相猜疑
│
└── char_04（35岁）—— 闺蜜 + 住同一栋楼

char_03（28岁）
└── char_04（35岁）—— 情敌（都喜欢过同一个人）

char_04（35岁）
└── （与所有人有间接连接）
```

## 五、性格与声音指纹规范

### 5.1 性格维度的五因素模型

每个角色应在以下五个维度上有明确的定位：

| 维度   | 高值表现                 | 低值表现             |
| ------ | ------------------------ | -------------------- |
| 开放性 | 好奇、创造性、喜欢新事物 | 传统、保守、抗拒变化 |
| 尽责性 | 有条理、可靠、自律       | 随性、不可靠、粗心   |
| 外向性 | 社交、热情、健谈         | 内向、安静、孤僻     |
| 宜人性 | 同情、合作、信任他人     | 冷漠、对抗、多疑     |
| 神经质 | 焦虑、敏感、情绪化       | 冷静、稳定、坚韧     |

**示例（张管家）**：
- 开放性：低（传统、恪守本分）
- 尽责性：高（极有条理、自律）
- 外向性：低（沉默寡言、孤僻）
- 宜人性：中（对主人忠诚，但对下人严厉）
- 神经质：中（表面冷静，但内心有隐忍的愤怒）

### 5.2 声音指纹的定义

声音指纹是角色独一无二的说话方式，由以下要素构成：

| 要素     | 说明                | 示例                       |
| -------- | ------------------- | -------------------------- |
| 词汇偏好 | 常用的特定词汇/短语 | "老实说……"、"依老奴之见……" |
| 句式习惯 | 句子长短、结构特点  | 多用短句、少用连接词       |
| 语气基调 | 说话的基本情绪底色  | 略带讽刺、温和恭敬         |
| 语速节奏 | 快/慢/间歇性停顿    | 语速缓慢、时有停顿         |
| 礼貌程度 | 正式/随意/粗鲁      | 极度礼貌、用敬语           |
| 口头禅   | 独有的口头表达      | "你懂我意思吧"、"……是吧"   |

### 5.3 声音指纹示例对照表

| 角色类型        | 词汇偏好                       | 句式                   | 语气                 | 语速           | 礼貌度 | 示例对话                                                     |
| --------------- | ------------------------------ | ---------------------- | -------------------- | -------------- | ------ | ------------------------------------------------------------ |
| **古风管家**    | "老奴"、"少爷"、"恕我直言"     | 文言句式，多用四字成语 | 恭顺中带着疏离       | 缓慢、字正腔圆 | 极高   | "少爷，老奴在这山庄二十载，从未见过如此蹊跷之事。"           |
| **市井混混**    | "得了吧"、"我跟你讲"、"操"     | 短句，多用口语连词     | 嚣张、自嘲交替       | 快速、激动     | 极低   | "得了吧！谁不知道我欠一屁股债？但杀人？我可没那么蠢！"       |
| **知识女性**    | "有趣"、"从逻辑上讲"、"换言之" | 长句，多用复合句       | 理性、略带优越感     | 适中、清晰     | 中等   | "从逻辑上讲，如果凶手是张管家，那厨房的钥匙链就出现了一个无法解释的缺口。" |
| **沉默阴郁型**  | "……"、"嗯"、"或许吧"           | 极少完整句，多用省略号 | 低沉的、压抑的       | 极慢、声音小   | 中等   | "……或许吧。你们不会明白的。"                                 |
| **活泼少女**    | "哇"、"真的假的"、"超～"       | 短句，大量语气词       | 天真烂漫、情绪起伏大 | 快速、跳跃     | 中低   | "哇！真的假的？张叔叔你居然会做饭？我以为你只会泡茶呢！"     |
| **老谋深算型**  | "有趣……"、"在下以为"、"诚然"   | 长短结合，善用转折     | 从容、一切尽在掌握   | 适中、字字清晰 | 高     | "有趣……诚然，此事疑点重重。但在下以为，越是显而易见的证据，越值得警惕。" |
| **军人/硬汉型** | "兄弟"、"明白"、"干"           | 短促有力，极少修饰     | 直接、不拐弯抹角     | 快速、简洁     | 中     | "明白。案发时我在后院。没人给我作证。但这就是事实。"         |

### 5.4 声音指纹在 AI 扮演中的作用

| 功能           | 说明                                                         |
| -------------- | ------------------------------------------------------------ |
| **角色一致性** | 确保 AI 扮演该角色时，每次发言都符合其语言习惯               |
| **玩家辨别**   | 玩家可以通过说话方式辨认角色，甚至发现异常（如：沉默者突然滔滔不绝） |
| **情感传递**   | 声音指纹本身传递角色的情绪状态和性格特征                     |
| **身份暗示**   | 当角色隐藏身份时，声音指纹的突然改变可能是揭示伏笔           |


## 六、角色设计常见模式与反模式

### 6.1 常见角色原型（可作参考，不建议照搬）

| 原型     | 特征                         | 适用场景    |
| -------- | ---------------------------- | ----------- |
| 忠仆     | 表面忠诚，实则隐藏重大秘密   | 本格/古风   |
| 不羁浪子 | 表面玩世不恭，实则洞察一切   | 情感/阵营   |
| 受害女性 | 看似柔弱无助，实则操控全局   | 变格/情感   |
| 智慧老者 | 提供关键信息，但自身也有秘密 | 社会派/本格 |
| 正义使者 | 固执追求正义，可能因此误判   | 社会派/硬核 |
| 双面间谍 | 身份多重，立场模糊           | 阵营/民国   |
| 痴情者   | 为爱痴狂，可能因此犯罪       | 情感/本格   |
| 复仇者   | 带着过去的创伤，寻找机会复仇 | 本格/社会派 |

### 6.2 绝对禁止的设计模式

| 编号 | 禁止项         | 说明                                                         |
| :--: | -------------- | ------------------------------------------------------------ |
|  1   | **边缘工具人** | 角色与案件完全无关，纯为凑人数。每个角色必须有至少一个与案件相关的秘密或嫌疑 |
|  2   | **纯粹好人**   | 角色没有任何秘密和嫌疑，完全清白。这会降低玩家的怀疑范围，减少推理趣味 |
|  3   | **信息吞噬者** | 角色知道所有真相但什么都不说。玩家无法从其口中获取任何信息   |
|  4   | **动机真空**   | 角色没有任何合理的杀人动机，纯为"凑嫌疑人名单"而存在         |
|  5   | **人格突变**   | 角色性格在游戏过程中前后不一致，没有合理解释                 |
|  6   | **工具人凶手** | 凶手角色只有"杀人"这一功能，没有独立的性格、背景和声音指纹   |
|  7   | **完美受害者** | 死者是纯洁无瑕的圣人，所有人都没有理由杀他（除非是变格设定） |
|  8   | **关系绝缘体** | 角色与所有其他角色都没有任何关系                             |

### 6.3 各类型角色的差异化设计

| 角色类型             | 设计重点                                     | 秘密层深度  |        声音指纹要求         | 关系网密度 |
| -------------------- | -------------------------------------------- | :---------: | :-------------------------: | :--------: |
| **真凶**             | 多层次动机 + 合理的藏匿行为 + 可被发现的破绽 | 最深（3层） | 最高（需区分公开/私下表现） |     高     |
| **帮凶**             | 协助行为 + 包庇动机 + 可被突破的心理防线     |  深（2层）  |             高              |     高     |
| **关键证人**         | 目击信息 + 隐瞒理由 + 被揭穿的可能           | 中（1-2层） |             中              |     中     |
| **无辜者（有秘密）** | 秘密本身 + 因秘密产生的可疑行为              | 中（1-2层） |             中              |     中     |
| **无辜者（清白）**   | 被误解的原因 + 澄清的路径                    | 浅（0-1层） |            基本             |     中     |

## 八、附录：角色设计工作流程

### 8.1 角色设计顺序

Step 1: 确定案件核心（死者是谁？凶手是谁？手法是什么？）→
Step 2: 设计真凶角色（动机最深、秘密最多、关系最复杂）→
Step 3: 设计核心关系角色（与真凶/死者有强关系的角色）→
Step 4: 填充剩余角色（确保每个角色都有动机和秘密）→
Step 5: 构建完整关系网（检查连接密度，填补空白）→
Step 6: 分配声音指纹（确保每个角色说话方式独特可辨）→
Step 7: 验证角色分配（确保玩家角色选择多样，玩家可扮演不同类型的角色）

### 8.2 角色设计速查表

| 角色数量 | 真凶数 | 帮凶数 | 关键证人 | 无辜者 | 最少关系连接 |
| :------: | :----: | :----: | :------: | :----: | :----------: |
|   4人    |   1    |   0    |    1     |   2    |     4条      |
|   5人    |   1    |  0-1   |   0-1    |  2-3   |     6条      |
|   6人    |   1    |  0-1   |   0-1    |  3-4   |     9条      |
|   7人    |   1    |   1    |   0-1    |  4-5   |     12条     |

### 8.3 玩家角色分配建议

| 角色类型   | 适合的玩家类型       | 说明                               |
| ---------- | -------------------- | ---------------------------------- |
| 真凶       | 擅长撒谎、心理素质强 | 需要玩家有较强的演技和心理承受能力 |
| 帮凶       | 擅长配合、灵活应变   | 需要玩家能配合真凶又不暴露自己     |
| 关键证人   | 擅长观察、记忆力强   | 需要玩家能记住并传递关键信息       |
| 侦探型角色 | 擅长逻辑推理         | 适合喜欢破案、领导讨论的玩家       |
| 情感型角色 | 擅长共情、情感表达   | 适合喜欢角色扮演、情感互动的玩家   |
| 边缘清白者 | 新手玩家             | 没有重大秘密，容易上手             |

### 8.4 角色分配平衡原则

| 原则         | 说明                               |
| ------------ | ---------------------------------- |
| 信息量均衡   | 每个角色掌握的信息量不能相差过大   |
| 嫌疑度均衡   | 每个角色都应被合理怀疑             |
| 互动机会均衡 | 每个角色都有足够的发言和互动机会   |
| 角色弧光完整 | 每个角色在整个故事中都有变化和成长 |
