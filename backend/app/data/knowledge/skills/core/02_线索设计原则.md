# 线索设计原则

> **说明**：本文档规范了剧本杀中线索的设计标准，包括线索类型、数量比例、难度分级、空间分布、推理链构建、红鲱鱼设计等。Clue Designer Agent 在设计线索时必须严格遵循本文档的约束，Reviewer Agent 将据此进行审查。


## 一、线索的基本概念

### 1.1 线索的定义

线索是玩家在游戏过程中通过搜证、对话、观察等方式获取的，有助于推进推理的信息碎片。每一条线索都是拼图的一部分——不多不少，刚好能拼出真相。

### 1.2 线索的功能

| 功能         | 说明                                               |
| ------------ | -------------------------------------------------- |
| **推进推理** | 为玩家提供推理的原材料，指向某个方向或排除某种可能 |
| **揭示背景** | 暴露角色的秘密、动机、人际关系                     |
| **制造误导** | 设置红鲱鱼，增加推理难度和趣味性                   |
| **营造氛围** | 提供时代/场景的细节描写，增强沉浸感                |


## 二、线索的类型与分类

### 2.1 按推理价值分类

|          类型          | 定义                                   |  占比   | 说明                                             |
| :--------------------: | -------------------------------------- | :-----: | ------------------------------------------------ |
|      **关键线索**      | 直接指向真凶、核心手法或关键动机的线索 | 30%-40% | 推理链中的必要节点，缺失则无法完成推理           |
| **误导线索（红鲱鱼）** | 指向无辜角色，转移玩家注意力的线索     | 40%-50% | 必须附带独立价值（揭示角色秘密），不能是纯粹噪音 |
|      **中性线索**      | 交代背景、塑造氛围、无指向性的线索     | 10%-20% | 增强沉浸感，不参与推理链                         |

### 2.2 按发现方式分类

| 类型         | 发现方式                      | 示例                                        |
| ------------ | ----------------------------- | ------------------------------------------- |
| **搜证线索** | 玩家在场景中主动搜索获得      | 书房地毯上的水渍、厨房冰柜缺失的冰块        |
| **对话线索** | 通过与NPC或其他玩家对话获得   | NPC口中说出的时间线信息、角色关系           |
| **观察线索** | 玩家通过观察NPC的言行举止获得 | NPC说谎时的微表情、紧张时的肢体语言         |
| **时间线索** | 通过时间线比对获得的逻辑推断  | 甲说8点在书房，但有人8点在花园看到他        |
| **逻辑线索** | 通过已有线索的逻辑推导得出    | 冰融化=水渍 → 凶器可能是冰 → 谁有机会接触冰 |

### 2.3 按物理形态分类

| 类型     | 说明     | 示例                               |
| -------- | -------- | ---------------------------------- |
| **物证** | 实体物品 | 凶器、血衣、指纹、脚印、信件、日记 |
| **人证** | 人的证言 | 目击证词、不在场证明、关系陈述     |
| **痕迹** | 物理残留 | 血迹形态、足迹、指纹、纤维、毛发   |
| **文书** | 书面材料 | 遗嘱、合同、日记、信件、账本、照片 |
| **环境** | 场景状态 | 门窗锁闭状态、室温、天气、现场布局 |


## 三、线索数量与比例规范

### 3.1 总量公式

| 参数     | 公式               | 示例（6人本）   |
| -------- | ------------------ | --------------- |
| 总线索数 | 角色数 × (2 ~ 3)   | 6 × 2.5 ≈ 15 条 |
| 关键线索 | 总线索数 × 30%~40% | 15 × 35% ≈ 5 条 |
| 误导线索 | 总线索数 × 40%~50% | 15 × 45% ≈ 7 条 |
| 中性线索 | 总线索数 × 10%~20% | 15 × 15% ≈ 2 条 |

### 3.2 配比对照表

| 人数 | 总线索 | 关键 | 误导 | 中性 |
| :--: | :----: | :--: | :--: | :--: |
| 4人  |  8-12  | 3-4  | 4-5  | 1-2  |
| 5人  | 10-15  | 4-5  | 5-7  | 1-2  |
| 6人  | 12-18  | 5-6  | 6-8  | 2-3  |
| 7人  | 14-21  | 6-7  | 7-10 | 2-3  |


## 四、线索难度分级

### 4.1 三级难度体系

|   难度   |  标识  | 发现条件                                        | 占关键线索比 | 说明                                   |
| :------: | :----: | ----------------------------------------------- | :----------: | -------------------------------------- |
| **简单** |  Easy  | 肉眼可见、无需工具、无需特殊条件                |    约20%     | 进入场景即可发现，用于建立初步嫌疑方向 |
| **中等** | Medium | 需要翻查、需要工具（钥匙/灯光等）、需要特定时间 |    约40%     | 需要玩家主动探索特定位置或满足条件     |
| **困难** |  Hard  | 需要破解机关/密码、需要组合道具、需要特定身份   |    约40%     | 需要玩家综合判断或解决小谜题           |

### 4.2 难度分布原则

- 第二幕（第一轮搜证）：以 **Easy + Medium** 为主
- 第四幕（第二轮搜证）：以 **Medium + Hard** 为主
- **关键推理链**中，Easy 线索只能建立“嫌疑”，Hard 线索才能形成“锁定”

### 4.3 难度与推理链的关系

推理链：Easy 线索（指向嫌疑）→ Medium 线索（缩小范围）→ Hard 线索（锁定真凶）→
谁有机会？ 谁有动机/能力？ 谁能唯一匹配所有条件？

## 五、线索空间分布原则

### 5.1 单场景分布约束

| 约束                     | 说明                                 |
| ------------------------ | ------------------------------------ |
| 每场景至少 2 条线索      | 避免玩家进入某个场景后空手而归       |
| 每场景至多 5 条线索      | 避免线索过于集中，搜完一个场景就破案 |
| 关键线索分散在 ≥3 个场景 | 防止玩家“一锤定音”，必须探索多个区域 |

### 5.2 多场景分布示例

| 场景     |  线索数  | 其中关键 |
| -------- | :------: | :------: |
| 书房     |   4条    |   1条    |
| 厨房     |   4条    |   2条    |
| 卧室区   |   3条    |   1条    |
| 花园     |   4条    |   1条    |
| **合计** | **15条** | **5条**  |

### 5.3 按幕分布约束

|   幕   | 可发现线索比例 | 说明                                  |
| :----: | :------------: | ------------------------------------- |
| 第一幕 |       0%       | 严禁发现任何案件线索                  |
| 第二幕 |    40%-50%     | 建立初步嫌疑，发现 Easy + Medium 线索 |
| 第三幕 |       0%       | 讨论幕，不开放新线索搜证              |
| 第四幕 |    50%-60%     | 发现 Medium + Hard 线索，形成锁定     |
| 第五幕 |       0%       | 投票幕，不开放新线索                  |


## 六、推理链设计

### 6.1 推理链的定义

推理链是从“初始线索”到“锁定真凶”的完整逻辑路径。玩家通过逐步发现和组合线索，沿着推理链一步步接近真相。

### 6.2 推理链的三步结构

|    步骤    | 名称     | 功能                 | 线索难度 | 示例（冰锥山庄）                               |
| :--------: | -------- | -------------------- | :------: | ---------------------------------------------- |
| **第一步** | 建立嫌疑 | 让玩家对某人产生怀疑 |   Easy   | 现场有厨房钥匙的痕迹 → 谁有厨房钥匙？          |
| **第二步** | 缩小范围 | 排除其他可能性       |  Medium  | 厨房冰柜少了一块冰 → 只有管家有厨房钥匙        |
| **第三步** | 形成锁定 | 唯一确定真凶         |   Hard   | 管家房间有融化的水痕 + 无不在场证明 → 锁定管家 |

### 6.3 推理链的硬性要求

| 要求               | 说明                                           |
| ------------------ | ---------------------------------------------- |
| **至少 3 步**      | 从线索到真凶至少需要 3 个逻辑跳跃              |
| **每步有线索支撑** | 推理链的每一步都对应至少一条可发现的线索       |
| **存在冗余路径**   | 如果某条关键线索被遗漏，必须有其他线索可以补位 |

### 6.4 冗余保护机制

为了防止玩家遗漏某条关键线索导致卡关，推理链必须设置冗余：

**主推理链**：
线索A → 线索B → 线索C → 锁定真凶

**冗余保护（备选路径）**：
线索D → 线索E → （与线索C汇合）→ 锁定真凶
或：线索F → 直接锁定（但难度最高）

**具体要求**：

- 推理链中每个关键推理节点至少有 **2 条线索** 可以支撑
- 如果玩家遗漏了任意一条关键线索，仍然有备选路径可以达成推理

### 6.5 推理链检查清单

| 序号 | 检查项                                        | 通过标准 |
| :--: | --------------------------------------------- | -------- |
|  1   | 是否存在从 Easy 线索到真凶的完整路径？        | 是       |
|  2   | 是否存在从 Medium+Hard 线索到真凶的完整路径？ | 是       |
|  3   | 是否至少有 2 条可独立到达真凶的推理路径？     | 是       |
|  4   | 每条路径是否至少包含 3 个逻辑步骤？           | 是       |
|  5   | 路径上的每一步是否有对应的可发现线索？        | 是       |


## 七、红鲱鱼（误导线索）设计

### 7.1 红鲱鱼的定义

红鲱鱼是指向无辜者、故意误导玩家判断的线索。它是增加推理难度、防止案件过于简单的重要手段。

### 7.2 合格红鲱鱼的标准

| 标准               | 说明                                                         |
| ------------------ | ------------------------------------------------------------ |
| **必须有独立价值** | 即使不指向真凶，也要揭示角色的某个秘密（如：出轨、债务、私生子等） |
| **必须逻辑合理**   | 不能是凭空出现的“垃圾信息”，要有合理解释                     |
| **必须有人认领**   | 每条红鲱鱼都要对应到某个具体角色，让该角色因此被怀疑         |

> **重要澄清：误导线索是真实线索，不是假线索。**
> 每条误导线索都揭示其指向角色的某个**真实秘密或可疑行为**（外遇、债务、私生子、前科、旧怨、反常举动），只是这些线索指向的是无辜者，让他们被**合理怀疑**。玩家必须**结合线索与其他信息推理**才能判断“此人可疑”——而不是线索本身撒谎，更不是凭空捏造证据。伪证、无中生有的血迹/脚印/纸条、指向不存在的人物的线索，一律不合格（属于“鬼魂线索”）。

### 7.3 红鲱鱼与关键线索的比例

|              比例               | 说明                                 |
| :-----------------------------: | ------------------------------------ |
|   关键线索 : 误导线索 ≈ 4 : 6   | 误导线索略多于关键线索，保证推理难度 |
| 每个角色至少被 1 条误导线索指向 | 确保每个人都被怀疑过，公平竞争       |

### 7.4 合格与不合格示例

#### 合格红鲱鱼

**线索**：在死者书房发现了一封未寄出的情书，署名是 **char_02** 的妻子。

**独立价值**：揭示了 死者与**char_02** 的妻子有私情。
**误导效果**：玩家会怀疑 **char_02** 因情杀人。
**真相**：死者确实有私情，但案发时**char_02** 在另一个城市开会（有火车票为证）。

####  不合格红鲱鱼

**线索**：在花园里发现了一根火柴。

**独立价值**：无。火柴与任何角色都无关联。
**误导效果**：无。玩家不知道这根火柴是谁的，也无法指向任何人。
**真相**：没有任何解释，就是一根火柴。

**结论**：纯粹的噪音，不合格。

## 八、线索描述规范

### 8.1 描述结构

每一条线索必须包含以下信息：

| 字段     | 必填 | 说明                               | 示例                                                         |
| -------- | :--: | ---------------------------------- | ------------------------------------------------------------ |
| 名称     |  是  | 线索的简短标题                     | 书桌上的水渍                                                 |
| 描述     |  是  | 对线索的详细描述，包括发现时的情景 | 深色地毯上有一块约手掌大小的深色水渍，边缘不规则，尚未完全干透 |
| 场景     |  是  | 在哪个场景发现的                   | 书房                                                         |
| 难度     |  是  | Easy / Medium / Hard               | Easy                                                         |
| 幕数     |  是  | 最早可在第几幕被发现               | 第二幕                                                       |
| 指向     |  是  | 指向哪个角色或方向                 | 指向管家（能出入厨房的人）                                   |
| 发现条件 |  否  | 特殊发现条件（如有）               | 需先获得厨房钥匙                                             |

### 8.2 描述语言要求

| 要求         | 说明                                         |
| ------------ | -------------------------------------------- |
| 具体可观察   | 描述玩家实际能看到/听到/摸到的东西，而非结论 |
| 避免主观判断 | 不要替玩家做判断（"这说明凶手用冰杀人"）     |
| 保留细节     | 细节越多，推理空间越大                       |

### 8.3 合格与不合格示例

####  合格描述

> "书房书桌的第三层抽屉里有一个被撬开的木盒。盒子内部有白色粉末残留物，旁边的账本显示上周有一笔 50 万元的支出，收款方是一家化工厂。"

- 具体可观察（撬开的木盒、白色粉末、账本记录）
- 细节丰富（第三层抽屉、上周、50万元、化工厂）
- 没有替玩家下结论

####  不合格描述

> "书桌里发现了一个重要线索，指向 char_02 购买了毒药。"

- "重要线索"——太模糊
- "指向 char_02"——替玩家判断了
- "购买了毒药"——没有描述具体证据


## 九、线索与搜证机制的配合

### 9.1 场景与线索绑定

- 每条线索必须绑定到唯一的具体场景
- 玩家到达该场景并选择探索时，才有机会发现该线索
- 同一场景内的多条线索，可通过不同搜索动作分别发现

### 9.2 探索轮次与线索获取

| 参数         | 第二幕（第一轮搜证） | 第四幕（第二轮搜证） |
| ------------ | :------------------: | :------------------: |
| 探索轮次     |         1 轮         |         1 轮         |
| 每轮可获线索 |        1-2 条        |        1-2 条        |
| 总可获线索   |        4-8 条        |        3-6 条        |
| 区域总数     | > 4（玩家无法搜完）  | > 3（玩家无法搜完）  |

### 9.3 NPC 并行搜索

- NPC 在搜证幕中会自行选择区域搜索
- 玩家不在的区域发生的发现，该 NPC 私下知道，玩家不知
- 玩家在场时，NPC 与玩家可能互动（搭话/阻挡/合作/藏证据）

### 9.4 线索的单一性

- 一条线索一旦被发现并被记录，就从场景中移除
- 其他角色无法再次发现同一条线索
- 但可以通过对话从发现者处获取信息


## 十、线索发现的呈现规范

### 10.1 发现时的旁白要求

- 描述必须有分量感，体现玩家努力的价值
- 包含至少 2 个感官细节
- 控制在 3-5 句话，不超过 100 字

### 10.2 合格与不合格示例

#### 合格发现旁白

> "你拉开书桌最下面的抽屉，发现有一个夹层。掀开夹层的底板，一张泛黄的信纸露了出来。信纸的边角已经卷曲，上面只有一行字——'我知道你做了什么。'落款日期是案发前三天。窗外一道闪电划过，照亮了那张纸。"

- 有分量感（夹层、泛黄的信纸）
- 2+感官细节（视觉：泛黄卷曲、闪电；触觉：摸到夹层）
- 具体可观察的内容

####  不合格发现旁白

> "你找到了一张重要的纸条，这是关键证据。"

- 没有分量感（太平淡）
- 无感官细节（只有视觉概括）
- 替玩家判断（"重要"、"关键证据"）


## 十一、常见错误与检查清单

### 11.1 常见错误

| 序号 | 错误             | 说明                                         |
| :--: | ---------------- | -------------------------------------------- |
|  1   | 关键线索过于集中 | 所有实锤证据都在同一个房间                   |
|  2   | 红鲱鱼无独立价值 | 纯粹为了误导而存在，浪费玩家时间             |
|  3   | 难度分配失衡     | Easy线索直接锁定真凶，或全部是Hard无人能发现 |
|  4   | 线索不唯一       | 同一线索有多种矛盾的解释，无法形成共识       |
|  5   | 线索未绑定场景   | 玩家不知该去哪里找某条线索                   |
|  6   | 线索描述过于抽象 | "一个重要的证据"这种表述毫无意义             |
|  7   | 推理链断裂       | 某一步没有线索支撑，玩家卡死                 |
|  8   | 秘密日记破万法   | 一本日记包含全部真相，找到即破案             |
|  9   | 一锤定音式线索   | 死亡留言直呼凶手名字、录音直接供认、指纹直接配到真凶——单条线索直接宣判 |
|  10  | 假线索           | 误导线索凭空捏造证据（无中生有的血迹/纸条），或指向不存在的人和事；误导线索必须真实且可被其他信息佐证 |

### 11.2 质量检查清单

Clue Designer Agent 在完成线索设计后，必须逐项确认：

| 序号 | 检查项     | 通过标准                         | 是否通过 |
| :--: | ---------- | -------------------------------- | :------: |
|  1   | 总量合规   | 总线索数 = 角色数 × (2~3)        |    ☐     |
|  2   | 比例合规   | 关键:误导:中性 = 3~4 : 4~5 : 1~2 |    ☐     |
|  3   | 场景分布   | 每场景 ≥2 且 ≤5 条线索           |    ☐     |
|  4   | 关键分布   | 关键线索分布在 ≥3 个场景         |    ☐     |
|  5   | 难度完整   | Easy + Medium + Hard 都存在      |    ☐     |

## 十二、附录：线索设计工作流程

### 12.1 线索设计顺序

**Step 1: 确定案件核心**
（死者是谁？真凶是谁？核心手法是什么？）→
**Step 2: 设计推理链**
（从初始线索到锁定真凶的完整路径）→
**Step 3: 分配关键线索**
（推理链每一步分配 1-2 条关键线索）→
**Step 4: 设计红鲱鱼**
（为每个无辜角色设计 1-2 条误导线索）→
**Step 5: 补充中性线索**
（填充氛围/背景信息）→
**Step 6: 分配场景与难度**
（将线索分配到各场景，标记难度等级）→
**Step 7: 按幕编排**
（决定各幕可发现的线索）→
**Step 8: 审查校验**
（逐一检查质量清单）
