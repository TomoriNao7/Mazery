# 五幕结构标准模板

> **说明**：本文档规范了剧本杀游戏的标准五幕结构。Director Agent 在进行分幕编排时必须严格遵循本文档的硬约束，Game Master Agent 在游戏进行中必须依据本文档控制每幕的节奏和边界。任何违反“硬约束”的设计将在 Reviewer 审查阶段被判定为 FAIL。


## 一、结构总览

### 1.1 五幕全景图

|    幕次    | 名称           | 核心功能                     | 可发现线索 | 时长占比 |       最大轮次        |
| :--------: | -------------- | ---------------------------- | :--------: | :------: | :-------------------: |
| **第一幕** | 开场介绍       | 破冰、角色亮相、背景铺垫     |   **0%**   |   15%    |         2N 轮         |
| **第二幕** | 第一轮搜证     | 广度探索、建立初始嫌疑       |  40%-50%   |   25%    |         1 轮          |
| **第三幕** | 集中讨论与私聊 | 信息交换、社交博弈、质询对质 |   **0%**   |   25%    | 公开 8 轮 + 私聊 2 轮 |
| **第四幕** | 第二轮搜证     | 深度发掘、获取锁定性证据     |  50%-60%   |   25%    |         1 轮          |
| **第五幕** | 最终投票与揭晓 | 推理陈述、投票指认、真相复盘 |   **0%**   |   10%    |         8 轮          |

*注：N = 角色总数（含玩家角色和AI角色，不包含GM）*

## 二、第一幕：开场介绍

### 2.1 功能定位

第一幕是游戏的“破冰”阶段，核心目标是让所有玩家熟悉自己的角色、了解故事背景、建立初步的人际关系认知。

| 功能             | 说明                                             |
| ---------------- | ------------------------------------------------ |
| **时代背景铺设** | 通过旁白描述故事发生的时代、地点、天气、社会氛围 |
| **场景氛围营造** | 描述当前场景的细节（视觉/听觉/嗅觉/触觉）        |
| **角色自我介绍** | 每位玩家和AI角色依次介绍自己的公开身份和公开性格 |
| **人际关系初显** | 通过角色间的互动对话，暗示或展示部分公开关系     |
| **事件铺垫**     | 暗示即将发生的案件，制造悬念                     |

### 2.2 硬约束（绝对禁止）

| 编号  | 约束项                   | 说明                                                         |
| :---: | ------------------------ | ------------------------------------------------------------ |
| C1-01 | **禁止发现任何案件线索** | 第一幕中绝对不允许出现任何与案件相关的物证/痕迹              |
| C1-02 | **禁止进入搜证环节**     | 不允许开放搜索区域或进行搜证动作                             |
| C1-03 | **禁止指控或投票**       | 不允许玩家指控他人或进行任何形式的投票                       |
| C1-04 | **禁止讨论核心案件**     | 不允许讨论“谁杀了人”“怎么杀的”等案件核心问题（案件尚未发生） |

### 2.3 结束条件

第一幕结束的条件为以下任一：

| 条件         | 说明                                         |
| ------------ | -------------------------------------------- |
| **正常结束** | 所有角色完成自我介绍，且场面对话自然告一段落 |
| **轮次上限** | 达到最大轮次（2N 轮）后强制推进              |

### 2.4 最大轮次与示例

| 角色数 | 最大轮次（2N） | 说明                |
| :----: | :------------: | ------------------- |
|  4人   |      8 轮      | 每人约 2 次发言机会 |
|  5人   |     10 轮      | 每人约 2 次发言机会 |
|  6人   |     12 轮      | 每人约 2 次发言机会 |
|  7人   |     14 轮      | 每人约 2 次发言机会 |

### 2.5 转场旁白模板

*"夜色渐深，暴风雪在窗外呼啸。众人各自回房休息，但谁也没有想到——今晚，将有一场无法挽回的悲剧发生。"*

*"随着最后一位客人落座，庄园的大门在身后缓缓关闭。没有人注意到，这意味着他们再也无法离开——至少，在真相水落石出之前。"*

## 三、第二幕：第一轮搜证（广度探索）

### 3.1 功能定位

第二幕是案件的正式开端——凶案已经发生，玩家开始调查。

| 功能         | 说明                                                         |
| ------------ | ------------------------------------------------------------ |
| **案发**     | 旁白描述案件发生（发现尸体、案发场景）                       |
| **初步搜证** | 玩家和NPC分头搜索不同区域，发现初始线索                      |
| **建立嫌疑** | 通过 Easy 和 Medium 难度的线索，让玩家对某些角色产生初步怀疑 |
| **形成假设** | 玩家开始形成关于“谁可能是凶手”的初步假设                     |

### 3.2 搜证机制

#### 3.2.1 探索规则

| 规则           | 说明                                                         |
| -------------- | ------------------------------------------------------------ |
| **回合制**     | 每轮每位玩家选择 1 个区域进行探索                            |
| **并行搜索**   | 玩家和 NPC 同时行动，各自选择区域                            |
| **区域锁定**   | 同一区域的线索被某玩家/NPC拿走后，其他玩家无法再获得同一条线索 |
| **互动触发**   | 玩家与 NPC 在同一区域时，可能触发互动（搭话/阻挡/合作/藏证据） |
| **信息不对称** | 玩家不在的区域发生的发现，NPC 私下知道，玩家不知             |

#### 3.2.2 区域设置

| 参数         | 说明                                    |
| ------------ | --------------------------------------- |
| 区域总数     | 必须 > 探索轮次（玩家无法搜完所有区域） |
| 每区域线索数 | 2-5 条（含关键线索和误导线索）          |
| 关键线索分布 | 关键线索必须分布在 ≥3 个不同区域        |

#### 3.2.3 区域设置示例（6人本 / 1轮探索）

| 区域     |  线索数  | 其中关键 | 关键线索指向                                 |
| -------- | :------: | :------: | -------------------------------------------- |
| 书房     |   4条    |   1条    | 指向管家（厨房钥匙痕迹）                     |
| 厨房     |   4条    |   2条    | 指向管家（冰柜少冰）、指向 char_02（毒药瓶） |
| 卧室区   |   3条    |   1条    | 指向 char_03（信件）                         |
| 花园     |   4条    |   1条    | 指向 char_04（脚印）                         |
| **合计** | **15条** | **5条**  | 关键线索分散在 4 个区域                      |

### 3.3 硬约束

| 编号  | 约束项             | 说明                                    |
| :---: | ------------------ | --------------------------------------- |
| C2-01 | **禁止投票指认**   | 不允许进行最终投票                      |
| C2-02 | **禁止私聊**       | 本幕不允许玩家与NPC私聊（讨论幕才开放） |
| C2-03 | **禁止攻击性行为** | 不允许玩家之间的肢体冲突或直接对抗      |
| C2-04 | **线索必须可发现** | 线索不能藏匿在完全不可能被发现的位置    |

### 3.4 结束条件

第二幕结束的条件为以下任一：

| 条件         | 说明                               |
| ------------ | ---------------------------------- |
| **正常结束** | 达到预设的探索轮次上限（1轮）      |
| **线索耗尽** | 所有可发现线索已被发现（极少发生） |

### 3.5 转场旁白模板

*"第一轮搜查结束。窗外暴风雪愈发猛烈，仿佛要将整座山庄吞没。你们各自回到客厅，交换着彼此发现的线索——虽然每个人都保留了一些秘密。"*

*"四轮搜查之后，你们手中的拼图碎片已经能够拼出一个模糊的轮廓。但关键的那几块，还藏在某个人的口袋里——或者说，藏在某个人的心里。"*

## 四、第三幕：集中讨论与私聊

### 4.1 功能定位

第三幕是社交博弈和信息交换的核心阶段——玩家不再搜证，而是通过对话、对质、私聊来交换信息、试探谎言、建立同盟。

| 功能            | 说明                                             |
| --------------- | ------------------------------------------------ |
| **公开讨论**    | 玩家和NPC在公开场合讨论已发现的线索和各自的推理  |
| **对质质询**    | 玩家可以对特定NPC或玩家进行公开质询              |
| **私聊交易**    | 玩家可以选择 1-2 个NPC进行私下谈话，获取隐藏信息 |
| **NPC自主互动** | NPC之间可能发生私下交流（玩家仅能看到表象）      |
| **逻辑梳理**    | 玩家整合线索，尝试构建完整的推理链条             |

### 4.2 公开讨论机制

#### 4.2.1 讨论规则

| 规则            | 说明                                          |
| --------------- | --------------------------------------------- |
| **自由发言**    | 所有角色可自由发言、提问、回应                |
| **质询机制**    | 玩家可点名质询某NPC，要求其澄清某件事         |
| **证据出示**    | 玩家可以出示已发现的线索作为质询依据          |
| **撒谎与揭穿**  | NPC和玩家均有权在规则内撒谎，但可能被线索揭穿 |
| **NPC自动发言** | 每轮AI会自动让至少 1 个NPC发言，避免冷场      |

#### 4.2.2 公开讨论轮次

| 参数       |          值           |
| ---------- | :-------------------: |
| 最大轮次   |         8 轮          |
| 每轮发言数 |     2-4 次发言/轮     |
| 总发言机会 | 所有角色至少发言 1 次 |

### 4.3 私聊机制

#### 4.3.1 私聊规则

| 规则          | 说明                                               |
| ------------- | -------------------------------------------------- |
| **私聊次数**  | 第三幕开放 1-2 次私聊机会（由游戏难度决定）        |
| **私聊对象**  | 玩家选择 1 个NPC进行一对一私下谈话                 |
| **私聊时长**  | 私聊对话为 3-5 轮问答，不超过 150 字/轮            |
| **私聊保密**  | 私聊内容仅玩家和该NPC可见，存入 InfoPropagationLog |
| **NPC诚实度** | 私聊中NPC撒谎概率降低 50%（但不降为 0）            |
| **真凶策略**  | 真凶会用次要秘密换取信任，但绝不承认杀人           |

#### 4.3.2 私聊的可视化

| 内容         | 对玩家本人 |    对其他玩家    |
| ------------ | :--------: | :--------------: |
| 私聊完整对话 |    可见    |      不可见      |
| 私聊表象描述 |    可见    | 可见（仅"表象"） |

**表象描述示例**：
> "你看到 A 把 B 拉到角落低声说话，B 听完后面色发白，匆匆走开了。"

#### 4.3.3 NPC私聊的触发条件

AI 主持人在第三幕中可能自动触发 NPC 间的私下交流：

| 触发条件 | 发起方             | 目标       | 玩家可见表象                                   |
| -------- | ------------------ | ---------- | ---------------------------------------------- |
| 试探     | 怀疑者             | 被怀疑对象 | "A 找 B 单独谈话，似乎在追问什么"              |
| 威胁     | 真凶/有秘密者      | 知情者     | "A 表情严肃地对 B 说了几句话，B 明显紧张起来"  |
| 结盟     | 目标一致的两个 NPC | 潜在盟友   | "A 和 B 避开众人，似乎在达成某种默契"          |
| 交易     | 信息持有者         | 信息需求者 | "A 和 B 交换了一个意味深长的眼神"              |
| 倾诉     | 压力大的 NPC       | 信任的对象 | "A 看起来情绪激动，B 在一旁低声安慰"           |
| 嫁祸     | 真凶               | 替罪羊     | "你注意到 A 今天对 B 格外热情，和平时判若两人" |

### 4.4 硬约束

| 编号  | 约束项             | 说明                               |
| :---: | ------------------ | ---------------------------------- |
| C3-01 | **禁止发现新线索** | 讨论幕中绝对不允许发现新的物证线索 |
| C3-02 | **禁止投票**       | 不允许进行最终投票（第五幕专属）   |
| C3-03 | **禁止攻击行为**   | 不允许肢体冲突或暴力恐吓           |
| C3-04 | **禁止代行推理**   | GM/NPC不能替玩家推理出答案         |

### 4.5 结束条件

第三幕结束的条件为以下任一：

| 条件         | 说明                                            |
| ------------ | ----------------------------------------------- |
| **正常结束** | 所有角色发言 ≥ 1 次，且私聊次数用尽             |
| **轮次上限** | 达到最大轮次（公开 8 轮 + 私聊 2 轮）后强制推进 |

### 4.6 转场旁白模板

*"讨论进入尾声。客厅里的气氛已经从最初的热烈变成了凝重的沉默。每个人都在心里盘算着什么——你知道，是时候进行最后一次搜查了。"*

*"私聊结束后，你感觉掌握了一些新的信息，但也产生了更多新的疑问。无论如何，第二轮的搜查即将开始——这一次，你们不会再有任何保留了。"*

## 五、第四幕：第二轮搜证（深度发掘）

### 5.1 功能定位

第四幕是在讨论基础上进行的深度搜证——玩家带着新的假设和疑问，对特定区域进行深入的、有针对性的搜索。

| 功能               | 说明                                         |
| ------------------ | -------------------------------------------- |
| **针对性搜查**     | 玩家根据讨论结果，选择深入调查特定区域       |
| **获取锁定性证据** | 发现 Medium 和 Hard 难度的关键线索           |
| **形成锁定推理**   | 关键证据帮助玩家从"怀疑某人"推进到"锁定某人" |
| **冗余保护**       | 如果第二幕遗漏了某些线索，本幕可以补位       |

### 5.2 搜证机制

#### 5.2.1 第二轮搜证与第一轮的区别

| 维度     | 第二幕（第一轮搜证） | 第四幕（第二轮搜证） |
| -------- | :------------------: | :------------------: |
| 探索轮次 |         1 轮         |         1 轮         |
| 线索难度 |    Easy + Medium     |    Medium + Hard     |
| 线索性质 |       建立嫌疑       |       形成锁定       |
| 探索心态 |        广撒网        |       精准打击       |
| 区域选择 |       基于直觉       |   基于讨论中的假设   |
| 线索分布 |     散布所有区域     | 集中在嫌疑人相关区域 |

#### 5.2.2 线索锁定规则

| 规则             | 说明                                                |
| ---------------- | --------------------------------------------------- |
| **Hard线索出现** | 本轮重点发现 Hard 难度的锁定性证据                  |
| **冗余补充**     | 如果第二幕中某关键线索被遗漏，本轮提供备份线索      |
| **NPC藏匿**      | 真凶/帮凶可能在本幕尝试藏匿或销毁证据（需玩家识破） |
| **最终确认**     | 在本幕结束前，所有推理链的必要条件均已向玩家开放    |

### 5.3 硬约束

| 编号  | 约束项                                 | 说明                                         |
| :---: | -------------------------------------- | -------------------------------------------- |
| C4-01 | **禁止投票指认**                       | 不允许进行最终投票（第五幕专属）             |
| C4-02 | **禁止私聊**                           | 本幕以搜证为主，不开放私聊                   |
| C4-03 | **关键线索必须在本幕结束前全部可发现** | 确保玩家在投票前拥有完整的推理材料           |
| C4-04 | **禁止引入全新诡计**                   | 本幕不能突然引入全新的、之前无任何铺垫的诡计 |

### 5.4 结束条件

第四幕结束的条件为以下任一：

| 条件                 | 说明                                         |
| -------------------- | -------------------------------------------- |
| **正常结束**         | 达到预设的探索轮次上限（1轮）                |
| **关键线索全部发现** | 所有指向真凶的必要线索均已被发现（极少发生） |

### 5.5 转场旁白模板

*"第二轮搜查结束。你们手中的证据已经足够多了——现在需要的，只是把这些碎片拼成一副完整的图画。回到客厅，你们知道，最后的时刻到了。"*

*"最后的搜查结束后，山庄的钟声敲响了。你们各自坐回原位，暴风雪在外面咆哮着——无论结果如何，今晚都必须做出一个决定。"*

## 六、第五幕：最终投票与真相揭晓

### 6.1 功能定位

第五幕是游戏的最终收束阶段——玩家进行最后的推理陈述，投票指认真凶，然后真相揭晓。

| 功能             | 说明                                   |
| ---------------- | -------------------------------------- |
| **最终推理陈述** | 每位玩家发表自己的最终推理结论         |
| **投票指认**     | 玩家投票指认自己认为是真凶的角色       |
| **真相揭晓**     | AI 主持人揭晓案件的全部真相            |
| **复盘评分**     | 系统展示推理链回溯、被忽略的细节、评分 |

### 6.2 投票流程

| 步骤                 | 说明                                          |
| -------------------- | --------------------------------------------- |
| **Step 1: 最终陈述** | 每位玩家依次陈述自己的推理结论（≤ 150 字/人） |
| **Step 2: 投票**     | 玩家选择一名角色进行投票指认                  |
| **Step 3: 投票统计** | AI 主持汇总所有投票（不公开，仅系统记录）     |
| **Step 4: 真相揭晓** | AI 主持揭晓真凶身份和完整案件真相             |
| **Step 5: 复盘**     | 展示推理链、被忽略的细节、评分、NPC结局       |

### 6.3 投票选项

| 选项          | 说明                       |
| ------------- | -------------------------- |
| 指认 [角色名] | 玩家认为该角色就是真凶     |
| 无法确定      | 玩家认为证据不足，无法指认 |

### 6.4 硬约束

| 编号  | 约束项             | 说明                              |
| :---: | ------------------ | --------------------------------- |
| C5-01 | **禁止发现新线索** | 第五幕绝对不允许发现任何新线索    |
| C5-02 | **禁止新对话**     | 不允许开启新的对话或私聊          |
| C5-03 | **禁止新场景**     | 不允许开启新的搜证场景            |
| C5-04 | **禁止暗示答案**   | GM/AI不得用任何方式暗示真凶身份   |
| C5-05 | **禁止引导投票**   | GM/AI不得引导玩家投给某个特定角色 |
| C5-06 | **禁止延期**       | 到达最大轮次后必须强制进入投票    |

### 6.5 结束条件

第五幕结束的条件为以下任一：

| 条件         | 说明                          |
| ------------ | ----------------------------- |
| **正常结束** | 所有玩家完成最终陈述和投票    |
| **轮次上限** | 达到最大轮次（8轮）后强制推进 |

## 七、全局约束与节奏控制

### 7.1 幕间转场规范

| 要求           | 说明                                               |
| -------------- | -------------------------------------------------- |
| **自然过渡**   | 转场必须自然地总结上一幕的发现，再引入下一幕的张力 |
| **不中断体验** | 转场不应让玩家感到突兀或出戏                       |
| **保持悬念**   | 转场时应保留适当的悬念，激发玩家继续的欲望         |
| **控制时长**   | 转场旁白控制在 3-5 句话，不超过 100 字             |

### 7.2 轮次计数器与强制推进

每幕内置轮次计数器，到达最大轮次时触发强制推进：

**SYSTEM OVERRIDE**: 本幕已达到互动上限。你必须立即推进到下一幕。
**不允许**：新线索、新对话、新场景。
**格式**：{"action": "advance_act", "narration": "..."}

### 7.3 防无法结束机制

| 机制         | 说明                                                    |
| ------------ | ------------------------------------------------------- |
| **轮次计数** | 每幕独立计数，精确到轮                                  |
| **软性提醒** | 到达最大轮次 80% 时，注入轻度提醒（"时间不多了……"）     |
| **硬性强制** | 到达最大轮次 100% 时，注入 SYSTEM OVERRIDE 强制推进     |
| **降级推进** | 如果 AI 连续 2 次无法生成有效转场，采用预置模板强制推进 |
