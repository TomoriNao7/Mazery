# 剧本杀核心设计法则（游戏适配版）

> **核心变更说明**：本法则承认剧本杀是“多人共享推理权”的游戏。因此，删除了“只能有一个侦探”的限制，取消了“禁止暧昧爱情”，并重新定义了“公平”的边界（玩家有权说谎，但物证必须诚实）。

---

## 第一章：硬核物证与公平逻辑（绝对不可妥协）

*此部分为全类型剧本（含变格/情感）的共通底线，违反即 FAIL。*

1.  **物证唯一性原则**：案件的物理真相（死者身份、致命死因、作案物理手法）**必须**在最终投票前，通过至少 3 条分布在 3 个不同场景的物证线索交叉锁定。
2.  **反超自然破案**：严禁使用“招魂问鬼”、“读心术”或“神仙托梦”作为获取决定性证据的手段（可以存在超自然背景，但**不能**作为破案的唯一逻辑闭环）。
3.  **非自曝原则**：严禁在无任何物证威胁的情况下，凶手因“内疚”或“程序正义”突然自曝。凶手必须是被玩家通过逻辑锤死的。
4.  **红鲱鱼合格线**：所有的误导线索（红鲱鱼）**必须**附带一个“非案件”的合理隐私（如：出轨证据、偷税记录、私生子信件），否则视为垃圾线索。

---

## 第二章：玩家隐私与社交博弈（剧本杀特有——此部分修改/删除了原著限制）

5.  **思想禁区**：AI 主持人（GM）**绝对禁止**替玩家叙述其内心真实想法（如：“你在想：我是不是该去杀了他”）。玩家的内心独白仅由玩家本人掌控。
6.  **侦探权下放**：剧本杀中**没有**唯一的侦探主角。**所有玩家平等**，均拥有完整的推理权和质疑权。AI 生成的 NPC 角色允许向不同玩家透露不同信息。
7.  **允许情感与爱情**：允许爱情、亲情、暧昧作为角色的**核心动机**。唯一的禁令是：**不能“因为爱情”而凭空抹去凶手的物理指纹或物证。**
8.  **私聊隐藏权**：玩家与 NPC 的私聊内容，对其他玩家默认不可见。AI 主持人仅向其他玩家播报“表象”（如：你看到 A 和 B 在角落低语，面色凝重），**不得**直接泄露私聊音视频内容。

---

## 第三章：凶手设定与游戏自由度

9.  **身份平权**：凶手可以是任何人——管家、仆人、警察、侦探、甚至死者自己（若是变格/设定系）。**但核心约束是**：凶手的公开戏份和互动频率，必须排在所有角色的前 50%，绝对不能是全程挂机的边缘人物。
10. **凶手唯一性**：直接实施致命一击的物理凶手必须唯一（可以有帮凶，但动手的只能有 1 个）。
11. **动机决定深度**：禁止使用“精神病发作”或“我就是想杀人”作为唯一动机。凶手必须有明确的 **“私人利害关系”**（财产、复仇、守护所爱之人、掩盖致命把柄）。

---

## 第四章：结构节奏与防宕机机制

12. **第一幕绝对安全区**：在第一幕（自我介绍及破冰环节），**绝对禁止**发现任何指向死因或凶手的实物线索。仅允许展示场景氛围和人物关系。
13. **线索锁死机制**：一旦某条线索在搜证中被玩家发现并记录到“线索板”，该线索的文本内容**永久锁定**，AI 后续回答中不允许修改该线索描述的字眼（防止 AI 幻觉导致前后矛盾）。
14. **轮次强制推进**：当某幕达到系统预设的最高互动轮次上限时，AI 主持人**必须无视玩家是否尽兴**，强制发布“时间流逝/暴风雪加剧/警方即将到来”的叙事，强行切入下一幕。
15. **NPC 说话字数限制**：在非私聊场合，AI 控制的 NPC 单次发言不得超过 **120 字**（约 3 句话）。防止 NPC 话太多替玩家把案子盘完了。

---

## 第五章：绝对禁止的低劣套路

|   序号   | 禁用烂梗                      | 理由                                                         |
| :------: | :---------------------------- | :----------------------------------------------------------- |
| **(1)**  | **全场失忆**                  | 禁止开局全员失忆，要靠读本念故事才能恢复记忆（太拖沓，且剥夺玩家主动探索感）。 |
| **(2)**  | **日记破万法**                | 禁止把死者或凶手的心理活动全部写在一本“超级日记”里，玩家找到日记直接破案。日记只能用于辅助验证，不能充当主要物证。 |
| **(3)**  | **时间线对表**                | 禁止让玩家通过“你 8:00 在哪？我 8:01 在哪？”的单纯报数来锁定凶手。时间线必须配合物理距离或障碍物才有意义。 |
| **(4)**  | **边缘工具人**                | 严禁生成一个“纯纯为了凑人数、完全与案件无关”的角色卡。每个 NPC/玩家角色必须至少有一个指向性的秘密或嫌疑。 |
| **(5)**  | **机械降神**                  | 禁止在最后投票阶段，突然出现一个“从未出场的目击证人”或“从未出现的监控录像”来石锤凶手。 |
| **(6)**  | **简单密码学**                | 禁止出现“死者血书：1379” -> 最后解释为“1=A, 3=C...”这类自作聪明的拼音首字母/九宫格解谜。 |
| **(7)**  | **双胞胎/易容术（突然袭击）** | 保留原著禁令：如果使用双胞胎或易容换脸，必须在第二幕结束前给出明显伏笔，严禁最后揭晓时才说“他有个整容了的哥哥”。 |
| **(8)**  | **精神状态免责**              | 严禁凶手以“梦游症”、“双重人格（医学确诊版）”作为脱罪理由，这会让逻辑推理形同虚设。 |
| **(9)**  | **NPC 透明化**                | 严禁 NPC 在非对话时间像木桩一样站在原地不动。NPC 必须有自主行动（如：我看到张管家刚才去了花园）。 |
| **(10)** | **全员恶人超载**              | 严禁所有角色全是凶手或全员恶人。必须有至少 1 个完全清白（仅因私德有亏而被怀疑）的角色作为“白莲花”参照系。 |
