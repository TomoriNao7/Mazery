# 剧本杀类型学（通用）

> **说明**：本文档是剧本杀的**类型地图**——按核心玩法（推理/还原/情感/机制/阵营/恐怖/欢乐）与推理流派（本格/变格/新本格）分类，说明每类剧本的**核心机制、设计要点、逻辑要求、适合玩家**，以及**"逻辑严谨性"在各类剧本中的权重差异**。类型决定了"这本本应该以什么为核心体验"，进而决定"逻辑严谨性做到什么程度才算合格"。
>
> **使用方式**：创作前先定类型（或类型组合），再按该类型的核心机制与逻辑要求选择诡计、线索密度、反转结构；**不同类型对"严谨"的定义不同**（硬核本要求逻辑链无懈可击，情感本的核心是情感闭环而非本格严谨）——用错类型的标准会写坏本子。
>
> **与其他文档的关系**：各 bg（背景）文档是按**题材**分类（古风/现代/科幻/仙侠……）；本文档按**玩法/流派**分类。题材×玩法是两个正交维度（如"古风+情感本""科幻+硬核本"）。诡计库见 [[01_诡计分类大全]]；逻辑严谨框架见各 bg §二。


## 一、类型维度总览

### 1.1 两个正交维度

| 维度     | 说明                                   | 分类举例                                   |
| -------- | -------------------------------------- | ------------------------------------------ |
| **题材** | 故事背景/世界观（覆盖在 rag/background/） | 现代、古风、民国、欧式、日式、校园、科幻、仙侠、西幻、恐怖志怪 |
| **玩法** | 核心体验/机制（本文档）                | 硬核本、还原本、情感本、机制本、阵营本、恐怖本、欢乐本 |

> **核心推论**：一个剧本 = **题材 × 玩法 × 推理流派**的三元组合。设计时先定三元，再查对应的 bg（题材）+ 本类型核心机制（本文档）+ 诡计库（[[01_诡计分类大全]]）。

### 1.2 推理流派（本格 / 变格 / 新本格）

| 流派     | 核心特征                                                     | 逻辑要求                                     | 代表风格                         |
| -------- | ------------------------------------------------------------ | -------------------------------------------- | -------------------------------- |
| **本格** | 现实世界规则内、注重"谜题"本身、线索可推导、真相唯一         | **最高**——六要素闭环、排除法、唯一性判定（见各 bg §二） | 古典推理、密室、暴风雪山庄     |
| **变格** | 允许超自然/心理/异常设定（梦境、人格分裂、时间循环、超能力），以"氛围与不可思议"为核心 | 中——超自然须**立规则守约**，设定内逻辑自洽 | 恐怖志怪、都市怪谈、心理本      |
| **新本格** | 本格的谜题骨架 + 允许更自由的设定与叙事，重"惊奇感"          | 高——诡计完整，但可叠加变格设定             | 设定系推理、叙诡结合、多重反转  |

> **逻辑严谨性的光谱**：本格 > 新本格 > 变格。但**变格不是"可以不严谨"**——变格的超自然要素必须"设定内自洽"（见各 bg §2.7 设定档位铁律），玩家接受的不是"没逻辑"，而是"在这个世界规则内成立"。


## 二、核心玩法类型（创作必知）

### 2.1 硬核推理本（硬核本 / 推凶本）

| 项目       | 内容                                                         |
| ---------- | ------------------------------------------------------------ |
| **核心体验** | 谜题本身——诡计、逻辑链、锁凶的"智力快感"                   |
| **核心机制** | 本格/新本格诡计（密室/不在场/身份/时间/叙诡）、线索链推理、排除法、唯一真相 |
| **设计要点** | 核诡过硬、线索公平（无天降）、凶手可辩、盘完逻辑通顺        |
| **逻辑要求** | **最高**——六要素闭环、时间线自洽、排除法穷尽、伪解答可反证（各 bg §二全部适用） |
| **适合玩家** | 推土机、资深玩家——追求"盘出来那一刻的爽"                  |
| **常见陷阱** | 核诡被秒破（线索太明显）/盘不出（线索太隐晦）、逻辑链断一环 |

> **设计铁律**：硬核本的一切为"谜题"服务——情感线、氛围线可少但要为逻辑线让位；**真相揭晓时玩家必须能复盘出"每一步怎么盘到的"**。

### 2.2 还原本（故事还原向）

| 项目       | 核心内容                                                     |
| ---------- | ------------------------------------------------------------ |
| **核心体验** | 还原故事真相——人物关系、身世、多年前旧案、世界真相         |
| **核心机制** | 身份/关系线索、回忆碎片、真相分层（表层故事/里层真相/最终真相）、"原来是这样"的反转 |
| **设计要点** | 人物关系图谱密、记忆/线索按层开放、真相层层剥笋            |
| **逻辑要求** | **中—高**——还原的逻辑是"关系网自洽 + 时间线完整"，真相的每一层都要有线索支撑、无矛盾 |
| **适合玩家** | 喜欢"吃瓜/看故事/情感沉浸"型玩家，也吸硬核玩家（若真相够震撼） |
| **常见陷阱** | 真相靠"玩家猜"而非"线索推"、关系线断裂、还原到一半无信息可用 |

> **设计铁律**：还原本的"谜"不是"谁是凶手"而是"真相是什么"——**每条关系线索都要在还原后回看"哦，原来那时就埋了"**。

### 2.3 情感本（沉浸本 / 哭哭本）

| 项目       | 核心内容                                                     |
| ---------- | ------------------------------------------------------------ |
| **核心体验** | 情感沉浸与共鸣——爱情/亲情/友情/家国，抉择与意难平          |
| **核心机制** | 角色代入、CP线、演绎（DM/NPC）、情感抉择、沉浸氛围           |
| **设计要点** | 角色有血有肉、情感递进、结局可悲可泣、抉择有重量            |
| **逻辑要求** | **中**——情感闭环优先；凶案可"软"（动机/情感驱动），但**重大逻辑硬伤仍伤体验**（情感本玩家也会盘） |
| **适合玩家** | 水龙头、情感玩家——追求"哭了/被触动"                       |
| **常见陷阱** | 情感空洞（为哭而哭）、角色边缘、剧情狗血逻辑崩坏            |

> **设计铁律**：情感本的"严谨"是**情感逻辑自洽**（角色的爱恨要有根、抉择要成立），凶案可以不是硬核但**不能违反基本人设**——"深爱的人突然无动机杀人"同样伤体验。

### 2.4 机制本

| 项目       | 核心内容                                                     |
| ---------- | ------------------------------------------------------------ |
| **核心体验** | 游戏机制/玩法——技能、道具、博弈、养成、对抗、大逃杀        |
| **核心机制** | 战斗/跑团/经营/谈判/收集等机制，胜负由机制决定              |
| **设计要点** | 机制平衡、策略深度、节奏把控、玩家互动性强                  |
| **逻辑要求** | **中**——凶案/剧情作为机制载体，**机制的规则自洽与平衡**比本格严谨更重要 |
| **适合玩家** | 喜欢游戏化体验、对抗博弈的玩家                              |
| **常见陷阱** | 机制不平衡（一角色碾压）、规则复杂到读不懂、剧情与机制割裂  |

> **设计铁律**：机制本的"严谨"是**规则严谨**——机制规则要可复现、可预期、平衡；凶案是机制的舞台而非逻辑迷宫。

### 2.5 阵营本

| 项目       | 核心内容                                                     |
| ---------- | ------------------------------------------------------------ |
| **核心体验** | 阵营对抗——明暗阵营、身份隐瞒、拉拢背叛、最终阵营判定      |
| **核心机制** | 身份暗置、私聊结盟、阵营任务、最终决战/判定                 |
| **设计要点** | 阵营分配平衡、身份信息差、背叛与忠诚的博弈                 |
| **逻辑要求** | **中**——阵营本的真凶/卧底线索要"足够盘但不要直接锁死"，核心是阵营归属 |
| **适合玩家** | 喜欢社交博弈、谍战/权谋元素的玩家                          |
| **常见陷阱** | 阵营过于明显（无悬念）、阵营完全隐藏（盘不出）、摇摆位失衡  |

> **设计铁律**：阵营本的"严谨"是**信息差与判定的严谨**——每个人的身份证据要能被"半确定"，最终判定要有依据。

### 2.6 恐怖本

| 项目       | 核心内容                                                     |
| ---------- | ------------------------------------------------------------ |
| **核心体验** | 恐怖氛围与惊吓——中恐/重恐/微恐，细思极恐                  |
| **核心机制** | 氛围渲染（灯光/音效/演绎）、单线任务、惊吓点、细思极恐的后劲 |
| **设计要点** | 氛围为王；"灵异感"最后要**归位**（见 bg_恐怖志怪 核心公理：恐怖是包装，真相归位到人） |
| **逻辑要求** | **中—低**（表面）但**结尾要高**——恐怖本常是变格设定，但结局的"细思极恐"要求设定自洽可回味 |
| **适合玩家** | 坦克、铁坦、喜欢刺激的玩家                                |
| **常见陷阱** | 为吓而吓无逻辑、灵异归位失败（吓完解释不清）、氛围与推理脱节 |

> **设计铁律**：恐怖本的最高境界是"**吓完之后回想更怕**"——这要求**归位设定自洽**（超自然有规则、细思能闭环），否则只剩廉价惊吓。

### 2.7 欢乐本

| 项目       | 核心内容                                                     |
| ---------- | ------------------------------------------------------------ |
| **核心体验** | 搞笑与轻松——综艺感、无压力推理、社交笑点                   |
| **核心机制** | 夸张人设、无厘头剧情、整蛊互动、轻松推理                    |
| **设计要点** | 笑点密度、人设有趣、推理轻松可过                            |
| **逻辑要求** | **低**——逻辑宽松，但**不欢迎硬伤**（欢乐本玩家也会盘两句） |
| **适合玩家** | 新手、休闲局、朋友聚会                                      |
| **常见陷阱** | 笑点尴尬、剧情空洞、无聊                                        |


## 三、变格设定库（超自然/异常设定通用知识）

> 变格本/恐怖本/科幻仙侠西幻本的"超自然要素"须**立规则、可归位**（见各 bg §2.7 设定档位）。以下是通用变格设定原型，题材版细节见对应 bg。

| 设定原型       | 规则要点                                         | 推理价值                           |
| -------------- | ------------------------------------------------ | ---------------------------------- |
| **穿越**       | 穿越有触发条件/限制/回不去                     | 身份错位、信息差（"懂未来"）       |
| **重生**       | 重生保留记忆、有代价/次数限制                  | 预知/蝴蝶效应、动机来自"前世的仇"  |
| **平行时空**   | 多时空有规则（分支/交汇/交叉）                  | 不在场证明、身份复数化             |
| **时间循环**   | 循环有起点/长度/记忆保留规律                    | "死去活来"、信息递进（每轮多知道一点） |
| **人格分裂/意识转移** | 人格切换有触发/记忆隔离                        | 身份诡计、凶手"不知道自己是凶手"   |
| **记忆篡改**   | 记忆可被修改/删除，留有"篡改痕"               | 还原类反转、身份错位               |
| **灵异/鬼魂**  | 灵异现象有规则、可被物理归位（见 bg_恐怖志怪）  | 超自然误导的归位反证               |
| **梦境/幻境**  | 梦境与现实有界限标记、醒来条件                  | "一切都是梦"的反转（慎用，易烂尾） |
| **超能力/异能** | 能力有消耗/限制/反制（见 bg_科幻、bg_仙侠、bg_西幻） | 设定系推理：能力规则+痕迹           |
| **濒死/死后意识** | 死后有意识保留时限/规则                         | 死者视角信息（特殊玩法）           |

> **使用铁律**：**变格设定必须"立规则"再"用规则"**——每条超自然设定都要回答：谁能用、代价是什么、有没有限制、有没有反制（见各 bg §2.7 三条铁律）。"穿越随便穿、记忆随便改、鬼随便显形"是变格本的硬伤。


## 四、类型组合与类型选择

### 4.1 常见类型组合

| 组合                 | 定位                               | 设计重心                       |
| -------------------- | ---------------------------------- | ------------------------------ |
| **硬核本（纯）**     | 谜题向                           | 核诡+逻辑链                    |
| **还原+情感**        | 故事向                           | 关系网+真相分层+情感线         |
| **恐怖+还原（细思极恐）** | 氛围向                           | 恐怖归位+细思反转              |
| **机制+阵营**        | 博弈向                           | 机制平衡+阵营信息差            |
| **硬核+还原（"故事型本格"）** | 谜题+故事双核                   | 诡计完整+真相分层              |
| **欢乐+还原**        | 社交向                           | 笑点+轻松还原                  |
| **恐怖+硬核**        | 氛围+谜题双核（恐怖的外壳，硬核的内核） | 恐怖氛围+本格严谨（高难度）    |

### 4.2 类型选择决策（创作第一步）

```
确定目标玩家 → 确定核心体验（谜题/故事/情感/博弈/氛围/搞笑）→ 确定玩法类型 → 结合题材（bg）→ 确定推理流派（本格/变格/新本格）→ 定"逻辑严谨性"标准（该类型对应 §二 要求）
```

> **提示**：**先定"这本到底想让玩家爽在哪"再选类型**。类型定错 = 逻辑标准用错 = 写坏本子（把情感本当硬核本写 → 玩家盘不出还哭不出来；把硬核本当情感本写 → 玩家索然无味）。


## 五、逻辑严谨性在不同类型中的权重（决策表）

| 类型     | 严谨重点                       | 可"软"部分               | 不可"软"的底线                         |
| -------- | ------------------------------ | ------------------------ | -------------------------------------- |
| **硬核本** | 逻辑链无懈可击                 | 情感线可简               | 六要素闭环、排除法、唯一性（全部硬）   |
| **还原本** | 关系网/真相分层自洽           | 凶手悬念可弱             | 真相每层有线索、无矛盾                 |
| **情感本** | 情感逻辑自洽                   | 凶案可"软"               | 角色动机与情感相符、无重大剧情硬伤     |
| **机制本** | 规则自洽与平衡                 | 剧情可薄                 | 机制可复现、平衡、规则清晰             |
| **阵营本** | 信息差与判定严谨               | 凶案可"软"               | 阵营归属可"半确定"、判定有依据         |
| **恐怖本** | 归位设定自洽（细思闭环）       | 推理可浅                 | 灵异可归位、吓完解释得清               |
| **欢乐本** | 轻松无硬伤                     | 逻辑宽松                 | 无明显硬伤（玩家也盘）                 |

> **核心推论**：**"严谨"不是所有本子的同一条标准，而是各类型的"底线清单"**——但所有类型的共同底线是：**无重大逻辑硬伤、线索公平、结局解释得通**。没有哪个类型允许"烂尾硬伤"。

## 七、常见逻辑漏洞（类型通用）

| 漏洞                 | 表现                                               | 规避方法                             |
| -------------------- | -------------------------------------------------- | ------------------------------------ |
| **类型标准用错**     | 情感本硬核写法/硬核本情感写法                     | 先定类型再定严谨标准（§4.2）         |
| **变格无规则**       | 超自然随便用、无代价无限制                         | 变格设定立规则+可归位（§三铁律）     |
| **烂尾（梦/幻境/失忆）** | 用"一切都是梦"式反转草草收场                     | 反转须有规则铺垫（梦境标记/记忆篡改痕） |
| **真凶无动机**       | 无差别/异常动机用于硬核本                         | 硬核本真凶必有可盘动机（[[05_犯罪动机原型库]]） |
| **多核失衡**         | 双核/多核类型（硬核+还原）二者都没做好            | 明确主核副核，副核服务主核           |
| **类型与玩家错配**   | 欢乐本给推土机/硬核本给新手                       | 按目标玩家选类型（§4.2）             |


## 八、速查表

### 一句话类型定位

```
硬核本=盘谜题 | 还原本=盘真相 | 情感本=哭与共鸣 | 机制本=玩机制 | 阵营本=站阵营 | 恐怖本=被吓+细思极恐 | 欢乐本=好笑不烧脑
```
