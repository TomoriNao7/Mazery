# 毒理学与毒药大全（剧本杀通用版）

> **说明**：本文档是剧本杀毒杀本的**通用毒理事实库**——常见毒物的**症状、剂量、潜伏期（发作时间）、解毒、来源渠道**，以及"以病掩毒""毒物伪装""检测边界"等创作要点。毒杀是剧本杀最高频的手段之一，其逻辑核心只有三条：**毒物症状与配方剂量对应、毒物的来源渠道可追、毒物的发作特性与凶手在场性自洽**。
>
> **使用方式**：设计毒杀案时，先定"毒物→症状→死因→验尸所见"的闭环，再反向设计"毒物从哪来、怎么下、何时发作、验不验得出"，最后核对潜伏期是否支撑凶手的在场/不在场设计。**每种毒物的剂量、症状、潜伏期是硬事实，须按表使用，不得张冠李戴**——"喝了氰化物却一小时后倒下"或"砒霜入口即死"都是硬伤。
>
> **与其他文档的关系**：本文档是**通用毒理版**；各 bg 文档的题材毒药速查（古风毒药、仙侠丹毒、西幻魔药）是**题材变体版**，须与本文档的原理兼容；验尸/毒物检测细节见 [[03_法医学与死亡判定基础]]；毒药诡计（手法层面）见 [[01_诡计分类大全]] 四-B。


## 一、毒药知识在剧本杀中的定位

### 1.1 毒杀案的三大逻辑锚点

| 锚点     | 内容                                                         | 推理价值                                     |
| -------- | ------------------------------------------------------------ | -------------------------------------------- |
| **症状对应** | 中毒的症状必须与毒物药理一致（瞳孔变化/气味/尸斑颜色/肌肉反应） | 玩家凭症状倒推毒物，从而查来源、查配制者   |
| **来源可追** | 毒物有购买/配制/偷取渠道（药铺/黑市/配方/熟人）             | "谁有机会拿到毒"是嫌疑窗口                 |
| **发作特性** | 潜伏期决定凶手在场性：急性毒凶手须在场，慢性/迟发毒可制造不在场 | 六要素"时机×机会"的关键（见各 bg §2.1）    |

### 1.2 毒杀在剧本杀中的两大经典形态

- **三刀两毒型**：多人分别下毒/动手，但只有一种毒是致死剂——"谁下的有效毒"是核心谜题（毒物叠加、被顶替、剂量归因）。
- **以病掩毒型**：毒物症状被误判为"疾病/神罚/衰竭"，真毒被掩盖——**误判的暴露必须靠线索**（药渣、配方、症状细节、验尸者被误导）。


## 二、毒物分类总览

### 2.1 按来源与性质分类

| 大类       | 代表                                           | 剧本杀特色                         |
| ---------- | ---------------------------------------------- | ---------------------------------- |
| **无机毒** | 砒霜（砷）、汞、铅、氰化物（剧毒）、亚硝酸盐 | 经典毒杀、毒物来源广               |
| **有机合成毒** | 安眠药、有机磷农药、鼠药（毒鼠强/磷化锌/氟乙酰胺）、百草枯 | 现代本常用、农业/医药背景          |
| **植物毒** | 乌头（附子）、曼陀罗（颠茄）、洋地黄（夹竹桃）、马钱子（番木鳖）、断肠草（钩吻） | 中药/草药背景（古风本高发）        |
| **动物毒** | 蛇毒、蝎毒、河豚毒素、蟾酥                    | 特色毒物、需特殊提取              |
| **生物毒素** | 肉毒毒素、蓖麻毒素、黄曲霉毒素                | 极微量即致死、投毒隐蔽              |
| **气体/吸入毒** | 一氧化碳（煤气/炭火）、硫化氢、氯气、挥发剂  | 环境型投毒、密闭空间              |
| **酒精/药物协同** | 酒精+安眠药、酒精+抗抑郁药                    | 现代本高发、剂量"被放大"            |

### 2.2 按发作速度分类（决定在场性）

| 发作速度 | 代表毒物                           | 对在场性的影响                             |
| -------- | ---------------------------------- | ------------------------------------------ |
| **速发**（数秒–数分钟） | 氰化物、肉毒毒素（神经麻痹极快）、乌头碱（数分钟–数小时） | 凶手须在场或近场；适合"当场毒杀"         |
| **中速**（数分钟–数小时） | 砒霜（口服数分钟–数小时发作）、有机磷（数分钟–数小时） | 可在"离场后短暂窗口"内发作，空间较灵活     |
| **迟发**（数小时–数天） | 安眠药过量（数小时）、铊（数天–数周）、秋水仙碱（2–12h）、百草枯（数天） | 可制造"不在场证明"，凶手可提前投毒离场    |
| **慢性**（数周–数月） | 重金属（砷/铅/汞慢性）、铊、黄曲霉毒素 | 长期下毒、以病掩毒（慢性中毒伪装慢性病） |

> **核心推论**：**"急性毒 + 凶手不在场"是常见漏洞**——急性毒凶手必须能控制投毒与发作的衔接；想用毒药做不在场证明，只能选中速/迟发/慢性毒，且要交代"毒物如何在指定时刻进入死者体内"。

### 3.5 慢性毒（长期投毒、以病掩毒）

| 毒物     | 剂量特点 | 潜伏期/发作 | 症状                                     | 检测特征                     | 伪装                   | 剧本杀用法                             |
| -------- | -------- | ----------- | ---------------------------------------- | ---------------------------- | ---------------------- | -------------------------------------- |
| **砷（慢性）** | 长期小剂量 | 数周–数月   | 脱发、色素沉着、多发性神经炎、贫血       | 毛发/指甲砷蓄积              | "慢性胃肠病""贫血"     | "久病不愈"的慢性投毒，动机可延展        |
| **铊**   | 长期/急性 | 数天–数周   | **特征性脱发**、周围神经痛、胃肠道症状   | 血/尿铊检测                  | "神经炎""脱发症"       | **脱发=铊中毒的标志性提示**，玩家可识破 |
| **汞**   | 长期    | 数周–数月   | 口腔炎、震颤、性格改变（汞毒性脑病）     | 血/尿汞检测                  | "神经衰弱""怪病"       | 慢性下毒、家族继承（水俣式）            |

> **剧本杀重点**：**慢性毒是"以病掩毒"的天然载体**——长期小剂量投毒让死者"久病不愈"，症状被当成慢性病。破绽点：① 症状细节与"已知慢性病"不符（脱发、神经痛等）；② 毒物长期来源（谁持续供毒）③ 病情的"无好转+被掩盖的给药渠道"。


## 四、投毒方式与现场痕迹

### 4.1 常见投毒路径

| 路径       | 说明                                         | 破绽/痕迹                                     |
| ---------- | -------------------------------------------- | -------------------------------------------- |
| **口服（食物/酒水/药）** | 最常用——混入饭菜、酒、汤药、点心              | 餐具残留、剩食、胃内容物（见 [[03_法医学与死亡判定基础]]）、呕吐物 |
| **注射**   | 针剂、胰岛素类、蛇毒注射                      | 注射点（针孔）、针管、冷藏胰岛素            |
| **吸入**   | 气体/挥发物/烟熏（一氧化碳、氯气）            | 密闭空间、通风被堵、气源痕迹                |
| **皮肤/黏膜** | 涂于把柄/座椅/化妆品/毒吻、毒粉吹入口鼻       | 接触部位中毒、特殊气味、残留粉末            |
| **肛门/阴道（特殊）** | 极少见，隐蔽投毒                             | 特殊，用于"验尸不细查"的诡计                |

### 4.2 投毒现场的关键物证

- **毒物容器**：药瓶/纸包/瓶盖/注射器——"容器去哪了"是凶器推理（见各 bg §2.3 工具三问）。
- **剩余毒物**：剩食/酒中残留、呕吐物——可检测/可对比配方。
- **剂量证据**：一次用量 vs 整瓶剂量——**"只少了一点点"是隐蔽投毒的痕迹**（慢性投毒少得慢，急性投毒一次少很多）。
- **配方/账本**：药铺抓药记录、炼金账册、黑市交易、实验室领用——来源渠道线索。
- **烹饪/冲泡痕迹**：谁经手了食物/酒水/药——"谁有下毒机会"的窗口。

### 4.3 检测边界（创作必须设定的能力墙）

- **时间**：毒物在体内代谢/降解，**死后过久检测可能为阴性**——"尸体发现晚，毒检阴性"不代表没中毒（但可作为破绽：为何延误发现？）。
- **挥发**：挥发性毒物（氰化物气体、一氧化碳、酒精）随时间减少——"死后很久仍检出高浓度"反而可疑。
- **检测范围**：剧本世界能检哪些毒（实验室/仵作/炼金/圣职的检测能力）须在剧本内交代——"检不出≠没有"，"检出了"才可定罪。
- **残留部位**：慢性毒蓄积在毛发/指甲/骨骼——"死后数周才送检"仍可检出慢性毒。

> **核心推论**：**毒物检测的"验得出/验不出"边界是诡计设计器**——急性毒要"当场能验"，慢性毒要"拖到验不出或误判"，挥发毒要"过时消失"，这些边界都须在剧本设定中明示。


## 五、以病掩毒与毒物伪装

### 5.1 症状酷似疾病（伪装方向表）

| 毒物         | 酷似的"病"                 | 破绽                         |
| ------------ | -------------------------- | ---------------------------- |
| 乌头碱/洋地黄 | 心脏病/猝死                 | 心律特征、伴随麻木/呕吐       |
| 安眠药过量   | 睡着/猝死                   | 昏迷而非自然睡眠、呼吸抑制   |
| 曼陀罗       | 醉酒/精神错乱               | 瞳孔散大（醉酒不散）、口干   |
| 有机磷       | 癫痫/哮喘/食物中毒           | 瞳孔缩小、流涎、蒜臭味       |
| 毒鼠强       | 癫痫/惊吓猝死               | 剧烈强直抽搐、无先兆         |
| 秋水仙碱     | 急腹症/胃肠炎/感染           | 无发热、伴多器官衰竭         |
| 慢性砷/汞/铊 | 慢性胃肠病/贫血/神经炎/脱发 | 症状细节、毛发指甲/脱发特征  |

### 5.2 伪装方向与暴露（攻防）

| 伪装方向           | 手段                                         | 暴露线索                                             |
| ------------------ | -------------------------------------------- | ---------------------------------------------------- |
| **以病掩毒**       | 选症状酷似疾病的毒、让验尸者误判             | 症状细节不符、药渣/配方残留、验尸者被误导的原因     |
| **以意外掩毒**     | 伪装煤气/误食/食物中毒/被蛇咬                 | 现场无意外触发条件、剂量/来源异常                   |
| **以自杀掩毒**     | 伪遗书+"喝了农药自杀"现场                    | 遗书笔迹、农药来源、现场无自取痕迹                 |
| **以神罚/超自然掩毒** | （恐怖志怪/仙侠/西幻）毒物症状被归因"诅咒/丹毒/神罚" | 归因无规则无痕迹，须落到"毒物归位"（见各 bg §2.7） |

### 5.3 混合投毒与剂量归因（"三刀两毒"的逻辑）

- **多人各投一种毒/各动一次手**：须明确**谁的那次是致死剂量**——时间上谁先发作、剂量上谁够致死、症状上谁对得上。
- **叠加效应**：两种毒/药物协同（酒精+安眠药、胰岛素+……）放大致死——"单看都不够，合起来致死"是高级设计，但叠加规则要可查证。
- **被顶替**：A 以为投了毒，实际被 B 换成了无效物；或 A 的毒被 B 的毒"覆盖"——**"谁投的有效毒"是核心谜题**。


## 六、逻辑约束与常见漏洞

| 漏洞                   | 表现                                             | 规避方法                                     |
| ---------------------- | ------------------------------------------------ | -------------------------------------------- |
| **毒物张冠李戴**       | 氰化物喝了却1小时才死、砒霜入口即死             | 严格按"剂量/潜伏期/症状"表（§三）            |
| **急性毒+凶手不在场**  | 速发毒却给凶手完美不在场证明                     | 速发毒凶手须在场/近场；不在场只能配中/迟发毒（§2.2） |
| **万灵毒**             | 一瓶毒能毒/能迷/能变形/能解，无配方无剂量       | 一毒一效、有剂量有症状（§三）                 |
| **万灵解药**           | 什么毒都能解                                   | 每种毒有特定反制，解药本身是线索（§三解药列） |
| **法医必能验出**       | 所有毒都能检测、永远准                         | 设检测边界：时间/挥发/检测范围/慢性残留（§4.3） |
| **检不出≠无毒被滥用**  | 靠"检不出"洗白却没交代边界                     | 边界须剧本内明示，玩家可据"边界"推理         |
| **毒物无来源**         | 谁都能拿到禁药，无需渠道线索                   | 毒物来源渠道须可追（药铺/黑市/配方/熟人）（§4.2） |
| **剂量被无视**         | 一碰即死、毒性忽强忽弱                         | 剂量与致死量对应，多次/慢性投毒有蓄积逻辑     |
| **症状被无视**         | 死因"中毒"却无中毒症状、无验尸特征             | 症状+验尸特征（瞳孔/气味/尸斑）三闭环（§三+[[03_法医学与死亡判定基础]]） |
| **解毒无时机**         | 死者"本该能救"却没人救，无解释                  | 抢救时机/在场者/延误原因须交代               |
