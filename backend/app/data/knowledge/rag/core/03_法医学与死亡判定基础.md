# 法医学与死亡判定基础（剧本杀适配版）

> **说明**：本文档系统整理了剧本杀创作中最常调用的法医学知识——**死亡时间（TOD）判定、死因分类、各类致死方式的验尸特征、死亡方式的判别（他杀/自杀/意外/自然）**，以及"尸体现象如何被破坏与伪造"这一诡计高发区。法医是推凶本的**客观地基**：六要素中的"死因""时机"高度依赖验尸结论，而"以病掩毒""篡改死亡时辰""无面尸""伪造现场"等诡计全部建立在"法医能验出什么、验不出什么"的边界上。
>
> **使用方式**：Agent 设计案件时，用本文档保证"死因—致死方式—验尸所见"三者闭环自洽；设计死亡时间诡计时，用本文档的判定原理反推"凶手如何误导验尸、又留下什么可被搜证的破绽"。法医知识是**硬事实**，不得凭感觉编造——写出的每个验状细节都要经得起"懂行的玩家"推敲。
>
> **与其他文档的关系**：各 bg（背景）文档的"验尸"一节是该题材的**简化应用版**，本文档是**通用原理版**；毒物细节见 [[04_毒理学与毒药大全]]；死亡时间诡计（手法层面）见 [[01_诡计分类大全]]。


## 一、法医知识在剧本杀中的定位

### 1.1 为什么法医是推凶本的地基

- **"死因"是六要素闭环的第一环**（见各 bg §2.1）：死者怎么死的，决定了凶手用手段、玩家找证据的方向。
- **"时机"（死亡时间）是时间线推理的锚点**：死亡时辰一旦被验尸锁定，谁在场、谁能动手就全部收窄；反过来，篡改死亡时间是最经典的时间诡计（见 [[01_诡计分类大全]] 三-E）。
- **"死亡方式"（他杀/自杀/意外/自然）是第一道排除关**：见各 bg §2.5 排除法，"自杀/意外/病亡"必须被验尸结论排除，才谈得上追凶。
- **法医知识的"边界"本身就是诡计素材**：检测不出≠没中毒、误判为病/意外≠没有他杀——"以病掩毒""以意外掩谋杀"是合法手段，但暴露必须靠线索。

### 1.2 法医证据在剧本中的三种形态

| 形态         | 说明                                                         | 玩家能做什么                         |
| ------------ | ------------------------------------------------------------ | ------------------------------------ |
| **验状**     | 医生/仵作/法医出具的书面尸检记录（死因、死亡时间、损伤特征） | 对比死因与现场，质疑结论             |
| **尸检所见** | 尸体上的具体现象（尸斑/尸僵/损伤/胃内容物/特殊气味）        | 与"死亡时辰/现场布置/饮食记录"交叉   |
| **检验行为** | 尸检是否被阻挠、验状是否被篡改、尸体是否被动过               | 怀疑"有人不想让尸检说话"             |

> **核心推论**：法医知识让玩家能**自行检验验状结论**，而不是被动接受。验状是"事实线索"（内容可信），但验状"是谁写的、何时写的、是否被篡改"是"推断线索"（可信度可被挑战）。


## 二、死亡时间判定（TOD）

> **死亡时间判定是剧本杀用得最多的法医知识**，也是死亡时间诡计的攻防核心。判定的基本原理是"死后尸体发生的系列变化（尸体现象）随时间推进而规律发展"，关键在**判定手段的精度**——有的手段只能给"小时级"的粗略窗口，有的能精确到"半小时内"，设计案件时须按精度选配。

### 2.1 常用判定手段总览

| 手段         | 估算范围     | 精度       | 受环境/个体影响 | 可靠性     | 剧本杀适用 |
| ------------ | ------------ | ---------- | --------------- | ---------- | ---------- |
| **尸冷**     | 死后数小时至数天 | 中（粗） | 大 | 早期较好 | ★★★ 常用 |
| **尸斑**     | 0–24h        | 中         | 中             | 中         | ★★★ 常用 |
| **尸僵**     | 1–72h        | 粗         | 大             | 中         | ★★★ 常用 |
| **胃内容物** | 死亡前4–6h    | 粗         | 小             | 高（若进食明确） | ★★★ 常用 |
| **角膜混浊** | 2–48h        | 粗         | 小             | 中         | ★★ 辅助 |
| **尸体腐败** | 1天–数周     | 很粗       | 大             | 中         | ★★ 辅助 |
| **昆虫定龄** | 1天–数周     | 较准       | 中             | 较高       | ★★ 户外 |
| **手表/时钟停摆、日记、胃内容物+最后一餐** | 精确         | 高         | 小             | 高         | ★★★ 最实用 |

> **提示**：剧本中**单靠尸体现象定死亡时间永远只能给一个"窗口"**（如"大约死于4–6小时前"），要精确到"某时辰"必须叠加**环境线索**（最后一餐时间、钟表停摆、无人看到的最后一次目击、雨水/月光等）——"验尸精确定到某分钟"是硬伤，除非有环境线索佐证。

### 2.2 尸冷（体表温度下降）

- **原理**：死后身体停止产热，体温按环境温度下降，下降速率近似"先快后慢"。
- **常用近似**：常温条件下**最初数小时约每小时下降0.5–1.5℃**（个体差异大），12小时后速率放缓。精确估算需公式（如 Glaister 法则、Henssge 曲线），剧本杀不必算到公式，用"窗口"即可。
- **影响因素（必须修正）**：
  - 环境温度：冷处降温快（冬季/冷库/水中），暖处慢；
  - 体型与衣物：肥胖/厚衣/被褥保温，降温慢；体瘦/裸身降温快；
  - 空气/水：水中散热远快于空气中；
  - 个体状态：死前发烧/剧烈运动使起始体温更高。
- **剧本杀用法**：尸冷给出死亡时间的**最早锚点**。**"环境温度与尸冷矛盾"是经典破绽**——如"室温20℃、尸冷却说死了12小时"，说明要么环境被动过手脚（暖气/冷气），要么尸体被冷藏/搬动过。

### 2.3 尸斑（坠积性充血）

- **原理**：死后血液靠重力沉降至身体**低位**，在低下部位形成紫红色斑块。
- **发展阶段**：
  | 阶段     | 出现时间   | 特征                           |
  | -------- | ---------- | ------------------------------ |
  | 沉降期   | 死后0.5–2h | 压之褪色，体位改变可移动       |
  | 扩散期   | 死后2–6h   | 部分固定，压之稍褪             |
  | 固定期   | 死后6–12h  | 压之不褪色，体位改变不再移动   |
- **剧毒导致颜色异常**（见 [[04_毒理学与毒药大全]]）：一氧化碳/氰化物 → **樱桃红色**；亚硝酸盐 → **暗紫/褐紫**；硝基苯/苯胺 → 蓝灰色。
- **剧本杀用法（高价值）**：
  - **体位检验**：尸斑位置应与尸体**最后保持的体位**的低位一致。**"仰卧尸体尸斑却分布在背部以外的位置"= 尸体被搬动过**——这是"死后移动尸体"的直接线索。
  - **压痕检验**：尸体压着硬物处无尸斑（受压处无血可坠），尸斑上的特殊压痕（如绳索/床单纹路）提示"尸体现位于硬物上或曾被捆"。
  - 与死亡时辰对应：固定期尸斑（>6h）配合死亡时间。

### 2.4 尸僵

- **原理**：死后肌肉逐渐僵硬，先小关节后大关节，按**头面部→颈部→上肢→躯干→下肢**的顺序发展，解除顺序相同。
- **时间规律**：
  | 阶段       | 死后时间   |
  | ---------- | ---------- |
  | 开始出现   | 1–3h（面部/颈部） |
  | 完全僵硬   | 6–12h      |
  | 持续       | 24–48h（2天左右） |
  | 缓解       | 48–72h后渐缓解（尸僵消失顺序与出现相反） |
- **影响因素**：高温加速、低温延迟；死前剧烈活动（肌肉乳酸）僵硬更快（"猝死僵硬"）；肥胖僵硬较弱。
- **剧本杀用法**：
  - 尸僵状态是死亡时间的粗略窗口。
  - **尸僵被破坏**：若尸体某部位（如手指/下颌）尸僵被强行扳开，说明"死后有人动过尸体"（如撬开握紧的手取出东西、打开口腔）——**撬开尸僵是"死后行为"的硬线索**。
  - **体位固定**：尸体保持死亡时的姿势，若尸僵固定的姿势与"死亡瞬间"不符（如已被扶坐却呈仰卧僵直），提示死后移动。

### 2.5 胃内容物与消化进度

- **原理**：消化按时间推进，通过胃/肠内食物状态反推**最后一餐进食时间**。
- **常用对应**（最后一次进餐后）：
  | 状态         | 时间参考   |
  | ------------ | ---------- |
  | 胃满、食物成形   | 0–1h 左右  |
  | 胃内容物与胃液混合 | 1–2h       |
  | 大部分排空     | 2–4h       |
  | 基本排空     | 4–6h       |
  | 十二指肠/空肠已见 | 6h+        |
- **剧本杀用法**：**"最后一餐+胃内容物=死亡时间的硬锚点"**，是本格推理最常用的时间定位法之一。例：死者19:00吃晚饭，胃内几乎排空 → 死亡发生在餐后4小时以上（23:00后）；若与"21:00目击还活着"矛盾，则死亡时间被人为改写。
- **注意**：精神紧张、药物、病态可致胃排空异常；呕吐后胃内容减少。这些细节可作为凶手动手脚的破绽。

### 2.6 角膜混浊与超生反应

- **角膜混浊**：死后2–3h开始浑浊，6–12h明显，24–48h完全混浊。粗略辅助。
- **超生反应**：死后数小时内肌纤维对电/机械刺激仍反应（瞳孔对药物反应等），只作"死亡不久"的粗略参考。
- **剧本杀用法**：作为辅助佐证，不单独定论。

### 2.7 尸体腐败与法医昆虫学

- **腐败进程**（常温下）：死后1–2天腹部出现绿色斑（尸绿，自右下腹开始）→ 静脉网显现 → 尸臭 → 24h–数天全身肿胀/水泡 → 软组织液化 → 白骨化（数月–数年，依环境）。冷/干燥/埋藏延缓，热/潮湿加速。
- **法医昆虫学**：尸体上的蝇卵→幼虫→蛹→成虫发育周期与温度相关，**可反推"苍蝇首次产卵的时间"≈尸体暴露时间**。这是户外/延迟发现尸体的重要手段。
- **尸蜡/白骨化**：用于"死亡很久"的案件，判定精确死亡时间困难，常只能给宽泛窗口。

### 2.8 环境与个体因素修正（定时间必须过一遍）

- **冷**（冬季/冷库/冰水）：所有尸体现象**延缓**——"冷藏过的尸体，尸斑/尸僵/尸冷全部被误导"，**冷藏是篡改死亡时间的首选手段**。
- **热**（夏季/火炉/暖气）：尸体现象**加速**。
- **个体**：肥胖/穿衣厚降温慢；瘦弱/裸体降温快；死前发烧、剧烈运动改变起始体温。
- **剧本杀用法**：上述任何一个修正因素都是"环境线索"。**"死亡时间被人为延长/缩短"必须交代手段（冷藏/加温/取暖/通风），手段本身要留下可搜证痕迹**（见§五）。

### 2.9 死亡时间的伪装与反伪装（诡计攻防）

| 伪装方向 | 手段示例                     | 可被发现的破绽                                         |
| -------- | ---------------------------- | ------------------------------------------------------ |
| **延长**（把死亡时间推早，制造"早已死亡"假象） | 冷藏尸体/冷库存放、置于低温环境、开空调制冷 | 房间低温异常、冷库痕迹、尸斑未固定却声称死亡很久、制冷设备运行痕迹 |
| **缩短**（把死亡时间推晚，制造"刚死亡"假象） | 加温/暖气/热源、温水浸泡、炉火边摆放 | 房间高温异常、尸体温度高于环境、加温设备的痕迹、被加温部位尸斑异常 |
| **混淆**（制造"死亡在X时"假象） | 移动尸体换体位（误导尸斑）、撬开尸僵、清洗/焚毁部分证据 | 尸斑与体位不符、尸僵被破坏、焚毁部位与"死亡瞬间"状态矛盾 |
| **干扰检查** | 伪造遗书/现场、提前让"目击者"作证、贿赂验尸者、抢尸体 | 遗书笔迹、目击者证词与其他证据矛盾、验状被篡改的痕迹 |

> **逻辑约束**：任何死亡时间的伪装，都必须**同时**满足——① 手段可被剧本内角色完成（有设备/有能力/有时间）；② 手段留下可搜证的破绽；③ 破绽与真凶的"知情范围"一致（凶手知道要藏尸于冷库，说明他熟悉该冷库）。


## 三、死因分类与死亡方式判别

### 3.1 死因分类（法医学视角）

| 大类             | 具体致死方式                             | 剧本杀常见用法                     |
| ---------------- | ---------------------------------------- | ---------------------------------- |
| **机械性损伤**   | 锐器（刺/切/砍/剪）、钝器（打击/砸压）、枪弹 | 凶器推理、创伤推理                 |
| **机械性窒息**   | 勒颈、缢死（上吊）、捂死、溺死、闷死   | 谋杀手段、伪装自杀/意外            |
| **中毒**         | 化学/生物/植物/药物毒物（见 [[04_毒理学与毒药大全]]） | 毒杀本核心、以病掩毒               |
| **烧死/烫死**    | 火焰、热液烫伤（死后焚尸 vs 生前烧死） | 焚尸灭迹、意外伪装                 |
| **电击死**       | 电流通过人体                         | 意外伪装、密室                     |
| **坠落死**       | 高处坠落                           | 自杀/意外伪装、推坠                 |
| **低温/高温死**  | 冻死、中暑/热射病                  | 环境型手法、意外                   |
| **疾病猝死**     | 心源性猝死（冠心病等）、脑血管意外   | "以病掩杀"的伪装层                 |
| **饥饿/脱水/衰竭** | 长期剥夺                       | 长期幽禁、谋财害命（慢性）         |
| **放射性/特殊**  | 辐射、气压、真空、超能力（变格）     | 变格本/科幻本专用（须立规则）      |

### 3.2 死亡方式判别（他杀/自杀/意外/自然）

> **这是剧本杀"排除法"（见各 bg §2.5）的法医依据。** 每个"排除自杀/意外"的结论都要有验尸线索支撑，不能靠人物关系拍脑袋。

| 判别维度       | 他杀倾向                                           | 自杀倾向                                     | 意外倾向                           |
| -------------- | -------------------------------------------------- | -------------------------------------------- | ---------------------------------- |
| **致命伤部位** | 身体要害（颈/胸/背/头）可多处                       | 常见于手腕、颈部、胸口（自己够得着处）     | 部位不典型，符合"事故现场"        |
| **致命伤数量** | 可多发、可有致命伤+补刀                            | 多为单一致命伤（少见"多刀自杀"）           | 单发，符合事故                      |
| **防御伤**     | **有防御伤（手臂/手掌上的挡击伤）→ 强烈指向他杀** | 无防御伤                                    | 可有碰撞擦伤，非挡击性             |
| **现场秩序**   | 有搏斗痕迹、物品翻乱、无遗书                       | 有遗书、物品有序、凶器在手上/身边           | 符合"意外过程"的现场               |
| **凶器位置**   | 凶器被藏/被处理/不在现场                           | 凶器在现场，多为常用的顺手工具              | 凶器即事故中的物件                 |
| **体位与伤口** | 伤口与现场体位矛盾（尸体被摆放过）                  | 伤口与自身体位一致、符合自杀动作              | 伤口符合坠落/撞击过程               |
| **痕迹**       | 挣扎痕迹、压痕、捆绑痕、堵口痕                     | 一般无                                            | 有环境性痕迹（滑倒/碰倒）          |

> **核心推论**：**"验尸排除自杀/意外 → 锁定他杀"是推凶的第一步**，但这条法医结论本身也可以被伪装（伪造遗书、布置现场、清除防御伤线索）。**伪造方向越完整，留下的"太完美"破绽越大**（遗书笔迹、自杀姿势不自然、凶器不符常规）。


## 四、各类致死方式验尸特征速查

> 设计案件时对照使用，保证"损伤形态—凶器—死因"闭环自洽。

### 4.1 锐器伤

| 类型     | 形态特征                                                     | 推断要点                                                     |
| -------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| **刺创** | 创口小、创道深（深度>入口宽度），入口边缘整齐，可有擦伤缘 | 凶器为刀具/匕首/锥；**刺创深度可估凶器刃长**；胸腹刺创伤及心/肺/大血管即致命 |
| **切创** | 浅而长，创缘平整，长度>深度                                 | 常见于颈部、腕部（自杀"割腕/刎颈"）；**可深达血管/气管** |
| **砍创** | 深且宽，创缘可卷曲，骨上常留砍痕                           | 凶器为斧/刀类较重的利器；力度大、损伤重                     |
| **剪创** | 双瓣创、剪痕特征明显                                       | 凶器为剪刀类；较少见致命，常伴挣扎                         |
| **死后损伤** | 出血少/无生活反应（创缘无血液浸染）、颜色无生活反应         | 区分"生前刺伤 vs 死后补刀"——生活反应是硬指标（创缘出血=生前） |

> **剧本杀重点**：**防御伤（手臂/前臂的刺切伤）是他杀的铁证信号**；"生前伤 vs 死后伤"的区分（创缘是否出血、是否形成生活反应）是"补刀焚尸/移尸后伪造"的攻防点。

### 4.2 钝器伤

| 类型       | 形态特征                                     | 推断要点                                 |
| ---------- | -------------------------------------------- | ---------------------------------------- |
| **擦伤**   | 表皮摩擦，方向性（可辨受力方向）             | 判断"从哪边来、往哪边倒"                 |
| **挫伤（瘀斑）** | 皮下出血，颜色随时间变化（红→紫→青→黄→绿） | **瘀斑颜色与形成时间对应**——"瘀斑还新鲜却说旧伤"是破绽 |
| **挫裂创** | 皮肤裂开，边缘不整，桥状组织               | 棍棒/砖石/重物打击                       |
| **骨折/颅脑损伤** | 颅骨骨折、颅内出血                       | 打击头部致死最常见；**打击方向可从骨折线推断** |
| **内脏破裂** | 肝脾破裂（钝性暴力）                       | 重击躯干                                     |

> **剧本杀重点**：**钝器凶器的"形状还原"**——创口形态（条状/方块/圆洞）可对应凶器截面（铁管/砖头/锤头），是"凶器去哪了"推理的核心；瘀斑颜色时间表可用于"旧伤 vs 新伤"的身份/动机线索。

### 4.3 勒颈 / 缢死 / 捂死 / 溺死（机械性窒息）

| 类型     | 关键验尸所见                                             | 推断要点                                                     |
| -------- | -------------------------------------------------------- | ------------------------------------------------------------ |
| **勒颈**（绳索环绕他人颈） | 颈部环行索沟、皮肤充血、眼结膜/面部点状出血（窒息征象）、颈部舌骨骨折 | 索沟环绕方向与勒痕可辨左右手/施力方向；**死者多不能自救** → 强烈指向他杀 |
| **缢死**（上吊自缢） | 缢沟位于颈前，向上斜行走至耳后（提空）；颜面苍白或淤血；颈部舌骨骨折少见 | 缢沟方向（开口向上的三角区）、体位（脚离地）可验"是否真上吊"；**他杀伪装上吊有体位/缢沟破绽** |
| **捂死/闷死** | 口鼻部擦伤/压痕、指甲抓痕、轻微窒息征象                 | 常伴挣扎；**口鼻压痕与"覆盖物"对应**（枕头/手掌）        |
| **溺死** | 口鼻周围蕈状泡沫（白沫）、肺水肿、胃/呼吸道内水中异物（水草/泥沙）、尸斑位置按上浮体位 | **生前溺死 vs 死后抛尸入水**的区分（气管内是否有水/异物）——"尸体在河里≠溺死" |

> **剧本杀重点**：**"上吊是自杀还是他杀伪装"**是最常用冲突点——**缢沟的走形、体位、舌骨骨折、手脚捆绑/口堵**是验尸能说话的证据；**"溺死 vs 抛尸"**靠气道/胃内是否有水鉴别，是"水边案件"的核心推理点。

### 4.4 烧死 / 电击死 / 坠落死

| 类型     | 关键验尸所见                                                     | 推断要点                                                     |
| -------- | ---------------------------------------------------------------- | ------------------------------------------------------------ |
| **烧死** | 皮肤烧伤分级（红斑→水疱→炭化）；**气道内烟灰炭末（生前烧死标志）**；颅骨热骨折、血液变硬 | **生前烧死 vs 死后焚尸**的关键在**气道烟灰**——死后焚尸气道干净。"斗拳姿势"（四肢屈曲）生前死后都可出现，不作区分依据 |
| **电击死** | 电流斑（接触处皮肤圆形凹陷/焦化）、皮肤金属化（金属微屑沉着） | 电流斑的接触点可对应"凶器（带电装置）"；**现场断电/无电装置**是破绽 |
| **坠落死** | 损伤集中于着地侧（多发粉碎性骨折、内脏破裂）、冲击伤范围大 | **着地点/楼层推算**（坠落高度与损伤程度）；**他杀推落 vs 自杀/意外**靠现场边缘痕迹（擦痕/脚印）与"是否自己攀爬" |

> **剧本杀重点**：**"火灾现场是烧死还是死后焚尸"**——气道烟灰是"烧死"的实锤与"焚尸"的反证；**坠落案件**的"推落 vs 自己跳"靠现场边缘的抓痕/擦痕（挣扎痕迹）与目击。


## 五、尸体现象的破坏与现场伪造（诡计高发区）

> 一切"法医被误导"的诡计都建立在**凶手对尸体/现场动了手脚**之上。动了手脚就要留痕——**这条"动过手脚的痕迹"就是玩家反攻的入口**。

| 动手脚目标     | 常见手法                                             | 留下的破绽                                     |
| -------------- | ---------------------------------------------------- | ---------------------------------------------- |
| **死亡时间**   | 冷藏/加温/空调/暖气/温水（§2.9）                    | 环境温度异常、设备运行痕迹、尸斑/尸冷矛盾     |
| **死亡方式**   | 伪造遗书、布置现场、把尸体摆成"自杀/意外"姿势      | 遗书笔迹、姿势不自然、凶器不符常规            |
| **身份**       | 毁容/焚尸/切除特征部位、换衣、移尸                 | 焚毁部位、换下的衣物、旧识认人/真名/血脉锚点（见 bg §3.4） |
| **尸斑误导**   | 死亡后移动尸体改变体位、捆绑后放置                 | 尸斑位置与体位不符、特殊压痕                  |
| **尸僵误导**   | 撬开尸僵（取物/检查）、死后扶坐                   | 撬动痕迹、僵直姿势与体位矛盾                  |
| **死因伪装**   | 清洗伤口、止血/缝合、覆盖药物痕迹、焚尸           | 清洗/缝合痕迹、药物残留、焚尸的气道烟灰判别   |
| **毒物清除**   | 洗胃/冲洗、移走毒物容器、伪造"呕吐物被清理"       | 清洗痕迹、容器去向、胃内容物残留（见 [[04_毒理学与毒药大全]]） |

> **逻辑约束**：① 每处"动手脚"都要有**执行者线索**（谁能接近尸体/现场、谁有设备/时间/动机）；② 每处"动手脚"都要留下**可被搜证的破绽**；③ 破绽与**真凶的知识范围**一致（会冷藏所以知道冷藏；熟悉火场所以伪造焚尸）——"外行人做到专业人士的事"是漏洞。


## 六、验尸在剧本杀中的线索化设计

### 6.1 验状书写规范（供 Agent 创作）

验状是"事实线索"，应写清以下栏目，让玩家可逐项检验：

| 栏目       | 内容示例                                                     |
| ---------- | ------------------------------------------------------------ |
| 基本信息   | 姓名/年龄/性别/发现地点/发现时间/检查时间                  |
| 外部检查   | 体表损伤分布与形态、尸斑/尸僵状态、特殊气味、瞳孔、口鼻耳腔 |
| 内部检查   | 胃内容物、内脏损伤、骨折、出血（可简化：是否深查）          |
| 死因判定   | 死因（如"失血性休克""机械性窒息""中毒"）                    |
| 死亡时间   | 估计窗口（如"约死于发现前4–6小时"）+ 依据（尸冷/胃内容物）   |
| 结论       | 死亡方式倾向（他杀/自杀/意外/待查）+ 可疑点                  |

> **设计要点**：验状中**故意留1–2处"可疑点"**（如"死亡时间与目击矛盾""尸斑与体位不符""胃内空无却声称刚吃完饭"），是玩家开启推理的钩子。

### 6.2 验尸与证据链的结合

- **验状 × 现场**：死因与现场布置互相印证（勒死却无挣扎现场？）。
- **验状 × 时间线**：死亡时间窗口与各角色行程收窄。
- **验状 × 毒物**：死因"中毒"须对应毒物症状与容器（见 [[04_毒理学与毒药大全]]）。
- **验状 × 身份**：损伤特征（旧疤/特征物）作为身份识别锚点（见 bg §3.4 无面尸）。
- **验状 × 死亡方式**："他杀"结论须排除自杀/意外/病亡（§3.2）。

### 6.3 法医能力的边界（创作时主动设定）

- **检测能力**：本剧本世界能验出什么（尸检深度）、验不出什么（某些毒物/微量残留），要在剧本内明确交代，避免"法医万能"或"法医瞎查"。
- **主观因素**：验尸者可能被收买、被威胁、因立场误判（"神罚""病亡"）——验尸者是**人证**而非机器。
- **尸体状态**：尸体被发现晚、腐烂/被焚/被破坏时，能验出的信息有限——**"烂到没法验"本身是线索**（谁拖延了发现？谁动了尸体？）。


## 七、逻辑约束与常见漏洞

| 漏洞                     | 表现                                                     | 规避方法                                           |
| ------------------------ | -------------------------------------------------------- | -------------------------------------------------- |
| **死亡时间"精确到分钟"** | 验尸单方面给出精确时辰，无环境线索佐证                   | 尸体现象只能给窗口，精确时辰须叠加环境线索（最后一餐/钟表/目击） |
| **法医万能**             | 所有毒物都能验出、所有痕迹都保留、验状永远正确           | 设定检测边界、验尸者是人可被质疑/收买（§6.3）     |
| **法医瞎查**             | 明显尸检能查出的线索却不查，只为拖剧情                   | 每个"验不出"都要有原因（技术/立场/尸体状态）      |
| **尸斑/尸僵与体位矛盾被忽略** | 尸体被移动/摆放却没被发现                               | 尸斑体位、僵直姿势是"动过尸体"的硬线索（§2.3/2.4） |
| **死因与损伤不符**       | 声称"中毒死"却无中毒症状、声称"勒死"却无索沟           | 死因—验尸所见—现场三闭环自洽（§二~四）           |
| **焚尸即烧死**           | 尸体被烧就说是"火灾烧死"                               | 气道烟灰判定"生前烧死 vs 死后焚尸"（§4.4）        |
| **水中尸体即溺死**       | 尸体在河里就说是溺死                                   | 气道/胃内是否有水鉴别"溺死 vs 抛尸"（§4.3）        |
| **冷藏/加温无痕迹**      | 死亡时间被篡改却无环境异常线索                           | 制冷/供热设备、环境温度异常作为破绽（§2.9）       |
| **毒物检测时间线错乱**   | 死后很久还"检出"易挥发毒物、急性毒物却"慢性症状"       | 毒物代谢/挥发/检出边界与死亡时间一致（见 [[04_毒理学与毒药大全]]） |
| **遗书太完美**           | 伪造遗书笔迹/内容/时机无破绽                             | 遗书笔迹、内容知情范围、书写环境（§3.2）          |


## 八、速查表

### 死亡时间估算速查（常温室内）

| 死后时间   | 主要可见现象                                                     |
| ---------- | ---------------------------------------------------------------- |
| 0–1h       | 尸冷开始；尸斑开始（0.5h+）；尸僵未明显                         |
| 1–2h       | 尸斑沉降期（压褪色）；角膜轻度混浊；尸僵面部开始（1–3h）        |
| 2–6h       | 尸斑扩散期（部分固定）；尸僵渐向全身发展；胃内容物视最后一餐    |
| 6–12h      | 尸斑固定（压不褪）；尸僵完全（6–12h）；角膜明显混浊             |
| 12–24h     | 尸僵持续；角膜完全混浊（24–48h）；尸斑持续固定                  |
| 24–72h     | 尸僵缓解（48–72h）；腹部尸绿开始（1–2天）                       |
| 数天–数周  | 腐败进展；昆虫定龄可估暴露时间                                   |

### 致死方式速查（验尸所见 → 死因 → 推断方向）

| 验尸所见                       | 可能的死因       | 关键推断/伪装点                     |
| ------------------------------ | ---------------- | ----------------------------------- |
| 手臂/前臂挡击伤 + 要害致命伤   | 他杀（锐器/钝器） | 防御伤=他杀铁证（§4.1/4.2）       |
| 颈部索沟 + 窒息征象            | 勒颈或缢死       | 缢沟走形区分勒/缢；他杀伪装上吊破绽（§4.3） |
| 气道烟灰/炭末 + 皮肤烧伤       | 生前烧死         | 气道干净=死后焚尸（§4.4）          |
| 樱桃红色尸斑 + 苦杏仁味        | 氰化物/一氧化碳   | 毒物判定见 [[04_毒理学与毒药大全]] |
| 瞳孔缩小 + 流涎 + 蒜臭味       | 有机磷中毒       | 农业/农药背景（[[04_毒理学与毒药大全]]） |
| 电流斑 + 金属化                | 电击死           | 现场带电装置与断电（§4.4）         |
| 瘀斑颜色"旧伤新伤"             | 旧伤 vs 近期伤   | 瘀斑颜色时间表（§4.2）             |

> **使用提示**：本文档是**事实库**，须与各 bg 的题材版验尸速查（题材特有验尸方式：仵作/炼金师/圣职/法医/异能）结合使用；毒物细节以 [[04_毒理学与毒药大全]] 为准。
