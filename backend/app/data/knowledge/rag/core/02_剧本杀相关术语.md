# 剧本杀相关术语大全

> **说明**：本文档整理了剧本杀行业中通用的术语、黑话和行话。涵盖基础概念、角色称谓、游戏机制、组局用语、玩家类型、剧本分类、推凶环节等。无论是剧本创作者、AI主持人还是新手玩家，均可通过本文档快速理解行业语言。


## 一、基础概念

| 术语            | 全称/别名                  | 含义                                                         |
| --------------- | -------------------------- | ------------------------------------------------------------ |
| **打本 / 盘本** | —                          | 玩剧本杀的简称                                               |
| **剧本杀**      | 谋杀之谜（Mystery Murder） | 一种角色扮演推理游戏，玩家通过扮演剧本中的角色，围绕凶案展开调查和推理 |
| **车**          | —                          | 指一局剧本杀的玩家队伍                                       |
| **DM**          | Dungeon Master             | 剧本杀主持人，负责整场游戏的流程推进、节奏把控、回答玩家疑问和适当给予提示 |
| **NPC**         | Non-Player Character       | 非玩家角色，指剧情中出现的不由玩家扮演的角色，用于完善和推动故事发展 |
| **OB / OB位**   | Observer                   | 旁观者，不参与游戏、只在旁边观看的人                         |
| **MC**          | Master of Ceremonies       | 主持人的另一种称呼，原指综艺节目主持人                       |
| **复盘**        | —                          | 游戏结束后，由DM还原故事的来龙去脉，解答玩家疑问             |
| **上帝视角**    | —                          | 知晓所有剧情的视角，在此视角下没有秘密                       |
| **时间线**      | —                          | 凶案发生的每个时间段，各角色分别做了什么事情                 |


## 二、角色相关术语

| 术语              | 含义                                                         |
| ----------------- | ------------------------------------------------------------ |
| **C位 / C位角色** | 信息量最大的核心角色，通常体验最好，但新手慎拿               |
| **侦探位 / 侦探** | 玩家角色之一，通常为无嫌疑角色，任务是帮助大家寻找真相和凶手 |
| **抗推位**        | 很多线索都会指向的角色，推凶的干扰项，俗称“背锅侠”           |
| **边缘角色**      | 与主线故事关联较弱、参与感不强的角色                         |
| **工具人**        | 线索库本库，时间线都在佐证其他人，自身缺乏独立剧情           |
| **摇摆位**        | 在阵营本中没有明确阵营定位，可以自由加入其他固定阵营的角色   |
| **白人**          | 侦探角色的别称                                               |
| **反串**          | 女性玩家饰演男性角色，或男性玩家饰演女性角色                 |


## 三、游戏流程与机制

| 术语            | 含义                                                         |
| --------------- | ------------------------------------------------------------ |
| **公聊**        | 所有玩家在一起公开讨论剧情                                   |
| **私聊**        | 玩家私下进行一对一或小范围的信息互通，内容不公开             |
| **搜证**        | 获取线索的过程，通常由DM发放或玩家去指定场景查找             |
| **实锤 / 石锤** | 比喻强有力的证据，可直接锁定凶手                             |
| **互证**        | 两人或以上相互证明没有犯案时间                               |
| **三刀两毒**    | 指常用的凶案套路——每个玩家角色都对死者动过手（下毒或行凶）   |
| **时间线**      | 案发时间段内各个角色的行动轨迹                               |
| **AP**          | Action Point，行动点数，用来兑换/收取线索                    |
| **BP**          | Battle Point，战斗点数，某些剧本中发生战斗时使用             |
| **HE**          | Happy Ending，好的结局                                       |
| **BE**          | Bad Ending，坏的结局                                         |
| **软逻辑**      | 没有推理出实际证据，只能根据动机和时间线来判定的逻辑         |
| **贴脸发言**    | 用游戏以外的因素在游戏中为自己做担保（如“如果我说谎就跳楼”），破坏游戏体验 |
| **自曝 / 自爆** | 直接暴露自己是凶手，或暴露了角色不想让其他人知道的事情       |
| **聊爆**        | 发言或反驳时无意间暴露了自己角色的秘密                       |
| **带节奏**      | 由逻辑强或煽动性强的玩家引导大家推动游戏进程                 |
| **挂机**        | 玩家不好好专心玩本，而是做其他事情（玩手机、发呆、睡觉等）   |
| **场外**        | 讨论与剧本无关的话题                                         |


## 四、组局用语

| 术语                | 含义                                                     |
| ------------------- | -------------------------------------------------------- |
| **组车 / 开车**     | 组织一场剧本杀游戏，凑齐玩家                             |
| **上车**            | 玩家加入某场游戏                                         |
| **拼车**            | 人数不足时，和不认识的玩家组成一桌一起玩                 |
| **锁车**            | 队伍人满，可以开本                                       |
| **跳车 / 下车**     | 约定好的玩家临时退出或不来了                             |
| **翻车**            | 组局失败；或游戏体验太差、无法继续进行；或凶手被抓住     |
| **炸车**            | 因人没组齐或其他不可抗力无法开本                         |
| **掀桌**            | 玩家玩到一半因体验不好中途不玩了                         |
| **车头**            | 带头组车的人                                             |
| **野车**            | 和完全陌生的玩家组队                                     |
| **固车 / 固定车队** | 固定的一群人一起玩                                       |
| **修仙局 / 修仙车** | 深夜（通常晚上11点以后）开始打本，通宵玩                 |
| **罗汉局**          | 全是男性玩家的局                                         |
| **仙女局**          | 全是女性玩家的局                                         |
| **皇后局**          | 一女多男的局                                             |
| **皇帝局**          | 一男多女的局                                             |
| **1=全世界**        | 有一个玩家想拼这个剧本，等待其他玩家上车                 |
| **吃DM**            | 该剧本非常依赖DM的控场和演绎能力，需要优秀DM才能有好体验 |
| **扶车**            | 玩家推理出现偏差时，DM给予适当提醒                       |


## 五、玩家类型

| 术语            | 含义                                                 |
| --------------- | ---------------------------------------------------- |
| **水龙头**      | 泪点极低、共情能力强的玩家，玩情感本必哭             |
| **菠萝头**      | 莫得感情的玩家，不被情感本的情节所动，专注推理       |
| **推土机**      | 逻辑狂魔，喜欢硬核推理，一门心思只管推凶             |
| **坦克 / 铁坦** | 胆子大、不害怕的玩家，非常适合恐怖本                 |
| **奶 / 毒奶**   | 胆子小、容易被吓到的玩家                             |
| **半奶 / 半坦** | 介于奶和坦之间的状态                                 |
| **天眼玩家**    | 提前看过剧透或玩过该本再来玩的玩家，破坏其他玩家体验 |
| **戏精 / LPZ**  | 演技炸裂、满嘴跑火车的玩家                           |
| **打野玩家**    | 喜欢拼车、和不同人组队的玩家                         |
| **高玩**        | 高水平玩家的简称                                     |
| **尖叫鸡**      | 玩恐怖本容易受惊尖叫的玩家                           |
| **情感喷泉**    | 比水龙头更容易情感爆发的玩家                         |
| **芝麻胆**      | 形容胆子非常小的玩家                                 |


## 六、剧本类型

| 术语                | 含义                                                     |
| ------------------- | -------------------------------------------------------- |
| **本格本**          | 以推理为核心，逻辑至上，杀人手法在现实中可用科学手段验证 |
| **变格本**          | 运用科学无法解释的超自然现象、恐怖或离奇元素             |
| **新本格**          | 现实逻辑为主，加入少量奇幻/科幻元素                      |
| **硬核本**          | 案件复杂、逻辑烧脑，需要较长时间推理，情感部分较少       |
| **还原本**          | 重点在于还原整个故事，有些甚至没有凶案                   |
| **情感本 / 哭哭本** | 以亲情、爱情等情感打动玩家，让玩家沉浸代入角色           |
| **欢乐本**          | 目标就是让玩家欢乐一整天，弱化凶案                       |
| **恐怖本**          | 重点在于营造恐怖氛围，常有单独搜证和NPC惊吓环节          |
| **阵营本**          | 玩家分为多个阵营进行对抗，不同阵营获胜条件不同           |
| **机制本**          | 互动性强，盘本过程中拥有技能，通过较量获得优势           |
| **机制阵营本**      | 机制+阵营的结合体，游戏分组对抗互动                      |
| **硬核还原本**      | 高难度推理+还原故事                                      |
| **撕逼本**          | 以争吵和对抗为核心的剧本                                 |
| **封闭式**          | 自由度较低，按剧本流程走                                 |
| **开放式**          | 自由度较高，玩家可影响剧情走向                           |
| **实景本**          | 将剧本中的场景在现实中还原出来                           |


## 七、推凶与案件相关

| 术语                  | 含义                                       |
| --------------------- | ------------------------------------------ |
| **凶手**              | 实施杀人行为的角色                         |
| **帮凶**              | 协助凶手作案或事后包庇的角色               |
| **死者 / 被害人**     | 被杀害的角色，通常为NPC                    |
| **密室**              | 在看似封闭的环境里发生的命案               |
| **叙述性诡计 / 叙诡** | 通过文字表述误导玩家对客观事实的判断       |
| **核诡**              | 核心诡计的简称                             |
| **作案手法**          | 凶手实施犯罪的具体方式                     |
| **作案动机**          | 凶手杀人的原因                             |
| **不在场证明**        | 证明某人在案发时不在现场的证据             |
| **搜证**              | 获取线索的过程                             |
| **线索卡**            | 印有线索信息的卡片，由DM发放或玩家搜证获得 |
| **红鲱鱼 / 误导线索** | 指向无辜者的虚假线索，用于增加推理难度     |
| **实锤**              | 有直接的证据或线索锁定凶手                 |
| **互证**              | 两人或以上相互证明没有犯案时间             |
| **三刀两毒**          | 所有角色都对死者采取过行动                 |


## 八、常见缩写与符号

| 缩写/符号 | 含义                                    |
| --------- | --------------------------------------- |
| **DM**    | Dungeon Master，主持人                  |
| **NPC**   | Non-Player Character，非玩家角色        |
| **OB**    | Observer，旁观者                        |
| **AP**    | Action Point，行动点数                  |
| **BP**    | Battle Point，战斗点数                  |
| **HE**    | Happy Ending，好结局                    |
| **BE**    | Bad Ending，坏结局                      |
| **C位**   | 核心角色                                |
| **LPZ**   | 老骗子，指演技好、善于说谎的玩家        |
| **=**     | 表示还缺几个人，如“4=2”即已有4人还差2人 |
| **Q1**    | 缺1人开本                               |
