# 犯罪动机原型库（剧本杀创作用）

> **说明**：本文档是剧本杀"动机"要素的**素材库与设计准则**——按心理学分类的动机原型、每个原型的核心诉求/人物画像/行为特征/伪装方式、以及动机与六要素（尤其"动机×身份"闭环）的结合方法。动机是六要素中最"人性"的一环：**动机必须足以支撑杀人、与真实身份的前史自洽、并能在游戏中被"动机线索"逐步揭示**。
>
> **使用方式**：设计角色时从原型库选取动机，按"表面动机/深层动机"分层设计，并保证——① 动机强度足够支撑谋杀（"为小事杀人"不合理）；② 动机与角色真实身份/前史一致（见 §2.2 动机×身份）；③ 动机线索可被搜证揭示（不能让动机只在复盘时才出现）。**动机是"人为什么杀人"的答案，设计得好，玩家盘到动机那一步就"恍然大悟"；设计得差，玩家盘完逻辑链却觉得"这人凭什么杀人"。**
>
> **与其他文档的关系**：六要素闭环与"动机×身份"互检见各 bg §2.1；角色设计方法论（工艺）见 skills/core/03_角色设计方法论；身份诡计（动机伪装的对象）见 [[01_诡计分类大全]] 一。


## 一、动机在剧本杀中的定位

### 1.1 动机是六要素闭环的一环

- **动机 × 身份**：凶手的动机必须与其**真实身份**（而非伪装外壳）的前史吻合——"变形/冒名者"若动机不对应真实身份，则是身份诡计破绽（见各 bg §3.3）。
- **动机 × 手段**：动机的"欲望强度"要与手段的"严重程度"匹配——为了小利杀人、为了一句话灭口，都需要额外解释（精神异常/被胁迫/冲动失控）。
- **动机 × 时机**：为何**此时**动手而非更早/更晚——往往由"触发事件"（死者要公布秘密、遗产将分、对方要先下手）决定。

### 1.2 动机设计的三大原则

| 原则         | 内容                                                         |
| ------------ | ------------------------------------------------------------ |
| **人人有动机** | 每个角色（含真凶）都要有合理动机与可疑之处——"没动机的人突然杀人"和"只有真凶有动机"都是漏洞（见各 bg §1.3 原则8） |
| **动机分级**   | 表面动机（玩家最先盘到的）+ 深层动机（真凶真正的执念）——表层用来"人人可疑"，深层用来"唯一锁定" |
| **动机线索化** | 动机不能只在复盘交代——必须有动机线索（书信/旧事/财务/关系证据）在游戏中可被搜证揭示 |

### 1.3 动机的心理学基础（为什么动机要"够重"）

- **杀人是一个"越过心理阈值"的行为**：从"讨厌/怨恨"到"动手杀人"之间有一道巨大的心理门槛。越过门槛通常需要——**强烈的情绪驱动**（爱/恨/恐惧）、**长期累积**（旧怨/屈辱）、**利益攸关**（生死/身家/名节）、或**心理异常**（共情缺失/偏执）。
- **"冲动杀人"也需要解释**：突发杀人往往由**即时触发**（被抓现行、被羞辱、被威胁）引发，且事后常有**恐惧/灭口动机**升级。
- **"利他性动机"可弱化恶感**：为救人/解脱他人（安乐死）、为大义（除害）——这类动机在情感本/大义本中常见，但同样要"够重"且与身份自洽。

### 1.4 动机揭露的节奏（剧本杀体验）

```
表层动机（前1/3，人人可疑）→ 中层动机（中段，排除误指向）→ 深层动机（后1/3，锁定真凶）→ 动机的"最后一块拼图"（真相时刻）
```

> **设计要点**：真凶的深层动机应是**最后才被完全揭示**的一块拼图——玩家靠动机锁定"为什么是他/她"，而动机的细节（一段旧事、一封密信、一个身份真相）在真相反转时揭晓，形成情绪与逻辑的双重爆点。


## 二、动机原型总览（七大动机源）

| 动机源   | 核心诉求                 | 典型原型                                 | 剧本杀适配度 |
| -------- | ------------------------ | ---------------------------------------- | ------------ |
| **财**   | 求财、脱困、免于贫穷     | 遗产继承、保险受益、债务缠身、勒索反杀 | ★★★ 最高    |
| **情**   | 爱、恨、占有、背叛       | 情杀、背叛、嫉妒、求而不得、占有欲     | ★★★ 最高    |
| **仇**   | 复仇、雪耻、申冤         | 隐忍复仇、受辱者、家族灭门、冤案     | ★★★ 最高    |
| **权**   | 权力、地位、控制         | 夺权者、竞争者、上位者、继承人战争     | ★★★ 高      |
| **恐**   | 灭口、自保、护秘         | 知情者灭口、秘密守护、被威胁反杀       | ★★★ 高      |
| **信仰/理念** | 信仰、大义、理想主义     | 教派狂热、复仇者（理念）、除害者     | ★★ 中       |
| **无差别/异常** | 无明确诉求、心理驱动     | 精神异常、反社会、病态模仿           | ★★ 中（慎用）|


## 三、动机原型库（创作直接调用）

> 每个原型给出：**核心诉求 / 人物画像 / 典型行为特征 / 伪装方式 / 六要素结合 / 常见破绽**。可按题材替换外壳（古代/现代/仙侠/西幻），内核不变。

### 3.1 财（求财 / 免于困顿）

#### 原型一：遗产继承者

| 项目   | 内容                                                         |
| ------ | ------------------------------------------------------------ |
| 核心诉求 | 独吞/提前拿到遗产，或防止遗产被重新分配                     |
| 人物画像 | 家族成员/养子/远亲——被遗嘱排除或份额不满者                  |
| 行为特征 | 关心遗嘱进度、打听继承安排、与死者关系"表面好实际紧张"        |
| 伪装方式 | 表现得"淡泊名利"；把矛盾伪装成"情感纠纷"                    |
| 六要素结合 | 动机×时机：死者"正要改遗嘱/公布继承人"是触发点              |
| 常见破绽 | 遗嘱文件/律师证词/家族账本——继承安排被改动或提前            |

#### 原型二：保险受益者 / 债务缠身者

| 项目   | 内容                                                         |
| ------ | ------------------------------------------------------------ |
| 核心诉求 | 理赔金救急；摆脱巨额债务（高利贷/赌债/医债）                 |
| 人物画像 | 受益人、欠债人——经济压力已到绝境                           |
| 行为特征 | 近期大量缺钱、被追债、反常的平静或慌张                       |
| 伪装方式 | 伪装"死者自然死亡/意外"，掩盖投保与债务                       |
| 六要素结合 | 动机×手段：为骗保常选"意外/自杀伪装"手法（见 [[03_法医学与死亡判定基础]] 死亡方式判别） |
| 常见破绽 | 保单金额/投保时间（死后短期投保可疑）、债务记录、理赔进度    |

#### 原型三：勒索者反杀 / 被敲诈者灭口

| 项目   | 内容                                                         |
| ------ | ------------------------------------------------------------ |
| 核心诉求 | 摆脱被勒索；或反杀勒索者                                   |
| 人物画像 | 被敲诈的人（有把柄在外）/ 敲诈者（被杀/被反杀）               |
| 行为特征 | 私下大额转账、见不得光的见面、把柄（书信/照片/记录）        |
| 伪装方式 | 把被杀者的死亡伪装成"自杀/意外"，销毁把柄                    |
| 六要素结合 | 动机×身份：把柄内容与真实身份（而非伪装身份）相关——身份诡计与动机联动 |
| 常见破绽 | 转账记录、被销毁的把柄痕迹、勒索信/威胁信                  |

#### 原型四：谋财害命（图财的"直接性"）

| 项目   | 内容                                                         |
| ------ | ------------------------------------------------------------ |
| 核心诉求 | 直接夺取财物（宝藏/珠宝/传家宝/宝物/财物）                  |
| 人物画像 | 贪婪者、盗宝者、觊觎家产者                                 |
| 行为特征 | 打听财物下落、作案后寻找财物/转移财物                        |
| 伪装方式 | 伪装"为情/为仇"的假动机，掩盖真实图财目的                    |
| 六要素结合 | 动机×手段：图财的作案现场常"翻找过/财物失窃"                 |
| 常见破绽 | 财物去向、赃物、知情者（谁偷听到藏宝地点）                  |

### 3.2 情（爱 / 恨 / 占有）

#### 原型五：被背叛的爱人

| 项目   | 内容                                                         |
| ------ | ------------------------------------------------------------ |
| 核心诉求 | 报复背叛/出轨，或要一个"了断"                              |
| 人物画像 | 恋人/配偶/暧昧对象——被背叛或眼见对方移情                   |
| 行为特征 | 近期情绪剧变、争吵/冷战、关注对方行踪                        |
| 伪装方式 | 伪装"和平分手/看开了"；把矛头引向第三者                      |
| 六要素结合 | 动机×时机：撞破/确认背叛是触发点                            |
| 常见破绽 | 争吵目击、情书/聊天记录、见证人（第三者）                  |

#### 原型六：求而不得的占有者

| 项目   | 内容                                                         |
| ------ | ------------------------------------------------------------ |
| 核心诉求 | "得不到就毁掉"；切断对方离开自己的可能                      |
| 人物画像 | 偏执的爱慕者/前伴侣——占有欲强、控制欲强                   |
| 行为特征 | 跟踪、限制对方、威胁"得不到就……"                          |
| 伪装方式 | 伪装"深情的受害者"，掩盖偏执                            |
| 六要素结合 | 动机×心理：占有型动机可导向"与死者同归于尽/杀情敌"          |
| 常见破绽 | 跟踪/骚扰记录、威胁言语、对死者行程异常了解                |

#### 原型七：嫉妒者

| 项目   | 内容                                                         |
| ------ | ------------------------------------------------------------ |
| 核心诉求 | 因嫉妒（事业/感情/才华/地位）而除之                        |
| 人物画像 | 处处被压一头的同侪/同行/同窗/手足——长期心理失衡              |
| 行为特征 | 与死者"表面亲近实则攀比"、私下诋毁                        |
| 六要素结合 | 动机×时机：死者又"压过一头"（获奖/晋升/告白）触发            |
| 常见破绽 | 嫉妒的旧事（同窗往事/职场竞争记录）、被忽略的怨念线        |

### 3.3 仇（复仇 / 雪耻 / 申冤）

#### 原型八：隐忍复仇者

| 项目   | 内容                                                         |
| ------ | ------------------------------------------------------------ |
| 核心诉求 | 多年隐忍，一朝复仇；为亲人/旧主/故友讨还                     |
| 人物画像 | 潜伏多年的"小角色"（仆从/门客/被灭门遗孤/隐姓埋名者）        |
| 行为特征 | 长期潜伏、关键时刻"恰好出现"、对死者旧事异常了解            |
| 伪装方式 | 隐藏真实身份（身份诡计联动，见各 bg §3.3）；伪装"无关路人"  |
| 六要素结合 | 动机×身份：复仇者常隐藏真实身份——**"这个角色到底是谁"是谜题的一半** |
| 常见破绽 | 旧身份痕迹（旧识认人/信物/伤疤）、对旧事的细节记忆          |

#### 原型九：受辱者 / 被欺压者

| 项目   | 内容                                                         |
| ------ | ------------------------------------------------------------ |
| 核心诉求 | 对长期羞辱/欺压/虐待的爆发性反抗                           |
| 人物画像 | 长期受欺凌者（下属/仆人/学生/家人/被霸凌者）                 |
| 行为特征 | 隐忍积累、偶发爆发、作案后"解脱感"                        |
| 六要素结合 | 动机×时机：一次"最后的羞辱"是引爆点                        |
| 常见破绽 | 屈辱往事（旧证人/书信/被欺压记录）                         |

#### 原型十：家族/集体复仇

| 项目   | 内容                                                         |
| ------ | ------------------------------------------------------------ |
| 核心诉求 | 为家族/门派/信仰共同体雪耻，动机超越个人                    |
| 人物画像 | 家族成员、同门、幸存者——"报仇是义务"                      |
| 行为特征 | 集体行动或独行但为集体、目标明确（指向特定凶手或集团）      |
| 伪装方式 | 伪装"个人恩怨"，掩盖集体动机（团伙/组织背景）               |
| 六要素结合 | 动机×机会：集体复仇常有帮手/接应——**帮凶边界要清晰**（谁参与、参与多少） |
| 常见破绽 | 组织关系、往来信物、共同计划痕迹                            |

### 3.4 权（权力 / 地位 / 控制）

#### 原型十一：夺权者 / 竞争者

| 项目   | 内容                                                         |
| ------ | ------------------------------------------------------------ |
| 核心诉求 | 夺取权力/位置/话语权（王位/宗主/掌门/家业/职位/话语权）      |
| 人物画像 | 竞争者、次位者、觊觎者——"就差一步"的位置                   |
| 行为特征 | 拉拢人心、打探安排、与死者竞争同一位置                      |
| 伪装方式 | 伪装"忠诚/无辜"；把矛盾导向外部敌人                        |
| 六要素结合 | 动机×时机：位置的"交接/册封/任命/传承"时刻是触发点           |
| 常见破绽 | 继承人名单、密谋往来、谁最受益于"位子空缺"                  |

#### 原型十二：上位者（为了保住权力而灭口）

| 项目   | 内容                                                         |
| ------ | ------------------------------------------------------------ |
| 核心诉求 | 消灭威胁自己地位/权威的人（知情人、挑战者、旧主）            |
| 人物画像 | 掌权者/权威者/既得利益者——权力有被动摇的风险               |
| 行为特征 | 打压异己、灭口知情者、清除把柄                              |
| 六要素结合 | 动机×身份：上位者"权威"使其有调用资源/掩盖现场的能力（动机×机会） |
| 常见破绽 | 被灭口的知情者线索、威胁记录、权力结构图（谁依赖谁）        |

### 3.5 恐（灭口 / 自保 / 护秘）

#### 原型十三：知情者灭口

| 项目   | 内容                                                         |
| ------ | ------------------------------------------------------------ |
| 核心诉求 | 杀掉唯一知情者，保住自己的秘密（罪行/丑闻/身份/背叛）        |
| 人物画像 | 有秘密可暴露的人——秘密一旦曝光则身败名裂/性命不保           |
| 行为特征 | 死者"恰好知道不该知道的事"、死者有要挟/暴露的迹象            |
| 伪装方式 | 制造"死者另有仇家"的烟雾；把秘密藏得更深                    |
| 六要素结合 | 动机×时机：死者"正要开口/已经开口一半"是触发点（抢在暴露前） |
| 常见破绽 | 死者生前搜集的把柄、最后接触的人、泄露的"半句话"           |

#### 原型十四：秘密守护者

| 项目   | 内容                                                         |
| ------ | ------------------------------------------------------------ |
| 核心诉求 | 守护一个比自己性命更重的秘密（家族丑闻/组织机密/替人顶罪/身世真相） |
| 人物画像 | 秘密的监护人——"宁可杀人也不让秘密见光"                    |
| 行为特征 | 对某些话题极度回避、保护特定对象/物                        |
| 六要素结合 | 动机×身份：秘密往往与真实身份相关——**秘密的内容就是反转点** |
| 常见破绽 | 秘密的"半面"（旧档案/禁地/知情老人/信物）                  |

### 3.6 信仰 / 理念 / 大义

#### 原型十五：信仰狂徒 / 理念者

| 项目   | 内容                                                         |
| ------ | ------------------------------------------------------------ |
| 核心诉求 | 为信仰/教派/主义清除异端、献祭、守护教义                  |
| 人物画像 | 狂热信徒、殉道者、理想主义独行者                          |
| 行为特征 | 作案带有"仪式感"/特定符号（区别于随机杀人）                  |
| 伪装方式 | 伪装"世俗动机"，掩盖信仰动机（掩盖仪式的真实含义）          |
| 六要素结合 | 动机×手段：信仰动机常带仪式性现场（符号/布置/牺牲对象选择） |
| 常见破绽 | 仪式符号、教派关系、被害者身份的共同特征（为何选ta）        |

#### 原型十六：利他性谋杀（除害 / 解脱）

| 项目   | 内容                                                         |
| ------ | ------------------------------------------------------------ |
| 核心诉求 | 除掉"该死的人"（施暴者/罪人），或解脱无法承受者（安乐死）    |
| 人物画像 | "正义感"强烈者、被长期折磨者的家属/挚友                      |
| 行为特征 | 作案后坦然/悲伤而非恐惧、认为"自己没错"                    |
| 六要素结合 | 动机×情感：本类型常见于情感本/复仇本，玩家易共情            |
| 常见破绽 | 被害者的"恶行"证据（须可查证，否则动机不成立）             |

### 3.7 无差别 / 心理异常（慎用型）

#### 原型十七：无差别/精神异常

| 项目   | 内容                                                         |
| ------ | ------------------------------------------------------------ |
| 核心诉求 | 无明确逻辑诉求（精神异常/反社会/病态冲动）                  |
| 人物画像 | 心理异常者——**用于剧本杀需极其谨慎**：无动机真凶会导致"推理链断裂" |
| 行为特征 | 作案随机、无获利、无情感驱动                                |
| 六要素结合 | 除非剧本定位为"心理本/变格本"，否则**不建议作为硬核本真凶动机** |
| 常见破绽 | 若无明确异常线索铺垫，无差别动机违反"人人有动机"原则         |

> **使用铁律**：**无差别/精神异常动机只适合作为"表面不可解"的烟雾或特定剧本类型**（心理本/变格本）；硬核推凶本的真凶必须有**可盘、可验、有铺垫**的动机。


## 四、动机伪装与动机迷雾（红鲱鱼）

### 4.1 动机伪装（真凶如何隐藏真实动机）

| 伪装方式         | 手段                                         | 破绽                                       |
| ---------------- | -------------------------------------------- | ------------------------------------------ |
| **表面动机替代** | 提供另一个"合理但虚假"的动机（"我杀他是为了钱"掩盖真实是灭口） | 表面动机与行为细节矛盾                     |
| **嫁祸动机**     | 让另一个角色"看起来动机最充分"（情杀/仇杀线索指向他） | 被嫁祸者的动机线索与手法能力不符           |
| **动机时间错位** | 把动机的"触发事件"伪装成与死亡无关           | 触发事件与死亡时机的关联被忽略处           |
| **动机分层**     | 深层动机藏在最里层，玩家先盘到表面动机       | 深层动机的线索（旧事/身份）须可搜证         |

### 4.2 动机迷雾（干扰项设计）

- **人人可疑**：给每个角色一个"说得过去的动机"（财/情/仇/恐各分配），让动机线无法单点锁定。
- **动机与能力错位**：A 有动机但无手法能力/机会；B 有机会但动机薄弱——"动机+机会+能力"三角交错制造推理密度。
- **伪动机指向**：死者的"仇家"不一定只有真凶——死者的过去（年轻时得罪过谁）是动机迷雾富矿。

### 4.3 动机 × 身份联动（身份诡计的动机层）

- **复仇者隐藏身份**（原型八）："这个人到底是谁"是谜题的一半——旧身份是动机的根。
- **冒名者动机**：冒名者杀人的动机与其**真实身份**的前史相关（如冒名者其实是旧仇人），身份揭晓时动机随之反转。
- **秘密守护者动机**（原型十四）：秘密内容=反转点，动机与秘密绑定。


## 五、动机设计流程（创作建议）

```
① 定真凶 → ② 选动机源（财/情/仇/权/恐/信仰）→ ③ 配原型（§三）→ ④ 定表面动机/深层动机 → ⑤ 核对"动机×身份/时机/手段"三闭环 → ⑥ 设计动机线索（书信/旧事/财务/关系/身份证据）→ ⑦ 设计动机迷雾（人人有动机+干扰项）→ ⑧ 定动机揭露节奏（§1.4）
```

### 动机线索清单（可直接取用）

| 线索类型   | 示例                                                         |
| ---------- | ------------------------------------------------------------ |
| 财务类     | 遗嘱、保单、债务记录、大额转账、账本缺口                    |
| 关系类     | 情书、争吵目击、密谈、关系证据（血缘/师徒/旧识）            |
| 旧事类     | 旧案件档案、陈年恩怨证人、被翻出的往事信物                  |
| 身份类     | 身份证据（身世/隐姓埋名/冒名痕迹），身份揭晓=动机反转       |
| 行为类     | 案发前反常行为（打听/跟踪/安排后事/清除痕迹）               |
| 触发类     | 死者"正要公布/揭穿/改判/离开"的临门一脚证据                 |


## 六、逻辑约束与常见漏洞

| 漏洞               | 表现                                             | 规避方法                                     |
| ------------------ | ------------------------------------------------ | -------------------------------------------- |
| **动机不足**       | "为几块钱/一句话杀人"无解释                       | 动机强度须匹配手段，弱动机须补"触发/恐惧/异常" |
| **动机只复盘**     | 动机线索在真相揭晓才首次出现                     | 动机必须线索化、可搜证（§1.2）                |
| **人人无动机**     | 除真凶外全员"清白"，无迷雾                       | 人人有动机、动机与能力/机会错位（§4.2）       |
| **动机与身份矛盾** | 冒名者动机与真实身份前史不符                     | 动机×身份闭环（§4.3）                        |
| **无差别动机硬核本** | 硬核推凶本真凶无动机可盘                         | 无差别只作烟雾/特定类型（§3.7铁律）           |
| **动机与手段不匹配** | 动机"图财"现场却无翻找、动机"情杀"却无情感痕迹 | 动机×手段闭环（§1.1）                        |
| **利他动机无证据** | "被害者该死"但无其恶行证据                       | 恶行须可查证，否则动机不成立（原型十六破绽）  |
| **动机揭露太早/太晚** | 动机线过早锁死真凶，或拖到复盘才揭               | 按表层→中层→深层节奏设计（§1.4）             |
