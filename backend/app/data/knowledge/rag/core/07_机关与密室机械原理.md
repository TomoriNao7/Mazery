# 机关与密室机械原理（剧本杀创作用）

> **说明**：本文档是密室案的**物理可行性知识库**——锁具与门闩的原理、从外开锁/拨闩的技巧、暗门暗格、机关构造、延时装置（定时作案）的物理原理与可行性，以及"密室如何形成、如何破除"的验证方法。密室是"推理小说皇冠上最耀眼的宝石"，但**密室必须物理可行**——一个机关要能成立，须经得起"懂机械的玩家"推敲。
>
> **使用方式**：设计密室案时，先定密室类型（见 [[01_诡计分类大全]] 二-A 密室分类），再查本文档确认"这个机关/开锁/延时方法**物理上可行吗、材料从哪来、会不会发出声音、怎么被识破**"。本文档的核心价值是**防止"魔术式机关"**——机关可以精巧，但不能违背物理常识。
>
> **与其他文档的关系**：密室诡计分类与"密室讲义索引"见 [[01_诡计分类大全]] 二-A；各 bg 的密室适配（结界密室/魔法锁/法术）见对应 bg §3.1；验尸/死因层面见 [[03_法医学与死亡判定基础]]。


## 一、密室的基本物理框架

### 1.1 密室 = 进 / 出 / 闭 三向都需解释

| 环节 | 问题                                         | 对应知识                 |
| ---- | -------------------------------------------- | ------------------------ |
| **进** | 凶手怎么进入封锁空间？                       | 门/窗/暗道/通风/潜入     |
| **出** | 凶手怎么离开？                               | 开锁/拨闩/翻窗/暗道/藏身 |
| **闭** | 门闩/锁/结界怎么在凶手离开后恢复封锁？       | 自动闭锁装置、延时、心理 |

> **核心推论**：**密室推理的本质是"把进/出/闭三个环节中至少一个的解释权交给物理或心理"**。三个环节都能解释 = 密室破解；任何一个环节无法解释且无规则支撑 = 硬伤。

### 1.2 密室的两大类型（物理 vs 心理）

- **物理密室**：密室是真的——凶手用机械/开锁/暗道手段完成进出闭（本节知识主要服务此类）。
- **心理密室**：密室是假的——门实际没锁/结界没生效/众人被"权威或错觉"误导不敢验证（"这是国王的房间，没人敢进"），破除靠"推翻封锁的错觉"（见 [[01_诡计分类大全]] 密室分类二）。


## 二、锁具与门闩知识

### 2.1 常见锁具原理

| 锁具         | 原理                                     | 从外开启的方法                               | 破绽/痕迹                       |
| ------------ | ---------------------------------------- | -------------------------------------------- | -------------------------------- |
| **弹子锁**   | 弹簧弹子对齐解锁                         | 撬锁（开锁器）；**钥匙复制/留钥匙**         | 撬痕、钥匙去向、备用钥匙归属    |
| **挂锁**     | 独立锁体，扣在锁扣上                     | 撬锁/剪断；**替换同型号挂锁**（锁扣换锁）     | 锁体新旧、锁扣变形、替换痕迹    |
| **门闩/插销** | 插在门框槽内的金属/木条                   | **门外拨闩**（铁丝/薄片/磁铁伸入门缝拨动）     | 门缝大小、门框刮痕、磁铁残留    |
| **防盗链**   | 链式限制开门角度                         | 无法从外直接断开（只能从外破坏/诱导开门）     | 链条状态、门框受力               |
| **双面钥匙/齿型锁** | 齿形复杂、双面齿                       | 撬锁难度高；**留钥匙/复制**                 | 钥匙保管链                       |
| **密码/电子锁（现代/科幻）** | 密码/电子验证                     | **口令泄露/记录**；系统记录（谁何时开）     | 系统日志、密码来源、遗留记录    |
| **魔法锁/禁制（仙侠/西幻）** | 法力/咒语封锁                    | **施法者权限/破除方式/熟悉度**（见各 bg §3.1） | 结界残件、施法痕迹、熟悉度线索  |

> **设计要点**：**"从外开锁"类密室的高价值破绽是"备用钥匙/口令/复制钥匙的归属"**——"谁有钥匙/谁能开"比"锁怎么开"更有推理价值（钥匙线索直指嫌疑人）。

### 2.2 门外拨闩（经典手法）的可行性条件

| 条件       | 说明                                                         |
| ---------- | ------------------------------------------------------------ |
| **门缝**   | 门缝须够宽（木板门缝、弹簧门）——**门缝大小是硬性条件**，写机关前先算门缝 |
| **工具**   | 铁丝/薄刀片/磁铁/细绳+挂钩（从门缝伸入拨动门闩/插销）      |
| **弹回**   | 拨开后门闩须**靠重力/弹簧回到锁闭位**——（闩槽倾斜/弹簧复位） |
| **声音**   | 拨动过程可能发出声响——"深夜/有人时"操作有暴露风险          |
| **痕迹**   | 门缝边缘刮痕、门闩上工具痕、磁铁残留——**事后可被搜证**     |

> **逻辑约束**：门外拨闩**不是万能的**——门缝太小、门闩无复位结构、需大力、有目击风险时都不成立。写这个手法必须交代：门缝多大、闩槽是否复位、工具哪来的、有没有留痕。

### 2.3 钥匙技巧

| 手法         | 说明                                                     | 破绽                     |
| ------------ | -------------------------------------------------------- | ------------------------ |
| **钥匙留门** | 锁从内锁但钥匙还在锁孔/门内——制造"人在内反锁"的假象     | 钥匙归属、为何锁内还插着 |
| **钥匙复制** | 复制/配过钥匙——"谁有备用钥匙"                             | 配钥匙记录、钥匙保管链   |
| **钥匙转移** | 作案后把钥匙放回死者身上/原处                             | 钥匙位置与"死者最后行动"矛盾 |
| **钥匙留锁外** | 钥匙从门外/门缝被收走                                     | 收钥匙的窗口、工具痕     |

> **核心推论**：**钥匙是密室案的"信息钥匙"**——谁持有、谁能拿、钥匙位置的异常，往往比"锁的构造"更能锁凶（钥匙保管链 = 嫌疑人窗口）。


## 三、暗门 / 暗格 / 暗道

| 形式     | 构造原理                                   | 识别/暴露方式                                 |
| -------- | ------------------------------------------ | -------------------------------------------- |
| **暗门** | 与墙/柜/画/书架融为一体，铰链隐藏         | 移动痕迹（地面磨损）、开合声音、背面构造     |
| **暗格** | 家具/墙内的隐藏空间（夹层/假底/双底）      | 尺寸异常（空间对不上）、接缝、灰尘分布       |
| **暗道** | 墙内/地下/壁炉后的通道                     | 入口（壁炉/书架/地砖）、粉尘脚印、另一端出口 |
| **夹层/假墙** | 双层墙/天花板/地板夹层                   | 房间尺寸内缩、温度差、回声、灰尘线           |
| **通风道** | 利用通风管道进出                           | 管道内擦痕/脚印、封口状态、管径是否可通过   |

> **设计要点**：**暗道的存在须在游戏早期有"暗示线索"**（建筑图纸、仆人传闻、房间尺寸异常、某处不让人碰）——"最后时刻才挖出暗门"是天降线索；暗道出口与"谁会经过那里"绑定。

> **逻辑约束**：① 暗道不能"无处不在"——要有建造者/使用者线索（为何有此暗道、谁掌握）；② 暗道行进有**时间与痕迹**（走过有灰尘脚印/声音）；③ 暗道入口的"使用痕迹"（开关磨损）可反推使用频率。


## 四、机关构造原理（物理可行性重点）

### 4.1 机关的能量来源

| 能量源     | 原理                                     | 可行性要点                       |
| ---------- | ---------------------------------------- | -------------------------------- |
| **重力**   | 重物下坠/杠杆借力——关门/落锁/压发      | 需落差、需轨道、落地有声响       |
| **弹簧/发条** | 弹性势能——自动回位/上锁/弹射            | 需安装、有寿命、有声音           |
| **磁铁**   | 磁吸定位/延时分离                       | 磁力有限、需预装                 |
| **水力/虹吸** | 水钟/蓄水池虹吸/浮球——定时              | 需水源、需静置、有水位线索       |
| **化学**   | 酸蚀线/化学延时（见 §5.3）              | 需原料、有气味/残留、时间粗糙     |
| **燃烧**   | 蜡烛/引线定时、烟火延时                 | 需火源、有烟/蜡痕、时间可控性差   |
| **弹性体（皮筋/线绳）** | 橡皮筋/细线张力延时                | 时效短、材料易断、有残留           |
| **冰/水溶解** | 冰块/冰条熔断定时                     | 依赖温度、时效粗糙、留水渍         |

### 4.2 机关设计五问（每处机关必过）

1. **能量从哪来？** 重力/弹簧/磁铁/水力/化学/燃烧/弹性——必须有明确能量源。
2. **材料从哪来？** 机关部件（弹簧/磁铁/冰/酸/线绳）必须在剧本内可被角色获取（五金店/厨房/日常用品）——"凭空出现的机关"是硬伤。
3. **会不会被事先发现？** 机关安装会留安装痕迹（螺丝孔/接线/包装）、发出声音、占用空间——**安装痕迹是密室案的重要破绽**。
4. **触发条件是什么？** 机关何时触发（开门/关门/定时/受热/受潮）——触发条件要可复现、可验证。
5. **会不会失效？** 机关有寿命/误差/干扰（弹簧锈、磁铁丢磁、冰化太快）——**"过于精密永不出错"的机关不合理**，失效误差要能支撑诡计的时间精度。

### 4.3 常见机关的可行性判断（速查）

| 机关             | 可行？ | 关键条件                                       | 常见错误写法                 |
| ---------------- | ------ | ---------------------------------------------- | ---------------------------- |
| **门外拨闩**     | 可行   | 门缝够宽、闩可复位                             | 门缝笔笔直却塞进粗铁丝       |
| **钥匙留门**     | 可行   | 钥匙在锁孔内即可                               | 忽略"为何锁内还插着钥匙"     |
| **自动闭锁（弹簧门闩/重力插销）** | 可行 | 闩有复位结构、有安装痕迹                       | "门闩自己就锁上了"无来源     |
| **冰块/冰条门闩** | 可行   | 温度够低、融化时间可控、留水渍                 | 暖气房里冰块门闩不化         |
| **磁铁拨闩**     | 可行   | 磁力够强、门缝可入磁铁                         | 弱磁铁吸不动钢闩             |
| **暗门暗道**     | 可行   | 有建造/使用痕迹、尺寸可通行                     | "哪都有暗道"                 |
| **定时落锁（重力/弹簧计时）** | 可行 | 计时精度支撑死亡时辰                           | 秒级误差却声称"刚好那分钟"   |
| **酸蚀/化学延时** | 可行   | 酸浓度/温度影响时间、有气味残留                 | 精度不可控却精确到刻         |
| **远程法术/结界** | 规则内 | 见各 bg §3.8（魔法规则自洽）                   | 魔法"凭空施放"               |


## 五、延时装置（定时作案原理）

> **延时装置是"不在场证明"的物理支撑**（见 [[01_诡计分类大全]] 三 时间诡计 + 各 bg §3.6）。原理只有两类：**真正延时**（装置让死亡/上锁延后发生）与**心理延时**（误判在场/死亡时辰）。写延时必须归类并验证**时间精度**。

### 5.1 延时手段精度对照

| 延时手段         | 时间精度     | 可靠性 | 残留/破绽                       | 剧本杀适用性       |
| ---------------- | ------------ | ------ | ------------------------------ | ------------------ |
| **发条/钟表机构** | 较准（分钟级）| 高     | 机械件/钟表来源/上发条痕迹     | ★★★ 可靠           |
| **蜡烛/引线**    | 粗（刻级）    | 中     | 蜡痕/烟痕/引线烬               | ★★ 常用           |
| **酸蚀线**       | 粗（可调）    | 中     | 酸瓶/气味/残留                  | ★★                |
| **冰融化**       | 粗（环境依赖）| 低     | 水渍/温度异常                  | ★★ 环境型         |
| **虹吸/水位**    | 中（可调）    | 中     | 水痕/容器                       | ★★                |
| **弹簧/皮筋张力** | 粗（易疲劳）  | 低     | 部件残留                       | ★ 短时            |
| **化学反应**     | 粗（温控敏感）| 低     | 试剂/气味/容器                  | ★                  |
| **慢性毒延迟发作** | 中—粗（见 [[04_毒理学与毒药大全]]） | 中 | 毒物检测/症状           | ★★★ 常用（不在场） |

### 5.2 延时作案设计流程

```
定"死亡时辰" → 定延时手段（§5.1精度是否支撑）→ 定触发条件 → 定延时装置安装与隐蔽 → 定装置残留破绽 → 定"谁能知道/完成安装"的嫌疑人窗口 → 反推玩家搜证发现破绽的路径
```

### 5.3 延时的逻辑约束

1. **精度必须支撑诡计**：死亡时辰设定到"刻"，延时就选发条/钟表类；设定到"半天"，才能用蜡烛/冰/慢性毒。**"秒级死亡却配蜡烛延时"是硬伤**。
2. **安装有痕迹**：延时装置（发条/酸瓶/引线）在案发前就已布置——**"案发前谁能接触现场布置装置"是嫌疑人窗口**。
3. **装置可被识破**：残留（水渍/蜡痕/酸瓶/机件）是玩家搜证可发现的——**"完美的无痕延时"不存在**。
4. **失效误差要有交代**：装置受温度/受潮/疲劳影响可能失效——设计时要说明"为什么这次恰好成功/失败"。

### 5.4 心理延时（误判在场/时辰）的物理支撑

| 心理延时方向   | 机制                                         | 物理破绽                     |
| -------------- | -------------------------------------------- | ---------------------------- |
| **误判死亡时辰** | 环境因素误导（空调/暖气/藏尸）              | 环境温度异常（见 [[03_法医学与死亡判定基础]]） |
| **误判在场**   | 目击者被误导（看错时辰/看错人/光线模糊）    | 目击证词与其他证据交叉矛盾   |
| **误判封锁**   | 结界/门被"权威错觉"认定封锁                  | 封锁错觉的破除线索（谁能验证）|


## 六、密室形成动机与破除（创作检查）

### 6.1 为什么做密室？（动机检查）

| 动机             | 说明                                             | 检查点                             |
| ---------------- | ------------------------------------------------ | ---------------------------------- |
| **伪装他杀为意外/自杀** | 密室让"自杀/意外"看似不可能，反证他杀 | 反证逻辑：密室本身制造"他杀感"     |
| **伪装神罚/超自然**（仙侠/西幻/恐怖） | 结界/魔法让"封锁"看似神迹 | 魔法归位反证（见各 bg §3.8/§3.9） |
| **制造不在场证明** | 密室掩盖死亡时辰/在场                        | 时辰线推理破解                     |
| **嫁祸**         | 让某人有"唯一可能"                             | 嫁祸对象有自我辩护线索             |
| **保护秘密**     | 封锁现场掩盖丑闻/圣物/证据                     | 密室有第二重目的（多重动机）       |

> **核心推论**：**"凶手为什么费劲做密室"是密室案的第二层谜题**——没有合理动机的密室是炫技（硬伤）；密室动机往往是破解方向的钥匙（伪造神罚→归位；掩盖时辰→盘时间线）。

### 6.2 密室破除检查清单

- [ ] 进的路径解释了吗？（门/窗/暗道/通风/藏身）
- [ ] 出的路径解释了吗？（开锁/拨闩/翻窗/暗道/延时闭锁）
- [ ] 闭的方式解释了吗？（自动闭锁/钥匙留门/心理封锁）
- [ ] 每个环节有**物证/人证/痕迹线索**可被搜证吗？
- [ ] 机关能量/材料/安装/触发/失效（§4.2五问）都成立吗？
- [ ] 延时精度支撑死亡时辰吗（§5.1）？
- [ ] 密室动机合理吗（§6.1）？
- [ ] 没有"无来源机关"和"秒级精确的粗延时"吗？


## 七、逻辑约束与常见漏洞

| 漏洞             | 表现                                         | 规避方法                                     |
| ---------------- | -------------------------------------------- | -------------------------------------------- |
| **魔术式机关**   | 机关凭空出现、永不出错、无能量来源           | 机关能量/材料/安装/触发/失效五问全过（§4.2） |
| **无痕延时**     | 延时装置无残留、无法被搜证                   | 每个装置留痕（水渍/蜡痕/酸瓶/机件）（§5.3） |
| **秒级粗延时**   | 死亡时辰精确到分钟却用蜡烛/冰延时             | 延时精度匹配时辰精度（§5.1）                |
| **门外拨闩无门缝** | 门缝笔直却塞进粗工具                         | 先算门缝/工具尺寸（§2.2）                   |
| **暗道天降**     | 最后才挖出暗道，无前期暗示                    | 暗道早期暗示线索（建筑图/传闻/尺寸异常）（§三） |
| **钥匙归属悬空** | 谁有备用钥匙无交代                             | 钥匙保管链明确（§2.3）                      |
| **密室无动机**   | 为密室而密室（炫技无理由）                     | 密室动机合理（§6.1）                        |
| **结界永固**     | 魔法锁/结界永远打不开                        | 施法者/破除方式/熟悉度可查（各 bg §3.1）    |
| **机关只有一种解释** | 机关"只有凶手会装"却无能力/时间线索         | 安装痕迹+安装窗口+能力匹配                 |
