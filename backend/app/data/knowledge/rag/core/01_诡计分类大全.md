# 诡计分类大全

> **说明**：本文档系统整理了推理小说与剧本杀中常见的各类诡计。诡计是“凶手为掩盖自己是杀人凶手而采取的手段”。江户川乱步曾将侦探小说中的诡计分为九大类共800余条。以下分类综合了古典推理理论（诺克斯、范·达因）、日本推理作家（江户川乱步、横沟正史、岛田庄司等）以及当代剧本杀创作实践。
>
> **使用方式**：Agent 在设计案件时，可从此文档中选取一种或多种诡计组合使用。组合时需注意逻辑自洽，避免多种诡计相互冲突。


## 一、关于凶手（或受害人）人身的诡计

此类诡计围绕“凶手是谁”“受害者是谁”“他们之间是什么关系”展开，通过混淆人物身份来制造谜团。

### （A）一人二角 / 一人多角

同一人扮演两个或多个角色，让玩家误以为存在多个不同的人。

| 编号 | 诡计名称                       | 说明                                                         |
| :--: | ------------------------------ | ------------------------------------------------------------ |
|  1   | 犯人变成受害者                 | 凶手伪装成受害者，让所有人以为他已经死了                     |
|  2   | 共犯者变成受害者               | 同伙被灭口后伪装成主要受害者，转移调查方向                   |
|  3   | 犯人打扮成受害者               | 凶手穿上受害者的衣服/伪装成受害者的模样出现在他人面前        |
|  4   | 犯人和受害者是同一个人         | 受害者即凶手（自杀伪装他杀，或利用假死脱罪）                 |
|  5   | 犯人想把嫌疑放到第三人身上     | 通过伪装引导调查指向无辜的第三人                             |
|  6   | 犯人是虚构的人物               | 凶手虚构出一个不存在的人，让所有罪行“归于”此人               |
|  7   | 二人一角                       | 两个人共同扮演同一个角色（轮流出现，制造“此人无处不在”的假象） |
|  8   | 一人三角 / 三人一角 / 二人四角 | 更复杂的多人多角色扮演                                       |

### （B）出人意料的犯人

真凶的身份出乎所有人意料。

| 编号 | 诡计名称               | 说明                                     |
| :--: | ---------------------- | ---------------------------------------- |
|  1   | 侦探是犯人             | 负责破案的人其实就是凶手                 |
|  2   | 审判员/警察/典狱是犯人 | 执法者/司法人员是凶手                    |
|  3   | 案件的发现者是犯人     | 第一个发现尸体的人就是凶手               |
|  4   | 案件的记述者是犯人     | 叙述整个故事的人就是凶手                 |
|  5   | 儿童或老人是犯人       | 看似不具备犯罪能力的人是真凶             |
|  6   | 伤残者/病人是犯人      | 看似行动不便的人实施了犯罪               |
|  7   | 尸体是犯人             | 死者“复活”杀人（通常是假死或双胞胎诡计） |
|  8   | 人偶是犯人             | 利用人偶/模型制造“凶手”的假象            |
|  9   | 许多人是犯人           | 多人共同犯罪，每个人都是凶手的一部分     |
|  10  | 动物是犯人             | 利用动物杀人（毒蛇、猛兽等）             |

### （C）犯人自我抹杀

凶手通过“杀死自己”来摆脱嫌疑。

| 编号 | 诡计名称     | 说明                     |
| :--: | ------------ | ------------------------ |
|  1   | 犯人自己烧死 | 用烧焦的尸体冒充自己已死 |
|  2   | 假死         | 伪造自己的死亡           |
|  3   | 变换相貌     | 通过整容/化妆改变外貌    |
|  4   | 消失         | 彻底人间蒸发             |

### （D）孪生子诡计

利用双胞胎或长相极其相似的人制造身份混淆。

| 编号 | 诡计名称       | 说明                                                 |
| :--: | -------------- | ---------------------------------------------------- |
|  1   | 双胞胎互换     | 双胞胎互换身份，一人替另一人承担罪行或制造不在场证明 |
|  2   | 一人分饰孪生   | 同一个人扮演双胞胎中的两个角色（需易容/伪装）        |
|  3   | 长相相似者冒充 | 利用长相相似的人冒充他人                             |


## 二、凶手出入现场的诡计

此类诡计围绕“凶手如何进出犯罪现场”展开，核心是“不可能犯罪”——凶手在物理上似乎不可能进入或离开现场。

### （A）密室诡计

密室杀人是指在封闭空间内（或众目睽睽之下）发生的凶杀案。密室是“推理小说皇冠上最耀眼的宝石”。

#### 分类一：按犯罪时凶手是否在室内

|           类型           | 编号 | 具体手法               | 说明                                                   |
| :----------------------: | :--: | ---------------------- | ------------------------------------------------------ |
|  **犯罪时犯人不在室内**  |  1   | 室内的机关             | 利用机械装置在凶手离开后自动行凶                       |
|                          |  2   | 从窗或缝隙在室外杀人   | 通过通风口、门缝、窗户等远程攻击                       |
|                          |  3   | 受害者自己进入密室中   | 受害者自行进入并锁门，凶手早已在内部等待               |
|                          |  4   | 密室中的他杀伪装成自杀 | 凶手离开后，现场看起来像自杀                           |
|                          |  5   | 密室中的自杀伪装成他杀 | 自杀者故意布置成他杀以陷害他人                         |
|                          |  6   | 在密室内的非人犯人     | 动物或机械装置是“行凶者”                               |
|   **犯罪时犯人在室内**   |  1   | 门的机械装置           | 利用机关从内部锁门后离开                               |
|                          |  2   | 犯罪时间提前           | 实际作案时间比人们以为的早                             |
|                          |  3   | 犯罪时间推迟           | 实际作案时间比人们以为的晚（密室中快速杀人后混入人群） |
|                          |  4   | 藏在门后               | 趁众人破门时混入人群                                   |
|                          |  5   | 火车密室               | 在行驶的火车上制造密室                                 |
| **犯罪时受害者不在室内** |  —   | 受害者尸体被移入密室   | 尸体在别处被杀后移入密室                               |
|     **密室逃脱诡计**     |  —   | 凶手行凶后离开密室     | 通过各种手段离开后使密室恢复上锁状态                   |

#### 分类二：按密室构成方式

| 编号 | 密室类型               | 说明                                           |
| :--: | ---------------------- | ---------------------------------------------- |
|  1   | 传统机械型密室         | 通过线绳、杠杆等物理装置实现门窗上锁和尸体移动 |
|  2   | 胶带密室               | 利用胶带被撕扯后不可复原的特性制造密室状态     |
|  3   | 无足迹密室（雪地密室） | 雪地/泥地无足迹，或只有死者自己的足迹          |
|  4   | 异物密室               | 用异物挡住门形成密室，重点在异物与门的物理交互 |
|  5   | 孤岛密室               | 高塔、山峰、大楼顶等孤立环境                   |
|  6   | 监视密室               | 周围布满监控/目击者，凶手理论上无法进出        |
|  7   | 误会密室               | 并不存在真正的密室，由当事人的一系列误会造成   |
|  8   | 瞬间密室               | 在门开的一瞬间形成密室，凶手趁机溜走或隐藏行踪 |
|  9   | 移动密室               | 飞机、轮船、电梯等移动载体上的密室             |
|  10  | 魔术密室               | 通过镜子、视觉错觉、光线关系等魔术手段构造     |
|  11  | 温度密室               | 极冷或极热环境与密室构成相关                   |
|  12  | 水密室                 | 密室在水底，但地面干燥、尸体未被水泡过         |
|  13  | 棺材密室               | 狭小封闭空间（如棺材、保险柜）内的密室         |
|  14  | 多重密室               | 两个以上密室叠加（如密室中的密室）             |

## 三、关于行凶时间的诡计

| 编号 | 诡计名称     | 说明                                   |

| 编号 | 诡计名称          | 说明                                   |
| :--: | ----------------- | -------------------------------------- |

|  3   | 伪造录音/录像时间 | 提前录制音视频制造“当时在别处”的假象   |

## 六、叙述性诡计

叙述性诡计是剧本杀中最主流的诡计类型之一，本质是“文字游戏”——通过表述方式误导玩家对客观事实的判断。

| 编号 | 诡计名称     | 说明                                                 |
| :--: | ------------ | ---------------------------------------------------- |
|  1   | 视角误导     | 全文以某人称叙述，最后揭示叙述者其实是凶手本人       |
|  2   | 时间线误导   | 将不同时间发生的事交叉叙述，让人误以为发生在同一时间 |
|  3   | 身份误导     | 姓与名分开称呼，实为同一人                           |
|  4   | 人称混用     | 第一、第二、第三人称混用制造混淆                     |
|  5   | 性别误导     | 用中性叙述掩盖角色真实性别                           |
|  6   | 年龄误导     | 用模糊描述掩盖角色真实年龄                           |
|  7   | 数字误导     | 用数字表述制造错觉                                   |
|  8   | 凶手角度讲述 | 以凶手的第一人称叙述整个故事                         |
|  9   | 倒叙误导     | 通过倒叙结构隐藏关键信息                             |


## 七、心理诡计

心理诡计通过操纵人的认知、常识或心理预期来达到欺骗目的。

| 编号 | 诡计名称     | 说明                                             |
| :--: | ------------ | ------------------------------------------------ |
|  1   | 常识反转     | 利用“最不可能的人就是凶手”的心理                 |
|  2   | 虚假信息植入 | 对着没人的地方喊“谁在那！”，让大家以为有外人在场 |
|  3   | 搜索盲区     | 搜查者以为搜过了某处，其实并未彻底搜查           |
|  4   | 模式误导     | 制造“按某种顺序/规则杀人”的假象，实则并非如此    |
|  5   | 模仿犯误导   | 模仿他人作案手法，让人误以为是同一人所为         |
|  6   | 催眠术       | 利用催眠控制他人行为                             |
|  7   | 梦游病       | 利用梦游作为脱罪或杀人的借口                     |
|  8   | 记忆丧失症   | 凶手或证人声称失忆                               |
|  9   | 正当防卫诡计 | 将谋杀伪装成正当防卫                             |

## 九、设定系诡计

设定系推理指在特定的世界观设定下展开本格推理——世界观可以是变格的（超自然、科幻），但案件本身的逻辑必须是本格的。

| 编号 | 诡计名称     | 说明                                   |
| :--: | ------------ | -------------------------------------- |
|  1   | 科幻设定     | 在未来科技、AI、虚拟现实等设定下的诡计 |
|  2   | 奇幻设定     | 在魔法、异能等设定下的诡计             |
|  3   | 特殊规则设定 | 在特定的社会规则或物理规则下的诡计     |
|  4   | 时间循环设定 | 利用时间循环制造不可能犯罪             |
|  5   | 平行世界设定 | 利用平行世界/多重宇宙制造身份混淆      |

## 附录：诡计组合使用指南

### A. 经典组合模式

| 组合                  | 说明                              | 示例                             |
| --------------------- | --------------------------------- | -------------------------------- |
| 密室 + 不在场证明     | 凶手制造密室的同时制造不在场证明  | 凶手在众人面前“不可能”进入密室   |
| 身份诡计 + 时间诡计   | 通过身份混淆 + 时间差制造双重谜团 | 双胞胎在不同时间出现在不同地点   |
| 叙述性诡计 + 心理诡计 | 文字误导 + 心理预期操纵           | 以凶手视角叙述，同时利用常识反转 |
| 物理诡计 + 凶器消失   | 利用物理原理杀人 + 凶器自动消失   | 冰块凶器杀人后融化               |

### B. 难度评级参考

| 难度 | 诡计类型                        | 说明                         |
| :--: | ------------------------------- | ---------------------------- |
| 入门 | 简单身份诡计、简单时间诡计      | 线索直接，容易推理           |
| 进阶 | 密室诡计、不在场证明            | 需要综合多线索推理           |
| 困难 | 叙述性诡计、多重诡计叠加        | 需要识别文字陷阱和逻辑漏洞   |
| 专家 | 设定系诡计、心理诡计 + 多重叠加 | 需要理解世界观设定和深层心理 |

### C. 剧本杀适配建议

1. **避免“全场失忆”**：不要以全员失忆作为开局，剥夺玩家主动探索感
2. **日记不是万能药**：不要把全部真相写在一本日记里让玩家找到即破案
3. **时间线需配合物证**：不要只靠“你几点在哪”的对表来破案
4. **双胞胎必须提前铺垫**：严禁最后才突然揭示“其实他有个双胞胎哥哥”
5. **核诡需可推理**：核心诡计必须通过线索可被玩家推理出来，不能全靠猜
