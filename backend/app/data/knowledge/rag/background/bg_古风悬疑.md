## 一、古风悬疑的定义与核心原则

### 1.1 什么是古风悬疑推理

古风悬疑以**古代或架空古代中国**为舞台的本格推理。核心公理与现代本格一致：**真相必须来自"线索 + 逻辑"，而非"灵感 + 权威"**。

**两条铁律**：

1. **"古风是包装，推理是内核。"** 古风的价值在于提供一个与现代**不同的证据体系与常识体系**，让老诡计焕发新意——但古风不能成为"不严谨的免罪符"。
2. **古风剧本必须"自己解释自己的世界"**：玩家对验尸、毒药、时辰、官制、称谓的认知参差不齐，剧本内所有关键知识必须以设定说明或知识线索卡形式给出（见ps_古风悬疑 §5.6知识自包含），**不得依赖玩家自带古代知识**。

### 1.2 古风 vs 现代本格：证据体系差异

| 维度     | 现代本格                   | 古风本格                                     |
| -------- | -------------------------- | -------------------------------------------- |
| **身份识别** | 指纹 / DNA / 人脸 / 证件    | 户籍 / 族谱 / 路引 / 纹身 / 胎记 / 旧伤痕 / 家人认尸 |
| **验尸**     | 法医仪器 / 毒理化验        | 仵作目验 / 银钗验毒（仅限硫化物）/ 蒸骨法    |
| **计时**     | 钟表 / 手机 / 监控时间戳    | 时辰制 / 更漏 / 日晷 / 更夫 / 蜡烛 / 线香     |
| **通讯**     | 电话 / 网络 / 监控          | 书信 / 驿站 / 信鸽 / 仆从传话                 |
| **门禁**     | 监控 / 门禁卡 / 智能锁      | 门户落锁 / 院墙 / 看门人 / 犬只 / 垂花门      |
| **记录**     | 支付 / 行车 / 日志          | 账册 / 契书 / 书信 / 药方 / 巡夜簿 / 驿站文书 |
| **杀人手段** | 现代凶器 / 药物 / 枪械      | 刀剑 / 暗器 / 机关 / 毒药 / 弓弩 / 钝器 / 勒缢 |

> **核心推论**：古风本格不是"少了科技更自由"，而是"**换了一套证据体系**"。古风剧本的严谨性，取决于对这套古代证据体系的使用是否自洽（§2.7时代要素排查）。

### 1.3 剧本杀公平原则（古风适配十诫）

> **剧本杀的核心是"所有玩家共同参与的解谜游戏"**，而非单一侦探的破案故事。以下原则改编自诺克斯十诫和范·达因准则，例证按古风语境改写：

| 编号 | 原则                   | 说明（古风例证）                                                     |
| ---- | ---------------------- | ------------------------------------------------------------------ |
| 1    | **凶手必须在场**       | 凶手必须在游戏开始时已在场，且以公开身份登场——不能中途冒出一个从未出场的人物 |
| 2    | **线索全面呈现**       | 所有关键线索（书信、凶器、验尸记录、账册）必须在游戏过程中可被发现，不得在真相揭晓时才"补"线索 |
| 3    | **公平追凶**           | 每个玩家（包括凶手）搜证与发言权利对等；凶手可撒谎，但不能被系统保护 |
| 4    | **物理可行**           | 手法必须物理可行——不得用轻功、内力、符咒等超自然力量（设定系/变格本须先立规则，见§2.3） |
| 5    | **侦探不是凶手**       | 主持推理的"侦探"角色（捕快/师爷/仵作若担任此职）不应是凶手——其他玩家角色可以是 |
| 6    | **身份诡计须提前暗示** | 易容/双生/替身/男扮女装等身份诡计必须在游戏中提前给出暗示线索（易容工具、家族双生传闻等） |
| 7    | **动机须有深度**       | 动机应与角色背景（家仇/夺嫡/夺宝/门派恩怨/利益）一致且足以支撑谋杀——不能是"一时冲动"或"疯了" |
| 8    | **人人有嫌疑**         | 每个角色（包括真凶）都应有合理动机与可疑之处，不让任何人过早被排除 |
| 9    | **关键线索唯一指向**   | 关键线索链最终应指向唯一的真凶，尽管中间存在误导                   |
| 10   | **不得隐藏证据**       | 主持人不得主动隐藏玩家已发现的证据——所有发现的线索都公开记录在线索板上 |

### 1.4 古风本格在剧本杀中的特殊考量

| 考量点         | 说明                                                         |
| -------------- | ------------------------------------------------------------ |
| **知识自包含** | 玩家对验尸/毒药/时辰/制度认知不一——关键知识必须在剧本内以"设定说明"给出（ps_古风悬疑 §5.6） |
| **时代取舍**   | 写实历史/架空世界/戏说历史三档，逻辑要求不同（ps_古风悬疑 §5.1）          |
| **设定系处理** | 巫术/魂术/蛊/轻功等超常设定，须先立"规则"再推理（§2.3、§3.4）|
| **称谓与等级** | 身份等级决定行为权限（谁能进书房、谁能见主上、谁掌钥匙）——既是氛围也是推理要素 |
| **信息传递成本** | 古代消息慢——书信、口信、驿站的时间差本身可以成为诡计的一部分 |


## 二、逻辑严谨性核心框架（古风适配）

> **创作任何古风剧本，都应先过本框架，再考虑诡计与氛围。** 逻辑严谨 = 时代要素自洽 + 六要素闭环 + 时间线自洽 + 物理可行 + 线索可推导 + 真相唯一 + 知识自包含。

### 2.1 案件六要素闭环（古风版）

一个合格的古风案件必须形成"六要素闭环"。真相揭晓后，六要素彼此咬合、无相互矛盾；任一要素被推翻都会牵动其他要素重新检验。

| 要素   | 定义                 | 真相揭晓时必须回答的问题                                       | 古风配套支撑证据                               | 常见漏洞                                     |
| ------ | -------------------- | ------------------------------------------------------------ | ---------------------------------------------- | -------------------------------------------- |
| **死因** | 致死原因与致死机制   | 死者怎么死的？伤痕/毒物/勒缢/溺毙与死亡因果是否自洽？         | 仵作验尸记录、现场血迹/痕迹、银钗验毒、胃内容物 | 死因与现场矛盾（银钗验毒阴性却称中毒死）     |
| **手段** | 凶手实现死因的方法   | 用什么凶器/毒药/机关？每一步物理动作是否可行？                | 凶器来源与去向、工具痕迹、机关制作痕迹         | 无来源凶器（府库/兵器铺查无）、暗器凭空出现   |
| **时机** | 死亡时间与作案时间窗 | 哪个时辰死的？凶手在哪个时段动的手？                          | 尸温/尸僵的粗判、更夫报时、烛火、行程核算     | 死亡时间跨多个时辰使手法失效、时辰换算错误     |
| **机会** | 作案窗口的到达者     | 案发时段谁能接触现场与死者？谁被排除？                        | 门户落锁/院墙/看门人/巡夜、仆从证词、钥匙归属 | 排除不完整、未考虑夹壁暗道/翻墙/仆从持钥      |
| **动机** | 杀人动因及其一致性   | 为何杀此人？为何此时杀？与角色背景是否自洽？                  | 家族关系/权谋利益/门派恩怨/书信账册             | 动机不足、动机与人物身份背景矛盾               |
| **身份** | 凶手/死者/涉事者真实身份 | 凶手是谁？死者是谁？是否涉及易容/双生/替身？                | 户籍/族谱/路引、纹身/胎记/旧疤、家人认尸、信物 | 身份诡计无提前暗示、置换后行为与真实身份不符   |

**闭环校验法**（六要素两两互检）：
- **死因 × 手段**：该死因必须能由该手段产生。例如慢性中毒（牵机药）不可能表现为瞬间毙命；银钗验毒只能佐证硫化物类毒药（§2.4）。
- **时机 × 机会**：死亡时辰窗口内，凶手必须"在场"或"可控"。若凶手有不在场证明，必须存在能成立的"替代到场路径"（延时毒药/定时机关/夹壁藏身/替身），否则矛盾。
- **动机 × 身份**：凶手的动机必须与其**真实身份**（而非伪装身份）的前史吻合。
- **手段 × 时机**：手法的执行时间必须落在作案窗口内；延时手法（线香/烛火/慢性毒）的精度必须支撑死亡时辰设定。
- 任何一处矛盾 = 剧本硬伤，须修正要素本身，**而非靠"玩家没想到"来掩饰**。

### 2.2 时间线一致性（古风版）

**法则 1 · 计时体系自洽**：古代计时为**时辰制**（子丑寅卯辰巳午未申酉戌亥，一时辰=2小时）与**五更制**（一更19:00-21:00，五更03:00-05:00）。全剧本须统一换算标准，不得出现时辰与现代时间混用的矛盾。更漏（铜壶滴漏）、日晷、燃香、蜡烛燃烧时长均可作计时线索，但精度各异——燃香与蜡烛受风力、湿度影响，误差较大，只能作**粗略**佐证，不能作精确到分钟的定案依据。

**法则 2 · 照明约束**：古代无电灯，夜间活动靠烛火/油灯/灯笼/月光。**黑夜里"看清什么"是可检验的事实**——谁在无灯时辰能看清书页、能辨认远处人影，须有照明来源交代。灯被吹灭、蜡烛燃烧时长、黑影误认，都是可利用的时间/目击线索。

**法则 3 · 行程约束**：古代交通靠步行/马匹/马车。参考速度——步行一日约30里，骑马每日百余里，驿站换马急递可更快。**"从甲地到乙地所需时辰/日数"是硬约束**：报称"两日路程"者若实际需五日，即是破绽。

**法则 4 · 交叉验证**：任一时段的证言/记录至少与一条独立信息源交叉印证：更夫打更 × 仆从走动、账册出入 × 书信封缄、驿站记录 × 行程核算。无交叉的单方证词属"待证信息"，不能直接当铁证。

**法则 5 · 空白时段必须有解释**：角色"独处无证明"的时段，要么是推理的关键（嫌疑窗口），要么必须有非犯罪理由（如私会、偷窃、密谋他事），否则是漏洞。

**法则 6 · 系统性偏差才有说服力**：时间被篡改时，偏差必须来自可解释的系统（漏刻被调、更夫被买通固定误报、某处日晷被人为偏转），并交代为何无人及时发现。临时、随意、无法解释的"对不上"是硬伤。

**构建步骤**：先写"客观物理时间轴"（死亡时辰定死）→ 再写每个角色的"主观时间轴"（各角色以为的时辰）→ 最后标注两者偏差及其来源，确保偏差线索可在游戏中被发现（见案例一《钟表馆事件》的古代版思路）。

### 2.3 物理可行性验证（古风版）

**工具三问**（对手段的每一步物理操作逐一过问）：
1. **工具从哪来？** 凶手必须有获得渠道——兵器铺、药铺、家传、府库、山中自采、匠人打造。线索须能指向该渠道。
2. **用后去哪了？** 凶器/毒药容器必须有处置（带走/丢弃/藏匿/留在现场被误导），去向合理且可被追查。
3. **留下什么痕迹？** 使用必然产生痕迹——刀刃与伤口形状匹配、血迹喷溅、机关运转痕迹、药物残渣、勒痕与绳索材质一致。

**硬性标准**：
- 手法必须能在200字内说清，且以"古代常识 + 基本物理"可验证。
- **武功边界**：写实历史本中，轻功、内力、点穴、隔空取物视为"技艺的上限"，**不得违背物理**（飞檐走壁仍受重力、声响、体力约束）；设定系/变格本若需超常武功，必须先立规则并明示（§3.4）。
- **机关验证**：夹壁、翻板、机括暗器需要匠人制作——留下制作痕迹与工匠来源线索，且机关受机关寿命、锈蚀、卡滞等自然故障约束，使用前后状态可被查验。
- **延时装置只有两类**：① 真正延时（线香/蜡烛定时、水漏、自燃引火物如硫磺火折、慢性毒药）；② 心理延时（所有人误判死亡/离场时辰，实际凶手当时就在场）。写延时必须先归类，再验证该类别的**时间精度**是否足以支撑死亡时辰设定。

### 2.4 线索—推理映射（古风版）

**证据类型**（古风本五类证）：
- **物证**：凶器、遗物、伤痕、毒物残留、机关残件、遗书
- **人证**：仆从、更夫、侍女、车夫、邻人、同僚的证词
- **书证**：书信、契书、账册、药方、遗嘱、家书、户籍册、族谱
- **口供**：嫌疑人供词（须与物证/书证交叉）
- **验状**：仵作验尸记录（身份特征、死因、伤痕——见§八验尸知识）

**线索三级**：
- **事实线索（F）**：直接陈述、无需推断即可采信（仵作验状、书信原文、账册记录）。注意：事实线索"内容"可信，但"解读"仍可被误导（验状写"项下绳索交过"是勒死，但绳索是谁系的仍需推断）。
- **推断线索（I）**：需结合设定/常识推断（血迹喷溅方向、勒痕深浅与自缢/他杀之别、胃内容物与死亡时辰）。
- **误导线索（R）**：指向伪解答，**必须在后期可被推翻或解释**，不能不了了之。

**古风证据的局限（必须主动处理）**：
- **银钗验毒只对硫化物（砒霜类）敏感**：乌头、断肠草、曼陀罗、夹竹桃等银钗不显色。**验毒阴性 ≠ 无毒**。
- **无指纹、无DNA、无照片**：身份识别靠纹身、胎记、旧伤痕、家人辨认、随身信物——识别锚点必须存在且不可伪造（§3.4）。
- **仵作验尸技术有限**：慢性中毒、心疾猝死等可能被误判为病死/暴毙——"以病掩毒、以毒掩病"是合法手段，但误判的暴露必须有线索。

**推理价值标注**：每条线索在创作时应标注——它单独证明什么？与哪条线索组合证明什么？为**排除**哪个可能性服务？无推理价值的线索不该出现（纯氛围线除外，且需控制数量）。

**链式推导要求**：
- 从"初始线索集"到"真凶"至少存在一条 **≥3 步的逻辑链**。
- 关键推理链的**每一步至少2条独立线索支撑**。
- 链的每一步都必须"可被反驳"且"存在反驳线索"——否则该步骤是霸王推理（单方面认定、不可检验）。

### 2.5 唯一性判定与完整排除法（古风版）

在指认真凶之前，所有"他杀外可能"必须先被排除，且每个被排除项都要有**至少一条明确的排除线索**：

| 须排除的可能性       | 古风排除线索示例                                       |
| -------------------- | ------------------------------------------------------ |
| 自杀                 | 遗书笔迹比对、现场无自伤工具、伤痕角度不符（自刎多自左至右且浅而乱） |
| 意外                 | 现场无意外触发条件（坠楼却无攀爬痕迹、误食却无食物中毒对象） |
| 病亡                 | 仵作验状死因明确为他杀（非病非暴毙）                   |
| 无死亡（假死/替身）  | 身份识别锚点确认尸体身份、后续有该人未死的行为矛盾     |
| 外部闯入者作案       | 院墙/门禁/犬只/巡夜排除外来者、封闭场景设定             |
| 合谋 / 帮凶          | 涉案人员信息边界清楚、行动窗口逐一排查（如仆从"恰好"不在） |
| 死亡时辰被伪造       | 计时体系交叉验证（更夫/漏刻/烛火/行程）                 |

**唯一性检验**：给定全部线索，是否**只有一套**六要素自洽？若存在第二套同样自洽的解释，剧本就有逻辑漏洞——除非它是设计好的"伪解答"，而伪解答必须有反证线索（§3.9）。

### 2.6 反证检验流程（真相定型后必做）

把"真相"当作敌人，模拟最刁钻的玩家从五个角度攻击：

| 攻击角度       | 攻击问题                                                   | 被攻击即漏洞的情形                                     |
| -------------- | ---------------------------------------------------------- | ------------------------------------------------------ |
| **时间攻击**   | 凶手在X时辰做了Y，有没有任何证据/矛盾能推翻？              | 时辰制时间线上存在不可调和、无法解释的冲突             |
| **物理攻击**   | 手法每一步真的可行吗？机关/毒药/武功是否违背物理或古代技术？ | 机关超时代、毒药银钗验不出却硬判中毒、轻功飞天         |
| **信息来源攻击** | 凶手作案所需的"关键信息"（死者位置、时辰、钥匙、现场布局）从哪得知？ | 凶手不该知道却必须知道，且无获取渠道线索（如钥匙在管家处而凶手无接触） |
| **动机攻击**   | 换成"自杀/意外/病亡/嫁祸"能否同样解释现场？                | 排除项缺线索，真相无法唯一化                           |
| **公平性攻击** | 玩家在游戏中能否获得推导真相所需的**一切**信息（含古风知识）？ | 关键信息在复盘时才补充、或依赖玩家自带古代知识         |

**修正策略**：漏洞无法用"补一句话"解决时，**宁可改动设定**（改手法/改时辰/改角色信息/改时代档位），也不要保留逻辑漏洞。

### 2.7 时代要素排查（古风的"科技排查"）

创作古风剧本，必须**先明确本世界的"证据能力边界"**——有哪些手段、没有哪些手段，且不得混用。

| 时代要素 | 古代形态                                   | 对诡计的约束                                     | 可利用的破绽                                         |
| -------- | ------------------------------------------ | ------------------------------------------------ | ---------------------------------------------------- |
| **计时** | 时辰/更漏/日晷/更夫/线香/蜡烛               | 时间精度低，死亡时辰难以精确定位                 | 更夫误报、漏刻被调、烛火误导、故意错认时辰           |
| **验尸** | 仵作目验/银钗验毒/蒸骨法                    | 只能判定大体死因与部分毒物                       | 慢性毒难查、银钗局限、仵作受贿或失职                 |
| **身份** | 户籍/族谱/路引/保甲/家人认尸                | 无照片无指纹，身份难以精确核验                   | 易容、双生、冒名、路引伪造、族谱被改                 |
| **门禁** | 门户落锁/院墙/看门人/犬只/垂花门            | 密室难但非不可能                                 | 钥匙复制、仆从开门、夹壁暗道、翻墙                   |
| **通讯** | 书信/驿站/信鸽/仆从传话                     | 消息慢，实时沟通难                               | 书信伪造、驿马误时、口信错传、信鸽被截               |
| **照明** | 烛火/油灯/灯笼/月光                         | 夜间活动受限，目击可信度降低                     | 灯被吹灭、蜡烛燃烧时长、黑影误认                     |
| **医药** | 郎中/脉象/草药/药铺                         | 慢性毒难确诊、外伤感染可致死                     | 误诊、以病掩毒、以毒掩病、药方留痕                   |
| **记录** | 账册/契书/书信/巡夜簿/驿站文书              | 书面记录是硬证据                                 | 账册篡改、书信伪造、骑缝印鉴被仿                     |

**三条铁律**：
1. **不得"假装有现代科技"**：古风剧本中不得出现监控、电话、照片、指纹比对、DNA鉴定。若确需"超时代便利"，必须是穿越/架空设定的明确规则（如"本世界有摄魂镜可留影"）。
2. **必须主动处理时代局限**：验毒不万能、计时不精确、身份靠人工核验、消息传递慢——这些局限要么被纳入推理，要么被明确交代失效理由。**不能"假装没有局限"**。
3. **时代知识必须自洽**：朝代器物、制度、称谓不可混搭（宋代剧本出现明朝锦衣卫是硬伤）；架空设定须自订并明示（"本世界无铁器""本世界有魂术"）。

### 2.8 常见逻辑漏洞清单（古风版避坑）

| 漏洞             | 表现                                                     | 规避方法                                         |
| ---------------- | -------------------------------------------------------- | ------------------------------------------------ |
| **易容无铺垫**   | 易容术神通广大却毫无预兆，任意冒充他人                   | 提前暗示易容工具/技艺/门派（§3.3）              |
| **武功超自然**   | 轻功/内力违背物理破坏手法（飞檐走壁无痕、隔空取物）      | 写实本限制武功；设定系先立规则（§2.3）          |
| **验毒误用**     | 银钗验毒对乌头/断肠草等所有毒都有效                      | 明确银钗只验硫化物（§2.4）                      |
| **时辰换算错**   | 时辰/更次与现代时间换算出错，时间线自相矛盾              | 统一时辰制换算标准（§2.2）                      |
| **穿越矛盾**     | 现代知识/器物泄漏却无交代                                 | 明确穿越规则与限制                               |
| **身份识别悬空** | 无照片却"一眼认出"远道之人、或认不出应认之人             | 靠纹身/胎记/旧疤/家人/信物核验（§3.4）          |
| **书信时间矛盾** | 书信往返、驿站投递时间与现实行程不符                     | 按驿站/行程核算（§2.2法则3）                    |
| **认尸草率**     | 尸体毁容/无头却无人质疑身份                              | 设立身份识别锚点（§3.4）                        |
| **照明忽略**     | 漆黑夜晚角色"看清"了本看不清的细节                       | 交代照明来源（灯笼/月光/烛火）（§2.2法则2）     |
| **知识依赖**     | 推理依赖玩家自带古代知识，而非剧本内线索                 | 关键知识以设定说明/知识线索卡给出（ps_古风悬疑 §5.6）       |
| **银钗万验**     | 用银钗验毒作为"全知检测"，反而不查其他证据               | 银钗局限+多证据交叉（§2.4）                     |
| **天降线索**     | 关键信息在真相揭晓时才首次出现                           | 线索前置、可搜证（§2.4）                        |
| **排除不完整**   | 忘了自杀/意外/病亡/假死/帮凶/外部闯入等选项              | 过完整排除项清单（§2.5）                        |


## 三、核心诡计类型库（古风适配）

### 3.1 古代密室（Locked Room）

古代密室的核心载体与"复室""夹壁""暗道"密切相关。"套房"即古代密室、复室之属。木门门闩、钥匙锁、院墙构成了古代密室的经典条件。

#### 密室的两大基本分类

| 类型                   | 说明                       | 关键特征                                   |
| ---------------------- | -------------------------- | ------------------------------------------ |
| **机械密室**（物理密室） | 通过机关、暗格、门闩装置实现密室 | 密室是真实的，凶手用物理手段完成       |
| **心理密室**（错觉密室） | 利用心理错觉制造密室假象   | 密室是假的——门闩实际被从外拨动、锁是假锁 |

#### 密室的形成者（剧本杀视角）

| 形成者         | 说明                                 | 在剧本杀中的实现                         |
| -------------- | ------------------------------------ | ---------------------------------------- |
| **凶手制造**   | 最常见的类型——凶手杀人后制造密室     | 凶手玩家需在搜证环节注意隐藏相关手法线索 |
| **死者制造**   | 自杀伪装成他杀，或死者无意制造密室   | 最终揭晓时需通过验状证明是自杀           |
| **帮凶制造**   | 第三人在案发后无意或有意制造密室条件 | 该角色有独立动机（保护某人/制造混乱）    |
| **多人共同制造** | 多人各自的行为叠加形成密室假象       | 每个参与者都以为自己是"唯一做手脚的人"   |

#### 密室讲义分类索引（古风选型用）

| 编号 | 密室类型（卡尔分类简版）                           | 古风实现示例                                 | 剧本杀适用性 |
| ---- | -------------------------------------------------- | -------------------------------------------- | ------------ |
| 1    | 案件实为意外/自杀，被误认为他杀                    | 坠楼被伪造成推落、自缢被伪造成他杀勒死       | ★★★ 高      |
| 2    | 机械机关：杀人后自动上锁                           | 翻板活门、门闩机括、夹壁回旋门               | ★★ 中       |
| 3    | 凶手作案时就在房间，事后混入人群或藏匿             | 藏身夹壁墙/暗格/阁楼，混入仆从堆             | ★★★ 高      |
| 4    | 锁被做手脚（假锁/卡扣），实则任何人可开             | 门闩被丝线/竹片从门缝拨动，烛火掩饰          | ★★★ 高      |
| 5    | 用工具从外部或门下拨动门闩                         | 细线/铁丝/竹条伸进门缝挑闩（古代无鱼线，用丝线、金属丝） | ★★ 中   |
| 6    | 死者自己锁门（自杀或误锁）                         | 死者自缢前反锁、误触门闩                     | ★★★ 高      |
| 7    | 伪装他杀的意外（利用现场布置误导死因）             | 伪造仇杀现场掩盖意外/自杀                    | ★★★ 高      |

#### 密室杀人的动机（剧本杀适用）

| 动机                 | 说明                             | 对应的剧本设计                         |
| -------------------- | -------------------------------- | -------------------------------------- |
| **伪装自杀/意外**    | 让密室看起来是自杀或意外         | 验状线索需揭示真正死因与表面不符       |
| **制造不在场证明**   | 让所有人以为死亡发生时无人能进出 | 时辰制时间线推理是破解关键             |
| **嫁祸给特定的人**   | 让某人有唯一"可能"作案的条件     | 嫁祸对象应有对应的自我辩护线索         |
| **制造恐怖氛围**     | 连环杀手的标志性手法             | 多起案件共享同一密室模式               |
| **掩盖真实手法或死亡时辰** | 密室本身是烟雾弹             | 玩家需跳出密室思考"为什么要做密室"     |

**逻辑约束（重点）**：
1. 密室必须**"进、出、闭"三步都能解释**：凶手怎么进、怎么出、门闩/锁怎么复原。
2. 心理密室必须交代**"门闩被如何误认"**：是被丝线从外拨动、是钥匙被放回、还是门框变形卡死——误认机制本身要有线索。
3. **夹壁/暗道必须有"建造者与用途"线索**：年代久远的老宅夹壁（可藏人）要有来历交代（前朝余党、防匪密室、家族秘道），否则是凭空出现的通道。
4. 制造密室必须比"不制造密室"更有利：找不到合理动机时，用"伪装意外"或"制造恐慌"作为默认解释。

> **创作提示**：设计密室案时，顺序为——先问"凶手为什么要做密室"（动机）→ 再设计"怎么做的"（手法）→ 最后验证"怎么破除的"（破案线索）。**密室形成有解，破除也必须有解。**

### 3.2 不在场证明（古代版）

#### 在剧本杀中的典型形式

| 形式             | 说明                                   | 破解方向                               |
| ---------------- | -------------------------------------- | -------------------------------------- |
| **更夫/巡夜作证** | 声称案发时听到打更、见到某人经过       | 打更时辰误认、更夫被买通、雨夜听错     |
| **仆从互相作证** | 多人相互证明某人在某处                 | 共犯作伪证/集体时辰误认/仆从利益捆绑   |
| **账册/出入簿**  | 账房记录、门房登记显示在别处           | 记录被篡改/代笔/骑缝印被仿             |
| **书信/驿马**    | 书信封缄、驿站记录显示人在他处         | 书信伪造/驿马误时/他人代寄             |
| **行程核算**     | "我这两日都在赶路，不可能回府作案"     | 里程矛盾/抄近路/换马/中途折返          |

#### 常见的"不在场证明破绽"类型

1. **时辰谎称**——更夫/仆人被误导，以为在某时辰看到了某人
2. **替身诡计**——有人冒充嫌疑人出现在别处（易容/双生）
3. **书证伪造**——书信、账册、驿站文书被人为改动
4. **里程错觉**——看似不可能的往返距离其实可以做到（抄近路/昼夜兼程/换马）
5. **共犯伪证**——两人或多人合谋提供虚假证词

#### 在剧本杀中设计不在场证明

**关键原则**：每个角色（包括真凶）都应有不在场证明。真凶的不在场证明必须"看起来合理但存在破绽"——且**破绽必须有线索**，而不是"天衣无缝"或"靠运气看穿"。

| 角色类型       | 不在场证明设计                                               |
| -------------- | ------------------------------------------------------------ |
| **真凶**       | 看似合理但有细微破绽的证明（如"我在书房读书"——但书房的夹壁通密室、或当夜无灯火） |
| **其他嫌疑人** | 有真实的/部分真实的不在场证明，但各有隐瞒的理由（如"那夜我在账房私挪款项所以不想说"） |
| **目击者**     | 可能错误地确认了时辰——不是故意的，是雨夜/烛光/记忆偏差     |

**逻辑约束**：不在场证明的破绽必须**指向可搜证的位置**（夹壁、账册、驿站记录、更夫巡夜簿），玩家通过搜证+交叉对比可发现，而非依赖某角色"突然想起"。

### 3.3 身份诡计（易容/双生/性别置换）

> **⚠️ 提示**：叙述性诡计在剧本杀中**受限制**（玩家能看到角色卡），但身份置换类诡计**有天然优势**——玩家彼此看到的角色卡有限，信息不对称正是剧本杀的特征。

#### 剧本杀中可用的身份诡计

| 类型             | 说明                                   | 实现方式                                         |
| ---------------- | -------------------------------------- | ------------------------------------------------ |
| **易容术**       | 以脂粉/染发/假须/面具改换容貌         | 提前在背景线索中暗示易容工具、技艺、门派或"变脸人"传说 |
| **双胞胎/替身**  | 双生兄弟姊妹互换身份，或雇替身冒名     | 提前暗示家族有双生传闻、某人常年蒙面/纱         |
| **性别置换**     | 女扮男装/男扮女装（古风常见梗）        | 通过外貌细节（"从不宽衣"、"声音低沉"）暗示      |
| **一人分饰两角** | 同一个人在不同场合使用两个身份         | 两个"角色"从不同时出现，玩家拼凑时辰线发现       |
| **冒名顶替**     | 顶替死者/失踪者的身份与户籍            | 户籍册、族谱、旧识认人、信物的综合推理           |

#### 逻辑约束（重点）

1. **提前暗示原则**：诡计成立所需的事实（易容工具的存在、家族有双生、某人从不以全脸示人、某人有男扮女装的先例）必须在**游戏早期**有线索。
2. **置换后行为一致**：置换后的角色，其行为细节必须与**真实身份**（而非伪装身份）吻合——真实的性别/年龄/习惯/旧伤是"无法完全伪装"的破绽细节，正是玩家的发现路径。
3. **身份识别锚点**：剧本中必须存在至少一条**不可伪造的身份识别线索**——纹身、胎记、旧伤痕（家人/旧识知晓）、刻字信物（玉佩、戒指）、族谱记载、户籍特征（如"左眉有痣"）。
4. **一人分饰两角**：必须保证"两个身份从不同时在场"——用时辰线核对每个"出场"时刻，任一时刻被两名独立角色同时目击即诡计破产。
5. **易容的边界**：易容可以改变容貌，但**难以瞬间改变身高体态、声音、旧伤**——长期相处之人（家人、贴身仆从）应能识破，故易容诡计需配合"无人长期接触"（如死者独居、嫌疑人少与众人相处）或"相关人员被调离"的前提。

### 3.4 无面尸诡计（古代版）

> **定义**：尸体面部被毁/无头/烧焦/高度腐败，身份无法直接辨认，"死者是谁"成为第一道谜题。

#### 在剧本杀中的典型运用

| 步骤         | 游戏内实现                                | 设计要点                                        |
| ------------ | ----------------------------------------- | ----------------------------------------------- |
| **误导阶段** | 现场发现尸体+遗留物品→玩家推断死者是A     | 遗留物品必须明显指向A（A的随身玉佩/衣物/信物）  |
| **发现矛盾** | 角色A的"目击"与尸体情况不匹配→触发怀疑    | A声称在某处看到谁/什么，与尸体状态冲突          |
| **真相揭示** | 线索显示尸体实际上是B                     | 通过纹身/胎记/旧疤/身高/家人认尸/信物揭示       |

#### 经典结构变体

| 变体             | 说明                           | 剧本杀适用                                 |
| ---------------- | ------------------------------ | ------------------------------------------ |
| **尸体是替身**   | 凶手杀了无关人士冒充特定死者   | 需要凶手有接触"替身"的渠道和机会           |
| **尸体数量错误** | 实际死亡人数与发现的尸体数不同 | 多具尸体需在不同场景发现，玩家需统计比对   |
| **死者还活着**   | 某角色假死                     | 该角色的"死亡"需有目击者，但验状线索不完整 |

#### 逻辑约束（重点）

1. **必须有一条明确可靠的"身份识别锚点"**——纹身、胎记、旧伤疤、特殊体态、刻字信物、家人认尸。古代无指纹/DNA，**锚点尤为关键**。
2. **"误认"必须有合理原因**：面部毁损、无头、烧焦、溺水肿胀、家人"拒绝细看"（如指认者另有目的）——否则玩家会质疑"为什么认错了"。
3. **识别线索的取得时机**：身份识别线索要在"误导阶段"之后、"真相揭晓"之前**可被搜证获得**，形成"先误导→再证伪→后锁定"的推理弧线。

### 3.5 暴风雪山庄模式（古风版）

#### 古风封闭空间载体

| 载体         | 封闭方式                                       | 适用诡计               |
| ------------ | ---------------------------------------------- | ---------------------- |
| **山间客栈** | 大雪封山、山洪断路、马匹失踪                   | 密室、连环杀人         |
| **孤岛/别庄** | 渡船沉没/被凿、山体滑坡封路                   | 身份诡计、无面尸       |
| **寺庙/道观** | 山门封闭、大雨阻路                             | 设定系（巫蛊/神怪）    |
| **皇宫/皇陵** | 宫禁、陵墓封闭、随行人员定员                   | 权谋、连环杀人         |
| **边关/围城** | 城门落锁、战乱封路                             | 替身、无面尸、阵营     |
| **商队/驿站** | 途中被困、前后路段被毁                         | 身份诡计、时间诡计     |

#### 逻辑约束（重点）

1. **凶手必须始终在幸存者中**；随着命案发生，嫌疑人集合必须**单调收缩**——不能中途出现"新到达者"或"此前不在场者"被排除后又复活。
2. 每一起新的命案都要**收窄可能性**（排除法推进），而不是制造无关混乱。
3. 连环案件要么共享同一凶手逻辑（特征/模式/被害者关联），要么明确揭示"第二凶手"，两者都需线索支撑。

### 3.6 时间诡计与延时机关（古风版）

#### 在剧本杀中的典型形式

| 形式           | 说明                                     | 破解方向                             |
| -------------- | ---------------------------------------- | ------------------------------------ |
| **死亡时辰伪造** | 通过验尸误导/环境干预让死亡时辰提前或推后 | 验状线索+环境线索（烛火/尸冷）比对   |
| **更漏/时钟误导** | 漏刻被调、更夫被买通固定误报             | 多个计时源读数矛盾、权威时间源对比   |
| **时辰线交错** | 两起事件的先后顺序被混淆                 | 目击证词交叉比对、物理痕迹的时序     |
| **延时杀人**   | 凶手动手后延迟死亡，制造不在场证明       | 凶器/机关的延时机制线索             |

#### 古风延时手段

| 延时手段       | 原理                                   | 精度与注意                                             |
| -------------- | -------------------------------------- | ------------------------------------------------------ |
| **线香定时**   | 线香/熏香燃烧到一定位置触发机关         | 受风力/湿度影响，只能作粗略定时                        |
| **蜡烛/油灯**  | 蜡烛燃尽触发/以灯油耗尽推断时辰        | 蜡烛长短、灯芯粗细影响精度                             |
| **水漏装置**   | 铜壶滴漏/水袋渗漏计时触发              | 需交代装置来源与安装者                                 |
| **自燃引火**   | 硫磺/火折子/浸油布条定时引火           | 受潮失效风险，需留装置残件线索                         |
| **慢性毒药**   | 低剂量累积/迟发毒物，延迟发作          | 发作时辰窗口宽，是"不在场证明"的经典手段               |

#### 逻辑约束（重点）

1. **偏差必须有系统来源**（§2.2法则6）：谁调的漏刻、何时调、为何无人发现，都要有交代。
2. **延时必须归类并验精度**：真延时（线香/烛火/水漏/慢性毒）or 心理延时（误判在场者）。真延时要验证时间精度能否支撑设定。
3. **死亡时辰伪造必须有验尸依据**：用什么手段误导了验尸结论（环境保温/降温、胃内容物做手脚、尸僵被破坏），该手段本身要留下可被发现的痕迹。
4. **古代计时不精确是双刃剑**：既给时间诡计留空间，也要求时间线推理"以相互矛盾的计时源"为突破口，而非单一定论。

### 3.7 毒药诡计（古风特色）

> 古代毒药是古风本最富特色的手段板块。其逻辑核心在两点：**毒物与死状的对应关系**、**银钗验毒的局限**（见§2.4）。

#### 毒药速查表（含逻辑约束）

| 毒药         | 中毒症状/死状                             | 银钗验毒 | 发作特性       | 来源渠道                     | 典型伪装                       |
| ------------ | ----------------------------------------- | -------- | -------------- | ---------------------------- | ------------------------------ |
| **砒霜/鹤顶红** | 剧烈腹痛、呕吐、七窍或有血               | **变黑** | 急性（10-50mg中毒，0.1-0.2g致死） | 药铺、炼丹、民间“鹤顶红”传闻 | 酒菜、茶水中；红色粉末入药     |
| **鸩酒**     | 如大醉状、眼闭即死、不能言语              | 视掺入毒物 | 急性         | 宫廷赐死、权贵之家           | 酒中掺毒（乌头/毒箭木/毒芹汁） |
| **乌头**     | 四肢麻木、呼吸困难、心脏骤停（似心疾）    | 不显色   | 急性但可迟发     | 草乌头取汁、箭毒、药铺       | 药中下毒、箭矢淬毒             |
| **断肠草（钩吻）** | 剧烈腹痛、肠变黑粘连                    | 不显色   | 急性           | 山野自采、草药铺             | 混入草药、汤药                 |
| **见血封喉** | 强心苷中毒，入血即心脏麻痹，迅速毙命      | 不显色   | 极急性（须入血） | 南方毒箭树、部落猎手         | 暗器/箭矢淬毒、利刃涂毒        |
| **牵机药**   | 全身抽搐、角弓反张，极为痛苦              | 不显色   | 急性           | 宫廷禁药（李煜被赐死）       | 赐酒/汤药                     |
| **曼陀罗**   | 幻觉谵妄、口干、瞳孔散大、心跳加快（似中邪） | 不显色 | 中等，可致昏迷死亡 | 山野、游方郎中               | 香薰/烟/酒茶（"迷魂"）         |
| **夹竹桃**   | 恶心呕吐、心律不齐、昏睡甚至死亡          | 不显色   | 中等           | 庭园种植、全株有毒           | 日常接触、泡水、焚叶烟熏       |

#### 逻辑约束（重点）

1. **银钗验毒只对硫化物（砒霜类）显黑**：乌头、断肠草、曼陀罗、夹竹桃等**不显色**。验毒阴性 ≠ 无毒；验毒阳性也要防"以其他硫化物（如染发剂）误染"。
2. **死状对应**：每种毒的症状必须与剧本描写一致——曼陀罗的幻觉可被误认"中邪"（可作误导向），乌头症状似心疾（可作"病亡"误导），但不能张冠李戴。
3. **来源渠道**：凶手必须有获得毒物的渠道（药铺购买/山中自采/府中存药/宫廷禁药），线索须能指向该渠道。宫廷禁药被民间角色持有即需解释。
4. **急/慢性决定在场性**：急性毒（见血封喉入血、大剂量砒霜）凶手须在场或近场；慢性/迟发毒（小剂量累积、牵机药）可制造不在场证明——毒物的发作特性必须支撑凶手的机会设定（§2.1时机×机会）。
5. **以病掩毒/以毒掩病**：慢性中毒被仵作误判病死、真病死被误判中毒——都是合法手段，但误判的暴露必须有线索（药渣、脉案、症状细节）。

### 3.8 权谋与栽赃（古风特色）

> 权谋是古风本区别于现代本格的最大动机库与叙事场。其推理价值在于：**权力格局决定谁"不能死"、谁"必须死"、谁"不敢查"。**

#### 权谋载体

| 载体         | 冲突内核                         | 典型诡计                   |
| ------------ | -------------------------------- | -------------------------- |
| **宫廷**     | 夺嫡、后妃争宠、权臣架空         | 赐死/毒杀/嫁祸/假传圣旨   |
| **官场**     | 升迁、贪腐、党争                 | 栽赃、伪造证据、灭口       |
| **门派/江湖** | 掌门之位、秘籍、恩怨仇杀         | 暗器、毒药、易容、灭门     |
| **家族**     | 继嗣、家产、嫡庶之争             | 密室、毒杀、调换身份       |
| **边境/战争** | 通敌、夺权、军功                 | 替身、无面尸、栽赃         |

#### 栽赃手法与逻辑约束

| 栽赃手法       | 实现                                     | 逻辑约束                                                     |
| -------------- | ---------------------------------------- | ------------------------------------------------------------ |
| **预置凶器**   | 把凶器藏入嫁祸对象处                   | 需有"凶手如何取得/放置凶器"的通道线索（钥匙、仆从配合）     |
| **伪造书证**   | 伪造书信/账册/密信指向某人              | 需有"笔迹/印鉴可仿"的铺垫与伪造工具线索；骑缝印可验         |
| **买通人证**   | 收买仆从/更夫作伪证                     | 需有金钱往来、威胁把柄等"买通"线索                           |
| **调换毒药**   | 替换药方/药包陷害郎中                   | 需有接触药铺/药方的机会与调换痕迹                             |
| **布置伪现场** | 伪造闯入痕迹/搏斗痕迹                   | 伪现场与真实痕迹的矛盾点即破绽                               |

**逻辑约束（重点）**：
1. **栽赃要有"栽赃通道"线索**：嫁祸对象身上的凶器/信物，凶手是如何取得的？无通道的栽赃是凭空指控。
2. **权谋动机要可被查证**：密谋、书信、账册、利益往来应留下可搜证的痕迹——权谋不是"背景板"，而是推理素材。
3. **权力豁免的处理**：皇权/门第可使人"不敢查"——这是动机与阻力的来源，但不能成为逻辑漏洞。玩家仍应能凭线索指向真凶，只是剧本内角色可能因权势而犹豫（这是戏剧张力，不是逻辑豁免）。

### 3.9 误导与伪解答工程（古风版）

**红鲱鱼设计原则**：

| 原则         | 说明                                         |
| ------------ | -------------------------------------------- |
| **有独立价值** | 即使不指向真凶，也揭示了某个角色的秘密或动机 |
| **合理存在**   | 不是凭空出现——与该角色的行为/背景一致        |
| **可被推翻**   | 后续有线索可推翻该误导，而不是"不了了之"     |
| **不过度集中** | 不要把大部分误导线索集中在同一个非真凶角色上 |

**古风常见误导源**：
- **中邪/巫术/怪力乱神**：曼陀罗的幻觉、魂术传说——先引导玩家往"非自然"方向想，再用物理/毒物线索拉回（适合设定系与写实本交融）。
- **遗书/绝笔**：伪造遗书误导自杀（笔迹、措辞、印鉴为破绽）。
- **江湖仇杀传闻**：死者"仇家遍布"误导外部闯入，实际内部作案。
- **旧案/祖上恩怨**：用陈年旧事分散注意力，掩盖当下动机。

**伪解答设计**：一个表面上能解释所有线索的"假真相"。要求：
- 伪解答必须能**暂时覆盖**绝大多数线索；
- 伪解答必须有**至少一条反证线索**，且该线索在游戏后期可被搜证获得；
- 伪解答被推翻的瞬间 = "恍然大悟"时刻。

**逻辑约束**：伪解答数量建议 **1–2 个**。每个伪解答的推翻线索要与真凶推理链**共用线索、互相咬合**，而非另起炉灶。

#### 误导的进阶形态：前提错误型

> **最高明的误导不是让玩家"想错答案"，而是让玩家"一开始就想错了问题"。** 一旦"死者是谁"这一前提错误，所有后续推理都失去根基。

典型：**无面尸 + 身份误认**（§3.4）、**伪解答依赖错误前提**（如"现场是密室"这个前提本身错了）。破绽点在于：推翻前提的那条线索（如"门其实没锁"、"死者其实是B"）必须是**玩家可主动质疑、可搜证验证**的（对应《嫌疑人X的献身》的古风变体：尸体身份认错）。


## 四、经典案例解析（逻辑严谨性视角）

以下案例解析侧重于"这个诡计**在逻辑上为什么成立**"以及"如何转化为剧本杀设计"，供创作时参考。解析基于各剧本公开的复盘要点，不涉及剧透细节。

### 4.1 案例一：《天启诡案》——长逻辑链锁唯一解

| 项目         | 内容                           |
| ------------ | ------------------------------ |
| **类型**     | 设定推理 / 古风 / 诡计 / 密室 |
| **核心亮点** | 三个案件 + 三重反转 + 长逻辑链 |

**结构**：3×3矩阵——第一案复合型谜面（多重悖论）、第二案绝对密室（两名死者如何进入密室、凶手如何行凶及潜逃）、第三案坠亡物理诡计（现场条件形成矛盾点引发悖论）。

**逻辑上为什么成立**：
- **全前置线索**：线索几乎无废话、全在游戏开始时前置——极致公平（§1.3原则2），推理靠"逻辑"而非"搜证运气"。
- **长逻辑链**：网状谜面的突破口在逻辑解，每一步可被线索推导、可被反驳（§2.4），逻辑链直指终点。
- **三重反转靠逻辑锁到唯一解**：多次反转不是"换个说法"，而是"排除旧解、逼出新解"，每次反转都用排除法收窄（§2.5）。
- **第三案教科书级收束**：所有线头在收束案一次性闭合——"一把钥匙开多把锁"（§2.5唯一性）。

**剧本杀借鉴价值**：

| 借鉴点           | 说明                                             |
| ---------------- | ------------------------------------------------ |
| **古风作为包装** | 天启大爆炸仅作背景，核心是对逻辑的考验           |
| **全前置线索**   | 所有线索在游戏开始时即给出，考验推理而非搜证     |
| **纯逻辑导向**   | 部分案件是纯逻辑导向案件，而非灵光一闪的诡计     |
| **长逻辑链**     | 网状谜面的突破口在逻辑解，逻辑链导向终点         |

### 4.2 案例二：《北宋奇案·汴京》——数据矛盾触发反转

| 项目         | 内容                          |
| ------------ | ----------------------------- |
| **类型**     | 古风 / 推理 / 本格密室 / 还原 |
| **核心亮点** | 本格密室 + 连环斩首案          |

**结构**：四起密室斩首案，均为本格密室；通过最后一起密室从"无解"到"有几解"，发现密室死亡人数与汴京城死亡人数对不上，从而把前三起案件重新盘一遍。

**逻辑上为什么成立**：
- **数据矛盾是可检验的硬事实**：死亡人数对不上，任何人通过**统计表格**都能发现（§2.4链式推导的起点）。
- **"无解到有几解"=排除项变化**：先认定无解（排除所有已知方案），再发现多出一人的可能，排除项集合被打开——这是排除法的动态推进（§2.5）。
- **多案件串联**：四起密室共享同一凶手逻辑与隐藏联系，重审前案时新线索闭合全局（§4.7启示）。

**剧本杀借鉴价值**：

| 借鉴点           | 说明                            |
| ---------------- | ------------------------------- |
| **连环密室**     | 多起密室案件之间存在关联        |
| **数据矛盾推理** | 死亡人数对不上→重新审查所有案件 |
| **历史背景融入** | 北宋历史作为案件背景            |

### 4.3 案例三：《麻衣神探》——多案件串联 + 基本演绎法

| 项目         | 内容                             |
| ------------ | -------------------------------- |
| **类型**     | 古风纯本格推理                   |
| **核心亮点** | 五个案件 + 基本演绎法 + 密室手法 |

**结构**：五个案件初看独立，实则串联同一世界观与人物关系；第一案用基本演绎法，仅三人可盘三小时；含盘人物关系的案件与一个精彩密室手法案件。

**逻辑上为什么成立**：
- **多案件串联共享世界观**：看似无关的案件共享人物关系，是"一个解答对应多个谜题"的结构（§2.5唯一性）。
- **基本演绎法**：从少量信息出发推出大量结论，每一步都必须能被线索严格推导、可被反驳（§2.4）。
- **人物关系推理**：以人物关系而非物证推理——古风本的人物关系（姻亲/主仆/师徒/仇怨）本身就是线索网。

**剧本杀借鉴价值**：

| 借鉴点           | 说明                                       |
| ---------------- | ------------------------------------------ |
| **多案件串联**   | 看似独立的案件实则共享同一世界观和人物关系 |
| **基本演绎法**   | 从少量信息出发，通过逻辑推演得出大量结论   |
| **人物关系推理** | 通过人物关系而非物证进行推理               |

### 4.4 案例四：《蛊魂铃》——变格设定系的规则自洽

| 项目         | 内容                         |
| ------------ | ---------------------------- |
| **类型**     | 变格 / 古风 / 推理 / 还原    |
| **核心亮点** | 魂术设定 + 身份错位          |

**核心设定——魂术**：角色可通过特殊手段附身于他人，造成身份错位和记忆混乱。主要任务是还原故事，凶案只是额外线索。

**逻辑上为什么成立**：
- **设定系必须有规则**：魂术不是无限全能的魔法，而是有代价、有条件的"规则性能力"——设定内仍可推理（§2.3、§3.4）。这是变格本"逻辑自洽"的样板。
- **身份错位让"我是谁"成为谜题**：附身导致身份/记忆混乱，与§3.3身份诡计的"一人分饰两角"同构，靠时间线与行为矛盾还原。
- **记忆碎片叙事**：角色记忆不完整需拼凑还原——碎片之间需逻辑咬合，不能靠"想起来"缝合。

**剧本杀借鉴价值**：

| 借鉴点             | 说明                         |
| ------------------ | ---------------------------- |
| **变格设定系推理** | 在"魂术"设定下展开逻辑推理   |
| **身份错位诡计**   | 附身导致"我是谁"成为核心谜题 |
| **记忆碎片叙事**   | 角色记忆不完整，需要拼凑还原 |

### 4.5 案例五：《沉冤录》——仵作验尸知识的运用

| 项目     | 内容                               |
| -------- | ---------------------------------- |
| **类型** | 古风 / 推理 / 还原                 |
| **背景** | 南宋理宗宝庆元年（1225年），丹徒县 |
| **核心亮点** | "验皮，验肉，验骨，验人心"四验结构 |

**逻辑上为什么成立**：
- **验尸知识增加证据可信度**：《洗冤集录》的专业知识（验状、伤痕、毒检）让证据链条有"专业可信"的锚点——证据可信是推理可信的前提（§八验尸知识）。
- **四验递进 = 推理层次**：验皮→验肉→验骨→验人心，对应"死因→伤痕→死法→动机"的推理纵深，是长逻辑链的古风化表达（§2.4）。
- **志怪传说与写实框架的共存**：卜算天机、怪力乱神作为氛围与误导源（§3.9），最终以可检验的证据收束——设定元素不破坏推理。

**剧本杀借鉴价值**：

| 借鉴点           | 说明                             |
| ---------------- | -------------------------------- |
| **仵作验尸元素** | 将《洗冤集录》的验尸知识融入剧本 |
| **南宋历史背景** | 真实历史框架下的戏说故事         |
| **志怪传说元素** | 卜算天机、怪力乱神作为氛围与误导 |
| **四验递进结构** | 死因→伤痕→死法→动机的推理纵深   |

### 4.6 案例六：《龙宴》——权谋+推理双线

| 项目     | 内容                           |
| -------- | ------------------------------ |
| **类型** | 古风权谋 / 推理还原 / 阵营机制 |
| **背景** | 架空王朝                       |

**结构**：新皇登基，贵族反对与江湖帮派威胁并存，皇帝寿辰的龙宴之际朝堂风云变幻。剧本前段以推理为主、暗中拉帮结派，后段以机制为主。

**逻辑上为什么成立**：
- **权谋提供深层动机**：夺嫡、改革vs保守的政治冲突，为谋杀提供"利益可查证"的动机（§3.8），而非泛泛之仇。
- **双线并行**：朝堂斗争与凶案推理交织——权谋不是背景板，而是动机与阻力的来源（谁能查、敢不敢查、受益者是谁）。
- **架空王朝设定**：脱离史实约束，自订规则并明示，证据体系内部自洽（§2.7铁律3）。

**剧本杀借鉴价值**：

| 借鉴点            | 说明                           |
| ----------------- | ------------------------------ |
| **权谋+推理双线** | 朝堂斗争与凶案推理并行         |
| **阵营对抗机制**  | 玩家分属不同阵营，各有目的     |
| **政治阴谋诡计**  | 改革派与守旧派的冲突           |
| **架空王朝设定**  | 脱离史实约束，自由构建权谋世界 |

## 六、古风剧本创作流程框架（逻辑先行）

> **顺序不可颠倒**：先定真相与时代、再过逻辑框架、再设计角色与线索，最后才排版分幕。

| 步骤 | 工作内容                                     | 产出物 / 验证点                                           |
| ---- | -------------------------------------------- | ---------------------------------------------------------- |
| 1    | **定义案件真相**                             | 古风六要素初稿：死因/手段/时机/机会/动机/身份（§2.1）     |
| 2    | **六要素闭环验证**                           | 两两互检（§2.1），修正任何一处矛盾                         |
| 3    | **时代要素排查**                             | 定档位（写实/架空/戏说，ps_古风悬疑 §5.1）；过§2.7表，明确证据体系边界 |
| 4    | **时间线设计**                               | 时辰制主时间线 + 每角色个人时间线 + 交叉验证（§2.2）       |
| 5    | **手法物理验证**                             | 工具三问 + 机关/毒药/武功边界验证（§2.3、§3.7）            |
| 6    | **反向设计线索链**                           | 从真相反推：需要哪些线索支撑每一步推导，标注推理价值与排除功能（§2.4） |
| 7    | **分配线索与分幕**                           | 线索分幕/分区域发放，关键线索冗余≥2；知识自包含（ps_古风悬疑 §5.6）   |
| 8    | **反证检验与逻辑自检**                       | 过§2.6五角度攻击 + §七自检清单                            |

| 推理步骤 | 需要的事实 | 支撑线索（≥2条） | 线索所在场景/幕 | 排除的可能性 |
| -------- | ---------- | ---------------- | --------------- | ------------ |
| 步1      | 死因是中毒 | 验状记录 / 药渣 / 杯沿残留 / 症状 | 幕2 / 验尸房   | 意外、病亡   |
| 步2      | 只有C能进密室 | 钥匙归属 / 门闩拨动痕迹 / 仆从证词 | 幕3 / 书房     | 外部闯入者   |
| …        | …          | …                | …               | …            |

## 七、逻辑自检清单（古风版）

### 7.1 逻辑闭环检查
- [ ] 六要素（死因/手段/时机/机会/动机/身份）两两互检无矛盾
- [ ] 死因与现场表现一致（无"银钗验毒阴性却说中毒死"类矛盾）
- [ ] 凶手作案所需的关键信息均有获取渠道（钥匙、时辰、现场布局）
- [ ] 存在完整排除项（自杀/意外/病亡/假死/外部闯入/合谋/时辰伪造均被排除且各有线索）

### 7.2 时间线检查（古风计时）
- [ ] 时辰/更次换算统一无误
- [ ] 主时间线物理自洽，所有记录/证词/巡夜可叠加
- [ ] 每个角色有时间线，空白时段有解释
- [ ] 任一证言至少与一条独立信息源交叉验证（更夫×仆从×账册×驿站）
- [ ] 时辰篡改类诡计有系统性来源 + 无人发现的合理理由
- [ ] 夜间目击有照明来源交代，无"漆黑看清"硬伤
- [ ] 行程/里程核算与角色声称相符

### 7.3 物理可行性检查（古风器物）
- [ ] 手法200字内可描述清楚
- [ ] 工具三问全部通过（来源/去向/痕迹）
- [ ] 机关有匠人来源与制作痕迹，非凭空出现
- [ ] 延时装置已归类（真延时/心理延时）且精度验证通过
- [ ] 密室"进、出、闭"三向都有解；夹壁/暗道有建造者与用途
- [ ] 无超自然武功（写实本）；设定系已立规则并明示
- [ ] 毒药死状与症状描写一致；银钗验毒局限已处理

### 7.4 线索公平性检查
- [ ] 所有关键线索在游戏过程中可被搜证获得（无天降线索）
- [ ] 关键推理链≥3步，每步≥2条独立线索支撑
- [ ] 每条线索标注了推理价值（无推理价值的线索已删除或转纯氛围）
- [ ] 身份诡计有提前暗示，且存在至少一条不可伪造的身份识别锚点
- [ ] 每条误导线索有收束（可被推翻或有解释）
- [ ] 推理所需古风知识已写入剧本（知识自包含，ps_古风悬疑 §5.6）

### 7.5 唯一性检查
- [ ] 给定全部线索，只有一套六要素自洽
- [ ] 伪解答（若有）能被明确反证线索推翻
- [ ] 排除法穷举了所有"他杀外可能"
- [ ] 合谋/帮凶的信息边界清晰（谁、何时、知道多少）

### 7.6 时代要素检查
- [ ] 档位（写实/架空/戏说）已定且全程守约
- [ ] 无"假装有现代科技"（监控/电话/照片/指纹/DNA）
- [ ] 时代局限已处理（验毒不万能/计时不精确/身份靠人工核验/消息慢）
- [ ] 朝代器物、制度、称谓无混搭；架空设定已自订并明示
- [ ] 角色行为权限与身份等级一致（谁能进书房、谁掌钥匙）

### 8.2 元素清单

**物理诡计元素**：
- 刀剑/弓弩/钝器/软兵器（鞭、绳）——见§四兵器知识
- 暗器（手掷/机括/特殊）——发射痕迹、匠人来源
- 机关（翻板/夹壁/机括暗器）——制作痕迹、机关寿命
- 烛火/线香/水漏——延时与计时
- 勒缢（缢/勒之别——见§八验尸知识）

**身份诡计元素**：
- 易容术（脂粉/假须/面具/染发）→ 需提前铺垫易容工具与技艺
- 双胞胎/替身 → 需提前给出家族双生传闻或替身雇佣线索
- 性别置换（女扮男/男扮女）→ 需通过"从不宽衣""声音"等细节矛盾揭示
- 一人分饰两角 → 需通过"两人从不同时出现"的时辰线揭示
- 冒名顶替 → 需通过户籍/族谱/信物/旧识认人综合推理

**时间诡计元素**：
- 死亡时辰伪造 → 需通过验状+环境线索（烛火/尸冷）比对
- 更漏/时钟误导 → 需通过多个计时源读数矛盾揭示
- 时辰线交错 → 需通过目击证词交叉比对
- 延时杀人 → 需通过延时机制的线索（线香残段/水漏装置/慢性毒药）揭示

**毒药元素**（见§3.7速查表）：
- 砒霜/鹤顶红、鸩酒、乌头、断肠草、见血封喉、牵机药、曼陀罗、夹竹桃
- 伪装方式：酒、茶、药膳、香薰、烟、胭脂、杯沿涂毒
- 银钗验毒的局限：只对硫化物（砒霜类）显黑

**权谋元素**：
- 宫廷（夺嫡/后妃/权臣）、官场（贪腐/党争）、门派（掌门/秘籍）、家族（继嗣/家产）
- 栽赃手法：预置凶器/伪造书证/买通人证/调换毒药/布置伪现场
- 书证：书信/账册/契书/遗诏/奏折——笔迹、印鉴、骑缝印可验

**氛围元素**：
- 建筑（飞檐/青砖/雕花/回廊/夹壁）、自然（竹影/月光/雨声/雪）
- 服饰（官服/常服/江湖装束）、器物（茶具/文房四宝/烛台/灯笼/乐器）
- 称谓（陛下/殿下/大人/公子/姑娘/草民）、时间（时辰制/五更/年号）


## 九、速查表

### 常用诡计速查

| 要设计的谜题               | 可考虑的诡计方向                     | 古风剧本中的实现方式                                 |
| -------------------------- | ------------------------------------ | ---------------------------------------------------- |
| "凶手怎么进去/出来的？"    | 密室（机械/心理/建筑·夹壁暗道）      | 场景线索卡还原门闩/钥匙/夹壁；时辰线推理谁有作案窗口 |
| "凶手怎么有不在场证明？"   | 时辰误导/替身/延时毒药/行程伪造      | 时辰线表格比对；更夫×账册×驿站交叉验证               |
| "死者到底是谁？"           | 无面尸/易容/替身                    | 验状+纹身/胎记/旧疤/信物/家人认尸综合推理             |
| "凶手为什么查不到？"       | 盲点误导/前提错误/权谋压制          | 伪解答设计→颠覆前提→重新推理；权谋作为动机与阻力     |
| "银钗验毒为什么查不出？"   | 毒物选择（银钗只验硫化物）          | 选乌头/断肠草/曼陀罗等不显色毒药；以病掩毒             |
| "所有人都可疑，到底是谁？" | 暴风雪山庄/连环杀人/多案件串联      | 排除法逐轮锁定；多案件共享世界观收束                   |

### 古风本格核心公式

```
逻辑严谨的古风本格剧本 = 时代要素自洽 + 六要素闭环 + 自洽时辰线 + 物理可行手法 + 可推导线索链 + 唯一真相 + 完整排除法 + 知识自包含
```

### 剧本创作优先级（逻辑先行）

1. **先设计真相与诡计**——这是本格推理的灵魂
2. **再过逻辑框架**——六要素闭环、时辰线、物理可行性、时代要素排查（本库第二章）
3. **再设计角色和动机**——角色为案件服务，动机与身份、等级权限互检
4. **再反向设计线索链**——从真相反推，建"线索链总表"，确保推理路径完整且公平
5. **最后设计分幕与氛围**——知识自包含，信息流速合理，玩家体验顺畅

### A. 《洗冤集录》与仵作验尸

《洗冤集录》由南宋宋慈于淳祐七年（1247年）撰成，是世界上现存第一部系统的法医学专著。开篇强调："狱事莫重于大辟，大辟莫重于初情，初情莫重于检验。"检验官须事必躬亲、及时赴现场，不避尸气、不听仵作喝报。

**勘验现场**："告状切不可信，须是详细检验，务要从实。"先打量尸身所在四至高低、距参照物远近，记录现场，周围用灰印封存，交人看管并立字据。

**辨认身份**："其尸首有无雕青、灸瘢？旧有何缺折肢体及伛偻、拳跛、秃头、青紫、黑色、红志、肉瘤、蹄踵诸般疾状？皆要一一于验状声载。"——纹身、艾灸瘢、骨折、驼背、跛足、秃头、痣斑等特征须在验状上明确记载（这是古风身份识别锚点的文献依据）。

**案件性质**："凡验尸，不过刀刃杀伤与他物斗打、拳手殴击，或自缢、或勒杀，或投水、或被人溺死，或病患，数者致命而已。"

**尸斑（血坠）**：死后仰卧者项后、背上、两肋、后腰等处有微赤色，是血脉坠下所致，非他故身死。

**机械性窒息**：
- **缢死**：自缢伤痕"脑后分八字，索子不交"；勒喉上则口闭、牙关紧、舌抵齿不出，勒喉下则口开、舌尖出齿门；口吻两角及胸前有吐涎沫。
- **勒死**：与缢死不同在"项下绳索交过"，多在项后系定，须有系不尽垂头处。
- **溺死**：腹肚胀拍着响、手脚爪缝有沙泥、口鼻内有水沫。
- **外物压塞口鼻死**：窒息征象。

**动物破坏与生前伤鉴别**："凡人死后被虫、鼠伤，即皮破无血，破处周围有虫鼠啮痕……若狗咬，则痕迹粗大。"——死后伤与生前伤的鉴别是判断"是否死后伪造现场"的依据。

**验骨**：晴明蒸骨法、阴雨煮骨法、灌油检法、涂墨检法、新绵拂拭检法等。

**银钗验毒**："若验服毒，用银钗，皂角水揩洗过，探入死人喉内，以纸密封，良久取出，作青黑色，再用皂角水揩洗，其色不去。"——**注意：银钗主要对硫化物（砒霜类）敏感，对乌头、断肠草、曼陀罗等不显色**（§2.4、§3.7）。

**证据与口供**："证以物必得实焉"，不能听一面之词。即使罪犯招供，也要查出证据；罪犯不招供，物证确凿亦可定罪，一切须"据状断之"。

### B. 古代官制与刑律速查

**中央三法司体系**（隋唐确立）：大理寺主审判（隋唐）/复核（明清）、刑部主复核（隋唐）/审判（明清）、御史台（明清为都察院）主监察。明代"三法司曰刑部、都察院、大理寺"，重大疑难案件行三司会审。

**地方司法体系**：县级由县令主审（可决断笞杖，徒以上报上级复核），宋代州县初审由司理参军与县尉指挥仵作勘验；州/府复核；明清省级设提刑按察使掌刑名。

**命案审理流程**（据清代南部县档案）：百姓呈递状纸→县衙传签提讯→胥吏差丁勘查→验伤验尸→提取证据→控辩陈述→知县判词宣判→原被告及仵作各具甘结结案。县令带仵作与刑房差役查勘，仵作验一处报一处，县官亲验并取凶器与伤痕比对。

**证据制度**："据状断之"——以物证为主，口供为辅，须交叉核实（§2.4五类证）。
