## 一、西幻的定义与核心原则

### 1.1 什么是西幻推理

西幻推理以**剑与魔法/魔法王国/神系世界**为舞台的本格推理。核心公理与现代本格一致：**真相必须来自"线索 + 逻辑"，而非"灵感 + 权威"**。西幻本的特殊性在于：**这个世界的能力体系是开放的**——有人会施法、有人会炼魔药、有人受神恩、有人能变形、龙与魔兽真实存在。因此西幻本的第一铁律是**"魔法规则自洽"**：每个魔法/神术/魔药/龙语都必须有**明确的规则**（谁能用、施法成本、施法时间、范围、反制与魔抗），在规则内可推理、在规则内可破解。

**两条铁律**：

1. **"魔法是设定，推理仍须落地。"** 西幻的价值在于提供一个**规则自成一体、超自然高度系统化**的世界，让老诡计焕发新意——但魔法不能成为"不严谨的免罪符"。任何用"法术/魔药/神术/变形"解释真相的手段，都必须**先立规则并明示，再绑定可搜证的魔力痕迹**（见§2.7魔法要素排查）。
2. **西幻剧本必须"自己解释自己的世界"**：玩家对魔法学派、魔药成分、神系规则、龙语、炼金的认知参差不齐且多来自影视游戏，剧本内所有关键知识必须以设定说明或知识线索卡形式给出（见§2.4知识自包含），**不得依赖玩家自带西幻知识**。

### 1.2 西幻 vs 现代本格：证据体系差异

| 维度     | 现代本格                   | 西幻本格                                     |

| **验尸**     | 法医仪器 / 毒理化验        | 医师/炼金术士探查、魔力残留检测、圣职验圣、魔药毒理 |

| **通讯**     | 电话 / 网络 / 监控          | 传讯术 / 使魔 / 信鸦 / 魔法镜像（规则限制距离与施法者） |
| **门禁**     | 监控 / 门禁卡 / 智能锁      | 魔法锁 / 结界 / 禁咒 / 石门机关 / 守卫（含魔法守卫） |

> **核心推论**：西幻本格不是"有魔法更自由"，而是"**换了一套证据体系 + 加了一层魔法规则**"。西幻本的严谨性，取决于对魔法体系的规则使用是否自洽（§2.7魔法要素排查），以及每个魔法手段是否**留下可搜证的魔力/物理痕迹**（§2.3、§2.8）。

### 1.3 剧本杀公平原则（西幻适配十诫）

> **剧本杀的核心是"所有玩家共同参与的解谜游戏"**，而非单一侦探的破案故事。以下原则改编自诺克斯十诫和范·达因准则，例证按西幻语境改写：

| 编号 | 原则                   | 说明（西幻例证）                                                     |
| ---- | ---------------------- | ------------------------------------------------------------------ |
| 1    | **凶手必须在场**       | 凶手必须在游戏开始时已在场，且以公开身份登场——不能是"一位从未出场的上古法师"远程咒杀（远程手段须有规则与痕迹，见§2.7） |
| 2    | **线索全面呈现**       | 所有关键线索（魔法书、卷轴、魔药瓶、编年史、龙语刻文）必须在游戏过程中可被发现，不得在真相揭晓时才"补"线索 |
| 3    | **公平追凶**           | 每个玩家（包括凶手）搜证与发言权利对等；凶手可撒谎，但不能被系统保护 |
| 4    | **物理可行**           | 手法必须物理可行——不得用"法术随心""神罚万能""巨龙天降"等无规则超自然力量（设定系能力须先立规则并明示，见§2.3、§2.7） |
| 5    | **侦探不是凶手**       | 主持推理的"侦探"角色（皇家调查官/圣职者/炼金师若担任此职）不应是凶手——其他玩家角色可以是 |
| 6    | **身份诡计须提前暗示** | 变形术/易容/复方汤剂式伪装/亡灵复活/冒名顶替等身份诡计必须在游戏中提前给出暗示线索（真名记录、血脉测试、某人从不示人等） |
| 7    | **动机须有深度**       | 动机应与角色背景（王位/领地/信仰/复仇/夺宝/巨龙宝藏/家族荣光）一致且足以支撑谋杀——不能是"被诅咒疯了"或"一时冲动" |
| 8    | **人人有嫌疑**         | 每个角色（包括真凶）都应有合理动机与可疑之处，不让任何人过早被排除 |
| 9    | **关键线索唯一指向**   | 关键线索链最终应指向唯一的真凶，尽管中间存在魔法误导 |
| 10   | **不得隐藏证据**       | 主持人不得主动隐藏玩家已发现的证据——所有发现的线索都公开记录在线索板上 |

### 1.4 西幻在剧本杀中的特殊考量

## 二、逻辑严谨性核心框架（西幻适配）

> **创作任何西幻剧本，都应先过本框架，再考虑诡计与氛围。** 逻辑严谨 = 魔法规则自洽 + 六要素闭环 + 时间线自洽 + 魔力痕迹可搜证 + 线索可推导 + 真相唯一 + 知识自包含。

### 2.1 案件六要素闭环（西幻版）

一个合格的西幻案件必须形成"六要素闭环"。真相揭晓后，六要素彼此咬合、无相互矛盾；任一要素被推翻都会牵动其他要素重新检验。

| 要素   | 定义                 | 真相揭晓时必须回答的问题                                       | 西幻配套支撑证据                               | 常见漏洞                                     |
| ------ | -------------------- | ------------------------------------------------------------ | ---------------------------------------------- | -------------------------------------------- |
| **死因** | 致死原因与致死机制   | 死者怎么死的？刀剑/魔药/法术/神罚/怪物与死亡因果是否自洽？    | 医师/炼金师探查记录、魔力残留、魔药毒理、圣职验圣 | 死因与现场矛盾（"被诅咒而死"却无任何魔力或物理致死条件） |
| **手段** | 凶手实现死因的方法   | 用什么武器/魔药/法术/神术/怪物？每一步能力操作是否在规则内可行？ | 魔药瓶、卷轴灰烬、法术伤痕（烧伤/冻伤/电痕）、咏唱记录 | 无来源凶器、魔法"凭空施放"、诅咒无代价无限制 |
| **时机** | 死亡时间与作案时间窗 | 什么时辰死的？凶手在哪个时段动的手？是否利用月相/施法窗口/禁咒期？ | 尸温/尸僵、沙漏钟楼、月相记录、施法咏唱时长 | 死亡时间跨多个时辰使手法失效、咏唱时长对不上 |
| **机会** | 作案窗口的到达者     | 案发时段谁能接触现场与死者？谁能突破结界/魔法锁？谁被排除？  | 结界/魔法锁/守卫、钥匙与口令、施法能力（谁会魔法）| 排除不完整、未考虑传送/隐形/变形（须规则）     |
| **动机** | 杀人动因及其一致性   | 为何杀此人？为何此时杀？与角色背景是否自洽？                  | 王位/领地/信仰/复仇/夺宝/家族/教派利益        | 动机不足、动机与人物身份背景矛盾               |
| **身份** | 凶手/死者/涉事者真实身份 | 凶手是谁？死者是谁？是否涉及变形/易容/亡灵/冒名？          | 真名/血脉/圣痕/族谱/纹章/旧识认人             | 身份诡计无提前暗示、置换后行为与真实身份不符   |

**闭环校验法**（六要素两两互检）：
- **死因 × 手段**：该死因必须能由该手段产生。例如魔药致死须与药性/剂量对应；诅咒致死须有魔力规则与痕迹（§2.3）。
- **时机 × 机会**：死亡时辰窗口内，凶手必须"在场"或"可控"。若凶手有不在场证明（远征/施法无法脱身），必须存在能成立的"替代到场路径"（延时魔药/定时法术/使魔/变形——均须规则），否则矛盾。
- **动机 × 身份**：凶手的动机必须与其**真实身份**（而非变形/伪装后的"外壳"身份）的前史吻合。
- **手段 × 时机**：手法的执行时间必须落在作案窗口内；延时手段（慢性魔药/定时法术/机关）的精度必须支撑死亡时辰设定。
- 任何一处矛盾 = 剧本硬伤，须修正要素本身，**而非靠"魔法嘛，解释不通也正常"来掩饰**。

### 2.2 时间线一致性（西幻版）

**法则 1 · 计时体系自洽**：王国常用**沙漏/日晷/钟楼**计时，配以**月相**（新月/满月等）与**魔法时辰**（施法窗口）。全剧本须统一换算标准，不得出现时刻混用、月相算错的矛盾。沙漏、蜡烛精度各异，只能作**粗略**佐证；钟楼、宫廷档案、施法咏唱时长是较硬的计时源。

**法则 2 · 施法时间与咏唱**：法术有**咏唱时长**（从数秒到数刻）——"凶手是否有时间完成施法"是可检验的事实。咏唱被打断、施法材料不足、魔力不济都会导致施法失败，施法时间与作案窗口的匹配是机会推理的核心。

**法则 3 · 月相与魔法周期**：若设定魔法受月相/星辰/节气影响，须**全程守约**——满月才可用的传送术，新月夜不能凭空发动。周期规则既提供诡计窗口，也提供"谁熟悉周期"的信息来源推理。

**法则 4 · 交叉验证**：任一时段的证言/记录至少与一条独立信息源交叉印证：守卫日志 × 编年史、炼金账册 × 魔药瓶、教廷记录 × 圣职证词、钟楼记录 × 施法咏唱。无交叉的单方证词属"待证信息"，不能直接当铁证。

**法则 5 · 空白时段必须有解释**：角色"独处无证明"的时段，要么是推理的关键（嫌疑窗口），要么必须有非犯罪理由（研读魔法/去酒馆/私下交易），否则是漏洞。

**法则 6 · 系统性偏差才有说服力**：时间被篡改时，偏差必须来自可解释的系统（钟楼被停、宫廷档案被改、占星记录被伪造），并交代为何无人及时发现。临时、随意、无法解释的"对不上"是硬伤。

**构建步骤**：先写"客观物理时间轴"（死亡时辰定死）→ 再写每个角色的"主观时间轴"（各角色以为的时辰）→ 最后标注两者偏差及其来源，确保偏差线索可在游戏中被发现。

### 2.3 物理可行性验证（西幻版）

**工具三问**（对手段的每一步物理/魔法操作逐一过问）：
1. **工具从哪来？** 凶手必须有获得渠道——武器（铁匠/战利品）、魔药（药剂铺/炼金室/配方）、卷轴（法师塔/黑市）、法术（学派传承/自修）。线索须能指向该渠道。
2. **用后去哪了？** 凶器/魔药瓶/卷轴灰烬/法杖必须处置（带走/丢弃/藏匿/毁去/留在现场被误导），去向合理且可被追查（魔力残留可被侦测）。
3. **留下什么痕迹？** 使用必然产生痕迹——魔力残留（侦测魔法）、法术伤痕（烧伤/冻伤/电击/腐蚀）、魔药瓶与剂量、卷轴燃烬、咏唱的口供与记录。

**硬性标准**：
- 手法必须能在200字内说清，且以"设定规则 + 基本逻辑"可验证。
- **魔法边界**：写实向（低魔）本中，魔法视为"稀缺技艺"，**不得违背规则**（施法有咏唱/材料/魔力消耗、可被打断、有反制与魔抗）；设定系（高魔）本若需超常魔法，必须先立规则并明示（§2.7、§3.9）。
- **魔法手段必须留痕**：任何用"法术/神术/变形"实现的手法，都必须设计**对应的可搜证痕迹**（魔力残留、卷轴灰烬、法术伤痕、咏唱记录）——"无痕施法"是硬伤，除非立规则说明本世界的魔力如何被掩盖（掩盖手段本身要留痕）。
- **延时装置只有两类**：① 真正延时（慢性魔药/定时法术/机关/炼金装置）；② 心理延时（所有人误判死亡/离场时辰，实际凶手当时就在场）。写延时必须先归类，再验证该类别的**时间精度**是否足以支撑死亡时辰设定。

### 2.4 线索—推理映射（西幻版）

**证据类型**（西幻本五类证）：
- **物证**：凶器/法杖、魔药瓶、遗物、伤痕、卷轴灰烬、结界残件、遗书
- **人证**：守卫、仆从、修士、炼金师、医师、酒馆老板、信使的证词
- **书证**：魔法书、卷轴、编年史、宫廷档案、炼金账册、教廷记录、遗嘱
- **口供**：嫌疑人供词（须与物证/书证交叉）
- **验状**：医师/炼金术士/圣职探查记录（身份特征、死因、魔力状态——见§八验尸知识）

**线索三级**：
- **事实线索（F）**：直接陈述、无需推断即可采信（验状原文、编年史、魔药配方）。注意：事实线索"内容"可信，但"解读"仍可被误导（验状写"死于魔力侵蚀"是死因，但施术者是谁、如何施术仍需推断）。
- **推断线索（I）**：需结合设定/规则推断（魔力残留强度与施法者对应、魔药症状与配方对应、结界破坏方式与熟悉度、咏唱时长与窗口匹配）。
- **误导线索（R）**：指向伪解答（"神罚""龙灾""诅咒""亡灵复仇"），**必须在后期可被推翻或解释**，不能不了了之。

**西幻证据的局限（必须主动处理）**：
- **侦测魔法有边界**：侦测魔法（识破隐形/感知魔力）有范围、有消耗、可被反制（反侦测结界/魔抗）——"侦测魔法万能"是硬伤，侦测的边界要立规则。
- **真名/血脉可被术法遮蔽**：真名魔法、血脉测试可能被伪造或遮蔽——遮蔽手段（咒语/法器/人为）须留下可被发现的痕迹。
- **医师/炼金师验尸技术有限**：慢性魔药、心疾猝死可能被误判为"神罚/衰竭"——"以病掩毒、以神罚掩杀"是合法手段，但误判的暴露必须有线索。

**推理价值标注**：每条线索在创作时应标注——它单独证明什么？与哪条线索组合证明什么？为**排除**哪个可能性服务？无推理价值的线索不该出现（纯氛围线除外，且需控制数量）。

**链式推导要求**：
- 从"初始线索集"到"真凶"至少存在一条 **≥3 步的逻辑链**。
- 关键推理链的**每一步至少2条独立线索支撑**。
- 链的每一步都必须"可被反驳"且"存在反驳线索"——否则该步骤是霸王推理（单方面认定、不可检验）。

### 2.5 唯一性判定与完整排除法（西幻版）

在指认真凶之前，所有"他杀外可能"必须先被排除，且每个被排除项都要有**至少一条明确的排除线索**：

| 须排除的可能性       | 西幻排除线索示例                                       |
| -------------------- | ------------------------------------------------------ |
| 自杀                 | 遗书/遗言笔迹比对、现场无自伤工具、伤痕角度不符        |
| 意外                 | 现场无意外触发条件（坠塔却无攀爬/施法失败痕迹、误食却无中毒对象） |
| 病亡/衰竭            | 医师验状死因明确为他杀（非病非衰竭非自然死亡）         |
| 神罚/天罚            | 现场无圣力/神罚痕迹、无亵渎证据（神罚要可查证）        |
| 龙灾/魔兽/怪物       | 现场无兽痕/龙息/魔力残留、尸检与怪物咬伤不符（须归位到人或规则） |
| 无死亡（假死/亡灵）  | 真名/血脉/旧识认人确认身份、后续有该人未死的行为矛盾     |
| 外部闯入者作案       | 结界/魔法锁/守卫排除外来者、封闭场景设定               |
| 合谋 / 帮凶          | 涉案人员信息边界清楚、行动窗口逐一排查（如守卫"恰好"不在） |
| 死亡时辰被伪造       | 计时体系交叉验证（钟楼/月相/沙漏/施法咏唱/档案）       |

**唯一性检验**：给定全部线索，是否**只有一套**六要素自洽？若存在第二套同样自洽的解释（尤其"第二套 = 魔法/神罚/龙灾"），剧本就有逻辑漏洞——除非它是设计好的"伪解答"，而伪解答必须有反证线索（§3.9）。

### 2.6 反证检验流程（真相定型后必做）

把"真相"当作敌人，模拟最刁钻的玩家从五个角度攻击：

| 攻击角度       | 攻击问题                                                   | 被攻击即漏洞的情形                                     |
| -------------- | ---------------------------------------------------------- | ------------------------------------------------------ |
| **时间攻击**   | 凶手在X时辰做了Y，有没有任何证据/矛盾能推翻？              | 时辰制时间线上存在不可调和、无法解释的冲突             |
| **物理攻击**   | 手法每一步真的可行吗？法术/魔药/神术/机关是否违背规则或设定？ | 魔法超设定、诅咒无代价、魔药"万灵验出"、变形无视反制     |
| **信息来源攻击** | 凶手作案所需的"关键信息"（死者位置、时辰、钥匙/口令、结界、配方）从哪得知？ | 凶手不该知道却必须知道，且无获取渠道线索（如卷轴在法师塔而凶手无接触） |
| **动机攻击**   | 换成"自杀/意外/病亡/神罚/龙灾/嫁祸"能否同样解释现场？      | 排除项缺线索，真相无法唯一化                           |
| **公平性攻击** | 玩家在游戏中能否获得推导真相所需的**一切**信息（含西幻知识）？ | 关键信息在复盘时才补充、或依赖玩家自带奇幻知识         |

**修正策略**：漏洞无法用"补一句话"解决时，**宁可改动设定**（改手法/改时辰/改角色信息/改魔法档位），也不要保留逻辑漏洞。

### 2.7 魔法要素排查（西幻的"科技排查"）

创作西幻剧本，必须**先明确本世界的"魔法能力边界"**——有哪些魔法/神术/魔药，每种的规则是什么，没有哪些，且不得混用。

| 魔法要素 | 典型形态                                   | 对诡计的约束                                     | 可利用的破绽                                         |
| -------- | ------------------------------------------ | ------------------------------------------------ | ---------------------------------------------------- |
| **法术（学派）** | 火/冰/雷/预言/变形/亡灵/防护……             | 法术有学派、有咏唱、有材料、有魔抗              | 咏唱时长、施法材料、魔力残留、学派门槛（谁会哪派）  |
| **魔药**   | 治疗/毒药/迷药/变形药/隐形药/爱情药         | 魔药有配方、剂量、毒性、制作者                  | 魔药瓶、配方、炼金账册、症状（§3.7）                 |
| **神术/圣职** | 治疗/祝福/圣光/神谕/神罚                    | 神术受神职/信仰约束，有行为戒律                 | 圣职行为约束（不得说谎/不得伤害信徒）、教廷档案（§3.8） |
| **变形术** | 变人/变物/动物形态                           | 变形有施法成本、有反制（变形被识破/被逼回原形） | 变形留痕、恢复原形的时机、反变形咒（§3.3）           |
| **预言**   | 占卜/预知/神谕/观星                         | 预言有歧义、有限制、可被误导                    | 预言的应验与歧义、占卜记录、预言者立场（§3.8）       |
| **结界/魔法锁** | 防护结界/禁咒/魔法锁/封印                   | 结界有施法者、有维持消耗、可被破除              | 结界破损、施法者权限、破除痕迹（§3.1）               |
| **召唤/使魔** | 召唤魔兽/使魔/元素生物                       | 召唤有契约、有代价、有维持                      | 召唤印记、使魔目击、契约记录                         |
| **亡灵/不死** | 复活/亡灵/吸血鬼/不死者                      | 亡灵有规则（灵魂/契约/束缚），不是"死了又活随便" | 亡灵存在痕迹（圣痕/灵魂印记）、复活代价             |
| **龙与魔兽** | 龙/兽人/精灵/矮人/地精                     | 怪物有生态、有行为逻辑                          | 龙息/兽痕/物种特征、怪物目击（§3.9）                 |
| **真名/血脉** | 真名魔法、血脉印记、圣痕                     | 真名/血脉是不可伪造的身份锚点，但可被遮蔽      | 真名记录、血脉测试、遮蔽痕迹（§3.3）                 |

**三条铁律**：
1. **每个魔法/神术/魔药必须有规则**：谁能用、施法成本（咏唱/材料/魔力）、施法时间、反制与魔抗——四问缺一即"能力悬空"。**"法术随心""神罚万能""魔药全能"是硬伤**。
2. **每个魔法手段必须有可搜证痕迹**：魔力残留、法术伤痕、卷轴灰烬、魔药瓶、咏唱记录——能量/物理/记录三类痕迹至少留其一。**"无痕施法"若无规则与反制交代，即是漏洞**。
3. **设定档位必须守约**：高魔/低魔、硬设定/软设定不可混用（本世界"无传送术"却靠传送作案是硬伤）；越强的魔法代价越大、反制越多，须全程守约。

### 2.8 常见逻辑漏洞清单（西幻版避坑）

| 漏洞             | 表现                                                     | 规避方法                                         |
| ---------------- | -------------------------------------------------------- | ------------------------------------------------ |
| **法术随心**     | 想施什么法术就施什么，无咏唱/材料/魔力消耗             | 立规则：法术有学派/咏唱/材料/反制（§2.7铁律1）|
| **神罚万能**     | 神罚/诅咒想降谁降谁，无圣力验证、无亵渎证据            | 神罚有规则与证据，需可查证（§2.5、§3.8）       |
| **魔药全能**     | 一瓶魔药能毒/能迷/能变形/能解，无配方无剂量             | 魔药单一功能+配方+剂量+症状（§3.7）           |
| **变形无代价**   | 想变谁就变谁，无成本无反制                              | 变形有施法成本/反制/逼回原形（§3.3）          |
| **诅咒无痕**     | 诅咒杀人无魔力残留、无施法痕迹                          | 诅咒留魔力残留/施法记录/反咒破绽              |
| **预言无歧义**   | 预言直指真相、无歧义、无立场                            | 预言有歧义/可被误导/占卜者立场可查（§3.8）    |
| **龙灾无敌**     | 龙/怪物作案无需解释、来去自由                          | 龙与怪物归位到人或规则，留兽痕/龙息/目击（§3.9）|
| **亡灵无规则**   | 死者随便复活、亡灵随便行动                              | 亡灵有规则（契约/束缚/代价），非"死了又活随便"（§3.8）|
| **结界永固**     | "结界封锁"作为万能密室，永远打不开                      | 结界有施法者/维持消耗/破除方式（§3.1）        |
| **身份识别悬空** | 真名/血脉"恰好"都失效，身份无法核验                     | 设立可查验的身份识别锚点，失效须有遮蔽痕迹（§3.3）|
| **穿越矛盾**     | 现代器物/认知泄漏却无交代                               | 明确穿越/异界规则与限制                       |
| **知识依赖**     | 推理依赖玩家自带奇幻知识（懂魔法/懂魔药才盘得动）      | 关键知识以设定说明/知识线索卡给出（§2.4）      |
| **天降线索**     | 关键信息在真相揭晓时才首次出现                         | 线索前置、可搜证（§2.4）                     |
| **排除不完整**   | 忘了自杀/意外/病亡/神罚/龙灾/假死/帮凶/外部闯入等选项   | 过完整排除项清单（§2.5）                     |


## 三、核心诡计类型库（西幻适配）

### 3.1 魔法密室（Locked Room）

西幻密室与"结界/魔法锁/城堡石墙"密切相关——"被封印的密室""结界封锁的现场"是西幻特色，但**密室本身仍是物理/规则问题**：谁能在结界内进出、魔法锁如何绕过、结界如何被破除。

#### 密室的两大基本分类

| 类型                   | 说明                       | 关键特征                                   |
| ---------------------- | -------------------------- | ------------------------------------------ |
| **机械密室**（物理密室） | 通过机关、暗格、石墙、魔法锁实现密室 | 密室是真实的，凶手用物理/魔法手段完成 |
| **心理密室**（错觉密室） | 利用心理错觉制造密室假象（"结界还开着""没人敢闯国王的房间"） | 密室是假的——结界实际被绕过、门闩被从外拨动、或众人因权威不敢验证 |

#### 密室的形成者（剧本杀视角）

| 形成者         | 说明                                 | 在剧本杀中的实现                         |
| -------------- | ------------------------------------ | ---------------------------------------- |
| **凶手制造**   | 最常见的类型——凶手杀人后制造密室     | 凶手玩家需在搜证环节注意隐藏相关手法线索 |
| **死者制造**   | 自杀伪装成他杀，或死者无意制造密室   | 最终揭晓时需通过验状证明是自杀           |
| **帮凶制造**   | 第三人在案发后无意或有意制造密室条件 | 该角色有独立动机（保护某人/制造混乱）    |
| **结界/魔法锁制造** | 魔法结界让现场"看似封锁"，实则可绕行 | 绕行路径（结界破除/施法者权限/魔法漏洞）需可搜证 |

#### 密室讲义分类索引（西幻选型用）

| 编号 | 密室类型（卡尔分类简版）                           | 西幻实现示例                                 | 剧本杀适用性 |
| ---- | -------------------------------------------------- | -------------------------------------------- | ------------ |
| 1    | 案件实为意外/自杀，被误认为他杀                    | "神罚身陨""诅咒而死"实为自杀/意外           | ★★★ 高      |
| 2    | 机械机关：杀人后自动上锁                           | 石墙机关、魔法锁自动闭合、禁咒封锁           | ★★ 中       |
| 3    | 凶手作案时就在房间，事后混入人群或藏匿             | 藏身密室/夹层/幻象后，混入人群             | ★★★ 高      |
| 4    | 锁被做手脚（假锁/卡扣），实则任何人可开             | 魔法锁被临时解开/咒语被破，门闩被法术拨动   | ★★★ 高      |
| 5    | 用工具从外部或门下拨动门闩                         | 无形之手/魔法使魔从外开门（须施法规则）     | ★★ 中       |
| 6    | 死者自己锁门（自杀或误锁）                         | 死者自封结界/误触魔法锁封锁现场             | ★★★ 高      |
| 7    | 伪装他杀的意外（利用现场布置误导死因）             | 伪造"龙灾/神罚"现场掩盖意外/自杀             | ★★★ 高      |

#### 密室杀人的动机（剧本杀适用）

| 动机                 | 说明                             | 对应的剧本设计                         |
| -------------------- | -------------------------------- | -------------------------------------- |
| **伪装神罚/龙灾**    | 让密室看起来是神罚或怪物所致     | 现场痕迹需在后期被归位反证推翻         |
| **制造不在场证明**   | 让所有人以为死亡发生时无人能进出 | 时辰制时间线推理是破解关键             |
| **嫁祸给特定的人**   | 让某人有唯一"可能"作案的条件     | 嫁祸对象应有对应的自我辩护线索         |
| **掩盖真实手法或死亡时辰** | 密室本身是烟雾弹             | 玩家需跳出密室思考"为什么要做密室"     |
| **保护王权/教廷秘密** | 封锁现场以掩盖丑闻/圣物/阴谋     | 多重动机叠加，密室有第二重目的          |

**逻辑约束（重点）**：
1. 密室必须**"进、出、闭"三步都能解释**：凶手怎么进、怎么出、结界/门闩/锁怎么复原。
2. 心理密室必须交代**"门闩/结界被如何误认"**：是被魔法拨动、是结界临时解除又恢复、还是众人因权威不敢验证——误认机制本身要有线索。
3. **结界/魔法锁密室必须有"施法者与破除方式"线索**：结界有施法者、有维持消耗（魔力/法器）、有破除路径（咒语/反制/施法者死亡），且"谁能施/谁能破"的熟悉度要可查（§3.8）。
4. 制造密室必须比"不制造密室"更有利：找不到合理动机时，用"伪装神罚/龙灾"或"保护秘密"作为默认解释。

> **创作提示**：设计密室案时，顺序为——先问"凶手为什么要做密室"（动机）→ 再设计"怎么做的"（手法）→ 最后验证"怎么破除的"（破案线索）。**密室形成有解，破除也必须有解。**

### 3.2 不在场证明（西幻版）

#### 在剧本杀中的典型形式

| 形式             | 说明                                   | 破解方向                               |
| ---------------- | -------------------------------------- | -------------------------------------- |
| **远征/出巡作证** | 声称案发时在远征/出巡，无人能证       | 行军记录、信使书信、驿站记录、行程核算 |
| **施法/冥想作证** | 声称案发时在施法/冥想/作弥撒           | 咏唱记录、施法材料消耗、教廷值勤记录   |
| **守卫/值勤作证** | 守卫声称案发时见到某人经过             | 时辰误认、守卫被买通、换岗漏洞         |
| **档案/账册作证** | 编年史、宫廷档案、炼金账册显示在别处   | 记录被篡改/代笔/骑缝印被仿             |
| **使魔/信鸦作证** | 使魔或信鸦记录显示人在他处             | 使魔被操控、信鸦被拦截、记录伪造       |

#### 常见的"不在场证明破绽"类型

1. **时辰谎称**——守卫/仆从被误导，以为在某时辰看到了某人
2. **替身诡计**——变形术/易容/幻象冒充嫌疑人出现在别处（§3.3）
3. **书证伪造**——编年史、档案、账册被人为改动
4. **传送/变形**——看似不可能的距离其实可以做到（传送术/变形/魔法门，须施法规则与记录）
5. **共犯伪证**——两人或多人合谋提供虚假证词

#### 在剧本杀中设计不在场证明

**关键原则**：每个角色（包括真凶）都应有不在场证明。真凶的不在场证明必须"看起来合理但存在破绽"——且**破绽必须有线索**，而不是"天衣无缝"或"靠运气看穿"。

| 角色类型       | 不在场证明设计                                               |
| -------------- | ------------------------------------------------------------ |
| **真凶**       | 看似合理但有细微破绽的证明（如"我在作弥撒"——但圣堂地下有密道、或当夜圣堂根本闭门） |
| **其他嫌疑人** | 有真实的/部分真实的不在场证明，但各有隐瞒的理由（如"那夜我去和情人幽会所以不想说"） |
| **目击者**     | 可能错误地确认了时辰——不是故意的，是雨夜/烛光/魔法干扰/记忆偏差 |

**逻辑约束**：不在场证明的破绽必须**指向可搜证的位置**（行军记录、咏唱记录、编年史、结界日志、密道），玩家通过搜证+交叉对比可发现，而非依赖某角色"突然想起"。

### 3.3 身份诡计（变形术/真名/易容/亡灵复活）

> **⚠️ 提示**：叙述性诡计在剧本杀中**受限制**（玩家能看到角色卡），但身份置换类诡计**有天然优势**——玩家彼此看到的角色卡有限，信息不对称正是剧本杀的特征。西幻的变形术/真名魔法是身份诡计的"增强器"，但**必须立规则**。

#### 剧本杀中可用的身份诡计

| 类型             | 说明                                   | 实现方式                                         |
| ---------------- | -------------------------------------- | ------------------------------------------------ |
| **变形术**       | 变人/变物/变形态冒充他人                | 提前暗示变形术的存在、反变形手段（逼回原形）、某人从不示人 |
| **复方伪装**     | 通过魔药/法术完全改容（复方汤剂类）     | 魔药配方、材料采购、服药副作用（临时性）        |
| **真名/血脉冒认** | 冒用他人真名/血脉/贵族身份              | 真名记录、血脉测试、族谱/纹章、旧识认人          |
| **亡灵复活**     | 死者"复活"冒充生者（或冒充亡灵）        | 复活规则（契约/代价）、亡灵存在的痕迹（§3.8）   |
| **一人分饰两角** | 同一个人在不同场合使用两个身份           | 两个"角色"从不同时出现，玩家拼凑时辰线发现       |

#### 逻辑约束（重点）

1. **提前暗示原则**：诡计成立所需的事实（变形术的存在、魔药配方的可获取、某人从不以真面目示人、亡灵传说）必须在**游戏早期**有线索。
2. **置换后行为一致**：置换后的角色，其行为细节必须与**真实身份**（而非伪装身份）吻合——真实的语言、习惯、旧伤、对旧事的记忆是"无法完全伪装"的破绽细节，正是玩家的发现路径。
3. **身份识别锚点**：剧本中必须存在至少一条**不可伪造的身份识别线索**——真名（真名魔法可验）、血脉印记、圣痕、族谱/纹章（教廷/宫廷记录可查）。锚点的查验要有渠道，且**锚点失效须有遮蔽痕迹**（被术法遮蔽的残迹、记录被删的痕迹）。
4. **变形/伪装有反制**：变形术须有反制手段（逼回原形咒、魔抗、施法被打断）——"变形无代价、无识破方法"是硬伤（§3.8）。
5. **亡灵复活有规则**：亡灵/复活须有规则（灵魂契约、代价、束缚、时限），且**亡灵身份与生者身份的行为矛盾**是发现路径——"死了又活随便"是硬伤（§3.8）。

### 3.4 无面尸诡计（西幻版）

> **定义**：尸体面部被毁/焚毁/腐烂/被魔法破坏，身份无法直接辨认，"死者是谁"成为第一道谜题。西幻的"龙息焚尸""诅咒毁容""变形后死亡"自带合理性外衣。

#### 在剧本杀中的典型运用

| 步骤         | 游戏内实现                                | 设计要点                                        |
| ------------ | ----------------------------------------- | ----------------------------------------------- |
| **误导阶段** | 现场发现尸体+遗留物品→玩家推断死者是A     | 遗留物品必须明显指向A（A的纹章戒指/佩剑/信物）  |
| **发现矛盾** | 角色A的"目击"与尸体情况不匹配→触发怀疑    | A声称在某处看到谁/什么，与尸体状态冲突          |
| **真相揭示** | 线索显示尸体实际上是B                     | 通过真名/血脉/旧疤/圣痕/族谱/旧识认人揭示       |

#### 经典结构变体

| 变体             | 说明                           | 剧本杀适用                                 |
| ---------------- | ------------------------------ | ------------------------------------------ |
| **尸体是替身**   | 凶手杀了无关人士冒充特定死者   | 需要凶手有接触"替身"的渠道和机会（奴隶/雇佣兵/买来的亡人） |
| **尸体数量错误** | 实际死亡人数与发现的尸体数不同 | 多具尸体需在不同场景发现，玩家需统计比对   |
| **死者还活着**   | 某角色假死（借"下葬"消失）     | 该角色的"死亡"需有目击者（入殓人），但验状线索不完整 |

#### 逻辑约束（重点）

1. **必须有一条明确可靠的"身份识别锚点"**——真名、血脉印记、旧伤疤、特殊体态、刻字信物（家族戒指/佩剑）、圣痕、旧识认人。西幻无指纹/DNA，**锚点尤为关键**。
2. **"误认"必须有合理原因**：面部毁损、龙息焚尸、诅咒毁容、腐烂、家人"拒绝细看"（如指认者另有目的）——否则玩家会质疑"为什么认错了"。
3. **识别线索的取得时机**：身份识别线索要在"误导阶段"之后、"真相揭晓"之前**可被搜证获得**，形成"先误导→再证伪→后锁定"的推理弧线。

### 3.5 暴风雪山庄模式（西幻版）

#### 西幻封闭空间载体

| 载体         | 封闭方式                                       | 适用诡计               |
| ------------ | ---------------------------------------------- | ---------------------- |
| **城堡/王宫** | 吊桥升起、城门封锁、暴雪封山                   | 密室、连环杀人、权谋   |
| **魔法学院** | 结界封锁、学年封闭、禁咒屏蔽                   | 身份诡计、无面尸、魔法密室 |
| **秘境/位面** | 传送门失效、位面封锁、空间紊乱                 | 密室、宝藏、设定系     |
| **孤岛/灯塔** | 风暴断路、渡船沉没、传送被断                   | 身份诡计、时间诡计     |
| **地牢/墓穴** | 石门落锁、禁咒封锁、甬道封闭                   | 藏尸、无面尸、亡灵     |
| **龙巢/山脉** | 龙封山、风暴围困、险径被毁                     | 龙灾归位、阵营、替身   |

#### 逻辑约束（重点）

1. **凶手必须始终在幸存者中**；随着命案发生，嫌疑人集合必须**单调收缩**——不能中途出现"新到达者"（"传送门又开了"不成立）或"此前不在场者"被排除后又复活。
2. 每一起新的命案都要**收窄可能性**（排除法推进），而不是制造无关混乱。
3. 连环案件要么共享同一凶手逻辑（特征/模式/被害者关联/"仪式感"），要么明确揭示"第二凶手"，两者都需线索支撑。

### 3.6 时间诡计与延时装置（西幻版）

#### 在剧本杀中的典型形式

| 形式           | 说明                                     | 破解方向                             |
| -------------- | ---------------------------------------- | ------------------------------------ |
| **死亡时辰伪造** | 通过验尸误导/魔法干预让死亡时辰提前或推后 | 验状线索+环境线索（魔力残留/尸冷/月相）比对 |
| **施法窗口伪装** | 咏唱/施法时段作为"无法脱身"的伪装窗口    | 咏唱记录、施法材料消耗、目击证词    |
| **时辰线交错** | 两起事件的先后顺序被混淆                 | 目击证词交叉比对、物理痕迹的时序     |
| **延时杀人**   | 凶手动手后延迟死亡，制造不在场证明       | 凶器/机关的延时机制线索             |

#### 西幻延时手段

| 延时手段       | 原理                                   | 精度与注意                                             |
| -------------- | -------------------------------------- | ------------------------------------------------------ |
| **慢性魔药**   | 低剂量累积/迟发毒，延迟发作            | 发作时辰窗口宽，是"不在场证明"的经典手段               |
| **定时法术**   | 延迟触发的法术（魔力节点/咒语预设）    | 需交代施法者来源与触发条件                             |
| **炼金装置**   | 定时机关（沙漏触发/酸蚀熔断）          | 需留装置残件与制造痕迹                                 |
| **使魔/傀儡**  | 使魔定时动作（须契约/操控规则）        | 使魔来源、操控痕迹、契约记录                           |
| **魔法幻象迟发** | 幻象掩盖死亡时刻（"以为死了/没死"）   | 幻象规则与破除，施法者痕迹                             |

#### 逻辑约束（重点）

1. **偏差必须有系统来源**（§2.2法则6）：谁停了钟楼、何时改的档案、为何无人发现，都要有交代。
2. **延时必须归类并验精度**：真延时（慢性魔药/定时法术/炼金装置）or 心理延时（误判在场者）。真延时要验证时间精度能否支撑设定。
3. **死亡时辰伪造必须有验尸依据**：用什么手段误导了验尸结论（魔力残留被清除、尸僵被破坏、环境保温/降温），该手段本身要留下可被发现的痕迹。
4. **施法窗口必须可验证**：咏唱时长、施法材料、魔力消耗、施法被打断——"施法万能护盾"不成立。

### 3.7 魔药与炼金诡计（西幻特色）

> 魔药是西幻本最富特色的手段板块。其逻辑核心在两点：**魔药与药性/剂量的对应关系**、**魔药的来源与制作者**（见§2.4）。

#### 魔药诡计速查表（含逻辑约束）

| 魔药         | 功效/毒性                                 | 验尸/症状对应     | 发作特性       | 来源渠道                     | 典型伪装                       |
| ------------ | ----------------------------------------- | -------- | -------------- | ---------------------------- | ------------------------------ |
| **毒药**     | 剧毒（夜枭草/狼毒/龙胆毒）               | 症状与毒理对应 | 急性或迟发     | 药剂铺、炼金室、草药师       | 混入酒菜、伪装药膳             |
| **迷药/昏睡** | 昏睡/致幻，类似颠茄类                     | 瞳孔/脉象异常 | 中等         | 药剂铺、黑市、炼金师         | 混入茶水、伪装香薰             |
| **变形药**   | 变人/变物形态（复方汤剂类）               | 服药后形态改变、有时限 | 依配方     | 炼金室、禁书配方             | 伪装成正常饮料，副作用暴露     |
| **隐形药**   | 短时隐形                                 | 隐形药残留（魔药瓶/气味） | 短时         | 炼金室、秘方                 | 作案后隐形逃脱（须时限与反侦测） |
| **爱情药**   | 魅惑/操控情感                             | 心神被控、行为异常 | 依剂量     | 黑市、魅魔传闻               | 伪装成礼物/香膏（须规则：非万能操控） |
| **炼金产物** | 腐蚀液/爆炸物/点金石                     | 腐蚀痕/爆炸残骸 | 依成分     | 炼金台、禁忌实验             | 伪装成意外事故（酸蚀/爆炸）    |

#### 逻辑约束（重点）

1. **魔药必须有药性/剂量对应**：每种魔药的症状与效果必须与配方、剂量一致——毒药的症状、迷药的致幻、变形药的时限不能张冠李戴（§2.4）。
2. **来源渠道**：凶手必须有获得魔药的渠道（药剂铺/炼金室/配方/黑市/草药师），线索须能指向该渠道。禁药（龙胆毒/黑市秘方）被普通角色持有即需解释。
3. **急/慢性决定在场性**：急性毒凶手须在场或近场；慢性/迟发毒可制造不在场证明——魔药的发作特性必须支撑凶手的机会设定（§2.1时机×机会）。
4. **以病掩毒/以神罚掩杀**：魔药中毒被误判"神罚/衰竭"、真病被误判中毒——都是合法手段，但误判的暴露必须有线索（药渣、配方、症状细节）。
5. **魔药知识自包含**：配方、药性、剂量、禁忌搭配必须以设定说明/知识线索卡给出——玩家不需要懂炼金也能盘，懂魔药反而是误导陷阱（§2.4）。

### 3.8 魔法与神术诡计（西幻特色）

> 魔法与神术是西幻本区别于其他题材的**独特证据体系**。其推理价值在于：**魔法有规则、有施法者、有痕迹**——结界是"密室"的载体，变形是"身份诡计"的载体，预言是"误导"的载体，神术受信仰约束。

#### 魔法诡计速查（含逻辑约束）

| 魔法类型     | 功能                                     | 诡计用途                                       | 逻辑约束                                     |
| ------------ | ---------------------------------------- | ---------------------------------------------- | -------------------------------------------- |
| **结界/魔法锁** | 封锁、防护、封印                         | 密室载体、进出权限（§3.1）                    | 有施法者/维持消耗/破除方式，可搜证          |
| **变形术**   | 变人/变物/变形态                         | 身份诡计（§3.3）                              | 有施法成本/反制/逼回原形，可搜证            |
| **预言/占卜** | 预知、占卜、观星                         | 误导（预言歧义/占卜者立场）（§3.9）           | 预言有歧义/可被误导/占卜者立场可查          |
| **诅咒**     | 下咒、厄运、束缚                         | 手段与延时（诅咒须归位到规则）                | 诅咒有魔力残留/施法记录/反咒破绽            |
| **神术/圣职** | 治疗/祝福/圣光/神罚                      | 神罚误导（§3.9）、圣职行为约束（动机/阻力）   | 神术受神职/信仰约束，有行为戒律            |
| **召唤/使魔** | 召唤魔兽/使魔/元素生物                   | 不在场证明（使魔作证）、手段                  | 召唤有契约/代价/维持，契约记录可查          |
| **亡灵/不死** | 复活/亡灵/吸血鬼                         | 身份诡计（亡灵冒充）、无面尸（§3.4）          | 亡灵有规则（契约/束缚/代价），非"随便复活" |
| **隐形**     | 短时隐形                                 | 不在场证明、潜入                               | 有时限/有反侦测（识破隐形），施法留痕       |

#### 神术与圣职的推理化（核心）

| 神术推理点     | 说明                                                         |
| -------------- | ------------------------------------------------------------ |
| **圣职行为约束** | 圣职者不得说谎/不得伤害信徒/不得亵渎——行为戒律既是动机（破誓）也是破绽（圣职不可能说某谎） |
| **神罚可查证**   | "神罚"必须留圣力痕迹/亵渎证据，且圣职者验圣是"人证"非"铁证"——神职者有立场（护教/灭口） |
| **教廷档案**     | 忏悔记录（保密但可被撬）、受洗记录、圣痕查验——教廷是书证/人证的富矿 |
| **预言者立场**   | 占卜师/先知有立场与局限——预言是"人证"，其解读可被误导 |

#### 逻辑约束（重点）

1. **每个魔法必须有规则与痕迹**：施法者、施法成本、施法时间、反制、魔力残留——五问缺一即"能力悬空"（§2.7铁律1、2）。
2. **结界/魔法锁必须有施法者与破除方式**："无解的结界密室"是硬伤（§3.1）。
3. **变形术有反制**：变形可被逼回原形、可被识破（魔抗/反变形咒），伪装不是永久的（§3.3）。
4. **预言是误导不是铁证**：预言有歧义、可被应验方式误导、占卜者立场可查——"预言直指真凶"是硬伤（§3.9）。
5. **神罚可查证**：神罚须留圣力痕迹与亵渎证据，圣职者的解释是"人证"可被质疑（§2.5排除项）。

### 3.9 误导与伪解答工程（西幻版）

**红鲱鱼设计原则**：

| 原则         | 说明                                         |
| ------------ | -------------------------------------------- |
| **有独立价值** | 即使不指向真凶，也揭示了某个角色的秘密或动机 |
| **合理存在**   | 不是凭空出现——与该角色的行为/背景一致        |
| **可被推翻**   | 后续有线索可推翻该误导，而不是"不了了之"     |
| **不过度集中** | 不要把大部分误导线索集中在同一个非真凶角色上 |

**西幻常见误导源**：
- **神罚/诅咒**：引导玩家认为是"亵渎遭神罚/被诅咒而死"——归位到毒/机关/人心（§2.5排除项）。
- **龙灾/魔兽/怪物**：引导玩家认为是"龙/兽人/魔兽袭击"——归位到人（兽痕伪造/怪物生态规则）或设定系规则的明示（§3.9）。
- **预言/神谕**：引导玩家认为"预言应验了，命运注定"——预言有歧义，解读被利用（§3.8）。
- **亡灵/诅咒复仇**：引导玩家往"亡灵索命"方向想，掩盖真实动机（或用亡灵传说掩盖"根本没死"）。
- **家族/教派旧怨**：用陈年旧事、世仇、教派斗争分散注意力，掩盖当下动机。

**伪解答设计**：一个表面上能解释所有线索的"假真相"。西幻本的伪解答天然是**"魔法解释"**——神罚/龙灾/诅咒/预言都能圆上，所以西幻本对伪解答的要求更高：
- 伪解答必须能**暂时覆盖**绝大多数线索；
- 伪解答必须有**至少一条反证线索**（"魔法归位"的那条规则/痕迹），且该线索在游戏后期可被搜证获得；
- 伪解答被推翻的瞬间 = "恍然大悟"时刻——**从"神罚/魔法"落到"规则与人心"的那一下**，是西幻本的爽点。

**逻辑约束**：伪解答数量建议 **1–2 个**。每个伪解答的推翻线索要与真凶推理链**共用线索、互相咬合**，而非另起炉灶。

#### 误导的进阶形态：前提错误型

> **最高明的误导不是让玩家"想错答案"，而是让玩家"一开始就想错了问题"。** 一旦"死者是谁"或"是不是谋杀"这一前提错误，所有后续推理都失去根基。

典型：**无面尸 + 身份误认**（§3.4）、**伪解答依赖错误前提**（如"现场是结界封锁的密室"这个前提本身错了——其实结界根本没开）。破绽点在于：推翻前提的那条线索（如"结界施法者其实已死""死者其实是B""那晚结界被临时解除过"）必须是**玩家可主动质疑、可搜证验证**的。


## 四、经典案例解析（逻辑严谨性视角）

以下案例解析侧重于"这个作品在**逻辑上为什么成立**"以及"如何转化为西幻剧本杀设计"，供创作时参考。解析基于各作品公开的剧情设定与复盘要点，不涉及未公开的细节。

### 4.1 案例一：《哈利·波特》——魔法规则的教科书

| 项目         | 内容                           |
| ------------ | ------------------------------ |
| **类型**     | 西幻 / 魔法学校 / 成长悬疑     |
| **核心亮点** | 魔法体系的规则自洽（施法/魔药/变形/预言） |

**结构**：霍格沃茨的成长悬疑——密室、魔药、变形、预言、魂器贯穿多部；魔法世界的规则（魔杖、咒语、变形术、复方汤剂、预言球）高度系统化。

**逻辑上为什么成立**：
- **魔法规则系统化**：每个法术有施法方式、魔杖、咒语、效果边界；复方汤剂是"身份诡计"的完美载体（有时限、需材料、可被识破）（§3.3、§2.7铁律1）。
- **密室的可破性**：密室无论多"魔法"，都有进入/破解的路径与线索（蛇语、钥匙、机关）（§3.1）。
- **预言有歧义**：预言（如预言球）有歧义、被应验方式误导、预言者立场可查（§3.8）。

**剧本杀借鉴价值**：

| 借鉴点           | 说明                                             |
| ---------------- | ------------------------------------------------ |
| **魔法规则系统化** | 法术有施法/材料/边界，防"法术随心"              |
| **变形伪装有破绽** | 复方汤剂类伪装有时限、需材料、可被识破           |
| **密室可破**     | 魔法密室必有进入/破解路径                        |
| **预言歧义**     | 预言可作误导，有歧义与立场                       |

### 4.2 案例二：《指环王》——至尊魔戒的设定规则

| 项目         | 内容                              |
| ------------ | --------------------------------- |
| **类型**     | 高魔西幻 / 神器 / 阵营           |
| **核心亮点** | 至尊魔戒"设定规则"的严格自洽     |

**结构**：至尊魔戒有其"规则"——只有末日火山能销毁、诱惑佩戴者、扭曲佩戴者意志——整个故事建立在"魔戒规则"之上。

**逻辑上为什么成立**：
- **神器有严格规则**：魔戒不可被常规手段销毁、诱惑有程度、作用有边界——设定自洽让"神器"不沦为"万能工具"（§2.7铁律1）。
- **诱惑/操控是动机深度**：魔戒的诱惑是"人心的腐蚀"——动机来自设定与人心，可转化为可查证的"追求权力者"（§2.1动机）。
- **任务逻辑=长链推理**：销毁魔戒的每一步（行程、路线、不可抗力）构成可检验的推进逻辑。

**剧本杀借鉴价值**：

| 借鉴点           | 说明                                     |
| ---------------- | ---------------------------------------- |
| **神器规则化**   | 圣物/神器有严格规则，不沦为万能工具     |
| **诱惑动机**     | 权力/圣物诱惑作为动机深度               |
| **设定自洽**     | 核心设定（魔戒/圣物）全程守约            |

### 4.3 案例三：《冰与火之歌》——权谋与魔法的双线

| 项目         | 内容                             |
| ------------ | -------------------------------- |
| **类型**     | 低魔西幻 / 权谋 / 预言 / 龙     |
| **核心亮点** | 权谋动机 + 魔法误导（预言/复活） |

**结构**：维斯特洛的权力游戏——绿之视野、红祭司复活、龙都是"魔法元素"，但主线是权谋与人心。

**逻辑上为什么成立**：
- **权谋是硬动机**：王位、领地、血脉、家族利益——权力格局决定谁"必须死"、谁"不敢查"（§3.8道统式权谋）。
- **预言/异象是误导源**：绿之视野、预言有歧义、可被应验方式误导——预言不是铁证（§3.8）。
- **龙是"规则化超凡"**：龙的设定（只有坦格利安血脉可御、龙食人、龙有生态）有规则有边界（§2.7铁律1）。

**剧本杀借鉴价值**：

| 借鉴点           | 说明                                   |
| ---------------- | -------------------------------------- |
| **权谋动机**     | 王位/领地/血脉作为可查证的硬动机      |
| **预言误导**     | 预言/异象有歧义，可被利用             |
| **超凡规则化**   | 龙/复活等超凡有规则与边界              |

### 4.4 案例四：《巫师》系列——怪物生态与炼金

| 项目         | 内容                              |
| ------------ | --------------------------------- |
| **类型**     | 暗黑西幻 / 猎魔人 / 炼金         |
| **核心亮点** | 怪物生态规则 + 魔药/炸弹/徽章     |

**结构**：猎魔人杰洛特接取怪物契约——每种怪物（食尸鬼/狼人/女巫）有生态、弱点、行为逻辑；魔药与炸弹（炼金）是猎魔人手段。

**逻辑上为什么成立**：
- **怪物生态规则化**：每种怪物有习性、弱点、行为逻辑——"怪物作案"可推理（兽痕/习性/目击），不是万能的（§3.9、§2.5排除项）。
- **炼金规则化**：魔药有配方、毒性（过量致幻）、来源；炸弹/陷阱有制造痕迹（§3.7）。
- **契约/悬赏动机**：怪物契约、王室委托构成可查证的任务动机。

**剧本杀借鉴价值**：

| 借鉴点           | 说明                                     |
| ---------------- | ---------------------------------------- |
| **怪物生态规则** | 怪物有习性/弱点/行为，可推理非万能      |
| **炼金证据链**   | 魔药配方/毒性/来源构成物证书证          |
| **契约动机**     | 悬赏/契约/委托作为硬动机                |

### 4.5 案例五：《龙枪编年史》——神系与圣职规则

| 项目         | 内容                              |
| ------------ | --------------------------------- |
| **类型**     | 高魔西幻 / 多神系 / 圣职         |
| **核心亮点** | 多神信仰、神术规则、月之魔法     |

**结构**：克莱恩大陆的多神体系（善良/中立/邪恶三面神）与月之魔法——圣职者神力来源、月相影响魔法强弱。

**逻辑上为什么成立**：
- **神系规则化**：多神体系有神职、有信仰要求、有行为约束——圣职者神力"受信仰/戒律约束"，不是神恩万能（§2.7铁律1、§3.8）。
- **月相影响魔法**：月之魔法强弱随月相变化——周期规则既是诡计窗口也是"谁熟悉周期"的信息来源（§2.2法则3）。
- **信仰动机**：神职、教派之争、圣物归属构成可查证的动机与证据（教廷档案/圣痕）。

**剧本杀借鉴价值**：

| 借鉴点           | 说明                                     |
| ---------------- | ---------------------------------------- |
| **神系规则化**   | 圣职者神力受信仰/戒律约束，非神恩万能   |
| **周期魔法**     | 月相/周期作为时间诡计窗口               |
| **教廷证据**     | 教廷档案/圣痕/受洗记录作为书证人证       |

### 4.6 案例六：《纳尼亚传奇》——异世界规则与时间流速

| 项目         | 内容                              |
| ------------ | --------------------------------- |
| **类型**     | 西幻 / 异世界 / 平行世界         |
| **核心亮点** | 异世界规则自洽、时间流速差异     |

**结构**：衣柜通向纳尼亚，不同世界的时间流速不同（纳尼亚数十年、现实片刻）——平行世界规则与时间差异构成设定核心。

**逻辑上为什么成立**：
- **异世界规则自洽**：纳尼亚有自己完整的世界规则（创世神话、物种、法则）——设定自洽是异世界推理的基础（§2.7铁律3）。
- **时间流速差异=终极时间诡计**：两界时间流速不同——"不在场/在场"的时间线因流速而重构，是时间诡计的极端形态（§3.6），但流速差异必须立规则、可验证（§2.2法则1）。

**剧本杀借鉴价值**：

| 借鉴点           | 说明                                     |
| ---------------- | ---------------------------------------- |
| **异世界规则**   | 平行世界/异界设定需自洽守约             |
| **时间流速诡计** | 两界流速差异作为时间诡计，须立规则       |
| **设定自洽**     | 完整世界规则（物种/法则/神话）           |

## 六、西幻剧本创作流程框架（逻辑先行）

> **顺序不可颠倒**：先定真相与魔法档位、再过逻辑框架、再设计角色与线索，最后才排版分幕。

| 步骤 | 工作内容                                     | 产出物 / 验证点                                           |
| ---- | -------------------------------------------- | ---------------------------------------------------------- |
| 1    | **定义案件真相**                             | 西幻六要素初稿：死因/手段/时机/机会/动机/身份（§2.1）     |
| 2    | **六要素闭环验证**                           | 两两互检（§2.1），修正任何一处矛盾                         |
| 3    | **魔法要素排查**                             | 定档位（高魔/低魔/硬设定/软设定，§2.7）；过§2.7表，明确魔法/神术/魔药能力边界 |
| 4    | **魔法痕迹设计**                             | 每个魔法手段绑定可搜证的魔力/物理/记录痕迹；规则先立并明示（§2.3、§2.7） |
| 5    | **时间线设计**                               | 时辰/钟楼主时间线 + 月相/施法窗口核算 + 每角色个人时间线 + 交叉验证（§2.2） |
| 6    | **手法物理验证**                             | 工具三问 + 魔法/魔药/神术/机关边界验证（§2.3、§3.7、§3.8） |
| 7    | **反向设计线索链**                           | 从真相反推：需要哪些线索支撑每一步推导，标注推理价值与排除功能（§2.4） |
| 8    | **分配线索与分幕**                           | 线索分幕/分区域发放，关键线索冗余≥2；西幻知识自包含（§2.4）   |
| 9    | **反证检验与逻辑自检**                       | 过§2.6五角度攻击 + §七自检清单                            |

## 七、逻辑自检清单（西幻版）

### 7.1 逻辑闭环检查
- [ ] 六要素（死因/手段/时机/机会/动机/身份）两两互检无矛盾
- [ ] 死因与现场表现一致（无"被诅咒而死却无任何魔力或物理致死条件"类矛盾）
- [ ] 凶手作案所需的关键信息均有获取渠道（钥匙/口令、时辰、结界、配方）
- [ ] 存在完整排除项（自杀/意外/病亡/神罚/龙灾/假死/外部闯入/合谋/时辰伪造均被排除且各有线索）

### 7.2 时间线检查（时辰/钟楼/月相）
- [ ] 时辰/钟楼/月相/施法咏唱换算统一无误
- [ ] 主时间线物理自洽，所有记录/证词/值勤可叠加
- [ ] 每个角色有时间线，空白时段有解释
- [ ] 任一证言至少与一条独立信息源交叉验证（守卫×编年史×炼金账册×教廷记录）
- [ ] 时辰篡改类诡计有系统性来源 + 无人发现的合理理由
- [ ] 施法/冥想窗口可验证（咏唱记录/材料消耗/值勤），非万能护盾

### 7.3 物理可行性检查（西幻器物）
- [ ] 手法200字内可描述清楚
- [ ] 工具三问全部通过（来源/去向/痕迹）
- [ ] **每个魔法手段绑定可搜证痕迹**（魔力残留/法术伤痕/卷轴灰烬/魔药瓶至少其一）
- [ ] **每个魔法/神术有规则**（施法者/成本/时间/反制/魔抗五问全过）
- [ ] 延时装置已归类（真延时/心理延时）且精度验证通过
- [ ] 密室"进、出、闭"三向都有解；结界有施法者与破除方式
- [ ] 魔药症状与配方对应；变形/预言/神术/亡灵有规则与痕迹

### 7.4 线索公平性检查
- [ ] 所有关键线索在游戏过程中可被搜证获得（无天降线索）
- [ ] 关键推理链≥3步，每步≥2条独立线索支撑
- [ ] 每条线索标注了推理价值（无推理价值的线索已删除或转纯氛围）
- [ ] 身份诡计有提前暗示，且存在至少一条不可伪造的身份识别锚点（真名/血脉/圣痕/族谱）
- [ ] 每条魔法误导（神罚/龙灾/诅咒/预言）有归位反证
- [ ] 推理所需西幻知识已写入剧本（知识自包含，§2.4）

### 7.5 唯一性检查
- [ ] 给定全部线索，只有一套六要素自洽
- [ ] 伪解答（若有，尤其"魔法解释"）能被明确反证线索推翻
- [ ] 排除法穷举了所有"他杀外可能"（含神罚/龙灾/亡灵）
- [ ] 合谋/帮凶的信息边界清晰（谁、何时、知道多少）

### 7.6 魔法要素检查
- [ ] 档位（高魔/低魔/硬设定/软设定）已定且全程守约
- [ ] 无"法术随心""神罚万能""魔药全能"（能力悬空）
- [ ] 能力局限已处理（侦测魔法有边界/真名血脉可被遮蔽但留痕/魔药有剂量毒性）
- [ ] 设定档位无混搭（无传送术却靠传送作案等硬伤）
- [ ] 角色行为权限与身份/施法能力一致（谁能进圣殿、谁掌结界口令）

### 8.2 元素清单

**魔法规则元素**：
- 学派（火/冰/雷/预言/变形/亡灵/防护/幻术）——见§附录A，施法有咏唱/材料/魔力/反制
- 法术（攻击/防御/辅助/幻术/诅咒）——施法成本、范围、魔抗
- 结界/魔法锁/禁咒——施法者、维持消耗、破除方式（§3.8）
- 隐形/传送——时限、反侦测、施法留痕

**魔药与炼金元素**：
- 毒药/迷药/变形药/隐形药/爱情药——配方、剂量、症状（§3.7）
- 炼金产物（腐蚀液/爆炸物/点金石）——制造痕迹、来源
- 配方/材料/禁忌搭配——知识自包含（见§附录B）

**神系与圣职元素**：
- 多神神系（神职、信仰要求、行为戒律）——圣职者神力受约束（§3.8）
- 神术（治疗/祝福/圣光/神罚）——神罚可查证、圣职可质疑
- 教廷档案/受洗记录/圣痕/忏悔记录——书证与人证

**身份诡计元素**：
- 变形术 → 需提前铺垫变形术存在、反制（逼回原形）
- 魔药伪装（复方汤剂类）→ 需提前铺垫配方/材料/副作用
- 真名/血脉冒认 → 需通过真名记录/血脉测试/族谱/旧识认人
- 亡灵复活 → 需规则（契约/代价/束缚）与行为矛盾
- 一人分饰两角 → 需通过"两人从不同时出现"的时辰线揭示

**时间诡计元素**：
- 死亡时辰伪造 → 需通过验状+环境线索（魔力残留/尸冷/月相）比对
- 施法/冥想窗口 → 需通过咏唱记录/材料消耗/值勤验证
- 时辰线交错 → 需通过目击证词交叉比对
- 延时杀人 → 需通过延时机制线索（慢性魔药/定时法术/炼金装置）揭示
- 月相周期 → 需通过月相记录与魔法规则对照

**氛围元素**：
- 建筑（城堡/钟楼/圣殿/地牢/龙巢）、自然（雾/雨/月/风暴）
- 器物（法杖/魔药瓶/卷轴/龙鳞/圣杯/烛台/沙漏）
- 声音（钟声/龙啸/咏唱/脚步声）、时间（钟楼/月相/魔法时辰/契约日）

| "凶手怎么进去/出来的？"    | 密室（机械/结界·魔法锁/心理）       | 结界施法者/破除方式还原；时辰线推理谁有权限          |

| "死者到底是谁？"           | 无面尸/变形/亡灵/冒名               | 真名+血脉/圣痕/旧识认人综合推理                      |
| "是神罚还是谋杀？"         | 魔法归位（规则/痕迹）                | 验状排除神罚/龙灾/亡灵；魔药归位到人                 |
| "魔法怎么会生效？"         | 能力规则（施法/代价/反制/魔抗）      | 魔法留魔力残留/卷轴灰烬/咏唱记录                     |

| "所有人都可疑，到底是谁？" | 暴风雪山庄/连环杀人/城堡封锁         | 排除法逐轮锁定；施法窗口/结界收窄嫌疑人              |

### 西幻核心公式

```
逻辑严谨的西幻剧本 = 魔法规则自洽 + 六要素闭环 + 自洽时辰/月相线 + 魔力痕迹可搜证 + 物理可行手法 + 可推导线索链 + 唯一真相 + 完整排除法 + 知识自包含
```

### 剧本创作优先级（逻辑先行）

1. **先设计真相与诡计**——这是本格推理的灵魂；西幻本的真相必须"魔法规则自洽"
2. **再过逻辑框架**——六要素闭环、时辰/月相线、物理可行性、魔法要素排查（本库第二章）
3. **再设计角色和动机**——角色为案件服务，动机与身份、施法权限互检
4. **再反向设计线索链**——从真相反推，建"线索链总表"，确保每个魔法误导都有归位反证
5. **最后设计分幕与氛围**——知识自包含，魔法规则先立后写，玩家体验顺畅


## 附录：西幻专业知识速查（创作调用）

> 供创作时直接引用，保证魔法、魔药、神系等设定**规则自洽**。使用时须结合§2.7魔法要素排查，确认与所选档位一致。

### A. 魔法学派与施法规则速查

**常见魔法学派**（不同作品自定体系，剧本须自订并守约）：
- **防护学**：护盾、防护结界、反制——防御魔法，有维持消耗。
- **咒法学**：远程法术（火/冰/雷/风）——攻击法术，有咏唱与材料。
- **预言学**：占卜、预知、侦测——预言有歧义、有限制。
- **变形学**：变人/变物/变形态——变形有成本、可被反制。
- **亡灵学**：复活、亡灵、死亡——受禁忌约束、有代价。
- **幻术学**：幻象、隐形、迷惑——幻象可被识破、有施法痕迹。
- **神术（圣职）**：治疗、祝福、圣光、神罚——受信仰/戒律约束。

**施法规则（设定系推理的关键）**：
| 规则项       | 说明                                             | 推理价值                     |
| ------------ | ------------------------------------------------ | ---------------------------- |
| **咏唱时长** | 法术从开始咏唱到生效的时间                       | 与作案窗口匹配（§2.2法则2）  |
| **施法材料** | 施法所需材料（粉尘/符文/施法物）                | 材料来源可查（§2.3工具三问） |
| **魔力消耗** | 施法耗损魔力，过度施法会虚脱/反噬                | "无代价施法"是硬伤           |
| **反制/魔抗** | 法术可被反制（反咒）、目标有魔抗                 | "无法反制的魔法"是硬伤       |
| **学派门槛** | 不同学派需不同天赋/传承                          | "谁属于哪派"是信息来源（§2.6）|
| **侦测边界** | 侦测魔法有范围/消耗/可被反制                     | 侦测不是万能的（§2.4）       |

> **使用铁律**：法术越强，咏唱越长、材料越贵、魔力消耗越大、反制越多——这是防"法术随心"的自洽底线（§2.7铁律1、2）。

### B. 魔药学与炼金术速查

**魔药基础**：魔药由**材料**（草药/矿物/动物成分）、**配方**（用量/顺序/火候）、**炼制**（时辰/器具）构成，制作者与配方是关键。

**魔药与毒副速查**：

| 魔药         | 功效                                     | 毒副/风险               | 验尸/探查对应         |
| ------------ | ---------------------------------------- | ----------------------- | ---------------------- |
| **治疗药**   | 恢复伤势、解毒                           | 剂量过则反伤            | 无                          |
| **毒药**     | 剧毒（夜枭草/狼毒/龙胆）                 | 致命                    | 症状与毒理对应         |
| **迷药**     | 昏睡/致幻/心神被控                        | 剂量过可致死亡          | 瞳孔/脉象异常          |
| **变形药**   | 变人/变物形态（复方类）                   | 有时限、副作用（变不回）| 服药痕迹、形态与时限    |
| **隐形药**   | 短时隐形                                 | 有气味/有残留、时限     | 魔药瓶、气味           |
| **爱情药/魅惑** | 操控情感                               | 非万能操控、有剂量限制  | 行为异常、药物残留     |
| **炼金产物** | 腐蚀液/爆炸物/点金石                     | 依成分、危险            | 腐蚀痕、爆炸残骸       |

> **使用铁律**：魔药必须"配方/剂量/症状对应"（§3.7逻辑约束1）；"随便一瓶魔药万能解决"是硬伤。

### C. 神系与圣职/龙与魔兽速查

**多神神系与圣职规则**：
- **神职**：神各有职司（战争/丰收/死亡/欺诈），圣职者向所属神祇借力。
- **信仰要求**：神术的获得需信仰与仪式；**行为戒律**（圣职不得说谎/不得伤害信徒/不得亵渎）——破戒即失神力（§3.8）。
- **神谕/占卜**：神谕有歧义、可被应验方式误导、祭司有立场——"神谕直指真凶"是硬伤（§3.8）。
- **神罚**：神罚须留圣力痕迹与亵渎证据——"神罚想降谁降谁"是硬伤（§2.5排除项）。

**龙与魔兽速查**（作为"龙灾/怪物"诡计的归位基础）：

| 物种       | 生态/行为特征                             | 推理用途                     |
| ---------- | ---------------------------------------- | ---------------------------- |
| **龙**     | 有领地、有巢、有弱点（龙语/龙息特征）    | 龙息痕可辨识、龙的行动可推理 |
| **兽人/地精** | 部落、劫掠、痕迹特征                      | 兽痕辨识、目击证词           |
| **狼人/吸血鬼** | 变身周期（月相）、银器弱点               | 月相周期与作案窗口、弱点反制 |
| **食尸鬼/亡灵** | 食腐、怕圣光、契约束缚                   | 亡灵存在有规则、非随便复活   |
| **精灵/矮人** | 长寿、工艺/箭术特长                       | 年龄/工艺特征作身份与机会线索 |

> **使用铁律**：龙与怪物"作案"必须归位——要么有人伪造兽痕/龙息，要么立规则明示怪物生态可推理（§3.9、§2.5排除项）。"龙天降、怪物无敌"是硬伤。
