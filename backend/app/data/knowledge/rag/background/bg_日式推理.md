## 一、日式推理的定义与核心原则

### 1.1 什么是日式推理

日式推理以**日本（或和风架空）舞台**为核心推理类型，横跨**本格、新本格、变格、社会派、设定系**等亚型。核心公理与其他类型一致：**真相必须来自"线索 + 逻辑"，而非"灵感 + 权威"**。

**两条铁律**：

1. **"妖怪是包装，推理是内核。"** 日式推理的最大魅力在于用妖怪传说、怨灵、咒术、都市传说制造"非自然"的第一层解释，再用物理与逻辑证据拉回"人的犯罪"。妖怪不能成为"不严谨的免罪符"。
2. **日式剧本必须"自己解释自己的世界"**：玩家对妖怪民俗、家制度、温泉旅馆规矩、日语称谓、和室建筑、时刻表等认知参差不齐，剧本内所有关键知识必须以设定说明或知识线索卡形式给出（见ps_日式推理 §5.8知识自包含），**不得依赖玩家自带日式知识**。

### 1.2 日式推理的四大亚型（先定基调再写案）

| 亚型       | 核心追求                   | 逻辑要求                                         | 典型舞台与元素                         |
| ---------- | -------------------------- | ------------------------------------------------ | -------------------------------------- |
| **本格**   | 诡计与解谜的纯粹性         | 严格公平，线索全呈现，真相唯一                   | 洋馆/老宅密室、暴风雪山庄、童谣杀人   |
| **新本格** | 在极端设定下重建解谜趣味   | 设定可超常但须自洽立规则；叙事可诡但证据链必须本格 | 孤岛、暴风雪山庄、馆系列、叙述性诡计   |
| **变格**   | 妖异氛围与心理惊悚         | 妖怪/超常必须"有解"，须最终以物理/逻辑收束       | 妖怪、怨灵、诅咒、病态心理             |
| **社会派** | 动机的社会深度与批判力     | 动机须可查证、与角色社会处境自洽；冤案/误判可反转 | 温泉旅馆、家族、会社、官僚、媒体、校园 |

> **推论**：日式本不是"有妖怪更自由"，而是"**换了一套叙事与证据体系**"。妖怪民俗、家制度、温泉旅馆既是氛围资产，也是**可被逻辑检验的证据与动机来源**。

### 1.3 剧本杀公平原则（日式适配十诫）

> **剧本杀的核心是"所有玩家共同参与的解谜游戏"**，而非单一侦探的破案故事。以下原则改编自诺克斯十诫和范·达因准则，例证按日式语境改写：

| 编号 | 原则                   | 说明（日式例证）                                                     |
| ---- | ---------------------- | -------------------------------------------------------------------- |
| 1    | **凶手必须在场**       | 凶手必须在游戏开始时已在场，且以公开身份登场——不能中途冒出一个从未出场的人物 |
| 2    | **线索全面呈现**       | 所有关键线索（宿帐、和服血迹、系图、家纹、遗书、录音）必须在游戏过程中可被发现，不得在真相揭晓时才"补"线索 |
| 3    | **公平追凶**           | 每个玩家（包括凶手）搜证与发言权利对等；凶手可撒谎，但不能被系统保护 |
| 4    | **物理可行**           | 手法必须物理可行——不得用妖怪、怨灵、咒术等超自然力量（设定系/变格本须先立规则，见§3.7、ps_日式推理 §5.4） |
| 5    | **侦探不是凶手**       | 主持推理的"侦探"角色（侦探/刑警/记者/旅馆老板娘若担任此职）不应是凶手——其他玩家角色可以是 |
| 6    | **身份诡计须提前暗示** | 双胞胎/替身/养子/一人分饰两角等身份诡计必须在游戏中提前给出暗示线索（双生传闻、系图疑点、家纹不符） |
| 7    | **动机须有深度**       | 动机应与角色背景（继承之争/家族恩怨/社会压迫/旧怨）一致且足以支撑谋杀——不能是"一时冲动"或"疯了" |
| 8    | **人人有嫌疑**         | 每个角色（包括真凶）都应有合理动机与可疑之处，不让任何人过早被排除 |
| 9    | **关键线索唯一指向**   | 关键线索链最终应指向唯一的真凶，尽管中间存在误导                   |
| 10   | **不得隐藏证据**       | 主持人不得主动隐藏玩家已发现的证据——所有发现的线索都公开记录在线索板上 |

### 1.4 日式本格在剧本杀中的特殊考量

| 考量点         | 说明                                                         |
| -------------- | ------------------------------------------------------------ |
| **妖怪归位**   | 妖怪/怨灵/诅咒叙事必须有"物理解释"，且该解释可被搜证发现——妖怪是误导，不是解答（§3.7、ps_日式推理 §5.4） |
| **知识自包含** | 玩家对和式术语/民俗/制度认知不一——关键知识必须在剧本内以"设定说明"给出（ps_日式推理 §5.8） |
| **时代档位**   | 明治/大正/昭和/战后/平成令和五档，家制度与证据体系各不同（ps_日式推理 §5.1） |
| **家族关系**   | 家督继承/养子/本家分家/家纹决定身份与动机——既是氛围也是推理要素（§3.3、ps_日式推理 §5.3） |
| **封闭空间**   | 温泉旅馆暴风雪封山、列车、孤岛——暴风雪山庄天然舞台，需交代隔离机制（§3.5） |
| **称谓与礼节** | 敬语、称呼（さん/様/先生/お嬢様）、座次、上座下座——可埋身份与行为权限线索 |


## 二、逻辑严谨性核心框架（日式适配）

> **创作任何日式剧本，都应先过本框架，再考虑诡计与氛围。** 逻辑严谨 = 时代要素自洽 + 六要素闭环 + 时间线自洽 + 物理可行 + 妖怪归位 + 线索可推导 + 真相唯一 + 知识自包含。

### 2.1 案件六要素闭环（日式版）

一个合格的日式案件必须形成"六要素闭环"。真相揭晓后，六要素彼此咬合、无相互矛盾；任一要素被推翻都会牵动其他要素重新检验。

| 要素   | 定义                 | 真相揭晓时必须回答的问题                                       | 日式配套支撑证据                               | 常见漏洞                                     |
| ------ | -------------------- | ------------------------------------------------------------ | ---------------------------------------------- | -------------------------------------------- |
| **死因** | 致死原因与致死机制   | 死者怎么死的？勒缢/溺毙/中毒/刺伤/坠亡与死亡因果是否自洽？     | 司法解剖记录、现场血迹/痕迹、胃内容物、法医报告 | 死因与现场矛盾（称溺死却无入水痕迹）         |
| **手段** | 凶手实现死因的方法   | 用什么凶器/毒药/机关？每一步物理动作是否可行？                | 凶器来源与去向、工具痕迹、延时装置             | 无来源凶器（旅馆内查无、凶器凭空消失）       |
| **时机** | 死亡时间与作案时间窗 | 几点死的？凶手在哪个时段动的手？                              | 尸温/尸僵、腕表/时钟、列车时刻表、宿帐记录     | 死亡时间跨多个时段使手法失效、时刻表换算错误   |
| **机会** | 作案窗口的到达者     | 案发时段谁能接触现场与死者？谁被排除？                        | 风吕时间表、房间钥匙、走廊目击、宿帐入住记录   | 排除不完整、未考虑越窗/檐廊/障子翻入/共犯     |
| **动机** | 杀人动因及其一致性   | 为何杀此人？为何此时杀？与角色社会处境是否自洽？              | 家族关系/继承之争/社会压迫/旧怨/书信账册       | 动机不足、动机与人物背景矛盾                 |
| **身份** | 凶手/死者/涉事者真实身份 | 凶手是谁？死者是谁？是否涉及双胞胎/替身/养子/身份倒错？      | 家纹/胎记/旧疤/系图/宿帐/照片/亲缘辨认        | 身份诡计无提前暗示、置换后行为与真实身份不符   |

**闭环校验法**（六要素两两互检）：
- **死因 × 手段**：该死因必须能由该手段产生。例如慢性中毒（铊/慢性下毒）不可能表现为瞬间毙命；勒死与自缢的缢沟形态必须区分。
- **时机 × 机会**：死亡时段窗口内，凶手必须"在场"或"可控"。若凶手有不在场证明，必须存在能成立的"替代到场路径"（延时装置/心理延时/替身/时刻表误差），否则矛盾。
- **动机 × 身份**：凶手的动机必须与其**真实身份**（而非伪装身份）的前史吻合——社会派的动机尤其依赖"这个人真正经历过什么"。
- **手段 × 时机**：手法的执行时间必须落在作案窗口内；延时手法（定时器/蜡烛/慢性毒）的精度必须支撑死亡时间设定。
- 任何一处矛盾 = 剧本硬伤，须修正要素本身，**而非靠"玩家没想到"来掩饰**。

### 2.2 时间线一致性（日式版）

**法则 1 · 计时体系自洽**：日式剧本通常使用**24小时制**（或大正以前的时辰制+刻钟）。全剧本须统一换算标准，不得出现时间制混用矛盾。钟表（怀表/座钟）、车站时刻表、宿帐记录时间是硬证据——**但钟表可被拨动、时刻表可被利用**（§3.2）。

**法则 2 · 时刻表是日式本格的特权武器**：列车/巴士时刻表、渡轮班次、缆车时间构成"物理上不可能往返"的错觉。参考——JR特急/新干线的停站时刻精确到分；地方线班次稀疏（每小时一班是常态）；夜间停运。**"从甲站到乙站所需分钟数"是硬约束**：声称乘某班车到达者，若该班车与尸体发现时间矛盾即是破绽。时刻表诡计的关键是"利用对班次/换乘的错误认知"，破绽须在剧本中给出真实时刻表作为线索。

**法则 3 · 行程约束**：日式交通分档——城市（电车/地铁/出租车）、地方（JR线/巴士）、深山（步行/接驳车/缆车）。**"下山进村所需时间"是硬约束**：大雪封山时步行速度骤降、夜间无巴士，都是可利用的机会/不在场证明要素。

**法则 4 · 交叉验证**：任一时段的证言/记录至少与一条独立信息源交叉印证：宿帐入住时间 × 风吕时间表 × 走廊目击、车站监控（昭和前无监控） × 车票 × 目击证词。无交叉的单方证词属"待证信息"，不能直接当铁证。

**法则 5 · 空白时段必须有解释**：角色"独处无证明"的时段，要么是推理的关键（嫌疑窗口），要么必须有非犯罪理由（私会、泡露天风吕、打电话、见不得光的勾当），否则是漏洞。

**法则 6 · 系统性偏差才有说服力**：时间被篡改时，偏差必须来自可解释的系统（全员被故意调慢的钟、刻意安排的"集体误认"、酒店停电掩盖时段），并交代为何无人及时发现。临时、随意、无法解释的"对不上"是硬伤。

**构建步骤**：先写"客观物理时间轴"（死亡时间定死）→ 再写每个角色的"主观时间轴"（各角色以为的时间）→ 最后标注两者偏差及其来源，确保偏差线索可在游戏中被发现。

### 2.3 物理可行性验证（日式版）

**工具三问**（对手段的每一步物理操作逐一过问）：
1. **工具从哪来？** 凶手必须有获得渠道——厨房刀具、仓库工具、家用凶器、毒药来源、网购。线索须能指向该渠道。
2. **用后去哪了？** 凶器/毒药容器必须有处置（带走/丢弃/藏匿/留在现场被误导），去向合理且可被追查。
3. **留下什么痕迹？** 使用必然产生痕迹——刀刃与伤口形状匹配、血迹喷溅、浴室水痕、毒物残留、勒痕与绳索材质一致。

**硬性标准**：
- 手法必须能在200字内说清，且以"日常常识 + 基本物理"可验证。
- **和室物理约束**：障子/襖（纸门）薄而无声响不透视，但有滑轨痕迹与开合声；畳（榻榻米）会留下足迹与压痕；**在风吕（浴室）内赤身**——无衣物即无凶器藏匿处、无通讯工具，这是日式本格可利用的独特逻辑要素（见ps_日式推理 §5.5）。
- **延时装置只有两类**：① 真正延时（定时器/蜡烛/水漏/慢性毒）；② 心理延时（所有人误判死亡/离场时间，实际凶手当时就在场）。写延时必须先归类，再验证该类别的**时间精度**是否足以支撑死亡时间设定。

### 2.4 线索—推理映射（日式版）

**证据类型**（日式本五类证）：
- **物证**：凶器、和服/浴衣血迹、鞋印、毛发、毒物残留、遗体布设
- **人证**：旅馆员工（女将/仲居/番头）、住客、邻居、车站员的证词
- **书证**：宿帐（入住登记簿）、遗嘱、家系图、书信、日记、遗书、车票、购物小票
- **口供**：嫌疑人供词（须与物证/书证交叉）
- **法证**：法医解剖记录、指纹/DNA（**按时代档位取舍**，战后现代有、大正昭和初无，见§2.7）

**线索三级**：
- **事实线索（F）**：直接陈述、无需推断即可采信（宿帐记录、车票、遗嘱原文）。注意：事实线索"内容"可信，但"解读"仍可被误导（宿帐写"A入住201房"，但谁住进去的仍需推断）。
- **推断线索（I）**：需结合设定/常识推断（血迹分布、缢沟与勒沟之别、胃内容物与死亡时间）。
- **误导线索（R）**：指向伪解答（妖怪传说、诅咒物证、神秘仪式），**必须在后期可被推翻或解释**，不能不了了之。

**日式证据的局限（必须主动处理）**：
- **妖怪叙事是最强的误导源，也是最危险的逻辑陷阱**：任何"灵异"线索都必须有非灵异的物理解释，且该解释可被搜证发现——否则是霸王解答。
- **指纹/DNA 按时代取舍**：大正/昭和初无DNA、无监控、无手机；战后现代有。时代档位决定证据能力（§2.7），不得混用。
- **法医技术局限**：慢性中毒、心疾猝死可能被误判——"以病掩毒、以毒掩病"是合法手段，但误判的暴露必须有线索。

**推理价值标注**：每条线索在创作时应标注——它单独证明什么？与哪条线索组合证明什么？为**排除**哪个可能性服务？无推理价值的线索不该出现（纯氛围线除外，且需控制数量）。

**链式推导要求**：
- 从"初始线索集"到"真凶"至少存在一条 **≥3 步的逻辑链**。
- 关键推理链的**每一步至少2条独立线索支撑**。
- 链的每一步都必须"可被反驳"且"存在反驳线索"——否则该步骤是霸王推理（单方面认定、不可检验）。

### 2.5 唯一性判定与完整排除法（日式版）

在指认真凶之前，所有"他杀外可能"必须先被排除，且每个被排除项都要有**至少一条明确的排除线索**：

| 须排除的可能性       | 日式排除线索示例                                       |
| -------------------- | ------------------------------------------------------ |
| 自杀                 | 遗书笔迹比对、现场无自伤工具、伤痕角度不符、缢沟与勒沟鉴别 |
| 意外                 | 现场无意外触发条件（坠亡却无坠点痕迹、溺亡却无入水路径） |
| 病亡                 | 法医报告死因明确为他杀（非病非暴毙）                   |
| 无死亡（假死/替身）  | 身份识别锚点确认尸体身份、后续有该人未死的行为矛盾     |
| 外部闯入者作案       | 封山/锁门/宿帐人数核对/监控排除外来者、封闭场景设定     |
| 合谋 / 帮凶          | 涉案人员信息边界清楚、行动窗口逐一排查（如某人"恰好"不在场） |
| 死亡时间被伪造       | 计时体系交叉验证（宿帐×风吕时间×腕表×目击）           |
| **妖怪/灵异作案**     | 所有灵异线索均被物理证据证伪（妖怪归位，§3.7）         |

**唯一性检验**：给定全部线索，是否**只有一套**六要素自洽？若存在第二套同样自洽的解释，剧本就有逻辑漏洞——除非它是设计好的"伪解答"，而伪解答必须有反证线索（§3.10）。

### 2.6 反证检验流程（真相定型后必做）

把"真相"当作敌人，模拟最刁钻的玩家从五个角度攻击：

| 攻击角度       | 攻击问题                                                   | 被攻击即漏洞的情形                                     |
| -------------- | ---------------------------------------------------------- | ------------------------------------------------------ |
| **时间攻击**   | 凶手在X时做了Y，有没有任何证据/矛盾能推翻？                | 时间线上存在不可调和、无法解释的冲突                   |
| **物理攻击**   | 手法每一步真的可行吗？机关/毒药/和室建筑是否违背物理？      | 障子无声机关、瞬移穿越温泉、灵异咒杀                   |
| **信息来源攻击** | 凶手作案所需的"关键信息"（死者位置、时间、钥匙、现场布局）从哪得知？ | 凶手不该知道却必须知道，且无获取渠道线索（如钥匙在女将处而凶手无接触） |
| **动机攻击**   | 换成"自杀/意外/病亡/嫁祸/妖怪作祟"能否同样解释现场？       | 排除项缺线索、妖怪未归位，真相无法唯一化               |
| **公平性攻击** | 玩家在游戏中能否获得推导真相所需的**一切**信息（含日式知识）？ | 关键信息在复盘时才补充、或依赖玩家自带日式知识         |

**修正策略**：漏洞无法用"补一句话"解决时，**宁可改动设定**（改手法/改时间/改角色信息/改时代档位），也不要保留逻辑漏洞。

### 2.7 时代要素排查（日式的"科技排查"）

创作日式剧本，必须**先明确本世界的"证据能力边界"**——有哪些手段、没有哪些手段，且不得混用。日式特色在于"时代档位"直接决定**家制度形态**（明治民法/战后新民法）与**科技能力**（有无手机/监控/DNA）。

| 档位       | 时间范围              | 证据能力                                         | 家制度形态                                   |
| ---------- | --------------------- | ------------------------------------------------ | -------------------------------------------- |
| **明治·大正** | 1868–1926           | 无指纹库/DNA/监控/手机；电话与电报可用；法医初步 | 旧民法家督制：长子继承、养子盛行、家名至上     |
| **战前昭和** | 1926–1945           | 同上+刑警勘察制度化；无监控                       | 旧民法延续，军国时代，镇压与阴谋               |
| **战后昭和** | 1945–1989           | 指纹库建立、法医进步；后期有录像带/大哥大        | 新民法废除家督制，遗产均分，但旧习残留         |
| **平成**   | 1989–2019           | 监控普及、DNA鉴定、手机/网络                     | 均分继承，都市化，家族瓦解                   |
| **令和/现代** | 2019–               | 智能监控、手机定位、DNA、网络痕迹                 | 更强调"心理家庭"与阶层问题                   |

**三条铁律**：
1. **不得"假装没有时代科技"**：大正本不能靠DNA/手机定位破案；平成本不能假装没有监控而设计"无人目击"。若确需"超时代便利"，必须是穿越/架空设定的明确规则。
2. **必须主动处理时代局限**：无监控时代靠人证与物证、有监控时代须交代监控盲区与失灵理由。**不能"假装没有局限"**。
3. **时代知识必须自洽**：家督制只存在于战后民法修订前；战后剧本沿用"长子继承"须有明确设定理由（家元制度/老铺传承可例外）。

### 2.8 常见逻辑漏洞清单（日式版避坑）

| 漏洞             | 表现                                                     | 规避方法                                         |
| ---------------- | -------------------------------------------------------- | ------------------------------------------------ |
| **妖怪作祟**     | 用怨灵/诅咒/狐狸精解释本可物理验证的现场                 | 妖怪归位：所有灵异线索必须有物理解释（§3.7）    |
| **神隐滥用**     | "人间蒸发"无任何物理痕迹与后文                          | 神隐类失踪必须交代去向与发现路径                 |
| **双生无铺垫**   | 双胞胎/替身出现得毫无预兆，任意冒充他人                 | 提前暗示双生传闻/系图疑点/体型差异（§3.3）      |
| **养子谜之继承** | 养子身份/继承资格在复盘时才揭晓                        | 系图、家谱、户籍作为可搜证线索前置（§3.3）      |
| **时刻表硬伤**   | 声称乘某班车却在不可能的时间内出现                     | 剧本内给出真实时刻表作为线索（§2.2法则2）       |
| **家纹/身份识别悬空** | 无照片时代却"一眼认出"远道之人、或认不出应认之人   | 靠家纹/胎记/旧疤/亲缘/宿帐核验（§3.3）          |
| **温泉盲区**     | 入浴时段被当作"无人"却无人核对风吕使用时间表           | 风吕时间表+浴后身体状态（湿润/发丝）作线索      |
| **监控悖论**     | 平成现代本中监控"恰好全坏"却无交代                     | 交代监控盲区或失灵理由（§2.7）                  |
| **童谣/仪式杀人不闭环** | 童谣杀人/仪式布设只作氛围不做推理闭环                | 仪式布设必须与死者选择/手法/现场一一对应         |
| **知识依赖**     | 推理依赖玩家自带日式知识（妖怪/家制度/敬语），而非剧本内线索 | 关键知识以设定说明/知识线索卡给出（ps_日式推理 §5.8）       |
| **天降线索**     | 关键信息在真相揭晓时才首次出现                           | 线索前置、可搜证（§2.4）                        |
| **排除不完整**   | 忘了自杀/意外/病亡/假死/帮凶/外部闯入/妖怪等选项         | 过完整排除项清单（§2.5）                        |


## 三、核心诡计类型库（日式适配）

### 3.1 日式密室讲义

日式本格（尤其横沟正史以降）以"密室讲义"著称——对密室类型做穷举式分类。和室的障子、襖、钥匙、檐廊（縁側）、外廊为密室提供了日式载体。

#### 密室的两大基本分类

| 类型                   | 说明                       | 关键特征                                   |
| ---------------------- | -------------------------- | ------------------------------------------ |
| **机械密室**（物理密室） | 通过机关、门闩装置实现密室 | 密室是真实的，凶手用物理手段完成       |
| **心理密室**（错觉密室） | 利用心理错觉制造密室假象   | 密室是假的——门闩实际被从外拨动、锁是假锁 |

#### 密室的形成者（剧本杀视角）

| 形成者         | 说明                                 | 在剧本杀中的实现                         |
| -------------- | ------------------------------------ | ---------------------------------------- |
| **凶手制造**   | 最常见的类型——凶手杀人后制造密室     | 凶手玩家需在搜证环节注意隐藏相关手法线索 |
| **死者制造**   | 自杀伪装成他杀，或死者无意制造密室   | 最终揭晓时需通过尸检证明是自杀           |
| **帮凶制造**   | 第三人在案发后无意或有意制造密室条件 | 该角色有独立动机（保护某人/制造混乱）    |
| **多人共同制造** | 多人各自的行为叠加形成密室假象       | 每个参与者都以为自己是"唯一做手脚的人"   |

#### 密室讲义分类索引（日式选型用）

| 编号 | 密室类型（卡尔分类简版）                           | 日式实现示例                                 | 剧本杀适用性 |
| ---- | -------------------------------------------------- | -------------------------------------------- | ------------ |
| 1    | 案件实为意外/自杀，被误认为他杀                    | 坠楼被伪造成推落、自缢被伪造成他杀勒死       | ★★★ 高      |
| 2    | 机械机关：杀人后自动上锁                           | 榻榻米下暗格、障子滑轨机括、窗户自动落锁     | ★★ 中       |
| 3    | 凶手作案时就在房间，事后混入人群或藏匿             | 藏身壁橱（押入れ）/阁楼/浴室夹层，混入员工房 | ★★★ 高      |
| 4    | 锁被做手脚（假锁/卡扣），实则任何人可开             | 门锁被细线/竹片从门缝拨动，障子纸被划开       | ★★★ 高      |
| 5    | 用工具从外部或门下拨动门闩                         | 细线/铁丝从门槛缝隙伸入挑闩                  | ★★ 中       |
| 6    | 死者自己锁门（自杀或误锁）                         | 死者上吊前反锁、误触门闩                     | ★★★ 高      |
| 7    | 伪装他杀的意外（利用现场布置误导死因）             | 伪造仇杀现场掩盖意外/自杀                    | ★★★ 高      |

#### 密室杀人的动机（剧本杀适用）

| 动机                 | 说明                             | 对应的剧本设计                         |
| -------------------- | -------------------------------- | -------------------------------------- |
| **伪装自杀/意外**    | 让密室看起来是自杀或意外         | 尸检线索需揭示真正死因与表面不符       |
| **制造不在场证明**   | 让所有人以为死亡发生时无人能进出 | 时间线推理是破解关键                   |
| **嫁祸给特定的人**   | 让某人有唯一"可能"作案的条件     | 嫁祸对象应有对应的自我辩护线索         |
| **制造恐怖氛围**     | 连环杀手的标志性手法             | 多起案件共享同一密室模式               |
| **掩盖真实手法或死亡时间** | 密室本身是烟雾弹             | 玩家需跳出密室思考"为什么要做密室"     |

**逻辑约束（重点）**：
1. 密室必须**"进、出、闭"三步都能解释**：凶手怎么进、怎么出、门闩/锁怎么复原。
2. 心理密室必须交代**"门闩被如何误认"**——误认机制本身要有线索。
3. **押入れ/阁楼/檐廊等日式藏身处必须有"空间真实性"**：壁橱高度、天花板检修口、屋檐宽度都要交代，不能凭空出现"刚好能藏人"的空间。
4. 制造密室必须比"不制造密室"更有利：找不到合理动机时，用"伪装意外"或"制造恐慌"作为默认解释。

> **创作提示**：设计密室案时，顺序为——先问"凶手为什么要做密室"（动机）→ 再设计"怎么做的"（手法）→ 最后验证"怎么破除的"（破案线索）。**密室形成有解，破除也必须有解。**

### 3.2 不在场证明与时刻表诡计（日式王牌）

时刻表诡计是日式本格标志性板块（《点与线》为典范）。核心是**利用人们对班次、换乘、时间的"错误认知"制造物理上不可能的往返错觉**。

#### 在剧本杀中的典型形式

| 形式             | 说明                                   | 破解方向                               |
| ---------------- | -------------------------------------- | -------------------------------------- |
| **列车时刻表诡计** | 声称乘某班车离开/到达，制造"不可能往返" | 剧本内给出真实时刻表，换乘衔接/班次错误暴露 |
| **宿帐时间伪造** | 登记簿时间被改/代签，制造不在场证明     | 笔迹比对、宿帐连续编号、员工记忆交叉   |
| **风吕时间表**  | "我一直在泡露天风吕"的独处证词          | 风吕使用登记、浴后状态（身体湿润/头发干湿） |
| **巴士/缆车**   | 末班车已过却声称乘车                     | 时刻表、司机证词、车票存根             |
| **电话/电报**   | 大正本中"打了电话"制造在场假象           | 通话时长、接线员记录、电话机位置       |

#### 常见的"不在场证明破绽"类型

1. **时间谎称**——证人被误导，以为在某个时间看到了某人
2. **替身诡计**——有人冒充嫌疑人出现在别处（双胞胎/易容）
3. **书证伪造**——宿帐、车票、记录被人为改动
4. **时刻表错觉**——看似不可能的距离其实有隐秘班次/换乘可以做到
5. **共犯伪证**——两人或多人合谋提供虚假证词

#### 在剧本杀中设计不在场证明

**关键原则**：每个角色（包括真凶）都应有不在场证明。真凶的不在场证明必须"看起来合理但存在破绽"——且**破绽必须有线索**，而不是"天衣无缝"或"靠运气看穿"。

| 角色类型       | 不在场证明设计                                               |
| -------------- | ------------------------------------------------------------ |
| **真凶**       | 看似合理但有细微破绽的证明（如"我一直在风吕里"——但风吕时间表显示超时、或浴衣/头发状态不符） |
| **其他嫌疑人** | 有真实的/部分真实的不在场证明，但各有隐瞒的理由（如"那晚我在电话里谈私事所以不想说"） |
| **目击者**     | 可能错误地确认了时间——不是故意的，是雨夜/远距离/记忆偏差     |

**逻辑约束**：不在场证明的破绽必须**指向可搜证的位置**（宿帐、风吕登记、车站、电话记录），玩家通过搜证+交叉对比可发现，而非依赖某角色"突然想起"。

### 3.3 身份诡计（双胞胎/替身/养子/家纹）

> **⚠️ 提示**：叙述性诡计在剧本杀中**受限制**（玩家能看到角色卡），但身份置换类诡计**有天然优势**——玩家彼此看到的角色卡有限，信息不对称正是剧本杀的特征。日式身份诡计的独特性在于**养子制度与家纹**（见附录C）。

#### 剧本杀中可用的身份诡计

| 类型             | 说明                                   | 实现方式                                         |
| ---------------- | -------------------------------------- | ------------------------------------------------ |
| **双胞胎/替身**  | 双生兄弟姊妹互换身份，或雇替身冒名     | 提前暗示家族有双生传闻、某人常年遮脸/不拍照     |
| **养子倒错**     | 以养子身份冒认血缘继承人（婿养子/相续养子） | 系图、户籍、家纹、老仆证词可戳穿                  |
| **家纹/名号错误** | 家纹、印章、和服纹样揭示真实出身       | 家纹是"不可伪造"的家族标识（§附录C），作识别锚点 |
| **一人分饰两角** | 同一个人在不同场合使用两个身份         | 两个"角色"从不同时出现，玩家拼凑时间线发现       |
| **性别置换**     | 女扮男装/男扮女装（宝冢/浪人梗）        | 通过外貌细节（"从不宽衣"、"声音低沉"）暗示      |
| **冒名顶替**     | 顶替死者/失踪者的身份与户籍             | 宿帐、户籍、旧识认人、信物的综合推理              |

#### 逻辑约束（重点）

1. **提前暗示原则**：诡计成立所需的事实（家族双生、养子传闻、某人从不以全脸示人、家纹存在疑点）必须在**游戏早期**有线索。
2. **置换后行为一致**：置换后的角色，其行为细节必须与**真实身份**（而非伪装身份）吻合——真实的性别/年龄/习惯/旧伤是"无法完全伪装"的破绽细节，正是玩家的发现路径。
3. **身份识别锚点**：剧本中必须存在至少一条**不可伪造的身份识别线索**——家纹、胎记、旧伤痕（家人/旧仆知晓）、刻字信物（戒指/怀表）、系图/户籍记载。
4. **一人分饰两角**：必须保证"两个身份从不同时在场"——用时间线核对每个"出场"时刻，任一时刻被两名独立角色同时目击即诡计破产。
5. **养子制度的知识自包含**：玩家未必懂"婿养子要改姓入籍"等规则——关键规则须以知识线索卡给出（ps_日式推理 §5.8），且该规则必须成为推理的一部分（而非背景）。

### 3.4 无面尸诡计（日式版）

> **定义**：尸体面部被毁/无头/烧焦/高度腐败，身份无法直接辨认，"死者是谁"成为第一道谜题。（《犬神家一族》的经典结构。）

#### 在剧本杀中的典型运用

| 步骤         | 游戏内实现                                | 设计要点                                        |
| ------------ | ----------------------------------------- | ----------------------------------------------- |
| **误导阶段** | 现场发现尸体+遗留物品→玩家推断死者是A     | 遗留物品必须明显指向A（A的和服/戒指/手表/名片）  |
| **发现矛盾** | 角色A的"目击"与尸体情况不匹配→触发怀疑    | A声称在某处看到谁/什么，与尸体状态冲突          |
| **真相揭示** | 线索显示尸体实际上是B                     | 通过家纹/胎记/旧疤/身高/亲缘辨认/信物揭示       |

#### 经典结构变体

| 变体             | 说明                           | 剧本杀适用                                 |
| ---------------- | ------------------------------ | ------------------------------------------ |
| **尸体是替身**   | 凶手杀了无关人士冒充特定死者   | 需要凶手有接触"替身"的渠道和机会           |
| **尸体数量错误** | 实际死亡人数与发现的尸体数不同 | 多具尸体需在不同场景发现，玩家需统计比对   |
| **死者还活着**   | 某角色假死（配合"神隐"叙事）   | 该角色的"死亡"需有目击者，但尸检线索不完整 |

#### 逻辑约束（重点）

1. **必须有一条明确可靠的"身份识别锚点"**——家纹、胎记、旧伤疤、特殊体态、刻字信物、亲缘辨认。无指纹/DNA 时代**锚点尤为关键**。
2. **"误认"必须有合理原因**：面部毁损、无头、烧焦、溺水肿胀、亲属"拒绝细看"（如指认者另有目的）——否则玩家会质疑"为什么认错了"。
3. **识别线索的取得时机**：身份识别线索要在"误导阶段"之后、"真相揭晓"之前**可被搜证获得**，形成"先误导→再证伪→后锁定"的推理弧线。

### 3.5 暴风雪山庄模式（日式版 · 温泉旅馆）

日式暴风雪山庄的经典载体是**被大雪封山的温泉旅馆**——既有封闭性，又有日式细节可埋证据。

#### 日式封闭空间载体

| 载体             | 封闭方式                                       | 适用诡计               |
| ---------------- | ---------------------------------------------- | ---------------------- |
| **温泉旅馆**     | 大雪封山、巴士停运、缆车停开                   | 密室、连环杀人、宿帐诡计 |
| **离岛/孤岛**    | 渡轮停航、天气恶劣                             | 身份诡计、无面尸       |
| **列车/列车密室** | 隧道/风雪滞留、停运列车                        | 时刻表诡计、密室       |
| **山间别墅/洋馆** | 大雪封路、桥梁被毁                             | 设定系、连环杀人       |
| **神社/寺院**    | 山门封闭、雨雪阻路                             | 妖怪/怨灵（变格）      |
| **闭关修验道场** | 修行封闭、仪式禁行                             | 设定系、仪式杀人       |

#### 温泉旅馆作为封闭舞台的独特逻辑要素

| 要素           | 逻辑用途                                                     | 示例线索                                         |
| -------------- | ------------------------------------------------------------ | ------------------------------------------------ |
| **宿帐**       | 人数核对、入住时间、身份登记——封闭集合的"花名册"             | 宿帐登记人数与尸体数对不上                       |
| **风吕（裸身）** | 入浴时无衣物=无凶器藏匿、无通讯；浴后状态可证在场性           | 头发干湿、身体湿润、浴衣状态                     |
| **员工体系**   | 女将/仲居/番头/板前各有权限与视角，是天然人证网               | 仲居送餐时间、板前备餐记录                       |
| **和室薄壁**   | 障子/襖薄而透声——"听到什么"是可靠证据，也是可被利用的误导   | 隔室听到的争吵/脚步/纸门滑轨声                   |
| **钥匙管理**   | 旅馆钥匙在女将/番头处统一管理——钥匙归属决定密室机会           | 备用钥匙位置、房卡记录                           |
| **封山交通**   | 大雪封山=外部无法进入、内部无法离开=凶手必在幸存者中          | 巴士停运通告、雪地上足印（可数出进出人数）       |

#### 逻辑约束（重点）

1. **凶手必须始终在幸存者中**；随着命案发生，嫌疑人集合必须**单调收缩**——不能中途出现"新到达者"或"此前不在场者"被排除后又复活。
2. 每一起新的命案都要**收窄可能性**（排除法推进），而不是制造无关混乱。
3. 连环案件要么共享同一凶手逻辑（特征/模式/被害者关联），要么明确揭示"第二凶手"，两者都需线索支撑。
4. **封山的"不可进/不可出"必须可被验证**：雪地足迹、巴士站台记录、唯一山路的封锁状态要有线索，不能只靠一句"雪太大"。

### 3.6 时间诡计与延时机关（日式版）

#### 在剧本杀中的典型形式

| 形式           | 说明                                     | 破解方向                             |
| -------------- | ---------------------------------------- | ------------------------------------ |
| **死亡时间伪造** | 通过尸检误导/环境干预让死亡时间提前或推后 | 尸检线索+环境线索（电热毯/暖房）比对   |
| **钟表误导**   | 全员/局部钟表被调慢，制造集体时间错位    | 多个计时源读数矛盾、广播报时对比     |
| **时刻表错位** | 两起事件的先后顺序被混淆（列车班次）      | 真实时刻表比对（§3.2）               |
| **延时杀人**   | 凶手动手后延迟死亡，制造不在场证明       | 凶器/机关的延时机制线索              |

#### 日式延时手段

| 延时手段       | 原理                                   | 精度与注意                                             |
| -------------- | -------------------------------------- | ------------------------------------------------------ |
| **定时器/电路** | 台灯/电饭煲/暖炉定时触发（现代）        | 需交代装置来源与安装者；停电则失效                     |
| **蜡烛/油灯**  | 蜡烛燃尽触发/以灯油耗尽推断时间        | 蜡烛长短、灯芯粗细影响精度                             |
| **冰块/溶解**  | 冰块撑住开关，融化后触发                | 冰化速度受室温影响，精度低                             |
| **慢性毒药**   | 低剂量累积/迟发毒物，延迟发作          | 发作时间窗口宽，是"不在场证明"的经典手段               |
| **电热毯/暖炉** | 人为加速/减缓尸温，误导死亡时间        | 尸温异常与室温对比可暴露                               |

#### 逻辑约束（重点）

1. **偏差必须有系统来源**（§2.2法则6）：谁调的钟、何时调、为何无人发现，都要有交代。
2. **延时必须归类并验精度**：真延时（定时器/蜡烛/冰块/慢性毒）or 心理延时（误判在场者）。真延时要验证时间精度能否支撑设定。
3. **死亡时间伪造必须有尸检依据**：用什么手段误导了尸检结论（保温/降温、胃内容物做手脚、尸僵被破坏），该手段本身要留下可被发现的痕迹。
4. **现代本的电热毯/暖炉是日式特有的尸温诡计载体**——温泉旅馆的暖房环境让"体温保持"成为可利用要素，但必须有环境温度记录线索。

### 3.7 妖怪与都市传说诡计（设定系规则）

> 妖怪是日式推理的灵魂包装，也是最危险的逻辑陷阱。**一切妖怪叙事都必须"归位"到物理与逻辑解释**——这是日式变格/设定系本"逻辑自洽"的底线。

#### 妖怪的三档处理（详见ps_日式推理 §5.4）

| 档位       | 妖怪的定位                     | 逻辑要求                                     |
| ---------- | ------------------------------ | -------------------------------------------- |
| **写实民俗** | 妖怪是当地信仰/传说，只是背景与动机来源 | 妖怪不参与作案；玩家最终以物证/人证破案     |
| **都市传说** | 妖怪叙事作为误导源（§3.10红鲱鱼）      | 每个灵异线索必须有非灵异解释，且可搜证证伪   |
| **设定系变格** | 妖怪真实存在，但能力有规则与代价        | 先立规则并明示（§3.7规则），设定内仍可推理   |

#### 常用妖怪及其"归位"映射

| 妖怪/民俗       | 民俗形象                           | 可归位到的物理/逻辑真相                         |
| --------------- | ---------------------------------- | ---------------------------------------------- |
| **雪女**        | 山中的白发女子，吹气成霜           | 暴雪夜低温致死、冻尸误认、白衣人影（雪地反光） |
| **河童**        | 水鬼，爱捉人入水                   | 溺亡、水潭中的尸体、水中拖曳痕迹               |
| **座敷童子**    | 家中孩童幽灵，带来财运             | 隐藏的孩子、被藏匿的未成年角色、密室的"第三人间" |
| **狐凭（狐付）** | 狐狸附身，性格大变                 | 精神疾病、药物影响（曼陀罗/麦角）、被胁迫扮演   |
| **天狗**        | 山中妖怪，掳人                       | 神隐/绑架、深山失踪、伪装修验者                 |
| **怨灵/咒杀**   | 死后报复，杀人于无形               | 慢性毒、家族仇恨的仪式化谋杀、集体心理暗示     |
| **妖刀/诅咒物** | 会"自己杀人"的刀                   | 借刀杀人、伪造成诅咒的连环案                   |
| **百鬼夜行**    | 群妖出行的夜                       | 集体幻觉、烟熏/致幻物、精心布置的恐怖夜        |
| **神隐**        | 被神怪带走，人间蒸发               | 绑架/藏匿/假死/替身——失踪与身份诡计的民俗外衣 |

#### 设定系妖怪的规则模板（若妖怪真实存在）

| 规则维度     | 要求                                                     | 示例                                                     |
| ------------ | -------------------------------------------------------- | -------------------------------------------------------- |
| **能力边界** | 妖怪能做什么、不能做什么须明确列出                       | "雪女只能致低温，不能直接穿越墙壁"                     |
| **代价/条件** | 使用能力需要满足的条件或付出代价                         | "狐凭须持有附身者私物，且只能持续一夜"                 |
| **可验证性** | 妖怪行为必须留下可被人类检视的"现象"                     | "低温症尸体、毛发结霜"                                 |
| **限制人类证据** | 妖怪不能凭空制造/销毁人类证据（凶器、指纹、目击）         | "妖怪不能移动 100kg 尸体除非分尸"                     |
| **动机人类化** | 妖怪的行动背后必须有可被理解的目的（复仇/守护/报复）      | "作祟的是被家族逼死的少女，向压迫者复仇"               |

#### 逻辑约束（重点）

1. **写实/都市传说档：妖怪永远不能是解答**——玩家必须能靠物理+逻辑指向"人"。妖怪只能作误导（§3.10），且误导必须在后期被证伪。
2. **设定系档：妖怪能力必须"可被推理"**——妖怪有规则、有代价、留下可验证现象，凶手/真凶借妖怪行事也须有动机与手法（§3.10）。
3. **"神隐"必须闭环**：失踪角色必须交代去向（藏匿/假死/离开/死亡），不能"被神带走"了之。

### 3.8 社会派动机与"系统性之恶"

> 社会派的核心不是诡计，而是**动机的社会深度**——凶手杀人，是因为被某个社会结构逼到了绝境。社会派的推理价值在于：**动机可查证、复仇有定时性、系统制造了帮凶与共犯**。

#### 社会派动机库（日式典型主题）

| 主题             | 动机内核                                       | 推理价值                                         |
| ---------------- | ---------------------------------------------- | ------------------------------------------------ |
| **阶层固化/贫富差距** | 出身决定命运，向上无门                        | 动机与角色社会处境一致；调查社会关系网           |
| **家族压迫**     | 家督制/长子继承/家名至上压死个体              | 继承之争、家谱系图、长年被牺牲者的反噬（ps_日式推理 §5.3）  |
| **官僚/警察黑幕** | 权力掩盖罪恶、冤案草菅人命                    | 档案造假、程序违规、知情者的沉默共犯             |
| **战争遗留**     | 军国时代旧债（暴行、实验、人贩）在后代身上索偿 | 年代纵深、幸存者后代的身份揭露                   |
| **校园霸凌**     | 被欺凌者/旁观者的罪与罚                        | 班级关系、时间跨度长的复仇                       |
| **职场压榨**     | 过劳、性骚扰、权力骚扰逼出绝望                | 加班记录、邮件、职场权力结构                     |
| **媒体舆论**     | 舆论杀人、大众狂欢                            | 报道时序、舆论操纵与案件的联系                   |
| **冤案/制度之恶** | 被诬陷者的复仇或受害                          | 翻案线索、旧案卷宗、程序漏洞                     |

#### 社会派在剧本杀中的设计要点

| 要点           | 说明                                                         |
| -------------- | ------------------------------------------------------------ |
| **动机可查证** | 社会处境（贫困/被欺凌/家族压迫）须以证据呈现：账目、信件、家谱、病历、警方档案 |
| **复仇定时性** | 为何"现在"杀人？必须有一个"压死骆驼的最后一根稻草"事件作为触发点 |
| **系统性共犯** | 加害者不是一个人，而是体制/群体——帮凶、知情者、沉默者形成共犯链 |
| **反转层次**   | 社会派常以"表面凶手"→"幕后真相"两层结构，揭示真正的"系统之恶" |
| **同情而非洗白** | 凶手动机值得同情，但手段仍是犯罪——玩家应能理解动机而不认同手段 |

#### 逻辑约束（重点）

1. **社会派动机必须有"证据化呈现"**：角色的悲惨处境不能只靠口述，要有可搜证的物证/书证（旧照、日记、档案、病历）。
2. **"最后一根稻草"必须存在**：为什么是今天、为什么杀这个人——触发事件要明确，否则动机悬浮。
3. **共犯信息边界清楚**：谁、何时、知道多少、参与多深，都要有边界，不能"全村皆知却无人报案"式的含糊。

### 3.9 死亡留言（Dying Message）

> 日式本格经典元素：死者在死前留下指向凶手的"留言"——日记、血字、录音、现场布置。死亡留言是**双刃剑**：它同时是最强的唯一指向线索与最强的误导工具。

#### 死亡留言的形式

| 形式         | 示例                                     | 逻辑要点                                     |
| ------------ | ---------------------------------------- | -------------------------------------------- |
| **血字**     | 尸体旁的血字/用手指在榻榻米上划刻        | 划刻方向、尸体姿势能否够到、字迹与身份关系   |
| **遗言/遗书** | 死前录音、临终遗言、遗书                 | 笔迹/声纹、书写时间、被发现的"刚好"性        |
| **现场布设** | 童谣、仪式物、照片、日常物品的特殊摆放    | 布设与死者知识/身份的关系                    |
| **日记/笔记** | 死者生前日记最后几页                     | 日记的"真实性"——是否被伪造/补写              |

#### 逻辑约束（重点）

1. **死亡留言必须有"可验证的真实性"**：字迹比对、录音声纹、书写工具的来源与时间——玩家要能判断留言真伪，否则是霸王线索。
2. **留言内容必须在死者知识范围内**：死者不能写下他不可能知道的信息。
3. **留言的"反噬"设计**：最精彩的死亡留言是"误导"——死者故意/被迫留下指向错误对象的留言，反证线索须在后期给出。

### 3.10 误导与伪解答工程（日式版）

**红鲱鱼设计原则**：

| 原则         | 说明                                         |
| ------------ | -------------------------------------------- |
| **有独立价值** | 即使不指向真凶，也揭示了某个角色的秘密或动机 |
| **合理存在**   | 不是凭空出现——与该角色的行为/背景一致        |
| **可被推翻**   | 后续有线索可推翻该误导，而不是"不了了之"     |
| **不过度集中** | 不要把大部分误导线索集中在同一个非真凶角色上 |

**日式常见误导源**：
- **妖怪/怨灵/诅咒**：先引导玩家往"非自然"方向想，再用物理/毒物线索拉回（§3.7）——日式本最富特色的误导。
- **仪式感杀人**：童谣、降灵会、密教仪式——制造"恐怖团体作案"假象，掩盖私人动机。
- **家族历史恩怨**：用陈年旧事（战前旧债、祖辈仇怨）分散注意力，掩盖当下动机。
- **遗书/绝笔**：伪造遗书误导自杀（笔迹、措辞为破绽）。

**伪解答设计**：一个表面上能解释所有线索的"假真相"。要求：
- 伪解答必须能**暂时覆盖**绝大多数线索；
- 伪解答必须有**至少一条反证线索**，且该线索在游戏后期可被搜证获得；
- 伪解答被推翻的瞬间 = "恍然大悟"时刻。

**逻辑约束**：伪解答数量建议 **1–2 个**。每个伪解答的推翻线索要与真凶推理链**共用线索、互相咬合**，而非另起炉灶。

#### 误导的进阶形态：前提错误型

> **最高明的误导不是让玩家"想错答案"，而是让玩家"一开始就想错了问题"。** 一旦"死者是谁"或"这里是否发生过犯罪"这一前提错误，所有后续推理都失去根基。

典型：**无面尸 + 身份误认**（§3.4）、**伪解答依赖错误前提**（如"现场是密室"这个前提本身错了）。破绽点在于：推翻前提的那条线索（如"门其实没锁"、"死者其实是B"）必须是**玩家可主动质疑、可搜证验证**的。


## 四、经典案例解析（逻辑严谨性视角）

以下案例解析侧重于"这个诡计**在逻辑上为什么成立**"以及"如何转化为剧本杀设计"，供创作时参考。解析基于各作品公开的复盘要点，不涉及关键剧透细节。

### 4.1 案例一：《点与线》——时刻表诡计与"不可能往返"

| 项目     | 内容                           |
| -------- | ------------------------------ |
| **类型** | 社会派 / 本格 / 时刻表诡计     |
| **核心亮点** | 以列车时刻表构建"物理上不可能的往返" |

**逻辑上为什么成立**：
- **时刻表是可查证的硬事实**：班次、换乘、停站时间精确到分，任何人拿到真实时刻表都能验证（§2.2法则2、§3.2）。
- **"不可能"是错觉，不是事实**：看似无法往返的距离，存在隐秘的换乘/班次衔接——破绽必须靠玩家比对真实时刻表发现。
- **社会派底色**：案件背后是官商勾结的利益网——动机与社会结构绑定（§3.8）。

**剧本杀借鉴价值**：

| 借鉴点         | 说明                                             |
| -------------- | ------------------------------------------------ |
| **时刻表线索** | 剧本内附真实时刻表作为线索卡，考验"换乘推理"     |
| **不可能往返** | 用班次衔接制造不在场证明的错觉                   |
| **社会派动机** | 官商勾结/利益网作为深层动机                     |

### 4.2 案例二：《犬神家一族》——家族继承 + 无面尸

| 项目     | 内容                           |
| -------- | ------------------------------ |
| **类型** | 本格 / 家族继承 / 无面尸       |
| **核心亮点** | 家族遗产争夺 + 尸体身份之谜      |

**逻辑上为什么成立**：
- **家族结构即嫌疑网**：继承人名单=嫌疑人名单，遗产分配=动机分布（§3.8、ps_日式推理 §5.3）。谁受益最大、谁最想谁死，一目了然。
- **无面尸是身份谜题引擎**：尸体身份被误导，玩家先盘"死的是谁"，再盘"谁杀的"——双重谜题（§3.4）。
- **家制度知识可查证**：遗嘱、系图、养子关系、继承顺位——家族内部的规则本身就是线索体系。

**剧本杀借鉴价值**：

| 借鉴点       | 说明                                       |
| ------------ | ------------------------------------------ |
| **继承结构** | 用家系图/遗嘱/养子关系构建动机分布         |
| **无面尸**   | 身份误认作为第一层谜题                     |
| **家族诡计** | 家纹/系图/养子作为身份识别锚点             |

### 4.3 案例三：《姑获鸟之夏》——妖怪设定系的规则自洽

| 项目     | 内容                           |
| -------- | ------------------------------ |
| **类型** | 设定系 / 变格 / 妖怪 / 推理    |
| **核心亮点** | 以妖怪传说包裹"非超自然的心理/物理真相" |

**逻辑上为什么成立**：
- **妖怪叙事与物理真相的"双解"结构**：妖怪传说解释了表面现象，但真正的解答是人的心理/物理机制——妖怪归位（§3.7）。
- **设定系必须有规则**：妖怪的"存在"不是无限万能，而是被限定在可推理的框架内（§3.7规则模板）。
- **民俗即线索**：妖怪传说不是背景板，而是指向真相的暗号系统（座敷童子→隐藏的孩子）。

**剧本杀借鉴价值**：

| 借鉴点         | 说明                                 |
| -------------- | ------------------------------------ |
| **妖怪包装**   | 妖怪传说作为误导与暗号系统           |
| **心理真相**   | 以心理/物理机制替代灵异解答          |
| **民俗线索**   | 民俗传说与物理证据互证               |

### 4.4 案例四：《白夜行》《砂之器》——社会派动机的深度

| 项目     | 内容                           |
| -------- | ------------------------------ |
| **类型** | 社会派                         |
| **核心亮点** | 动机源于社会结构而非个人恩怨 |

**逻辑上为什么成立**：
- **动机可查证**：两个被社会遗弃的人、被阶层壁垒压死的天才——处境以成长经历、社会关系、旧档案呈现（§3.8）。
- **复仇有定时性**：罪与罚的伏笔跨越多年，"现在"发生是因为最后一根稻草落下。
- **受害者与加害者的互为镜像**：凶手并非天生的恶，而是被系统性之恶逼出来的——这是社会派区别于本格的最大深度。

**剧本杀借鉴价值**：

| 借鉴点         | 说明                                         |
| -------------- | -------------------------------------------- |
| **深动机**     | 动机源于社会处境，可查证、可共情             |
| **长伏笔**     | 过去的因在现在的果，伏笔需在剧本内可还原     |
| **双主角/镜像** | 受害者与加害者互为镜像的人物结构             |

### 4.5 案例五：《本阵杀人事件》——日式本格密室

| 项目     | 内容                           |
| -------- | ------------------------------ |
| **类型** | 本格 / 密室 / 古早日式         |
| **核心亮点** | 和式建筑中的密室                |

**逻辑上为什么成立**：
- **和室空间即密室载体**：本阵（宿驿）的和室、障子、钥匙构成密室条件——建筑细节是物理可行性验证的对象（§2.3）。
- **雪地/足迹类环境证据**：雪地上的足迹可数出进出人数，是"封闭性"的可验证证据（§3.5）。
- **本格公平**：所有线索在游戏中可被搜证获得，靠逻辑而非运气。

**剧本杀借鉴价值**：

| 借鉴点       | 说明                                     |
| ------------ | ---------------------------------------- |
| **和式密室** | 以和室建筑细节（障子/押入れ/檐廊）做密室 |
| **雪地证据** | 环境证据验证"不可进出"                   |
| **本格公平** | 线索全前置，考验纯逻辑                   |

## 六、日式剧本创作流程框架（逻辑先行）

> **顺序不可颠倒**：先定真相与时代、再过逻辑框架、再设计角色与线索，最后才排版分幕。

| 步骤 | 工作内容                                     | 产出物 / 验证点                                           |
| ---- | -------------------------------------------- | ---------------------------------------------------------- |
| 1    | **定义案件真相**                             | 日式六要素初稿：死因/手段/时机/机会/动机/身份（§2.1）     |
| 2    | **六要素闭环验证**                           | 两两互检（§2.1），修正任何一处矛盾                         |
| 3    | **时代要素排查**                             | 定档位（ps_日式推理 §5.1）；过§2.7表，明确家制度形态与证据体系边界     |
| 4    | **妖怪/主题定性**                            | 选妖怪档位（写实/都市传说/设定系，ps_日式推理 §5.4）与是否走社会派（ps_日式推理 §5.6） |
| 5    | **时间线设计**                               | 24小时制主时间线 + 每角色个人时间线 + 交叉验证（§2.2）     |
| 6    | **手法物理验证**                             | 工具三问 + 和室/风吕/延时装置边界验证（§2.3、§3.6）        |
| 7    | **反向设计线索链**                           | 从真相反推：需要哪些线索支撑每一步推导，标注推理价值与排除功能（§2.4） |
| 8    | **分配线索与分幕**                           | 线索分幕/分区域发放，关键线索冗余≥2；知识自包含（ps_日式推理 §5.8）   |
| 9    | **妖怪归位检验**                             | 所有灵异线索均有物理解释且可搜证证伪（§3.7、ps_日式推理 §5.4）         |
| 10   | **反证检验与逻辑自检**                       | 过§2.6五角度攻击 + §七自检清单                            |

## 七、逻辑自检清单（日式版）

### 7.1 逻辑闭环检查
- [ ] 六要素（死因/手段/时机/机会/动机/身份）两两互检无矛盾
- [ ] 死因与现场表现一致（无"称溺死却无入水痕迹"类矛盾）
- [ ] 凶手作案所需的关键信息均有获取渠道（钥匙、时间、现场布局）
- [ ] 存在完整排除项（自杀/意外/病亡/假死/外部闯入/合谋/时间伪造/妖怪作祟均被排除且各有线索）

### 7.2 时间线检查（日式计时）
- [ ] 时间制（24小时/时辰制）换算统一无误
- [ ] 主时间线物理自洽，所有记录/证词/风吕登记可叠加
- [ ] 每个角色有时间线，空白时段有解释
- [ ] 任一证言至少与一条独立信息源交叉验证（宿帐×风吕×列车×目击）
- [ ] 钟表/时间篡改类诡计有系统性来源 + 无人发现的合理理由
- [ ] 时刻表类诡计有真实时刻表线索卡支撑，换乘/班次推算正确
- [ ] 夜间目击有照明来源交代，无"漆黑看清"硬伤
- [ ] 行程/交通核算与角色声称相符（封山时步行速度、末班车时间）

### 7.3 物理可行性检查（日式器物）
- [ ] 手法200字内可描述清楚
- [ ] 工具三问全部通过（来源/去向/痕迹）
- [ ] 和室空间（押入れ/阁楼/檐廊）有空间真实性，非凭空藏身处
- [ ] 延时装置已归类（真延时/心理延时）且精度验证通过
- [ ] 密室"进、出、闭"三向都有解；藏身处有空间交代
- [ ] 无超自然手法（写实/都市传说档）；设定系已立规则并明示
- [ ] 风吕（裸身）逻辑已处理（无凶器藏匿/入浴在场性/浴后状态）

### 7.4 妖怪归位检查（日式特有）
- [ ] 所有妖怪/怨灵/诅咒线索均有非灵异解释
- [ ] 每个灵异线索可被搜证证伪（物理证据存在且可获得）
- [ ] "神隐"/失踪角色有明确去向交代（非"被神带走"了之）
- [ ] 设定系妖怪能力有规则、有代价、留下可验证现象
- [ ] 妖怪元素绑定了至少一条可搜证的物理线索

### 7.5 线索公平性检查
- [ ] 所有关键线索在游戏过程中可被搜证获得（无天降线索）
- [ ] 关键推理链≥3步，每步≥2条独立线索支撑
- [ ] 每条线索标注了推理价值（无推理价值的线索已删除或转纯氛围）
- [ ] 身份诡计有提前暗示，且存在至少一条不可伪造的身份识别锚点（家纹/胎记/旧疤/信物）
- [ ] 每条误导线索有收束（可被推翻或有解释）
- [ ] 推理所需日式知识已写入剧本（知识自包含，ps_日式推理 §5.8）

### 7.6 唯一性检查
- [ ] 给定全部线索，只有一套六要素自洽
- [ ] 伪解答（若有）能被明确反证线索推翻
- [ ] 排除法穷举了所有"他杀外可能"（含妖怪作祟）
- [ ] 合谋/帮凶/知情者的信息边界清晰（谁、何时、知道多少）

### 7.7 时代与家制度检查
- [ ] 档位（明治/大正/昭和/平成/令和）已定且全程守约
- [ ] 无"假装有现代科技"或"假装没有现代科技"（按档位）
- [ ] 时代局限已处理（无监控时代靠人证物证/有监控时代交代盲区）
- [ ] 家制度形态与时代匹配（家督制仅战前/均分继承战后），养子/继承规则自洽
- [ ] 称谓、器物、制度无跨时代混搭；妖怪档位（写实/都市传说/设定系）已定且守约

### 8.2 元素清单

**物理诡计元素**：
- 和室建筑（障子/襖/押入れ/阁楼/檐廊/围炉里）——密室与藏身处
- 刃物（菜刀/剪刀/日本刀）、钝器、绳索（勒缢）——凶器来源在旅馆厨房/仓库/房间
- 浴衣/和服/腰带——可作凶器（腰带勒杀）或物证（血迹/撕损）
- 电热毯/暖炉/定时器——尸温诡计与延时装置
- 蜡烛/油灯/线香——延时与计时

**身份诡计元素**：
- 双胞胎/替身 → 提前给出双生传闻、系图疑点
- 养子/婿养子/相续养子 → 系图、户籍、家纹、老仆证词
- 家纹/印章/和服纹样 → "不可伪造"的身份识别锚点
- 一人分饰两角 → 通过"两人从不同时出现"的时间线揭示
- 性别置换 → 通过"从不宽衣""声音"等细节矛盾揭示
- 冒名顶替 → 宿帐/户籍/旧识认人综合推理

**时间诡计元素**：
- 死亡时间伪造 → 尸检+环境线索（电热毯/暖房）比对
- 钟表误导 → 多个计时源读数矛盾
- 时刻表错位 → 真实时刻表比对（§3.2）
- 延时杀人 → 定时器/蜡烛/冰块/慢性毒机制线索

**妖怪/民俗元素**（见§附录A速查）：
- 雪女、河童、座敷童子、狐凭、天狗、怨灵、妖刀、百鬼夜行、神隐
- 归位方式：低温/溺亡/藏匿/药物/绑架/假死——每个都须绑定物理线索

**家族制度元素**（见§附录C速查）：
- 本家/分家、家督继承、养子、家纹、系图、遗嘱、老铺家元
- 继承顺位、名号断承、家宝、佛龛供奉

**社会派元素**（见§附录D速查）：
- 阶层固化、官僚黑幕、战争遗留、校园霸凌、职场压榨、媒体舆论、冤案
- 旧照、日记、档案、病历、账目、剪报、录音

**氛围元素**：
- 雪、温泉雾气、障子光影、挂轴、香炉、暖帘、提灯、旧照片、摇铃
- 敬语、称呼、座次、上座下座——关系与权限的映射

| "妖怪是不是真的？"         | 妖怪归位（物理真相）                 | 每个灵异线索绑定物理证据，逐步证伪（§3.7）           |
| "为什么是现在杀人？"       | 社会派触发事件/继承临界点            | "最后一根稻草"事件明确，动机可查证（§3.8）           |
| "所有人可疑，到底是谁？"   | 暴风雪山庄/连环杀人/家族继承         | 温泉旅馆封山排除法逐轮锁定；家系图动机分布           |

### 日式本格核心公式

```
逻辑严谨的日式本格剧本 = 时代档位自洽 + 六要素闭环 + 自洽时间线 + 物理可行手法 + 妖怪归位 + 可推导线索链 + 唯一真相 + 完整排除法 + 知识自包含
```

### 剧本创作优先级（逻辑先行）

1. **先设计真相与诡计**——这是本格推理的灵魂
2. **再过逻辑框架**——六要素闭环、时间线、物理可行性、时代档位（本库第二章）
3. **再定妖怪/主题基调**——妖怪档位与社会派选题，先立规则再写作（ps_日式推理 §5.4、ps_日式推理 §5.6）
4. **再设计角色和动机**——家族结构与身份诡计互检（ps_日式推理 §5.3）
5. **再反向设计线索链**——从真相反推，建"线索链总表"，确保推理路径完整且公平
6. **最后设计分幕与氛围**——知识自包含，信息流速合理，玩家体验顺畅
