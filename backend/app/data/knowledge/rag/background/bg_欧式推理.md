## 一、欧式推理的定义与核心原则

### 1.1 什么是欧式推理

欧式推理以**中世纪欧洲（或架空欧陆）**为舞台的推理类型，天然继承"英式本格"的古典血脉——**密室、不可能犯罪、童谣杀人、封闭庄园/孤岛**均源自欧式传统。核心公理与现代本格一致：**真相必须来自"线索 + 逻辑"，而非"灵感 + 权威"**。

**两条铁律**：

1. **"欧式是包装，推理是内核。"** 欧式的价值在于提供一个与现代**不同的证据体系与常识体系**（城堡、教会、骑士、纹章），让古典诡计焕发新意——但欧式不能成为"不严谨的免罪符"。
2. **欧式剧本必须"自己解释自己的世界"**：玩家对城堡结构、爵位继承、纹章、教会法、中世纪毒药、钟声计时的认知参差不齐，剧本内所有关键知识必须以设定说明或知识线索卡形式给出（见ps_欧式推理 §5.6知识自包含），**不得依赖玩家自带欧式历史知识**。

### 1.2 欧式 vs 古风/现代本格：证据体系差异

| 维度     | 现代本格                   | 欧式（中世纪）本格                             |
| -------- | -------------------------- | ---------------------------------------------- |
| **身份识别** | 指纹 / DNA / 人脸 / 证件    | 纹章 / 封印 / 信物 / 疤痕 / 胎记 / 仆从辨认 / 族谱 |
| **验尸**     | 法医仪器 / 毒理化验        | 粗糙检视（中世纪解剖受限）/ 试毒人 / 症状推断 |
| **计时**     | 钟表 / 手机 / 监控时间戳    | 教堂钟声（祷时）/ 日晷 / 水钟 / 沙漏 / 烛火   |
| **通讯**     | 电话 / 网络 / 监控          | 信使 / 快马 / 传令官 / 信鸦 / 口头传话          |
| **门禁**     | 监控 / 门禁卡 / 智能锁      | 吊桥 / 城门 / 闸门 / 门闩 / 守卫 / 城墙 / 护城河 |
| **记录**     | 支付 / 行车 / 日志          | 羊皮纸文书 / 蜡封 / 手抄本 / 账簿 / 领地册 / 忏悔记录 |

> **核心推论**：欧式本格不是"少了科技更自由"，而是"**换了一套证据体系**"。欧式剧本的严谨性，取决于对这套中世纪证据体系的使用是否自洽（§2.7时代要素排查）。

### 1.3 剧本杀公平原则（欧式适配十诫）

> **剧本杀的核心是"所有玩家共同参与的解谜游戏"**，而非单一侦探的破案故事。以下原则改编自诺克斯十诫和范·达因准则，例证按欧式语境改写：

| 编号 | 原则                   | 说明（欧式例证）                                                     |
| ---- | ---------------------- | ------------------------------------------------------------------ |
| 1    | **凶手必须在场**       | 凶手必须在游戏开始时已在场，且以公开身份登场——不能中途冒出一个从未出场的人物 |
| 2    | **线索全面呈现**       | 所有关键线索（文书、蜡封、凶器、纹章、信物、验尸记录）必须在游戏过程中可被发现，不得在真相揭晓时才"补"线索 |
| 3    | **公平追凶**           | 每个玩家（包括凶手）搜证与发言权利对等；凶手可撒谎，但不能被系统保护 |
| 4    | **物理可行**           | 手法必须物理可行——不得用巫术、恶魔、诅咒、圣迹等超自然力量（设定系/变格本须先立规则，见§2.3） |
| 5    | **侦探不是凶手**       | 主持推理的"侦探"角色（巡回法官/骑士/修士/学者若担任此职）不应是凶手——其他玩家角色可以是 |
| 6    | **身份诡计须提前暗示** | 私生子/顶替/女扮男装/双生等身份诡计必须在游戏中提前给出暗示线索（纹章疑点、族谱矛盾、旧识迟疑） |
| 7    | **动机须有深度**       | 动机应与角色背景（继承权/领地/恩怨/宗教/政治）一致且足以支撑谋杀——不能是"一时冲动"或"疯了" |
| 8    | **人人有嫌疑**         | 每个角色（包括真凶）都应有合理动机与可疑之处，不让任何人过早被排除 |
| 9    | **关键线索唯一指向**   | 关键线索链最终应指向唯一的真凶，尽管中间存在误导                   |
| 10   | **不得隐藏证据**       | 主持人不得主动隐藏玩家已发现的证据——所有发现的线索都公开记录在线索板上 |

## 二、逻辑严谨性核心框架（欧式适配）

> **创作任何欧式剧本，都应先过本框架，再考虑诡计与氛围。** 逻辑严谨 = 时代要素自洽 + 六要素闭环 + 时间线自洽 + 物理可行 + 建筑可验证 + 线索可推导 + 真相唯一 + 知识自包含。

### 2.1 案件六要素闭环（欧式版）

一个合格的欧式案件必须形成"六要素闭环"。真相揭晓后，六要素彼此咬合、无相互矛盾；任一要素被推翻都会牵动其他要素重新检验。

| 要素   | 定义                 | 真相揭晓时必须回答的问题                                       | 欧式配套支撑证据                               | 常见漏洞                                     |
| ------ | -------------------- | ------------------------------------------------------------ | ---------------------------------------------- | -------------------------------------------- |
| **死因** | 致死原因与致死机制   | 死者怎么死的？刺伤/勒缢/毒杀/坠亡与死亡因果是否自洽？         | 检视记录、现场血迹/痕迹、试毒人、症状描述     | 死因与现场矛盾（中毒症状却称刺伤致死）       |
| **手段** | 凶手实现死因的方法   | 用什么凶器/毒药/机关？每一步物理动作是否可行？                | 凶器来源与去向、工具痕迹、机关制作痕迹         | 无来源凶器（武库/厨房查无）、密道凭空出现     |
| **时机** | 死亡时间与作案时间窗 | 哪个时辰死的？凶手在哪个时段动的手？                          | 钟声/烛火/尸温的粗判、仆从走动、行程核算       | 死亡时间跨多个时段使手法失效、祷时换算错误     |
| **机会** | 作案窗口的到达者     | 案发时段谁能接触现场与死者？谁被排除？                        | 城门/吊桥/守卫/钥匙归属、仆从证词、领地记录   | 排除不完整、未考虑密道/暗道/攀墙/仆从持钥      |
| **动机** | 杀人动因及其一致性   | 为何杀此人？为何此时杀？与角色背景是否自洽？                  | 继承权/领地/宗教/政治恩怨/文书契约             | 动机不足、动机与人物身份背景矛盾               |
| **身份** | 凶手/死者/涉事者真实身份 | 凶手是谁？死者是谁？是否涉及顶替/私生子/女扮男装/双生？    | 纹章/封印/信物/疤痕/族谱/仆从辨认              | 身份诡计无提前暗示、置换后行为与真实身份不符   |

**闭环校验法**（六要素两两互检）：
- **死因 × 手段**：该死因必须能由该手段产生。例如慢性毒（钟乳石/水银长期摄入）不可能表现为瞬间毙命；剑伤与匕首伤的创口形态必须区分。
- **时机 × 机会**：死亡时段窗口内，凶手必须"在场"或"可控"。若凶手有不在场证明，必须存在能成立的"替代到场路径"（延时毒药/定时机关/密道藏身/替身），否则矛盾。
- **动机 × 身份**：凶手的动机必须与其**真实身份**（而非伪装身份）的前史吻合。
- **手段 × 时机**：手法的执行时间必须落在作案窗口内；延时手法（蜡烛/水钟/慢性毒）的精度必须支撑死亡时间设定。
- 任何一处矛盾 = 剧本硬伤，须修正要素本身，**而非靠"玩家没想到"来掩饰**。

### 2.2 时间线一致性（欧式版）

**法则 1 · 计时体系自洽**：中世纪计时为**教会祷时（Canonical Hours）**与**日晷/水钟/沙漏/烛火**。祷时八段——晨祷（Matins）、赞经（Lauds）、初祷（Prime）、第三时（Terce）、第六时（Sext）、第九时（None）、晚祷（Vespers）、夜祷（Compline）——教堂钟声即报时系统。全剧本须统一换算标准，不得出现祷时与现代时间混用的矛盾。日晷夜间失效、水钟可被放水做手脚、沙漏可被翻转、蜡烛燃烧受风与蜡质影响，**精度各异**，只能作**粗略**佐证。

**法则 2 · 照明约束**：中世纪无电灯，夜间靠火把/蜡烛/油灯/壁炉/月光。**黑夜里"看清什么"是可检验的事实**——谁在无火光的钟点能看清羊皮纸文字、能辨认远处人影，须有照明来源交代。烛台被吹灭、蜡烛燃烧时长、火光下误认，都是可利用的时间/目击线索。

**法则 3 · 行程约束**：中世纪交通靠步行/马匹/马车/舟船。参考速度——步行一日约20-30英里，骑马每日40-60英里，快马换乘急递可更快。**"从甲地到乙地所需时日"是硬约束**：报称"三日路程"者若实际需七日，即是破绽。渡河（无桥处靠渡船）、翻山（驿道与隘口）都是行程核算要素。

**法则 4 · 交叉验证**：任一时段的证言/记录至少与一条独立信息源交叉印证：教堂钟声 × 仆从走动、羊皮纸文书蜡封 × 见证人、领地铁匠/马厩记录 × 行程核算。无交叉的单方证词属"待证信息"，不能直接当铁证。

**法则 5 · 空白时段必须有解释**：角色"独处无证明"的时段，要么是推理的关键（嫌疑窗口），要么必须有非犯罪理由（私下密会、偷情、偷窃、向忏悔神父告解），否则是漏洞。

**法则 6 · 系统性偏差才有说服力**：时间被篡改时，偏差必须来自可解释的系统（钟楼钟被停、水钟被放水、更夫被买通固定误报、某座日晷被偏转），并交代为何无人及时发现。临时、随意、无法解释的"对不上"是硬伤。

**构建步骤**：先写"客观物理时间轴"（死亡时间定死）→ 再写每个角色的"主观时间轴"（各角色以为的时间）→ 最后标注两者偏差及其来源，确保偏差线索可在游戏中被发现。

### 2.3 物理可行性验证（欧式版）

**工具三问**（对手段的每一步物理操作逐一过问）：
1. **工具从哪来？** 凶手必须有获得渠道——武库、厨房刀具、领主兵器、药圃/毒物来源、匠人打造。线索须能指向该渠道。
2. **用后去哪了？** 凶器/毒药容器必须有处置（带走/丢弃/藏匿/留在现场被误导），去向合理且可被追查。
3. **留下什么痕迹？** 使用必然产生痕迹——刀刃与伤口形状匹配、血迹喷溅、密道开启痕迹、毒物残留、勒痕与绳索材质一致。

**硬性标准**：
- 手法必须能在200字内说清，且以"中世纪常识 + 基本物理"可验证。
- **城堡建筑可验证**：密道/密室/暗格（祈祷室夹层）必须有**建造者与用途线索**（战争密道、走私通道、主教避难所、领主金库暗道）；石墙厚度、螺旋楼梯、塔楼高度、吊桥机关都是物理约束——**"从塔顶到地面所需时间""密道能否走通"是可检验的事实**。
- **武功/战力边界**：写实中世纪本中，骑士铠甲有重量与噪音（锁子甲行动有响声）、长弓射程受限于弓力、弩的装填耗时——**铠甲/弓箭/重器的物理属性必须遵守**；设定系/变格本若需超常（巫术/恶魔），必须先立规则并明示（§3.7）。
- **延时装置只有两类**：① 真正延时（蜡烛定时、水钟、沙漏、自燃引火物如浸油布条、慢性毒药）；② 心理延时（所有人误判死亡/离场时间，实际凶手当时就在场）。写延时必须先归类，再验证该类别的**时间精度**是否足以支撑死亡时间设定。

### 2.4 线索—推理映射（欧式版）

**证据类型**（欧式本五类证）：
- **物证**：凶器、遗物、血迹、毒物残留、密道痕迹、遗书
- **人证**：仆从、守卫、马夫、厨房伙计、邻庄、教堂执事的证词
- **书证**：羊皮纸文书、蜡封印信、契约、账册、遗嘱、族谱、领地图册、忏悔告解记录
- **口供**：嫌疑人供词（须与物证/书证交叉）
- **检状**：粗糙验尸/检视记录（身份特征、死因、伤痕——见§附录A）

**线索三级**：
- **事实线索（F）**：直接陈述、无需推断即可采信（羊皮纸文书原文、蜡封契约、账册记录）。注意：事实线索"内容"可信，但"解读"仍可被误导（文书写"伯爵于赞经时回堡"，但谁写的、何时写的仍需推断）。
- **推断线索（I）**：需结合设定/常识推断（血迹分布、创口与凶器匹配、胃内容物与死亡时间）。
- **误导线索（R）**：指向伪解答，**必须在后期可被推翻或解释**，不能不了了之。

**欧式证据的局限（必须主动处理）**：
- **中世纪验尸极粗糙**：解剖在教会禁忌下受限，死亡时间判定粗略；慢性中毒、心疾猝死常被误判为病死/暴毙——"以病掩毒、以毒掩病"是合法手段，但误判的暴露必须有线索。
- **无指纹、无DNA、无照片**：身份识别靠纹章、封印、信物、疤痕、胎记、仆从辨认——识别锚点必须存在且不可伪造（§3.3）。
- **毒物检验几乎为零**：砷的"马什试验"（Marsh test）是19世纪才发明——**中世纪无法化学验毒**，只能靠症状/试毒人/厨余/药圃排查（§3.7）。

**推理价值标注**：每条线索在创作时应标注——它单独证明什么？与哪条线索组合证明什么？为**排除**哪个可能性服务？无推理价值的线索不该出现（纯氛围线除外，且需控制数量）。

**链式推导要求**：
- 从"初始线索集"到"真凶"至少存在一条 **≥3 步的逻辑链**。
- 关键推理链的**每一步至少2条独立线索支撑**。
- 链的每一步都必须"可被反驳"且"存在反驳线索"——否则该步骤是霸王推理（单方面认定、不可检验）。

### 2.5 唯一性判定与完整排除法（欧式版）

在指认真凶之前，所有"他杀外可能"必须先被排除，且每个被排除项都要有**至少一条明确的排除线索**：

| 须排除的可能性       | 欧式排除线索示例                                       |
| -------------------- | ------------------------------------------------------ |
| 自杀                 | 遗书笔迹比对、现场无自伤工具、伤痕角度不符             |
| 意外                 | 现场无意外触发条件（坠楼却无攀爬痕迹、误食却无食物中毒对象） |
| 病亡                 | 检视记录死因明确为他杀（非病非暴毙）                   |
| 无死亡（假死/顶替）  | 身份识别锚点确认尸体身份、后续有该人未死的行为矛盾     |
| 外部闯入者作案       | 城墙/吊桥/城门/守卫排除外来者、封闭场景设定             |
| 合谋 / 帮凶          | 涉案人员信息边界清楚、行动窗口逐一排查（如仆从"恰好"不在） |
| 死亡时间被伪造       | 计时体系交叉验证（钟声/烛火/沙漏/行程）                 |
| **巫术/恶魔/圣迹作案** | 所有超常线索均被物理证据证伪（§3.7）                   |

**唯一性检验**：给定全部线索，是否**只有一套**六要素自洽？若存在第二套同样自洽的解释，剧本就有逻辑漏洞——除非它是设计好的"伪解答"，而伪解答必须有反证线索（§3.9）。

### 2.6 反证检验流程（真相定型后必做）

把"真相"当作敌人，模拟最刁钻的玩家从五个角度攻击：

| 攻击角度       | 攻击问题                                                   | 被攻击即漏洞的情形                                     |
| -------------- | ---------------------------------------------------------- | ------------------------------------------------------ |
| **时间攻击**   | 凶手在X时做了Y，有没有任何证据/矛盾能推翻？                | 时间线上存在不可调和、无法解释的冲突                   |
| **物理攻击**   | 手法每一步真的可行吗？密道/毒药/铠甲/城堡建筑是否违背物理或时代技术？ | 密道凭空出现、毒药无来源、铠甲无声瞬移、巫术飞天     |
| **信息来源攻击** | 凶手作案所需的"关键信息"（死者位置、时辰、钥匙、密道、现场布局）从哪得知？ | 凶手不该知道却必须知道，且无获取渠道线索（如钥匙在管家处而凶手无接触） |
| **动机攻击**   | 换成"自杀/意外/病亡/嫁祸/巫术作祟"能否同样解释现场？      | 排除项缺线索、超常未归位，真相无法唯一化               |
| **公平性攻击** | 玩家在游戏中能否获得推导真相所需的**一切**信息（含欧式知识）？ | 关键信息在复盘时才补充、或依赖玩家自带欧式历史知识     |

**修正策略**：漏洞无法用"补一句话"解决时，**宁可改动设定**（改手法/改时间/改角色信息/改时代档位），也不要保留逻辑漏洞。

### 2.7 时代要素排查（欧式的"科技排查"）

创作欧式剧本，必须**先明确本世界的"证据能力边界"**——有哪些手段、没有哪些手段，且不得混用。

| 时代要素 | 中世纪形态                                   | 对诡计的约束                                     | 可利用的破绽                                         |
| -------- | -------------------------------------------- | ------------------------------------------------ | ---------------------------------------------------- |
| **计时** | 教堂钟声/日晷/水钟/沙漏/烛火                  | 时间精度低，死亡时间难以精确定位                 | 钟楼钟被停、水钟放水、烛火误导、故意错认祷时         |
| **验尸** | 粗糙检视/试毒人/症状推断（解剖受限）           | 只能判定大体死因与部分毒物                       | 慢性毒难查、以病掩毒、检视官受贿或失职               |
| **身份** | 纹章/封印/信物/族谱/仆从辨认                   | 无照片无指纹，身份难以精确核验                   | 纹章被仿、顶替、私生子冒认、族谱被改                 |
| **门禁** | 城门/吊桥/闸门/城墙/护城河/守卫                 | 封闭性极强，密室更真实但也更难                    | 密道、贿赂守卫、守卫渎职、翻墙、吊桥机关做手脚       |
| **通讯** | 信使/快马/传令官/信鸦/口头传话                 | 消息慢，实时沟通难                               | 信被截、快马误时、口信错传、传令官被买通             |
| **照明** | 火把/蜡烛/油灯/壁炉/月光                       | 夜间活动受限，目击可信度降低                     | 烛台被吹灭、蜡烛燃烧时长、火光下误认                 |
| **医药** | 修道士医术/草药/放血/炼金术                     | 慢性毒难确诊、外伤感染可致死                     | 误诊、以病掩毒、药圃留痕、炼金术掩盖毒源             |
| **记录** | 羊皮纸文书/蜡封/手抄本/账册/领地图册             | 书面记录是硬证据                                 | 文书篡改、蜡封被仿、手抄本传抄错误、账册造假         |

**三条铁律**：
1. **不得"假装有现代科技"**：欧式剧本中不得出现监控、电话、照片、指纹比对、DNA鉴定、化学验毒（马什试验）。若确需"超时代便利"，必须是穿越/架空设定的明确规则。
2. **必须主动处理时代局限**：验毒不万能、计时不精确、身份靠人工核验、消息传递慢——这些局限要么被纳入推理，要么被明确交代失效理由。**不能"假装没有局限"**。
3. **时代知识必须自洽**：中世纪器物、制度、称谓不可混搭（如把15世纪的火药与13世纪的骑士混用要交代）；架空设定须自订并明示（"本世界无铁器""本世界有教会魔法"）。

### 2.8 常见逻辑漏洞清单（欧式版避坑）

| 漏洞             | 表现                                                     | 规避方法                                         |
| ---------------- | -------------------------------------------------------- | ------------------------------------------------ |
| **密道凭空出现** | 城堡密道/暗格毫无建造者与用途交代                         | 交代密道来历（战争/走私/避难/金库）与启用线索（§2.3） |
| **巫术解案**     | 用恶魔/巫术/圣迹解释本可物理验证的现场                   | 超常归位：所有灵异线索必须有物理解释（§3.7）    |
| **顶替无铺垫**   | 私生子/替身/女扮男装毫无预兆，任意冒充他人               | 提前暗示纹章疑点/族谱矛盾/旧识迟疑（§3.3）      |
| **验毒误用**     | 中世纪本里用现代化学验毒破案                             | 明确中世纪无法化学验毒，靠症状/试毒人/药圃排查（§3.7） |
| **祷时换算错**   | 祷时/时辰与现代时间换算出错，时间线自相矛盾               | 统一祷时换算标准（§2.2）                        |
| **纹章识别悬空** | 无照片却"一眼认出"远道之人、或认不出应认之人             | 靠纹章/封印/信物/疤痕/族谱/仆从核验（§3.3）     |
| **文书时间矛盾** | 书信往返、信使投递时间与现实行程不符                     | 按信使/行程核算（§2.2法则3）                    |
| **认尸草率**     | 尸体毁容/无头却无人质疑身份                              | 设立身份识别锚点（§3.3）                        |
| **照明忽略**     | 漆黑夜晚角色"看清"了本看不清的细节                       | 交代照明来源（火把/烛台/月光）（§2.2法则2）     |
| **知识依赖**     | 推理依赖玩家自带中世纪知识，而非剧本内线索               | 关键知识以设定说明/知识线索卡给出（ps_欧式推理 §5.6）       |
| **天降线索**     | 关键信息在真相揭晓时才首次出现                           | 线索前置、可搜证（§2.4）                        |
| **排除不完整**   | 忘了自杀/意外/病亡/假死/帮凶/外部闯入/巫术等选项          | 过完整排除项清单（§2.5）                        |


## 三、核心诡计类型库（欧式适配）

### 3.1 欧式密室讲义（城堡密室）

欧式推理以"密室/不可能犯罪"为皇冠上的明珠，而城堡是密室诡计的天然载体。卡尔《三口棺材》的密室讲义是这一板块的经典框架。

#### 密室的两大基本分类

| 类型                   | 说明                       | 关键特征                                   |
| ---------------------- | -------------------------- | ------------------------------------------ |
| **机械密室**（物理密室） | 通过机关、暗格、门闩装置实现密室 | 密室是真实的，凶手用物理手段完成       |
| **心理密室**（错觉密室） | 利用心理错觉制造密室假象   | 密室是假的——门闩实际被从外拨动、锁是假锁 |

#### 密室的形成者（剧本杀视角）

| 形成者         | 说明                                 | 在剧本杀中的实现                         |
| -------------- | ------------------------------------ | ---------------------------------------- |
| **凶手制造**   | 最常见的类型——凶手杀人后制造密室     | 凶手玩家需在搜证环节注意隐藏相关手法线索 |
| **死者制造**   | 自杀伪装成他杀，或死者无意制造密室   | 最终揭晓时需通过检视证明是自杀           |
| **帮凶制造**   | 第三人在案发后无意或有意制造密室条件 | 该角色有独立动机（保护某人/制造混乱）    |
| **多人共同制造** | 多人各自的行为叠加形成密室假象       | 每个参与者都以为自己是"唯一做手脚的人"   |

#### 密室讲义分类索引（欧式选型用）

| 编号 | 密室类型（卡尔分类简版）                           | 欧式实现示例                                 | 剧本杀适用性 |
| ---- | -------------------------------------------------- | -------------------------------------------- | ------------ |
| 1    | 案件实为意外/自杀，被误认为他杀                    | 坠楼被伪造成推落、自缢被伪造成他杀勒死       | ★★★ 高      |
| 2    | 机械机关：杀人后自动上锁                           | 吊桥机括、塔楼石门、暗格活板、铰链门         | ★★ 中       |
| 3    | 凶手作案时就在房间，事后混入人群或藏匿             | 藏身密室暗格/祈祷室夹层/盔甲内/仆人房间，混入人群 | ★★★ 高      |
| 4    | 锁被做手脚（假锁/卡扣），实则任何人可开             | 门闩被细线/铁条从门缝拨动，蜡烛火掩饰        | ★★★ 高      |
| 5    | 用工具从外部或门下拨动门闩                         | 细铁丝/铁条伸进门缝挑闩（中世纪无鱼线，用金属丝/皮革条） | ★★ 中   |
| 6    | 死者自己锁门（自杀或误锁）                         | 死者自缢前反锁、误触门闩                     | ★★★ 高      |
| 7    | 伪装他杀的意外（利用现场布置误导死因）             | 伪造仇杀现场掩盖意外/自杀                    | ★★★ 高      |

#### 密室杀人的动机（剧本杀适用）

| 动机                 | 说明                             | 对应的剧本设计                         |
| -------------------- | -------------------------------- | -------------------------------------- |
| **伪装自杀/意外**    | 让密室看起来是自杀或意外         | 检视线索需揭示真正死因与表面不符       |
| **制造不在场证明**   | 让所有人以为死亡发生时无人能进出 | 祷时/钟声时间线推理是破解关键          |
| **嫁祸给特定的人**   | 让某人有唯一"可能"作案的条件     | 嫁祸对象应有对应的自我辩护线索         |
| **制造恐怖氛围**     | 连环杀手的标志性手法             | 多起案件共享同一密室模式               |
| **掩盖真实手法或死亡时间** | 密室本身是烟雾弹             | 玩家需跳出密室思考"为什么要做密室"     |

**逻辑约束（重点）**：
1. 密室必须**"进、出、闭"三步都能解释**：凶手怎么进、怎么出、门闩/锁怎么复原。
2. 心理密室必须交代**"门闩被如何误认"**——误认机制本身要有线索。
3. **密道/暗格必须有"建造者与用途"线索**：战争密道、走私通道、主教避难所、金库暗道要有来历交代，否则是凭空出现的通道。
4. 制造密室必须比"不制造密室"更有利：找不到合理动机时，用"伪装意外"或"制造恐慌"作为默认解释。

> **创作提示**：设计密室案时，顺序为——先问"凶手为什么要做密室"（动机）→ 再设计"怎么做的"（手法）→ 最后验证"怎么破除的"（破案线索）。**密室形成有解，破除也必须有解。**

### 3.2 不在场证明（欧式版）

#### 在剧本杀中的典型形式

| 形式             | 说明                                   | 破解方向                               |
| ---------------- | -------------------------------------- | -------------------------------------- |
| **钟声/祷时作证** | 声称案发时听到教堂钟声、见到某人经过   | 祷时误认、钟楼钟被停、雨夜听错         |
| **仆从互相作证** | 多人相互证明某人在某处                 | 共犯作伪证/集体时间误认/仆从利益捆绑   |
| **账册/领地图册** | 账房记录、领地登记显示在别处           | 记录被篡改/代笔/蜡封被仿               |
| **文书/信使**    | 羊皮纸文书蜡封、信使记录显示人在他处   | 文书伪造/信使误时/他人代寄             |
| **行程核算**     | "我这几日都在赶路，不可能回堡作案"     | 里程矛盾/抄近路/换马/中途折返          |

#### 常见的"不在场证明破绽"类型

1. **祷时谎称**——证人被误导，以为在某个钟点看到了某人
2. **替身诡计**——有人冒充嫌疑人出现在别处（双生/顶替/女扮男装）
3. **书证伪造**——文书、账册、信使记录被人为改动
4. **里程错觉**——看似不可能的往返距离其实可以做到（抄近路/昼夜兼程/换马）
5. **共犯伪证**——两人或多人合谋提供虚假证词

#### 在剧本杀中设计不在场证明

**关键原则**：每个角色（包括真凶）都应有不在场证明。真凶的不在场证明必须"看起来合理但存在破绽"——且**破绽必须有线索**，而不是"天衣无缝"或"靠运气看穿"。

| 角色类型       | 不在场证明设计                                               |
| -------------- | ------------------------------------------------------------ |
| **真凶**       | 看似合理但有细微破绽的证明（如"我整夜在礼拜堂祷告"——但守夜修士未曾见到烛火、或祈祷时间与钟声不符） |
| **其他嫌疑人** | 有真实的/部分真实的不在场证明，但各有隐瞒的理由（如"那夜我在地窖偷喝藏酒所以不想说"） |
| **目击者**     | 可能错误地确认了时间——不是故意的，是雨夜/火光/记忆偏差     |

**逻辑约束**：不在场证明的破绽必须**指向可搜证的位置**（密道、钟楼、账册、马厩记录、守夜簿），玩家通过搜证+交叉对比可发现，而非依赖某角色"突然想起"。

### 3.3 身份诡计（纹章/私生子/顶替/性别置换）

> **⚠️ 提示**：叙述性诡计在剧本杀中**受限制**（玩家能看到角色卡），但身份置换类诡计**有天然优势**——玩家彼此看到的角色卡有限，信息不对称正是剧本杀的特征。欧式身份诡计的独特性在于**纹章/封印与私生子制度**（见§附录B）。

#### 剧本杀中可用的身份诡计

| 类型             | 说明                                   | 实现方式                                         |
| ---------------- | -------------------------------------- | ------------------------------------------------ |
| **纹章/封印**    | 家族纹章、印章揭示或伪造真实身份       | 纹章是"不可伪造"的家族标识（§附录B），作识别锚点；伪造纹章需匠人/绘制者线索 |
| **私生子冒认**   | 非婚生子冒认合法继承人                 | 提前暗示族谱疑点、老仆证词、领结婚证/洗礼记录矛盾 |
| **顶替/替身**    | 顶替死者/失踪者的身份与领受             | 纹章、信物、疤痕、仆从辨认的综合推理             |
| **双胞胎/双生**  | 双生兄弟姊妹互换身份，或雇替身冒名     | 提前暗示家族有双生传闻、某人常年蒙面/戴盔       |
| **性别置换**     | 女扮男装/男扮女装（女骑士/修女梗）      | 通过外貌细节（"从不宽衣"、"声音低沉"）暗示      |
| **一人分饰两角** | 同一个人在不同场合使用两个身份         | 两个"角色"从不同时出现，玩家拼凑时间线发现       |
| **殉道/假死**    | 借"圣迹/殉道/战死"假死脱身或换身份      | "死亡"需有目击者，但检视线索不完整               |

#### 逻辑约束（重点）

1. **提前暗示原则**：诡计成立所需的事实（纹章疑点、族谱矛盾、双生传闻、某人从不以全脸示人）必须在**游戏早期**有线索。
2. **置换后行为一致**：置换后的角色，其行为细节必须与**真实身份**（而非伪装身份）吻合——真实的性别/年龄/习惯/旧伤是"无法完全伪装"的破绽细节，正是玩家的发现路径。
3. **身份识别锚点**：剧本中必须存在至少一条**不可伪造的身份识别线索**——纹章、封印、旧伤痕（家人/老仆知晓）、刻字信物（戒指/圣物/佩剑）、族谱记载、洗礼记录。
4. **一人分饰两角**：必须保证"两个身份从不同时在场"——用时间线核对每个"出场"时刻，任一时刻被两名独立角色同时目击即诡计破产。
5. **私生子的识别**：私生子往往有"无法直接证明"的特征——领洗记录、教父教母、继承权争议都是可查证线索；中世纪私生子**不能继承**（除非国王特批），这是动机与身份的核心矛盾点。

### 3.4 无面尸诡计（欧式版）

> **定义**：尸体面部被毁/无头/烧焦/高度腐败/锁子甲罩面，身份无法直接辨认，"死者是谁"成为第一道谜题。

#### 在剧本杀中的典型运用

| 步骤         | 游戏内实现                                | 设计要点                                        |
| ------------ | ----------------------------------------- | ----------------------------------------------- |
| **误导阶段** | 现场发现尸体+遗留物品→玩家推断死者是A     | 遗留物品必须明显指向A（A的佩剑/戒指/纹章/锁子甲） |
| **发现矛盾** | 角色A的"目击"与尸体情况不匹配→触发怀疑    | A声称在某处看到谁/什么，与尸体状态冲突          |
| **真相揭示** | 线索显示尸体实际上是B                     | 通过纹章/疤痕/体态/身高/仆从辨认/信物揭示       |

#### 经典结构变体

| 变体             | 说明                           | 剧本杀适用                                 |
| ---------------- | ------------------------------ | ------------------------------------------ |
| **尸体是替身**   | 凶手杀了无关人士冒充特定死者   | 需要凶手有接触"替身"的渠道和机会           |
| **尸体数量错误** | 实际死亡人数与发现的尸体数不同 | 多具尸体需在不同场景发现，玩家需统计比对   |
| **死者还活着**   | 某角色假死（配合"殉道/神隐"叙事） | 该角色的"死亡"需有目击者，但检视线索不完整 |

#### 逻辑约束（重点）

1. **必须有一条明确可靠的"身份识别锚点"**——纹章、封印、疤痕、胎记、特殊体态、刻字信物、仆从辨认。中世纪无指纹/DNA，**锚点尤为关键**。
2. **"误认"必须有合理原因**：面部毁损、无头、烧焦、盔甲罩面、亲属"拒绝细看"（如指认者另有目的）——否则玩家会质疑"为什么认错了"。
3. **识别线索的取得时机**：身份识别线索要在"误导阶段"之后、"真相揭晓"之前**可被搜证获得**，形成"先误导→再证伪→后锁定"的推理弧线。

### 3.5 封闭空间（欧式版 · 城堡/孤岛）

#### 欧式封闭空间载体

| 载体           | 封闭方式                                       | 适用诡计               |
| -------------- | ---------------------------------------------- | ---------------------- |
| **城堡**       | 吊桥升起、护城河、城门落锁、围城                 | 密室、连环杀人、继承案 |
| **孤岛/庄园**  | 渡船沉没/被凿、风暴封航                         | 童谣杀人、无面尸、暴风雪山庄 |
| **修道院**     | 山门封闭、戒律禁出（修士誓言）                   | 设定系（圣迹/异端）、连环杀人 |
| **比武场/驿馆** | 比武封场、驿馆驻守                             | 决斗、身份诡计         |
| **城镇（瘟疫隔离）** | 瘟疫封城、关卡封锁                           | 连环杀人、嫁祸、封闭社会 |

#### 逻辑约束（重点）

1. **凶手必须始终在幸存者中**；随着命案发生，嫌疑人集合必须**单调收缩**——不能中途出现"新到达者"或"此前不在场者"被排除后又复活。
2. 每一起新的命案都要**收窄可能性**（排除法推进），而不是制造无关混乱。
3. 连环案件要么共享同一凶手逻辑（特征/模式/被害者关联），要么明确揭示"第二凶手"，两者都需线索支撑。
4. **"不可进出"必须可被验证**：吊桥/城门/渡船的封锁状态、守卫换岗记录、雪地/泥地足迹（可数出进出人数）要有线索，不能只靠一句"封城了"。
5. **童谣/仪式杀人必须闭环**：每一起命案与童谣/圣徒传/诅咒内容一一对应，布设必须与死者选择/手法/现场对应（化用《无人生还》结构）。

### 3.6 时间诡计与延时机关（欧式版）

#### 在剧本杀中的典型形式

| 形式           | 说明                                     | 破解方向                             |
| -------------- | ---------------------------------------- | ------------------------------------ |
| **死亡时间伪造** | 通过检视误导/环境干预让死亡时间提前或推后 | 检视线索+环境线索（壁炉火/烛火）比对   |
| **钟声/祷时误导** | 钟楼钟被停、水钟被放水、报时被买通        | 多个计时源读数矛盾、权威时间源对比   |
| **时间线交错** | 两起事件的先后顺序被混淆                 | 目击证词交叉比对、物理痕迹的时序     |
| **延时杀人**   | 凶手动手后延迟死亡，制造不在场证明       | 凶器/机关的延时机制线索             |

#### 欧式延时手段

| 延时手段       | 原理                                   | 精度与注意                                             |
| -------------- | -------------------------------------- | ------------------------------------------------------ |
| **蜡烛定时**   | 蜡烛/圣烛燃烧到一定位置触发机关         | 受风力/蜡质影响，只能作粗略定时                        |
| **水钟装置**   | 水钟/渗漏计时触发                      | 需交代装置来源与安装者                                 |
| **沙漏**       | 沙漏计时触发/以漏沙推断时间             | 可被翻转做手脚，精度低                                 |
| **自燃引火**   | 浸油布条/硫磺/火绒定时引火             | 受潮失效风险，需留装置残件线索                         |
| **慢性毒药**   | 低剂量累积/迟发毒物，延迟发作          | 发作时间窗口宽，是"不在场证明"的经典手段               |

#### 逻辑约束（重点）

1. **偏差必须有系统来源**（§2.2法则6）：谁停的钟、何时停、为何无人发现，都要有交代。
2. **延时必须归类并验精度**：真延时（蜡烛/水钟/沙漏/慢性毒）or 心理延时（误判在场者）。真延时要验证时间精度能否支撑设定。
3. **死亡时间伪造必须有检视依据**：用什么手段误导了检视结论（壁炉保温/地窖降温/胃内容物做手脚/尸僵被破坏），该手段本身要留下可被发现的痕迹。
4. **中世纪计时不精确是双刃剑**：既给时间诡计留空间，也要求时间线推理"以相互矛盾的计时源"为突破口，而非单一定论。

### 3.7 毒药诡计（欧式特色）

> 中世纪毒药是欧式本最具特色的手段板块。其逻辑核心在两点：**毒物与死状的对应关系**、**中世纪无法化学验毒的局限**（见§2.4、§3.7）。

#### 毒药速查表（含逻辑约束）

| 毒药         | 中毒症状/死状                             | 化学验毒（中世纪） | 发作特性       | 来源渠道                     | 典型伪装                       |
| ------------ | ----------------------------------------- | ----------------- | -------------- | ---------------------------- | ------------------------------ |
| **砒霜/砷**   | 剧烈腹痛、呕吐、腹泻、抽搐                 | **无法化学验毒**（马什试验为19世纪发明） | 急性 | 药圃、炼金术、民间"毒粉"传闻 | 酒菜、蜜饯、汤药中             |
| **颠茄（致命茄）** | 瞳孔散大、口干、谵妄、皮肤潮红、心跳加速 | 无法化学验毒        | 急性可迟发       | 庭园种植、女巫草药、药圃     | 酒中下毒、香薰、烟             |
| **毒芹**     | 麻痹自下肢而上、呼吸困难、死亡            | 无法化学验毒        | 急性           | 沼泽野草、草药铺             | 混入草药、汤药、酒             |
| **乌头（狼毒）** | 四肢麻木、呼吸困难、心脏骤停（似心疾）    | 无法化学验毒        | 急性可迟发       | 山野自采、箭毒、药圃         | 药中下毒、箭矢淬毒             |
| **曼陀罗**   | 幻觉谵妄、口干、瞳孔散大、心跳加快（似中邪） | 无法化学验毒       | 中等，可致昏迷死亡 | 山野、游方巫师               | 香薰/烟/酒茶（"迷魂"）         |
| **水银/汞**  | 慢性中毒：口炎、震颤、神经损伤、狂躁       | 无法化学验毒        | 慢性           | 炼金术、镜子工匠、药剂       | 长期混入食物、药膏             |
| **蟾蜍毒**   | 剧烈心悸、呕吐、可致死                    | 无法化学验毒        | 急性           | 药圃、民间秘方               | 涂抹器皿、酒中                 |
| **蛇毒**     | 局部肿胀、出血、可致死                    | 无法化学验毒        | 急性（须入血）   | 猎蛇者、药师                  | 暗器淬毒、利刃涂毒             |

#### 逻辑约束（重点）

1. **中世纪无法化学验毒**：砒霜等毒物在中世纪**检测手段几乎没有**——只能靠症状、试毒人（宫廷有试毒官）、厨余/酒桶/药圃排查。**毒药诡计的破绽必须靠"症状-毒物对应"与"来源渠道"推理**，而非"验毒发现"。
2. **死状对应**：每种毒的症状必须与剧本描写一致——颠茄的谵妄可被误认"被恶魔附身"（可作误导向）、乌头症状似心疾（可作"病亡"误导），但不能张冠李戴。
3. **来源渠道**：凶手必须有获得毒物的渠道（药圃/炼金术/草药铺/庭园），线索须能指向该渠道。宫廷禁物被平民角色持有即需解释。
4. **急/慢性决定在场性**：急性毒（蛇毒入血、大剂量砒霜）凶手须在场或近场；慢性/迟发毒（水银长期摄入、小剂量累积）可制造不在场证明——毒物的发作特性必须支撑凶手的机会设定（§2.1时机×机会）。
5. **以病掩毒/以毒掩病**：慢性中毒被检视误判病死、真病死被误判中毒——都是合法手段，但误判的暴露必须有线索（药渣、药圃、症状细节、忏悔/医嘱）。

### 3.8 继承/宗教/政治权谋（欧式特色）

> 欧式的动机库集中在**继承权、领地、宗教、政治**四大主轴——它们共同决定"谁不能死、谁必须死、谁不敢查"。

#### 权谋载体

| 载体         | 冲突内核                         | 典型诡计                   |
| ------------ | -------------------------------- | -------------------------- |
| **贵族继承** | 长子继承/私生子/遗嘱/领地分割     | 毒杀、顶替、伪造遗嘱、灭口 |
| **教会**     | 主教之争/异端审判/圣物/赎罪券     | 毒杀、嫁祸异端、销毁证据   |
| **王权/宫廷** | 继承王位/摄政/权臣架空           | 嫁祸、伪造文书、毒杀       |
| **领地/封臣** | 采邑归属/效忠/边界之争           | 诬陷、伪造契约、暗杀       |
| **战争/边境** | 通敌/军功/领地争夺               | 替身、无面尸、栽赃         |

#### 继承与身份的制度约束（动机核心）

| 制度       | 说明                                                         | 推理用途                                     |
| ---------- | ------------------------------------------------------------ | -------------------------------------------- |
| **长子继承制** | 领地/头衔/财产由长子继承，次子从军或入教会                   | 长幼决定动机分布——次子"一无所有"是天然嫌疑 |
| **私生子** | 非婚生子不能继承（除非国王特批），地位低下                   | 私生子身份的揭露=身份诡计+动机爆发点        |
| **遗嘱/契约** | 领主可立遗嘱/赠地，蜡封文书是法律依据                         | 遗嘱真伪（蜡封、笔迹、见证人）是核心线索     |
| **嫁妆/寡妇** | 女性通过嫁妆与寡妇继承权掌握财产                             | 婚姻、丧夫、嫁妆账目可埋动机                 |
| **圣物/领地权证** | 教会圣物、领地特许状（Charter）是权力凭证                    | 凭证真伪/被窃/被毁是动机与案件触发点         |

#### 宗教要素的推理价值

| 宗教要素       | 说明                                                         | 推理用途                                     |
| -------------- | ------------------------------------------------------------ | -------------------------------------------- |
| **教会法庭**   | 与世俗法庭并行的审判体系，教士由教会审判                     | 行为权限——教士不受世俗审判（司法豁免）      |
| **忏悔保密**   | 神父对告解内容终身保密                                       | "唯一知情人"的沉默可作信息封锁/反转钥匙      |
| **避难权**     | 教堂内可提供庇护，世俗追捕不得入                           | 凶手藏身教堂=追捕盲区，可作诡计              |
| **异端审判**   | 宗教裁判所可拷问、火刑                         | 嫁祸异端/制造恐慌掩盖私怨                     |
| **圣迹/预言**  | 圣迹、预言、显灵被当作超自然证据                             | 可作误导源（§3.9），须以物理证据归位          |

#### 逻辑约束（重点）

1. **继承/权谋动机要可被查证**：遗嘱、契约、账册、族谱、领地文书应留下可搜证的痕迹——权谋不是"背景板"，而是推理素材。
2. **宗教豁免要交代边界**：教会法庭/避难权可作行为权限的戏剧张力，但不能成为逻辑漏洞——玩家仍应能凭线索指向真凶。
3. **超常（圣迹/预言/诅咒）不是解答**：一切宗教超常叙事必须归位到物理/逻辑解释（§2.5排除项、§3.7）。

### 3.9 误导与伪解答工程（欧式版）

**红鲱鱼设计原则**：

| 原则         | 说明                                         |
| ------------ | -------------------------------------------- |
| **有独立价值** | 即使不指向真凶，也揭示了某个角色的秘密或动机 |
| **合理存在**   | 不是凭空出现——与该角色的行为/背景一致        |
| **可被推翻**   | 后续有线索可推翻该误导，而不是"不了了之"     |
| **不过度集中** | 不要把大部分误导线索集中在同一个非真凶角色上 |

**欧式常见误导源**：
- **巫术/恶魔/诅咒/圣迹**：颠茄的幻觉、恶魔附身传说、预言应验——先引导玩家往"非自然"方向想，再用物理/毒物线索拉回（适合设定系与写实本交融）。
- **遗书/绝笔**：伪造遗书误导自杀（笔迹、措辞、蜡封为破绽）。
- **仇敌传闻**：死者"树敌众多"（邻庄、政敌、宗教对头）误导外部闯入，实际内部作案。
- **陈年旧怨**：用祖辈恩怨、战争旧债分散注意力，掩盖当下动机。

**伪解答设计**：一个表面上能解释所有线索的"假真相"。要求：
- 伪解答必须能**暂时覆盖**绝大多数线索；
- 伪解答必须有**至少一条反证线索**，且该线索在游戏后期可被搜证获得；
- 伪解答被推翻的瞬间 = "恍然大悟"时刻。

**逻辑约束**：伪解答数量建议 **1–2 个**。每个伪解答的推翻线索要与真凶推理链**共用线索、互相咬合**，而非另起炉灶。

#### 误导的进阶形态：前提错误型

> **最高明的误导不是让玩家"想错答案"，而是让玩家"一开始就想错了问题"。** 一旦"死者是谁"或"这里是否发生过犯罪"这一前提错误，所有后续推理都失去根基。

典型：**无面尸 + 身份误认**（§3.4）、**伪解答依赖错误前提**（如"现场是密室"这个前提本身错了）。破绽点在于：推翻前提的那条线索（如"门其实没锁"、"死者其实是B"）必须是**玩家可主动质疑、可搜证验证**的。


## 四、经典案例解析（逻辑严谨性视角）

以下案例解析侧重于"这个诡计**在逻辑上为什么成立**"以及"如何转化为剧本杀设计"，供创作时参考。解析基于各作品公开的复盘要点，不涉及关键剧透细节。

### 4.1 案例一：《无人生还》——童谣杀人 + 封闭孤岛

| 项目     | 内容                           |
| -------- | ------------------------------ |
| **类型** | 本格 / 暴风雪山庄 / 连环杀人   |
| **核心亮点** | 孤岛封闭 + 童谣对应杀人          |

**逻辑上为什么成立**：
- **封闭空间单调收缩**：孤岛封航、凶手必在幸存者中，嫌疑人集合随每起命案单调收缩（§3.5逻辑约束）。
- **童谣对应是"仪式闭环"**：每起命案与童谣内容一一对应，玩家可用童谣预测/验证下一起命案——布设既是氛围也是推理素材（§3.5）。
- **数据核对**：登岛人数与尸体数比对、死亡顺序与童谣顺序比对——"数据矛盾触发推理"是硬事实（§2.5）。

**剧本杀借鉴价值**：

| 借鉴点       | 说明                                       |
| ------------ | ------------------------------------------ |
| **孤岛封闭** | 封闭空间+凶手必在幸存者中的排除法推进       |
| **童谣杀人** | 仪式布设与命案一一对应，作推理素材          |
| **人数核对** | 登岛名单与尸体数比对触发反转                |

### 4.2 案例二：《罗杰疑案》——叙述性诡计（剧本杀的边界）

| 项目     | 内容                           |
| -------- | ------------------------------ |
| **类型** | 本格 / 叙述性诡计              |
| **核心亮点** | "最不可能的人"——视角陷阱        |

**逻辑上为什么成立**：
- **叙述性诡计依赖"叙述视角的隐瞒"**：以第一人称叙述隐瞒作案——这在小说里成立，但在**剧本杀中受限制**（玩家能看到角色卡、且没有"叙述者"垄断信息）。
- **转化方式**：把"叙述者隐藏身份"转化为**信息不对称诡计**——某个角色掌握的信息被他主动隐瞒、或剧本对其身份关键信息刻意不前置（对应§3.3身份诡计）。

**剧本杀借鉴价值**：

| 借鉴点         | 说明                                             |
| -------------- | ------------------------------------------------ |
| **视角隐瞒**   | 把"叙述诡计"转化为"角色主动隐瞒关键信息"        |
| **最不可能者** | "最可信的叙述者/侦探位角色"成为凶手的反直觉设计 |
| **信息前置限制** | 剧本杀中身份诡计必须提前暗示（§1.3原则6）        |

### 4.3 案例三：《玫瑰的名字》——中世纪舞台 + 符号学/宗教

| 项目     | 内容                             |
| -------- | -------------------------------- |
| **类型** | 中世纪历史 / 连环谋杀 / 符号学    |
| **核心亮点** | 修道院连环谋杀 + 神秘符号书 + 宗教异端 |

**逻辑上为什么成立**：
- **中世纪舞台的证据体系自洽**：修道院封闭、修士誓言、无现代科技——案发只能靠人证/书证/建筑线索（§2.7）。
- **符号/典籍是"可解码的线索"**：神秘符号书、圣经典故、图书检索——**知识型线索**作为推理素材，但必须以剧本内可获得的"解码规则"给出（ps_欧式推理 §5.6知识自包含）。
- **宗教要素的动机纵深**：异端/禁书/赎罪——宗教争端的背后是权力与信仰的冲突，动机有深度（§3.8）。
- **连环案件的共享逻辑**：多起命案共享同一"书/符号"逻辑，逐步收窄（§3.5）。

**剧本杀借鉴价值**：

| 借鉴点         | 说明                                     |
| -------------- | ---------------------------------------- |
| **中世纪舞台** | 修道院/城堡的封闭与证据体系自洽          |
| **符号/典籍线索** | 可解码的知识型线索，解码规则须剧本内给出 |
| **宗教动机**   | 异端/教义之争作为深层动机                |
| **连环收窄**   | 多案共享逻辑，排除法推进                 |

### 4.4 案例四：《三口棺材》——密室讲义/不可能犯罪

| 项目     | 内容                             |
| -------- | -------------------------------- |
| **类型** | 本格 / 密室 / 不可能犯罪          |
| **核心亮点** | 密室讲义 + 大雪封城 + "尸体消失/出现" |

**逻辑上为什么成立**：
- **密室讲义是"分类穷举"工具**：对密室类型做系统分类，保证"任何密室都能被解释且唯一"（§3.1）。
- **环境证据可验证封闭性**：雪地足迹（数得出进出人数）、封城封路——"不可进出"是可检验的事实（§3.5）。
- **不可能的"出现/消失"**：以"尸体在不可能的位置被发现"制造悖论——悖论的破绽必须是可搜证验证的（如密道、时间差）。

**剧本杀借鉴价值**：

| 借鉴点       | 说明                                   |
| ------------ | -------------------------------------- |
| **密室讲义** | 用系统分类法穷举密室解法，保证唯一     |
| **雪地证据** | 环境证据验证"不可进出"                 |
| **不可能悖论** | 悖论的破绽须可搜证，而非"灵光一闪"    |

### 4.5 案例五：《东方快车谋杀案》——封闭空间 + 集体作案

| 项目     | 内容                             |
| -------- | -------------------------------- |
| **类型** | 本格 / 封闭空间 / 集体作案         |
| **核心亮点** | 列车封闭 + 全员共犯的结构           |

**逻辑上为什么成立**：
- **封闭空间的"人人有嫌疑"**：列车/城堡封闭，嫌疑人集合固定且单调收缩（§3.5）。
- **集体作案的信息边界**：帮凶/共犯链必须信息边界清楚——谁、何时、知道多少、参与多深（§2.5）。
- **动机的统一性**：多个加害者共享同一深层动机（复仇）——动机的"系统性"是集体作案成立的前提（§3.8）。

**剧本杀借鉴价值**：

| 借鉴点       | 说明                                     |
| ------------ | ---------------------------------------- |
| **全员共犯** | 封闭空间+多人参与的信息边界设计          |
| **共享动机** | 一个复仇动机支撑多人行动                 |
| **结构反转** | "真凶是谁"让位于"多少人参与"的反转       |

## 六、欧式剧本创作流程框架（逻辑先行）

> **顺序不可颠倒**：先定真相与时代、再过逻辑框架、再设计角色与线索，最后才排版分幕。

| 步骤 | 工作内容                                     | 产出物 / 验证点                                           |
| ---- | -------------------------------------------- | ---------------------------------------------------------- |
| 1    | **定义案件真相**                             | 欧式六要素初稿：死因/手段/时机/机会/动机/身份（§2.1）     |
| 2    | **六要素闭环验证**                           | 两两互检（§2.1），修正任何一处矛盾                         |
| 3    | **时代要素排查**                             | 定档位（ps_欧式推理 §5.1）；过§2.7表，明确证据体系边界                 |
| 4    | **时间线设计**                               | 祷时/钟声主时间线 + 每角色个人时间线 + 交叉验证（§2.2）     |
| 5    | **手法物理验证**                             | 工具三问 + 密道/塔楼/毒药/延时装置边界验证（§2.3、§3.7）   |
| 6    | **反向设计线索链**                           | 从真相反推：需要哪些线索支撑每一步推导，标注推理价值与排除功能（§2.4） |
| 7    | **分配线索与分幕**                           | 线索分幕/分区域发放，关键线索冗余≥2；知识自包含（ps_欧式推理 §5.6）   |
| 8    | **反证检验与逻辑自检**                       | 过§2.6五角度攻击 + §七自检清单                            |

### 关键产出物：线索链总表（创作时必建）

| 推理步骤 | 需要的事实 | 支撑线索（≥2条） | 线索所在场景/幕 | 排除的可能性 |
| -------- | ---------- | ---------------- | --------------- | ------------ |
| 步1      | 死因是毒杀 | 检视记录 / 药渣 / 杯沿残留 / 症状 | 幕2 / 厨房     | 意外、病亡   |
| 步2      | 只有C能进密室 | 钥匙归属 / 门闩拨动痕迹 / 仆从证词 | 幕3 / 塔楼     | 外部闯入者   |
| 步3      | "恶魔作祟"实为人为 | 密道灰尘/启用痕迹 / 毒物来源 / 脚印 | 幕4 / 密道     | 巫术/圣迹     |
| …        | …          | …                | …               | …            |

> 这张表是"逻辑严谨性"的实体化：它能直接暴露天降线索、单线索支撑、密道无来历、排除不完整等问题，在创作阶段即可发现漏洞，而非成稿后才发现。


## 七、逻辑自检清单（欧式版）

### 7.1 逻辑闭环检查
- [ ] 六要素（死因/手段/时机/机会/动机/身份）两两互检无矛盾
- [ ] 死因与现场表现一致（无"中毒症状却说刺伤致死"类矛盾）
- [ ] 凶手作案所需的关键信息均有获取渠道（钥匙、密道、时辰、现场布局）
- [ ] 存在完整排除项（自杀/意外/病亡/假死/外部闯入/合谋/时间伪造/巫术均被排除且各有线索）

### 7.2 时间线检查（欧式计时）
- [ ] 祷时/时辰换算统一无误
- [ ] 主时间线物理自洽，所有记录/证词/钟声可叠加
- [ ] 每个角色有时间线，空白时段有解释
- [ ] 任一证言至少与一条独立信息源交叉验证（钟声×仆从×文书×马厩）
- [ ] 时间篡改类诡计有系统性来源 + 无人发现的合理理由
- [ ] 夜间目击有照明来源交代，无"漆黑看清"硬伤
- [ ] 行程/里程核算与角色声称相符

### 7.3 物理可行性检查（欧式器物）
- [ ] 手法200字内可描述清楚
- [ ] 工具三问全部通过（来源/去向/痕迹）
- [ ] 密道/暗格有建造者与用途，非凭空出现
- [ ] 延时装置已归类（真延时/心理延时）且精度验证通过
- [ ] 密室"进、出、闭"三向都有解；塔楼/楼梯/壁炉烟道物理自洽
- [ ] 无超自然手法（写实本）；设定系已立规则并明示
- [ ] 毒药死状与症状描写一致；中世纪无法化学验毒的局限已处理

### 7.4 线索公平性检查
- [ ] 所有关键线索在游戏过程中可被搜证获得（无天降线索）
- [ ] 关键推理链≥3步，每步≥2条独立线索支撑
- [ ] 每条线索标注了推理价值（无推理价值的线索已删除或转纯氛围）
- [ ] 身份诡计有提前暗示，且存在至少一条不可伪造的身份识别锚点（纹章/封印/疤痕/信物）
- [ ] 每条误导线索有收束（可被推翻或有解释）
- [ ] 推理所需欧式知识已写入剧本（知识自包含，ps_欧式推理 §5.6）

### 7.5 唯一性检查
- [ ] 给定全部线索，只有一套六要素自洽
- [ ] 伪解答（若有）能被明确反证线索推翻
- [ ] 排除法穷举了所有"他杀外可能"（含巫术/圣迹）
- [ ] 合谋/帮凶/知情者的信息边界清晰（谁、何时、知道多少）

### 7.6 时代要素检查
- [ ] 档位（写实/架空/戏说）已定且全程守约
- [ ] 无"假装有现代科技"（监控/电话/照片/指纹/DNA/化学验毒）
- [ ] 时代局限已处理（验毒不万能/计时不精确/身份靠人工核验/消息慢）
- [ ] 中世纪器物、制度、称谓无混搭；火器出现时间与档位一致；架空设定已自订并明示
- [ ] 角色行为权限与身份等级一致（谁能进内廷、谁掌钥匙、教士司法豁免）

### 8.2 元素清单

**物理诡计元素**：
- 刀剑/匕首/战斧/长弓/弩/钝器——见§附录A兵器知识
- 勒缢（缢/勒之别）、坠亡（塔楼/城墙）、溺亡（护城河/渡口）
- 密道/暗格/塔楼/壁炉烟道——建造者与用途三要素（§2.3）
- 烛台/蜡烛/水钟/沙漏——延时与计时
- 铁条/金属丝/皮革条——拨动门闩的工具（§3.1）

**身份诡计元素**：
- 纹章/印章/封印 → "不可伪造"的家族标识（§附录B）
- 私生子/顶替/替身 → 族谱/洗礼/老仆证词/继承权争议
- 性别置换（女扮男装）→ 通过"从不宽衣""声音"等细节矛盾揭示
- 一人分饰两角 → 通过"两人从不同时出现"的时间线揭示
- 殉道/假死 → 借"圣迹/战死"假死脱身或换身份

**时间诡计元素**：
- 死亡时间伪造 → 检视+环境线索（壁炉/地窖/烛火）比对
- 钟声/祷时误导 → 多个计时源读数矛盾
- 时间线交错 → 目击证词交叉比对
- 延时杀人 → 蜡烛/水钟/沙漏/慢性毒机制线索

**毒药元素**（见§3.7速查表）：
- 砒霜/砷、颠茄、毒芹、乌头、曼陀罗、水银、蟾蜍毒、蛇毒
- 伪装方式：酒、蜜饯、汤药、香薰、烛烟、杯沿涂毒、箭矢淬毒
- 中世纪局限：无法化学验毒，靠症状/试毒人/厨余/药圃排查

**继承/宗教元素**：
- 长子继承/私生子/遗嘱/领地/嫁妆/寡妇继承权（§附录B）
- 教会法庭/忏悔保密/避难权/异端审判/圣物/赎罪券（§3.8）
- 书证：遗嘱/契约/账册/族谱/领地图册/蜡封印信

**氛围元素**：
- 城堡（城墙/塔楼/吊桥/护城河/壁炉/烛台/挂毯）、自然（雨/雪/风暴/月光）
- 宗教（钟声/祈祷/圣像/香火）、武器（剑/盾/铠甲）、服饰（贵族礼服/修士袍/锁子甲）
- 称谓（国王/殿下/大人/小姐/修士）、时间（祷时/钟声/年号）

### 欧式本格核心公式

```
逻辑严谨的欧式本格剧本 = 时代要素自洽 + 六要素闭环 + 自洽时间线 + 物理可行手法 + 建筑可验证 + 可推导线索链 + 唯一真相 + 完整排除法 + 知识自包含
```

### 剧本创作优先级（逻辑先行）

1. **先设计真相与诡计**——这是本格推理的灵魂
2. **再过逻辑框架**——六要素闭环、时间线、物理可行性、时代要素排查（本库第二章）
3. **再设计角色和动机**——继承/宗教/政治权谋为动机库，角色为案件服务（§3.8）
4. **再反向设计线索链**——从真相反推，建"线索链总表"，确保推理路径完整且公平
5. **最后设计分幕与氛围**——知识自包含，信息流速合理，玩家体验顺畅


## 附录：欧式专业知识速查（创作调用）

> 供创作时直接引用，保证城堡建筑、爵位继承、纹章、毒药、计时等细节**真实可信**。使用时须结合§2.7时代要素排查，确认与所选档位一致。

### A. 中世纪城堡建筑与检视速查

**城堡主体结构**：
- **城墙（Curtain Wall）**：环绕城堡的石质防御墙，设箭孔（Arrow Slits）与城垛（Crenellations）。夜间城头以火把巡守。
- **城门（Gatehouse）**：城堡唯一出入口，配吊桥（Drawbridge）、闸门（Portcullis）、护城河（Moat）。城门落锁=封闭性验证点。
- **主堡（Keep/Donjon）**：城堡中心高塔，领主居所与最后防线。多为密室/坠亡/藏身场所。
- **塔楼（Tower）**：四角/城墙上的防御塔，螺旋楼梯（Spiral Staircase，中世纪多为右旋便于右利手上方防守）。
- **大厅（Great Hall）**：宴会/集会主厅，主人与仆从分餐。毒杀/公开对峙的舞台。
- **礼拜堂（Chapel）**：家族礼拜场所，常设暗格（祈祷室夹层），可提供避难权。
- **地牢/地窖（Dungeon/Cellar）**：关押与储藏。藏尸、禁锢、隐藏密道所在。
- **密道（Secret Passage）**：战争密道/走私通道/避难通道/金库暗道——**必须交代建造者与用途**。
- **厨房/酒窖**：凶器（刀具）与毒药（食物/酒）来源；厨师/酒窖管理员是关键人证。

**中世纪检视（验尸）局限**：中世纪验尸极粗糙——教会对解剖有限制（尸体神圣），死亡时间判定只能靠尸温/尸僵的粗判、目击与时辰推定。**无化学验毒**。检视官（Coroner，英格兰自12世纪末出现）多作死因的行政记录而非法医学鉴定。**"死亡时间的精确"在中世纪几乎不可能**——这既限制时间诡计精度，也要求时间推理靠"相互矛盾的计时源"（§3.6）。

**试毒人（Food Taster）**：宫廷/大贵族用试毒人先尝饮食以防毒杀——试毒人的存在本身是毒杀诡计的约束与线索（若试毒人中毒，则毒在"试毒之后"加入）。

### B. 贵族爵位、纹章与继承速查

**爵位等级**（自高而低）：国王（King）→ 大公（Archduke/Grand Duke）→ 公爵（Duke）→ 侯爵（Marquess）→ 伯爵（Earl/Count）→ 子爵（Viscount）→ 男爵（Baron）→ 骑士（Knight）→ 从骑士（Squire）。**等级决定行为权限**——谁能佩剑、谁能骑马入堡、谁能坐上位、谁能觐见国王。

**封建关系**：领主（Lord）授封地（Fief）予封臣（Vassal），封臣行臣服礼（Homage）与效忠誓言。领地（Manor）是基本单位，庄园领主（Lord of the Manor）辖佃农。**"谁拥有哪块地、谁欠谁效忠"是政治动机的核心**。

**纹章（Coat of Arms）**：家族的图案标识，饰于盾牌、旗帜、印章、城堡门楣。**纹章具有家族独属性**——同一家族不同分支以"标记"（Marks）区分。**纹章是"不可伪造"的身份识别锚点**：仿制纹章需纹章官/画师/盾匠知晓家族纹章的细节（§3.3），错误细节即破绽。

**印章/封印（Seal）**：蜡封（Wax Seal）压印家族/领主印章，用于文书生效。**蜡封可被仿铸**（需取得原印或工匠复制）——文书真伪的鉴证点在蜡封与笔迹（§3.8）。

**长子继承制（Primogeniture）**：领地/头衔/主要财产由长子继承；次子多从军或入教会；**私生子（Bastard）不能继承**（除非国王特批合法化）。**继承顺位是动机分布的骨牌**——长子继承则次子与私生子"一无所有"；无子则女儿/旁支/国王收回成为争夺焦点。

**遗嘱与领地权证**：领主可立遗嘱/赠地/立特许状（Charter）——**遗嘱/契约的真伪（蜡封、笔迹、见证人）是中世纪继承案的核心线索**。

### D. 中世纪计时与宗教速查

**教会祷时（Canonical Hours）**与教堂钟声：

| 祷时       | 约当时间   | 说明                                   |
| ---------- | ---------- | -------------------------------------- |
| 晨祷（Matins） | 午夜/黎明前 | 修士半夜起身祷告                     |
| 赞经（Lauds） | 黎明       | 晨祷后的赞颂祷告                     |
| 初祷（Prime） | 清晨6时     | 一天劳作开始前                       |
| 第三时（Terce） | 上午9时   | 圣灵降临纪念                         |
| 第六时（Sext） | 正午       | 午祷                                   |
| 第九时（None） | 下午3时   | 午后祷告                             |
| 晚祷（Vespers） | 日落       | 掌灯时的祷告                         |
| 夜祷（Compline） | 就寝前     | 一日最后的祷告                       |

> **注意**：祷时依季节与修道院规矩浮动，"约当时间"仅供换算参考——**剧本中若以祷时作精确计时，须交代换算基准**（§2.2法则1）。教堂钟声是城镇/城堡最普及的报时系统，可作时间线交叉验证源。

**宗教制度**（行为权限与动机）：
- **教会法庭（Ecclesiastical Court）**：审判教士与涉及信仰的案件——教士享有**司法豁免**（世俗法庭不得审判教士）。
- **避难权（Right of Sanctuary）**：教堂内可庇护罪犯，世俗追捕不得入内——**追捕盲区**可作诡计（§3.8）。
- **忏悔保密（Seal of Confession）**：神父对告解内容终身保密——**"唯一知情人"的沉默**可作信息封锁/反转钥匙。
- **异端审判（Inquisition）**：可拷问、火刑——嫁祸异端、制造恐慌的手段。
- **圣物（Relic）与圣迹**：圣物是教会权力凭证；圣迹/预言可作**误导源**，必须归位到物理证据（§3.9）。
