## 一、本格推理的定义与核心原则

### 1.1 什么是本格推理

本格推理（古典推理）以**逻辑至上的推理解谜**为核心：所有谜面在文本/游戏内公平呈现，真相可由玩家**只用已有线索**通过纯逻辑推导得出。它讲究"公平游戏"——玩家掌握的信息足以解答谜题，剧本不偷偷藏关键信息。

**核心公理**：真相必须来自"线索 + 逻辑"，而非"灵感 + 权威"。剧本中任何一句"最终真相"都要能被引证到具体线索，任何推理步骤都要能被另一名玩家用同样线索复核。

### 1.2 本格 vs 新本格（现代本格）

|      | 本格推理（黄金时代）          | 新本格推理                        |
| ---- | ----------------------------- | --------------------------------- |
| 时代 | 1920–1940年代                 | 1980年代后                        |
| 代表 | 阿加莎·克里斯蒂、埃勒里·奎因 | 岛田庄司、绫辻行人、我孙子武丸   |
| 特征 | 以现实世界为舞台，诡计基于物理可能 | 大胆、脱离现实的诡计，特殊建筑/设定 |
| 核心 | 公平解谜、逻辑严谨            | 不可能犯罪的华丽诡计              |

> **现代本格的特质**：舞台是现代都市，科技（监控、手机、门禁）高度介入。这既约束了老式诡计，也提供了新诡计（见 §2.7 科技约束）。**"现代"不等于"可以不管物理"——反而要求更严谨地处理科技证据。**

### 1.3 剧本杀公平原则（十诫改编）

> **剧本杀的核心是"所有玩家共同参与的解谜游戏"**，而非单一侦探的破案故事。以下原则改编自诺克斯十诫和范·达因准则，是"逻辑严谨"的前提：

| 编号 | 原则                   | 说明                                                         |
| ---- | ---------------------- | ------------------------------------------------------------ |
| 1    | **凶手必须在场**       | 凶手必须在游戏开始时已在场，且以公开身份登场——不能中途冒出一个从未出现的人物 |
| 2    | **线索全面呈现**       | 所有关键线索必须在游戏过程中可被发现，不得在真相揭晓时才"补"线索 |
| 3    | **公平追凶**           | 每个玩家（包括凶手）都拥有同等的搜证和发言权利，凶手可以撒谎但不能被系统保护 |
| 4    | **物理可行**           | 手法必须物理可行——不能用超自然力量或现实中不存在的工具（设定系/变格本除外） |
| 5    | **侦探不是凶手**       | 主持推理的"侦探"角色（如果有）不应是凶手——但其他玩家角色可以是 |
| 6    | **身份诡计须提前暗示** | 双胞胎/易容/性别置换等身份诡计必须在游戏中提前给出暗示线索   |
| 7    | **动机须有深度**       | 动机应与角色背景故事一致，且足够支撑谋杀行为——不能是"疯了"或"一时冲动" |
| 8    | **人人有嫌疑**         | 每个角色（包括真凶）都应有合理的动机和可疑之处，不让任何人过早被排除 |
| 9    | **关键线索唯一指向**   | 关键线索链最终应指向唯一的真凶，尽管中间存在误导             |
| 10   | **不得隐藏证据**       | 主持人不得主动隐藏玩家已发现的证据——所有发现的线索都公开记录在线索板上 |

### 1.4 本格推理在剧本杀中的特殊考量

| 考量点         | 说明                                                         |
| -------------- | ------------------------------------------------------------ |
| **多人视角**   | 剧本杀的最大优势——不同玩家拥有不同信息，拼凑真相的过程本身就是推理 |
| **信息不对称** | 凶手知道自己犯罪，其他角色各自有秘密——玩家需要在"隐瞒自己的秘密"和"找出凶手"之间权衡 |
| **线索卡系统** | 线索可以分幕、分区域发放，控制信息流速，确保游戏体验的节奏感 |
| **投票机制**   | 最终投票让"指认真凶"成为游戏高潮——玩家必须在有限信息下做出判断 |
| **角色扮演**   | 玩家既是侦探也是嫌疑人——每个人都要为自己辩护，同时质疑他人   |


## 二、逻辑严谨性核心框架（本版核心）

> **创作任何剧本，都应先过本框架，再考虑诡计与氛围。** 逻辑严谨 = 六要素闭环 + 时间线自洽 + 物理可行 + 线索可推导 + 真相唯一 + 反证通过。

### 2.1 案件六要素闭环

一个合格的本格案件必须形成"六要素闭环"。真相揭晓后，六要素彼此咬合、无相互矛盾；任一要素被推翻都会牵动其他要素重新检验。

| 要素   | 定义                     | 真相揭晓时必须回答的问题                                 | 配套支撑证据                                   | 常见漏洞                                     |
| ------ | ------------------------ | -------------------------------------------------------- | ---------------------------------------------- | -------------------------------------------- |
| **死因** | 致死原因与致死机制       | 死者怎么死的？损伤/毒物/窒息与死亡的因果链是否自洽？     | 尸检线索、现场血迹/痕迹、胃内容物、呕吐物     | 死因与现场表现矛盾（如溺死却全身干燥）       |
| **手段** | 凶手实现死因的方法       | 用什么工具/手法？每一步物理动作是否可行？                | 凶器来源与去向、工具痕迹、微量物证             | 无来源凶器、工具凭空消失、机关违背物理       |
| **时机** | 死亡时间与作案时间窗     | 什么时候死的？凶手在哪个时间段动的手？                   | 尸温/尸僵/胃内容物、时间线佐证、监控           | 死亡时间过宽使手法失效、时间线互相冲突       |
| **机会** | 作案窗口的到达者         | 案发窗口内谁能接触现场与死者？谁被排除？                 | 不在场证明、门禁记录、目击                     | 排除不完整、未考虑翻窗/暗道/远程等替代路径   |
| **动机** | 杀人动因及其一致性       | 为何杀此人？为何此时杀？与角色背景是否自洽？             | 人物关系网、利益冲突、情感积怨线索             | 动机不足、动机与人物前史矛盾                 |
| **身份** | 凶手/死者/涉事者真实身份 | 凶手是谁？死者是谁？是否存在置换？                       | 身份识别线索、关系印证、双胞胎/替身暗示        | 身份诡计无提前暗示、置换后行为与身份不符     |

**闭环校验法**（六要素两两互检）：
- **死因 × 手段**：该死因必须能由该手段产生，且该手段留下的痕迹必须与现场一致。
- **时机 × 机会**：死亡时间窗口内，凶手必须"在场"或"可控"。若凶手有不在场证明，必须存在一个能成立的"替代到场路径"（延时装置/远程/替身），否则矛盾。
- **动机 × 身份**：凶手的动机必须与其**真实身份**（而非伪装身份）的前史吻合。
- **手段 × 时机**：手法的执行时间必须落在作案窗口内；若是延时手法，延时精度必须支撑死亡时间设定。
- 任何一处矛盾 = 剧本硬伤，须修正要素本身，**而非靠"玩家没想到"来掩饰**。

### 2.2 时间线一致性

**法则 1 · 主时间线物理自洽**：所有角色活动、目击、监控、记录都发生在同一条物理时间上。钟表可以"被调快"，但必须交代：是谁、在何时、为何调，且调表对**所有**场景与角色的影响是一致的、可被线索发现的。

**法则 2 · 每角色一条个人时间线**：凶手、每个嫌疑人、每个次要角色各自的时间线都要完整可查。允许存在"空白时段"，但空白必须是**设计**而非疏忽。

**法则 3 · 交叉验证**：任一时段的证言/记录至少与一条独立信息源交叉印证（人证 × 物证、监控 × 痕迹、通讯 × 位置）。无交叉的单方证词，属于"待证信息"，不能直接当铁证。

**法则 4 · 空白时段必须有解释**：角色"独处无证明"的时段，要么是推理的关键（嫌疑窗口），要么必须有非犯罪理由（如不愿暴露的秘密），否则是漏洞。

**法则 5 · 系统性偏差才有说服力**：时间被篡改时，偏差必须来自可解释的系统（如"钟表馆所有时钟走速为正常1.2倍"、"某人手表固定慢X分钟"），并交代为何无人及时发现。临时、随意、无法解释的"对不上"是硬伤。

**构建步骤**：先写"客观物理时间轴"（死亡时刻定死）→ 再写每个角色的"主观时间轴"（各角色以为的时间）→ 最后标注两者偏差及其来源，确保偏差线索可在游戏中被发现（见案例一《钟表馆事件》）。

### 2.3 物理可行性验证

**工具三问**（对手段的每一步物理操作逐一过问）：
1. **工具从哪来？** 凶手必须有获得该工具的渠道（购买/偷取/现场既有），且线索要能指向该渠道。
2. **用后去哪了？** 工具必须有处置（带走/丢弃/留在现场被误导/隐藏），去向必须合理且可被追查。
3. **留下什么痕迹？** 使用工具必然产生痕迹（损伤特征/粉尘/指纹/血迹/锈迹），痕迹与工具、与手法必须互相印证。

**硬性标准**：
- 手法必须能在200字内说清，且"中学物理与常识"即可验证。
- 禁止：无来源凶器、瞬移、凭空消失的证物、违背能量守恒的延时、不需要任何工具接触的杀人。
- **延时装置只有两类**：① 真正延时（机械/化学/自然过程，如冰块融化、弹簧机构、慢性毒物）；② 心理延时（所有人误判死亡/离场时间，实际凶手当时就在场）。写延时必须先归类，再验证该类别的**时间精度**是否足以支撑死亡时间设定（冰的融化时间受室温影响，误差可能超过剧情窗口）。

### 2.4 线索—推理映射

**线索三级**：
- **事实线索（F）**：直接陈述、无需推断即可采信（尸检报告、监控画面、门禁记录）。注意：事实线索的"内容"可信，但"解读"仍可被误导。
- **推断线索（I）**：需结合设定/常识推断（血迹喷溅方向、胃内容物消化程度）。
- **误导线索（R）**：指向伪解答，**必须在后期可被推翻或解释**，不能不了了之。

**推理价值标注**：每条线索在创作时应标注——它单独证明什么？与哪条线索组合证明什么？为**排除**哪个可能性服务？没有推理价值的线索不该出现（纯氛围线除外，且需控制数量）。

**链式推导要求**：
- 从"初始线索集"到"真凶"至少存在一条 **≥3 步的逻辑链**：线索A+线索B → 结论C；C+线索D → 结论E……直至真凶。
- 关键推理链的**每一步至少2条独立线索支撑**（防止单线索被遗漏即整链卡死）。
- 链的每一步都必须"可被反驳"且"存在反驳线索"——否则该步骤是霸王推理（单方面认定、不可检验）。

### 2.5 唯一性判定与完整排除法

在指认真凶之前，所有"他杀外可能"必须先被排除，且每个被排除项都要有**至少一条明确的排除线索**：

| 须排除的可能性       | 排除线索示例                                             |
| -------------------- | -------------------------------------------------------- |
| 自杀                 | 遗书笔迹鉴定、现场无自伤工具、损伤角度不符               |
| 意外                 | 现场无意外触发条件、死者当时处境不存在意外源             |
| 病亡                 | 尸检死因明确为他杀（非自然原因）                         |
| 无死亡（假死）       | 身份识别线索确认尸体身份、后续有该人未死的行为矛盾       |
| 外部闯入者作案       | 门窗无破坏、门禁/监控排除外来者、封闭环境设定             |
| 合谋 / 帮凶          | 涉案人员信息边界清楚、行动窗口逐一排查                   |
| 死亡时间被伪造       | 尸检结论有交叉佐证（胃内容物+尸温+环境）                 |

**唯一性检验**：给定全部线索，是否**只有一套**六要素自洽？若存在第二套同样自洽的解释，剧本就有逻辑漏洞——除非它是设计好的"伪解答"，而伪解答必须有反证线索（见 §3.7）。

### 2.6 反证检验流程（真相定型后必做）

把"真相"当作敌人，模拟最刁钻的玩家从五个角度攻击：

| 攻击角度       | 攻击问题                                                   | 被攻击即漏洞的情形                                   |
| -------------- | ---------------------------------------------------------- | ---------------------------------------------------- |
| **时间攻击**   | 凶手在X时刻做了Y，有没有任何证据/矛盾能推翻？              | 时间线上存在不可调和、无法解释的冲突                 |
| **物理攻击**   | 手法每一步真的可行吗？工具真的存在且可达吗？               | 机关、延时、凶器存在物理硬伤                         |
| **信息来源攻击** | 凶手作案所需的"关键信息"（死者位置、时机、现场布局）从哪得知？ | 凶手不该知道却必须知道，且无获取渠道线索             |
| **动机攻击**   | 换成"意外/自杀/嫁祸"能否同样解释现场？                     | 排除项缺线索，真相无法唯一化                         |
| **公平性攻击** | 玩家在游戏中能否获得推导真相所需的**一切**信息？           | 关键信息在复盘时才补充（违反§1.3原则2）              |

**修正策略**：漏洞无法用"补一句话"解决时，**宁可改动设定**（改手法/改时间/改角色信息），也不要保留逻辑漏洞。

### 2.7 现代本格的科技约束与利用

现代背景（城市、智能手机、监控、网络）对诡计是双刃剑——它限制了老式诡计，也提供了新诡计。创作现代本格**必须先做"科技排查"**：

| 现代要素         | 对老诡计的约束                 | 可利用的漏洞 / 新诡计                              |
| ---------------- | ------------------------------ | -------------------------------------------------- |
| 监控摄像头       | 密室、伪装到场、身份冒充受限   | 监控被删/被遮/故障期；伪造时间戳；只拍局部盲区     |
| 手机定位 / 通讯  | 不在场证明变强                 | 定位分享被伪造、手机被他人携带、关机信号、双卡     |
| 门禁 / 智能锁    | 密室几乎不可能                 | 断电/信号屏蔽/复刻卡/指纹膜/远程开锁APP后门        |
| 人脸识别 / 身份系统 | 身份诡计受限                   | 信息滞后（员工资料未更新）、双胞胎识别误差、证件混用 |
| 移动支付 / 消费记录 | 时间线铁证                     | 他人代付、记录删除、离线支付                       |
| 快递 / 外卖 / 网约车 | 到访记录变完整                 | 代收代送、他人下单、用他人账号                     |

**现代本格三条铁律**：
1. **必须主动处理科技证据**：剧本中出现的监控、手机、门禁，要么给出可信的失效理由（断电/被动手脚/盲区），要么其记录必须被纳入推理。**不能"假装没有监控"**。
2. **数字痕迹也有物理逻辑**：删除≠消失（有备份/云端/日志）、伪造需要权限与工具、账号行为需要真人或自动化脚本——伪造方是谁、如何实现，本身要被线索支撑。
3. **科技是双刃剑**：能用科技造诡计，就能用科技破解诡计；设计"科技诡计"时，必须配套设计"科技破绽"供玩家发现。

### 2.8 常见逻辑漏洞清单（避坑）

| 漏洞             | 表现                                                       | 规避方法                                       |
| ---------------- | ---------------------------------------------------------- | ---------------------------------------------- |
| **时间线矛盾**   | 两个角色的叙述/记录在同一时刻冲突且无解释                  | 建主时间线 + 交叉验证（§2.2）                  |
| **天降线索**     | 关键信息在真相揭晓时才首次出现                             | 线索前置、可搜证（§2.4）                       |
| **无来源工具**   | 手法需要某物，却无人能提供                                 | 过"工具三问"（§2.3）                           |
| **死亡时间过宽** | 死亡时间跨度大，无法锁定窗口，手法失效                     | 收紧尸检结论、加独立佐证                       |
| **动机断裂**     | 动机不足以支撑极端行为，或与人物前史矛盾                   | 动机×身份互检（§2.1）                          |
| **信息不可达**   | 凶手行为依赖其不可能知道的信息                             | 信息源头排查（§2.6 信息来源攻击）              |
| **双身份撞车**   | 一人分饰两角，却在同一时刻被两人同时目击                   | 时间线确保"两角从不同时在场"                   |
| **排除法不完整** | 忘了自杀/意外/帮凶/假死/外部闯入等选项                     | 过完整排除项清单（§2.5）                       |
| **红鲱鱼失收**   | 误导线索后期无人解释、不了了之                             | 每条误导必有收束（§3.7）                       |
| **密室无解**     | 密室如何形成有解，凶手"怎么出去"却无解                     | 密室"进+出+闭"三向验证（§3.1）                 |
| **帮凶模糊**     | 帮凶知道多少、何时入伙未界定                               | 写清合谋的信息边界                             |
| **身份无暗示**   | 双胞胎/替身/性别置换毫无预兆                               | 提前埋身份暗示线索（§3.3）                     |
| **科技缺失**     | 现代背景却完全无视监控/手机/门禁                           | 过科技排查表（§2.7）                           |
| **对话泄露矛盾** | 角色在前期剧本中"说漏嘴"关键信息，与后期设定冲突           | 全员剧本语言统一、关键信息版本受控             |


## 三、核心诡计类型库（含逻辑约束）

### 3.1 密室杀人（Locked Room Mystery）

约翰·迪克森·卡尔《三口棺材》"密室讲义"按**凶手离开房间的途径**分类。以下为剧本杀适配版。

#### 密室的两大基本分类

| 类型                   | 说明                       | 关键特征                                   |
| ---------------------- | -------------------------- | ------------------------------------------ |
| **机械密室**（物理密室） | 通过物理装置、机关实现密室 | 密室是真实的，凶手用物理手段完成           |
| **心理密室**（错觉密室） | 利用心理错觉制造密室假象   | 密室是假的——房间实际没锁，只是让人以为锁了 |

#### 密室的形成者（剧本杀视角）

| 形成者         | 说明                                 | 在剧本杀中的实现                         |
| -------------- | ------------------------------------ | ---------------------------------------- |
| **凶手制造**   | 最常见的类型——凶手杀人后制造密室     | 凶手玩家需在搜证环节注意隐藏相关手法线索 |
| **死者制造**   | 自杀伪装成他杀，或死者无意制造密室   | 最终揭晓时需通过尸检线索证明是自杀       |
| **帮凶制造**   | 第三人在案发后无意或有意制造密室条件 | 该角色有独立动机（保护某人/制造混乱）    |
| **多人共同制造** | 多人各自的行为叠加形成密室假象       | 每个参与者都以为自己是"唯一做手脚的人"   |

#### 密室杀人的动机（剧本杀适用）

| 动机                 | 说明                             | 对应的剧本设计                         |
| -------------------- | -------------------------------- | -------------------------------------- |
| **伪装自杀/意外**    | 让密室看起来是自杀或意外         | 尸检线索需要揭示真正死因与表面不符     |
| **制造不在场证明**   | 让所有人以为死亡发生时无人能进出 | 时间线推理是破解关键                   |
| **嫁祸给特定的人**   | 让某人有唯一"可能"作案的条件     | 嫁祸对象应有对应的自我辩护线索         |
| **制造恐怖氛围**     | 连环杀手的标志性手法             | 多起案件共享同一密室模式               |
| **掩盖真实手法或死亡时间** | 密室本身是烟雾弹             | 玩家需跳出密室思考"为什么要做密室"     |

**逻辑约束（重点）**：
1. 密室必须**"进、出、闭"三步都能解释**：凶手怎么进、怎么出、门锁怎么复原。只解释"闭"（门从内反锁）不够，凶手"出"的路径必须闭环。
2. 心理密室必须交代**"锁被如何误认"**：是门被鱼线从外拨动反锁、是钥匙被放回、还是门框变形卡死——误认机制本身要有线索。
3. 制造密室必须比"不制造密室"更有利：若密室毫无收益，玩家会质疑"凶手为什么要做密室"。找不到合理动机时，用"伪装意外"或"制造恐慌"作为默认解释。

> **创作提示**：设计密室案时，顺序为——先问"凶手为什么要做密室"（动机）→ 再设计"怎么做的"（手法）→ 最后验证"怎么破除的"（破案线索）。**密室形成有解，破除也必须有解。**

#### 密室讲义分类索引（剧本杀选型用）

| 编号 | 密室类型（卡尔分类简版）                         | 剧本杀适用性 |
| ---- | ------------------------------------------------ | ------------ |
| 1    | 案件实为意外/自杀，被误认为他杀                  | ★★★ 高      |
| 2    | 机械机关：杀人后自动上锁                         | ★★ 中       |
| 3    | 凶手作案时就在房间，事后混入人群或藏匿           | ★★★ 高      |
| 4    | 锁被做手脚（假锁/卡扣），实则任何人可开          | ★★★ 高      |
| 5    | 用工具从外部或门下拨动门闩（鱼线/钩子）          | ★★ 中       |
| 6    | 死者自己锁门（自杀或误锁）                       | ★★★ 高      |
| 7    | 伪装他杀的意外（利用现场布置误导死因）           | ★★★ 高      |

### 3.2 不在场证明（Alibi）

#### 在剧本杀中的典型形式

| 形式              | 说明                               | 破解方向                           |
| ----------------- | ---------------------------------- | ---------------------------------- |
| **声称在A处**     | 嫌疑人声称案发时在某个有人证的地方 | 证词矛盾/时间对不上/证人本身可疑   |
| **门禁/监控记录** | 刷卡记录、监控录像显示在别处       | 记录被伪造/卡被他人使用/时间被篡改 |
| **共同证人**      | 多人相互证明                       | 共犯作伪证/集体时间误认            |
| **物理条件**      | "我那天脚受伤了，不可能去二楼"     | 伤势被低估/有他人协助              |

#### 常见的"不在场证明破绽"类型

1. **时间谎称**——证人被误导，以为在某时某刻看到了某人
2. **替身诡计**——有人冒充嫌疑人出现在别处
3. **伪造记录**——人为修改了监控/门禁/消费时间
4. **距离错觉**——看似不可能的移动距离其实可以做到（车速/换乘/抄近路）
5. **共犯伪证**——两人或多人合谋提供虚假证词

#### 在剧本杀中设计不在场证明

**关键原则**：每个角色（包括真凶）都应有不在场证明。真凶的不在场证明必须"看起来合理但存在破绽"——且**破绽必须有线索**，而不是"天衣无缝"或"靠运气看穿"。

| 角色类型       | 不在场证明设计                                               |
| -------------- | ------------------------------------------------------------ |
| **真凶**       | 看似合理但有细微破绽的证明（如"我在书房看书"——但书房窗户开着，可以翻出去） |
| **其他嫌疑人** | 他们有真实的/部分真实的不在场证明，但各有隐瞒的理由（如"我在偷东西所以不想说"） |
| **目击者**     | 他们可能错误地确认了时间——不是故意的，是记忆偏差             |

**逻辑约束**：不在场证明的破绽必须**指向可搜证的位置**（现场窗户、监控盲区、废弃记录），玩家通过搜证+交叉对比可发现，而非依赖某角色"突然想起"。

### 3.3 身份诡计（剧本杀特别版）

> **⚠️ 提示**：叙述性诡计在剧本杀中**受限制**（玩家能看到角色卡），但身份置换类诡计**有天然优势**——玩家彼此看到的角色卡有限，信息不对称正是剧本杀的特征。

#### 剧本杀中可用的身份诡计

| 类型               | 说明                                 | 实现方式                                         |
| ------------------ | ------------------------------------ | ------------------------------------------------ |
| **双胞胎置换**     | 一对双胞胎互换了身份                 | 提前在背景线索中暗示"某人有个双胞胎兄弟/姐妹"    |
| **性别冒充**       | 某人扮成异性                         | 通过外貌描述（"总是戴手套"、"从不更衣"）暗示     |
| **一人分饰两角**   | 同一个人在不同场合使用两个身份       | 两个"角色"从不同时出现，玩家拼凑时间线发现       |
| **死者身份误认**   | 尸体被误认为另一个人                 | 尸检线索+人物关系+随身物品的综合推理             |
| **角色卡信息不对称** | 两名玩家的角色卡对同一件事有不同说法 | 通过交叉对比发现矛盾                             |

**逻辑约束（重点）**：
1. **提前暗示原则**：诡计成立所需的事实（存在双胞胎、某人从不以全脸示人、某人从不更衣、家族有男扮女装的先例）必须在**游戏早期**有线索，不能临揭晓才公布。
2. **置换后行为一致**：置换后的角色，其行为细节必须与**真实身份**（而非伪装身份）吻合——真正的性别/年龄/职业/习惯是"无法完全伪装"的，这些破绽细节正是玩家的发现路径。
3. **身份识别锚点**：剧本中必须存在至少一条**无法伪造的身份识别线索**（刻字戒指、定制义肢、手术疤痕、特殊胎记、家族谱系中的独有记载），用于最终锁定真实身份。
4. **一人分饰两角**：必须保证"两个身份从不同时在场"——用时间线核对每个"出场"时刻，任一时刻被两名独立角色同时目击即诡计破产。

### 3.4 无面尸诡计

> **定义**：尸体面部被毁或身份无法直接辨认，"死者是谁"成为第一道谜题。

#### 在剧本杀中的典型运用

无面尸诡计的核心是：**玩家根据线索先认定死者是A，后来发现实际上是B。**

| 步骤         | 游戏内实现                                | 设计要点                                        |
| ------------ | ----------------------------------------- | ----------------------------------------------- |
| **误导阶段** | 现场发现尸体+遗留物品→玩家推断死者是A     | 遗留物品必须明显指向A（A的随身物）              |
| **发现矛盾** | 角色A的"目击"与尸体情况不匹配→触发怀疑    | A声称在某处看到谁/什么，与尸体状态冲突          |
| **真相揭示** | 线索显示尸体实际上是B                     | 通过DNA/指纹/特殊身体特征（伤疤/胎记/纹身）揭示 |

#### 经典结构变体

| 变体             | 说明                           | 剧本杀适用                                 |
| ---------------- | ------------------------------ | ------------------------------------------ |
| **尸体是替身**   | 凶手杀了无关人士冒充特定死者   | 需要凶手有接触"替身"的渠道和机会           |
| **尸体数量错误** | 实际死亡人数与发现的尸体数不同 | 多具尸体需在不同场景发现，玩家需统计比对   |
| **死者还活着**   | 某角色假死                     | 该角色的"死亡"需有目击者，但尸检线索不完整 |

**逻辑约束（重点）**：
1. **必须有一条明确可靠的"身份识别线索"**——DNA、指纹、特殊身体特征、手术疤痕、纹身、无法伪造的随身物品（刻字戒指、定制义肢等）。
2. **"误认"必须有合理原因**：面部毁损、高度腐败、家属拒绝认尸、随身物品被调换——否则玩家会质疑"为什么认错了"。
3. **识别线索的取得时机**：身份识别线索要在"误导阶段"之后、"真相揭晓"之前**可被搜证获得**，形成"先误导→再证伪→后锁定"的推理弧线。

### 3.5 暴风雪山庄模式

#### 经典结构（适配剧本杀）

| 阶段             | 内容                           | 对应剧本杀幕数              |
| ---------------- | ------------------------------ | --------------------------- |
| **第一幕：入局** | 所有人因故聚集在封闭空间       | 第一幕：角色介绍+场景铺垫   |
| **第二幕：首杀** | 发生第一起命案，但"不可能"     | 第二幕：发现尸体+第一轮搜证 |
| **第三幕：排查** | 众人开始互相怀疑，出现更多线索 | 第三幕：集中讨论+私聊       |
| **第四幕：连锁** | 可能发生第二起/第三起命案      | 第四幕：第二轮搜证+深入推理 |
| **第五幕：揭晓** | 最终投票+真相复盘              | 第五幕：投票+揭晓           |

**逻辑约束（重点）**：
1. **凶手必须始终在幸存者中**；随着命案发生，嫌疑人集合必须**单调收缩**——不能中途出现"新到达者"或"此前不在场者"被排除后又复活。
2. 每一起新的命案都要**收窄可能性**（排除法推进），而不是制造无关混乱。
3. 连环案件要么共享同一凶手逻辑（特征/模式/被害者关联），要么明确揭示"第二凶手"，两者都需线索支撑。

#### 优势
- 天然限制——凶手必须在幸存者中
- 玩家可以逐一排除，逻辑性强
- 每个角色都有"被困"的共同处境，增强代入感

### 3.6 时间诡计与延时装置

#### 在剧本杀中的典型形式

| 形式           | 说明                                     | 破解方向                             |
| -------------- | ---------------------------------------- | ------------------------------------ |
| **死亡时间伪造** | 通过尸检误导/环境干预让死亡时间提前或推后 | 尸检线索+环境线索比对               |
| **时钟/计时误导** | 钟表被调快/调慢，造成时间认知偏差        | 多个时钟的读数矛盾、权威时间源对比  |
| **时间线交错** | 两起事件的先后顺序被混淆                 | 目击证词的交叉比对、物理痕迹的时序  |
| **延时杀人**   | 凶手动手后延迟死亡，制造不在场证明       | 凶器/机关的延时机制线索             |

#### 逻辑约束（重点）

1. **偏差必须有系统来源**（见§2.2法则5）：谁调的钟、何时调、为何无人发现，都要有交代。
2. **延时必须归类并验精度**：真延时（机械/化学/自然）or 心理延时（误判在场者）。真延时要验证时间精度能否支撑设定（如慢性毒药的发作窗口、冰块的融化时长受温度影响）。
3. **死亡时间伪造必须有尸检依据**：用什么手段误导了尸检结论（如环境保温/降温、胃内容物做手脚、尸僵被破坏），该手段本身要留下可被发现的痕迹。
4. **现代背景优先用数字时间线**：监控、门禁、支付记录是天然的时间锚点，时间诡计若无视它们，必须给出可信失效理由（§2.7）。

### 3.7 误导与伪解答工程（红鲱鱼）

**红鲱鱼设计原则**：

| 原则         | 说明                                         |
| ------------ | -------------------------------------------- |
| **有独立价值** | 即使不指向真凶，也揭示了某个角色的秘密或动机 |
| **合理存在**   | 不是凭空出现——与该角色的行为/背景一致        |
| **可被推翻**   | 后续有线索可推翻该误导，而不是"不了了之"     |
| **不过度集中** | 不要把大部分误导线索集中在同一个非真凶角色上 |

**伪解答设计**：一个表面上能解释所有线索的"假真相"。要求：
- 伪解答必须能**暂时覆盖**绝大多数线索（否则玩家一眼识破）；
- 伪解答必须有**至少一条反证线索**，且该线索在游戏后期可被搜证获得；
- 伪解答被推翻的瞬间 = "恍然大悟"时刻，应安排在新线索出现之后。

**逻辑约束**：伪解答数量建议 **1–2 个**（过多导致玩家疲劳与线索通胀）。每个伪解答的推翻线索要与真凶推理链**共用线索、互相咬合**，而非另起炉灶。

#### 误导的进阶形态：前提错误型

> **最高明的误导不是让玩家"想错答案"，而是让玩家"一开始就想错了问题"。** 一旦"死者是谁"这一前提错误，所有后续推理都失去根基。

典型：**无面尸 + 身份误认**（§3.4）、**伪解答依赖错误前提**（如"现场是密室"这个前提本身错了）。这种误导的破绽点在于：推翻前提的那条线索（如"门其实没锁"、"死者其实是B"）必须是**玩家可主动质疑、可搜证验证**的（见案例四《嫌疑人X的献身》）。


## 四、经典案例解析（逻辑严谨性视角）

以下案例解析侧重于"这个诡计**在逻辑上为什么成立**"以及"如何转化为剧本杀设计"，供创作时参考。

### 案例一：《钟表馆事件》——系统性时间偏差

| 项目         | 内容              |
| ------------ | ----------------- |
| **作者**     | 绫辻行人          |
| **类型**     | 新本格 / 建筑推理 |
| **核心诡计** | 时间差 + 建筑诡计 |

**诡计设计**：钟表馆所有时钟走速为正常时间的1.2倍——馆内时间6分钟 = 正常时间5分钟。该设定**持续运行了十几年**，不是临时调整。凶手利用"时间差"制造不在场证明。

**逻辑上为什么成立**：
- **偏差有系统性来源**：全馆时钟统一偏快，不是零散矛盾（§2.2法则5）。
- **长期存在但无人察觉有合理理由**：馆内人员长期生活在馆内，认知被同化。
- **破绽可被玩家发现**：任何与"外部时间"的对照（电话、访客、权威时间源）都会暴露偏差——发现路径清晰。

**剧本杀改编思路**：

| 小说中的实现                   | 在剧本杀中的转化                                             |
| ------------------------------ | ------------------------------------------------------------ |
| 读者通过文字描述发现"时钟不对" | 地图/场景线索卡揭示"所有钟表统一偏快X分钟"                   |
| 凶手利用时间差进出馆内         | 时间线推理：角色A在"馆内时间20:00"被目击在馆外，实际对应"正常时间19:40"，凶手在此空隙行动 |
| 建筑设定是长期存在的           | 游戏前给玩家一张"钟表馆规则"作为设定说明，增强公平性         |

**可借鉴的剧本杀元素**：
- 设定一个"建筑的例外规则"（所有钟表快X分钟/某个房间比外面热/特定时段门禁自动解除等）
- 玩家需要先**发现规则** → 再**理解规则如何被利用** → 最后**指认利用规则的人**

### 案例二：《占星术杀人魔法》——数量矛盾触发反转

| 项目         | 内容                        |
| ------------ | --------------------------- |
| **作者**     | 岛田庄司                    |
| **类型**     | 新本格 / 宏大诡计           |
| **核心诡计** | 无面尸 + 分尸重组（五变六） |

**诡计设计**：凶手将五具尸体分别砍去不同部位，重新拼接成六具尸体。每一具除头尾之外中间都少了一截——错位组合后却能完整拼成六具。

**逻辑上为什么成立**：
- **数量矛盾是可检验的硬事实**：头部、躯干、四肢的计数对不上，任何人通过**表格统计**都能发现（§2.4链式推导的起点）。
- **触发重新审视**：数量矛盾迫使玩家推翻"每具尸体=一个死者"的默认前提，转向"部位重组"假设——推理方向被数据强制扭转。
- **每个部位都有唯一归属**：身份识别锚点（§3.3）让重组后每个"完整个体"可被单独验证。

**剧本杀改编思路**：

| 小说中的实现             | 在剧本杀中的转化                                        |
| ------------------------ | ------------------------------------------------------- |
| 多具尸体在不同时间被发现 | 在不同幕/不同区域陆续发现多具尸体                       |
| 数量对不上的矛盾点       | 玩家整理尸体部位数量时发现"头部比躯干多1个"等矛盾       |
| 推理出尸体被重组         | 通过"部位数量矛盾"触发重新审视所有尸体线索              |

**可借鉴的剧本杀元素**：
- 设计一个**数据矛盾**作为触发反转的机关（如"目击者说有6个人在场，但记录只有5个名字"）
- 玩家需要先**建立表格统计** → **发现数字对不上** → **推导出"少/多了什么"** → **指认真凶**

### 案例三：《首无·作祟之物》——一把钥匙开多把锁

| 项目         | 内容                           |
| ------------ | ------------------------------ |
| **作者**     | 三津田信三                     |
| **类型**     | 本格 / 民俗推理                |
| **核心诡计** | 身份置换（龙凤双胞胎性别置换） |

**诡计设计**：秘守家族龙凤双胞胎——后出生的男孩为兄长。真相是：**13岁时死的不是"妹妹"（女），而是男扮女装的"姐姐"（男）；活下来的"哥哥"实际上是女性。**

**逻辑上为什么成立**：
- **一个核心设定解释所有谜团（唯一性）**：身份置换一经揭示，所有散落的不在场证明、痕迹、目击矛盾一次性闭合（§2.5）。
- **排除法先排除再推翻**：读者一度排除了双胞胎诡计，后期用新线索推翻——"看似排除"本身成了误导（§3.7）。
- **身份置换有提前暗示**：家族规矩、外貌描述矛盾反复出现，符合公平原则（§1.3原则6）。

**剧本杀改编思路**：

| 小说中的实现                       | 在剧本杀中的转化                                             |
| ---------------------------------- | ------------------------------------------------------------ |
| 读者通过后续案件反推最初的身份     | 多起案件线索中反复出现"某人的外貌特征不匹配"的暗示           |
| 读者排除了双胞胎诡计后又发现没排除 | 中期给"看似排除了某种可能性"的线索，后期用新线索推翻         |
| 一个核心设定解释所有谜团           | 真相复盘时用一条时间线串联所有案件                           |

**可借鉴的剧本杀元素**：
- 设计多个看似无关的谜团（不同人的不在场证明/不同场景的痕迹/不同时间段的目击）
- 最终用一个核心设定（身份置换/时间错位/建筑秘密）一次性解释全部
- 这种设计让真相复盘成为"恍然大悟"时刻

### 案例四：《嫌疑人X的献身》——前提错误型误导

| 项目         | 内容                 |
| ------------ | -------------------- |
| **作者**     | 东野圭吾             |
| **类型**     | 本格 / 社会派融合    |
| **核心诡计** | 盲点误导（前提错误） |

**诡计设计**：石神杀了一个流浪汉，用其尸体冒充傅坚。警方从一开始就搞错了"死者是谁"——所有调查都建立在错误的前提上。看似是"靖子是否有不在场证明"的几何问题，实际上是"死者到底是不是傅坚"的函数问题。

**逻辑上为什么成立**：
- **误导不靠说谎，靠"信息空白"**：警方（玩家）接收到的信息指向"死者=傅坚"这一认定，而该认定从未被正式验证。
- **前提检验是破局点**：只要有人质疑"死者真的是傅坚吗"，整个错误的调查框架即崩塌——这要求**推翻前提的线索必须可搜证获得**（如指纹比对、身体特征差异）。
- **与公平原则兼容**：前提虽被误导，但验证前提所需的线索在故事内存在，只是"没人想到去查"。

**剧本杀改编思路**：

| 小说中的实现                     | 在剧本杀中的转化                                             |
| -------------------------------- | ------------------------------------------------------------ |
| 警方基于错误前提展开所有调查     | 游戏初期给玩家一个"看似确凿"的身份认定线索                   |
| 读者花大量时间试图解决错误的问题 | 玩家反复围绕某个"前提"推理，直到有人质疑前提本身             |
| 最终的翻转是"你从一开始就想错了" | 后期出现一条颠覆前提的线索，所有之前的推理都需重新来过       |

**可借鉴的剧本杀元素**：
- **伪解答设计**：让玩家在某个阶段得出"看似合理"的结论（如"A是凶手"），后期用关键线索颠覆前提，推理重来
- **多重反转的进阶形态**：不是"答案变了"，而是"问题本身变了"

### 案例五：《剪刀男》——叙述性诡计（剧本杀中的限制与转化）

| 项目         | 内容              |
| ------------ | ----------------- |
| **作者**     | 殊能将之          |
| **类型**     | 本格 / 叙述性诡计 |
| **核心诡计** | 性别叙诡          |

**诡计设计**：全书以"我"为第一人称叙述，前五分之四让读者以为"剪刀男"是男性，结局告知"他"其实是"她"。作者从未直接说"我"是男性，读者基于社会常识自动补全了认知。

**逻辑上为什么成立**：叙诡的本质是**让读者基于常识自动补全错误信息**——作者陈述的全部是事实，是读者自己脑补了性别。这不违反"公平原则"（信息都在），只是利用了认知默认。

**剧本杀中的限制**：
> **⚠️ 注意**：完全依赖"文字叙述性别"的诡计在剧本杀中**难以直接使用**（玩家能看到角色卡，直接知道性别）。但可借其本质：**利用玩家对年龄/国籍/职业/关系的常识默认**实现类似效果。

**可在剧本杀中使用的改编方式**：

| 改编方式                 | 说明                                               |
| ------------------------ | -------------------------------------------------- |
| **角色卡信息留白**       | 某些角色的性别/年龄/国籍在游戏开始时不明确，通过线索逐步揭示 |
| **统一中性人称**         | 所有角色卡/线索描述用"TA"或"某人"，无性别暗示      |
| **关键线索推翻常识默认** | 某条线索揭示"你以为的X角色，实际上是Y"             |

**逻辑约束**：利用"常识默认"时，被默认的事实（如"角色的性别/年龄"）必须在角色卡或线索中以**留白**形式出现（而非直接陈述错误信息），否则违反公平原则（§1.3原则2）。


## 五、剧本杀创作流程框架（逻辑先行）

> **顺序不可颠倒**：先定真相、再过逻辑框架、再设计角色与线索，最后才排版分幕。逻辑是地基，诡计与氛围是装修。

| 步骤 | 工作内容                                           | 产出物 / 验证点                                           |
| ---- | -------------------------------------------------- | ---------------------------------------------------------- |
| 1    | **定义案件真相**                                   | 六要素初稿：死因/手段/时机/机会/动机/身份                  |
| 2    | **六要素闭环验证**                                 | 两两互检（§2.1），修正任何一处矛盾                         |
| 3    | **科技排查**                                       | 过§2.7表格，处理监控/手机/门禁，明确失效理由或纳入推理     |
| 4    | **时间线设计**                                     | 主时间线 + 每角色个人时间线 + 交叉验证（§2.2）             |
| 5    | **手法物理验证**                                   | 过"工具三问"，验证延时精度（§2.3）                        |
| 6    | **反向设计线索链**                                 | 从真相反推：需要哪些线索支撑每一步推导，标注推理价值与排除功能（§2.4） |
| 7    | **分配线索与分幕**                                 | 线索分幕/分区域发放，关键线索冗余≥2，确保玩家游戏中可获得全部关键信息（§1.3） |
| 8    | **反证检验与逻辑自检**                             | 过§2.6五角度攻击 + §六自检清单                            |

### 关键产出物：线索链总表（创作时必建）

| 推理步骤 | 需要的事实 | 支撑线索（≥2条） | 线索所在场景/幕 | 排除的可能性 |
| -------- | ---------- | ---------------- | --------------- | ------------ |
| 步1      | 死因是X    | 尸检报告 / 现场痕迹A / 胃内容物 | 幕2 / 区域B     | 意外、病亡   |
| 步2      | 只有C能进密室 | 门禁记录 / 窗户攀爬痕迹 | 幕3 / 区域D     | 外部闯入者   |
| …        | …          | …                | …               | …            |

> 这张表是"逻辑严谨性"的实体化：它能直接暴露天降线索、单线索支撑、排除不完整等问题，在创作阶段即可发现漏洞，而非成稿后才发现。


## 六、逻辑自检清单（真相定型后逐项检查）

### 6.1 逻辑闭环检查
- [ ] 六要素（死因/手段/时机/机会/动机/身份）两两互检无矛盾
- [ ] 死因与现场表现一致（无"溺死却全身干燥"类矛盾）
- [ ] 凶手作案所需的关键信息均有获取渠道（信息来源攻击通过）
- [ ] 存在完整排除项（自杀/意外/病亡/假死/外部闯入/合谋/时间伪造均被排除且各有线索）

### 6.2 时间线检查
- [ ] 主时间线物理自洽，所有记录/证词/监控可叠加
- [ ] 每个角色有时间线，空白时段有解释
- [ ] 任一证言至少与一条独立信息源交叉验证
- [ ] 时间篡改类诡计有系统性来源 + 无人发现的合理理由
- [ ] 无"双身份撞车"（两角同一时刻被两人同时目击）

### 6.3 物理可行性检查
- [ ] 手法200字内可描述清楚
- [ ] 工具三问全部通过（来源/去向/痕迹）
- [ ] 延时装置已归类（真延时/心理延时）且精度验证通过
- [ ] 密室"进、出、闭"三向都有解
- [ ] 无超自然/现实中不存在的工具（设定系/变格本除外）

### 6.4 线索公平性检查
- [ ] 所有关键线索在游戏过程中可被搜证获得（无天降线索）
- [ ] 关键推理链≥3步，每步≥2条独立线索支撑
- [ ] 每条线索标注了推理价值（无推理价值的线索已删除或转纯氛围）
- [ ] 身份诡计有提前暗示，且存在至少一条不可伪造的身份识别锚点
- [ ] 每条误导线索有收束（可被推翻或有解释）

### 6.5 唯一性检查
- [ ] 给定全部线索，只有一套六要素自洽
- [ ] 伪解答（若有）能被明确反证线索推翻
- [ ] 排除法穷举了所有"他杀外可能"
- [ ] 合谋/帮凶的信息边界清晰（谁、何时、知道多少）

### 6.6 现代要素检查
- [ ] 监控/手机/门禁等科技证据已处理（失效理由或纳入推理）
- [ ] 数字痕迹（删除/伪造/远程操控）有实现方与实现渠道线索
- [ ] 无"假装没有监控"的背景失真


## 七、现代本格推理场景与元素库

### 7.1 经典场景（含线索分布建议）

| 场景            | 特征                     | 适合的诡计类型             | 关键线索可能的藏匿点               |
| --------------- | ------------------------ | -------------------------- | ---------------------------------- |
| **暴风雪山庄**  | 封闭、与世隔绝、连环杀人 | 密室、不在场证明、连环杀人 | 壁炉/地窖/书房的暗格               |
| **孤岛/游轮**   | 有限空间、有限嫌疑人     | 密室、无面尸、身份诡计     | 船舱/甲板/货舱                     |
| **神秘宅邸**    | 复杂建筑、隐藏房间       | 建筑诡计、密室、暗道       | 密道入口/书房夹层/花园隐蔽角落     |
| **大学/研究所** | 高智商角色、专业知识     | 毒药、物理诡计、逻辑诡计   | 实验室/档案室/办公室               |
| **列车**        | 移动空间、时间精确       | 不在场证明、身份冒充       | 行李架/座位夹缝/车厢连接处         |
| **都市公寓**    | 现代小区、邻里关系       | 科技诡计、数字时间线       | 门禁记录/监控盲区/手机数据/快递柜   |
| **写字楼/公司** | 职场关系、利益冲突       | 动机诡计、嫁祸             | 办公电脑/门禁权限/茶水间监控        |

### 7.2 可用元素清单

**物理诡计元素**：
- 冰/干冰（延时凶器、密室机关）
- 线绳/鱼线（门外操作门锁、移动物品）
- 定时装置（机械定时、冰块融化定时）
- 镜子/光影（视觉错觉、身份混淆）
- 建筑暗门/密道（建筑诡计）

**身份诡计元素**：
- 双胞胎/长相相似者 → 需提前给出家族关系线索
- 易容/伪装 → 需通过专业工具/技能线索揭示
- 性别混淆 → 需通过外貌描述细节矛盾揭示
- 一人分饰两角 → 需通过"两人从不同时出现"的时间线揭示
- 无面尸/身份误认 → 需通过身体特征/随身物品综合推理

**时间诡计元素**：
- 死亡时间伪造 → 需通过尸检线索+环境线索比对
- 时钟/计时装置误导 → 需通过多个时钟读数矛盾揭示
- 时间线交错 → 需通过目击证词交叉比对
- 延时杀人 → 需通过凶器/机关的延时机制线索揭示

**现代科技元素**（现代本格特色）：
- 监控录像 → 删除/遮盖/故障期/伪造时间戳（需配套破绽线索）
- 手机定位/通讯 → 伪造分享/他人携带/关机信号
- 门禁/智能锁 → 断电/复刻卡/远程后门
- 支付/外卖/快递记录 → 代付/代收/他人账号
- 网络痕迹 → 账号行为需真人或脚本（伪造需权限线索）

**心理诡计元素**：
- 思维盲点 → 通过"看似合理的前提是否成立"的反问触发
- 先入为主的判断 → 通过颠覆前提的线索触发反转
- 目击者的心理暗示 → 通过重新审视目击证词
- 虚假的不在场证明 → 通过时间线+物理痕迹比对


## 八、速查表

```

```

### 剧本创作优先级（逻辑先行）

1. **先设计真相与诡计**——这是本格推理的灵魂
2. **再过逻辑框架**——六要素闭环、时间线、物理可行性、科技排查（本库第二章）
3. **再设计角色和动机**——角色为案件服务，动机与身份互检
4. **再反向设计线索链**——从真相反推，建"线索链总表"，确保推理路径完整且公平
5. **最后设计分幕和节奏**——确保信息流速合理，玩家体验顺畅
