## 一、民国谍战的定义与核心原则

### 1.1 什么是民国谍战推理

民国谍战推理以**民国时期（约1912–1949，核心舞台为1920–1940年代的租界都会与战乱城市）**为舞台的本格推理。核心公理与现代本格、古风一致：**真相必须来自"线索 + 逻辑"，而非"灵感 + 权威"**。民国谍战在"逻辑严谨"上的独特难点有二：

1. **证据体系处于过渡带**：电报/电话/无线电/相机/钟表/汽车/枪械已经存在，但**精度、普及度与可靠性处处受限**（人工电话总机、无监控、无手机、指纹应用简陋、法医只能粗判死因），既不能像古风那样"无科技"，也不能像现代本格那样"全科技"。
2. **信息本身就是凶器与证据**：谍战的核心是"谁在骗谁"。真名/化名/代号、卧底/双面/顶替、密写/密码/死信箱，构成了现代本格没有的**身份真假维度**与**情报流转维度**——推理既要破"凶案"，也要破"身份案"与"情报案"。

**两条铁律**：

1. **"民国谍战是包装，推理是内核。"** 民国元素的价值在于提供一套**与现代、古风都不同的证据体系与身份体系**——但民国谍战不能成为"不严谨的免罪符"。
2. **民国谍战剧本必须"自己解释自己的世界"**：玩家对密码学、军统/中统、帮派规矩、租界制度、民国器物认知参差不齐，剧本内所有关键知识必须以设定说明或知识线索卡形式给出（见ps_民国谍战 §5.6知识自包含），**不得依赖玩家自带民国知识**。

### 1.2 民国谍战 vs 现代本格 vs 古风：证据体系差异

| 维度     | 古风本格                     | **民国谍战**                                 | 现代本格                   |
| -------- | ---------------------------- | -------------------------------------------- | -------------------------- |
| **身份识别** | 户籍/族谱/路引/纹身/胎记       | **化名/代号/证件/照片/指纹（简陋）/熟人/口音/伤疤** | 指纹/DNA/人脸/证件         |
| **验尸**     | 仵作目验/银钗验毒            | **法医/西医初步检验（大城）+ 仵作（乡野并存）；毒理极有限** | 法医仪器/毒理化验          |
| **计时**     | 时辰/更漏/日晷               | **钟表/火车站大钟/广播报时/电报时间戳/教堂钟/汽笛** | 手机/监控/数字时间戳       |
| **通讯**     | 书信/驿站/信鸽               | **电报/无线电台/电话（人工总机）/书信/报纸/交通员** | 电话/网络/监控             |
| **门禁**     | 门户落锁/院墙/看门人         | **公寓门房/洋房佣人/巡捕/会馆/堂口眼线**     | 监控/门禁卡/智能锁         |
| **取证**     | 账册/契书/书信/巡夜簿        | **电文/密码本/电台记录/报纸/银行票据/巡捕房档案/暗房底片** | 支付/行车/日志/监控        |
| **杀人手段** | 刀剑/暗器/机关/毒药          | **枪械/刀/毒药/炸弹/延时机关/汽车制造意外** | 现代凶器/药物/枪械         |
| **执法权**   | 单一官府                     | **租界巡捕房/华界警察/宪兵/特工机构多重并存、管辖割裂** | 单一警方                   |

> **核心推论**：民国谍战不是"古风+现代科技的简单相加"，而是**"过渡科技 + 碎片化执法权 + 身份真假战场"**三者的交织。剧本的严谨性，取决于对这三者的处理是否自洽（§2.7时代要素排查）。

### 1.3 剧本杀公平原则（民国谍战适配十诫）

> **剧本杀的核心是"所有玩家共同参与的解谜游戏"**，而非单一特工的破案故事。以下原则改编自诺克斯十诫和范·达因准则，例证按民国谍战语境改写：

| 编号 | 原则                   | 说明（民国谍战例证）                                                     |
| ---- | ---------------------- | ------------------------------------------------------------------ |
| 1    | **凶手必须在场**       | 凶手必须在游戏开始时已在场，且以公开身份登场——不能中途冒出一个从未出场的人物 |
| 2    | **线索全面呈现**       | 所有关键线索（电文、密码本、密写信件、枪械、验尸记录、巡捕房档案）必须在游戏过程中可被发现，不得在真相揭晓时才"补"线索 |
| 3    | **公平追凶**           | 每个玩家（包括凶手/卧底）搜证与发言权利对等；凶手可撒谎，但不能被系统保护 |
| 4    | **物理可行**           | 手法必须物理可行——不得用"神通广大无所不能的特工技能"或超自然力量 |
| 5    | **侦探不是凶手**       | 主持推理的"侦探"角色（探长/巡捕房警探若担任此职）不应是凶手——其他玩家角色可以是 |
| 6    | **身份诡计须提前暗示** | 卧底/双面/顶替/易容/化名等身份诡计必须在游戏中提前给出暗示线索（伪造证件、身世疑点、旧识"认不出"） |
| 7    | **动机须有深度**       | 动机应与角色背景一致且足以支撑杀人（党国使命/组织纪律/帮派利益/灭口/家仇/夺财），不能是"一时冲动"或"疯了" |
| 8    | **人人有嫌疑**         | 每个角色（包括真凶）都应有合理动机与可疑之处，不让任何人过早被排除 |
| 9    | **关键线索唯一指向**   | 关键线索链最终应指向唯一的真凶，尽管中间存在误导                     |
| 10   | **不得隐藏证据**       | 主持人不得主动隐藏玩家已发现的证据——所有发现的线索都公开记录在线索板上 |

### 1.4 民国谍战在剧本杀中的特殊考量

| 考量点         | 说明                                                         |
| -------------- | ------------------------------------------------------------ |
| **知识自包含** | 玩家对密码学/机构/帮派/租界制度认知不一——关键知识必须在剧本内以"设定说明"给出（ps_民国谍战 §5.6） |
| **身份真假维度** | 谁是真名、谁是化名、谁是卧底——身份案与凶案交织，是民国谍战本区别于其他题材的最大推理维度（§3.3） |
| **信息流转维度** | 情报从哪来、传给谁、用什么载体、在哪个时间窗——情报流转本身就是证据链（§3.7） |
| **管辖碎片化** | 租界/华界/日占区各有执法者，管辖割裂既可被凶手利用，也可成为推理的排除项（§3.8） |
| **时代取舍**   | 写实历史/虚构城市/戏说三档，逻辑要求不同（ps_民国谍战 §5.1）              |
| **过渡科技**   | 有电话但有人工总机、有相机但要暗房、有指纹但应用简陋——科技"半可用"是双刃剑（§2.7） |


## 二、逻辑严谨性核心框架（民国谍战适配）

> **创作任何民国谍战剧本，都应先过本框架，再考虑诡计与氛围。** 逻辑严谨 = 时代要素自洽 + 六要素闭环 + 时间线自洽 + 物理可行 + 线索可推导 + 真相唯一 + 身份自洽 + 知识自包含。

### 2.1 案件六要素闭环（民国版）

一个合格的民国谍战案件必须形成"六要素闭环"。真相揭晓后，六要素彼此咬合、无相互矛盾；任一要素被推翻都会牵动其他要素重新检验。

| 要素   | 定义                 | 真相揭晓时必须回答的问题                                       | 民国配套支撑证据                                 | 常见漏洞                                     |
| ------ | -------------------- | ------------------------------------------------------------ | ------------------------------------------------ | -------------------------------------------- |
| **死因** | 致死原因与致死机制   | 死者怎么死的？枪伤/刀伤/毒杀/勒杀/炸弹/坠楼与死亡因果是否自洽？ | 法医/医生检验记录、弹道（入口/出口/子弹）、毒理症状、现场痕迹 | 死因与现场矛盾（枪伤却是"病亡"、毒死却无任何来源） |
| **手段** | 凶手实现死因的方法   | 用什么枪/毒/刀/炸弹/机关？每一步物理动作是否可行？            | 凶器来源与去向、子弹匹配、工具痕迹、机关制作痕迹 | 无来源枪械（黑市/军火渠道查无）、炸弹凭空出现   |
| **时机** | 死亡时间与作案时间窗 | 什么时候死的？凶手在哪个时段动的手？                          | 钟表/广播报时/电报时间戳、法医粗判、火车电车时刻、目击 | 死亡时间过宽使手法失效、时间源互相冲突           |
| **机会** | 作案窗口的到达者     | 案发时段谁能接触现场与死者？谁被排除？                        | 公寓门房/佣人/巡捕/堂口眼线证词、出入登记、钥匙归属 | 排除不完整、未考虑翻窗/暗道/跳板/跨区绕过门禁    |
| **动机** | 杀人动因及其一致性   | 为何杀此人？为何此时杀？与角色背景是否自洽？                  | 党国使命/组织纪律/帮派利益/情报交易/灭口/家仇/财杀 | 动机不足、动机与人物"真实身份"（而非伪装身份）前史矛盾 |
| **身份** | 凶手/死者/涉事者真实身份 | 凶手是谁？死者是谁？是否涉及卧底/双面/顶替/易容/化名？      | 证件/照片/指纹（简陋）/熟人旧识/口音/伤疤/身世履历 | 身份诡计无提前暗示、置换后行为与真实身份不符   |

**闭环校验法**（六要素两两互检）：
- **死因 × 手段**：该死因必须能由该手段产生。例如枪伤必须能对上子弹口径与弹道；慢性毒（砒霜小剂量）不可能表现为瞬间毙命。
- **时机 × 机会**：死亡时间窗口内，凶手必须"在场"或"可控"。若凶手有不在场证明，必须存在能成立的"替代到场路径"（延时毒/定时装置/跨区绕行/替身/委托行动），否则矛盾。
- **动机 × 身份**：凶手的动机必须与其**真实身份**（而非伪装身份）的前史吻合——卧底杀人，动机在"真实任务"而非"公开身份"。
- **手段 × 时机**：手法的执行时间必须落在作案窗口内；延时手法（定时炸弹/慢性毒/自燃装置）的精度必须支撑死亡时间设定。
- 任何一处矛盾 = 剧本硬伤，须修正要素本身，**而非靠"玩家没想到"来掩饰**。

### 2.2 时间线一致性（民国版）

**法则 1 · 计时体系自洽**：民国城市中**钟表、广播报时、火车站大钟、电报时间戳、教堂钟声、工厂/码头汽笛**并存。钟表并非人人都有（底层靠估摸），且钟表可被调快调慢、可停摆。全剧本须统一"以哪个时间源为准"，并允许不同时间源之间存在**可解释的偏差**（怀表慢5分钟、车站大钟是标准时）。

**法则 2 · 时刻表是硬约束**：火车（沪宁线/沪杭甬线）、电车、轮渡、班轮都有班次时刻。**"从A地到B地需要多久"是可检验的硬事实**——报称"赶上了头班火车"者若按时刻表赶不上，即是破绽。深夜的行动受限于电车收车、渡轮停航、汽车稀少。

**法则 3 · 通信有时间戳**：电报有拍发与送达时间、报纸有发行时间、信件有邮戳、电台联络有定时窗口。**情报的"发出时间"与"到达时间"之差**是可验证的——凶手收到情报的时间决定其行动窗口。

**法则 4 · 交叉验证**：任一时段的证言/记录至少与一条独立信息源交叉印证：门房所见 × 电车售票员 × 电报局记录 × 巡捕房巡逻簿。无交叉的单方证词属"待证信息"，不能直接当铁证。

**法则 5 · 空白时段必须有解释**：角色"独处无证明"的时段，要么是推理的关键（嫌疑窗口/发报窗口），要么必须有非犯罪理由（私会情妇、赌场躲债、去密会某人不便说），否则是漏洞。

**法则 6 · 系统性偏差才有说服力**：时间被篡改时，偏差必须来自可解释的系统（某处挂钟统一被调、某报务员固定早报5分钟、电报局记录被改），并交代为何无人及时发现。临时、随意、无法解释的"对不上"是硬伤。

**构建步骤**：先写"客观物理时间轴"（死亡时刻定死，含电报/报纸/时刻表锚点）→ 再写每个角色的"主观时间轴"（各角色以为的时间）→ 最后标注两者偏差及其来源，确保偏差线索可在游戏中被发现。

### 2.3 物理可行性验证（民国版）

**工具三问**（对手段的每一步物理操作逐一过问）：
1. **工具从哪来？** 凶手必须有获得渠道——枪械（黑市/帮派走私/军警配发/缴获）、毒药（药铺/诊所/化学用品店/军火化学）、炸药（军事/矿场/黑市）。线索须能指向该渠道。
2. **用后去哪了？** 凶器/弹壳/毒药容器/装置必须有处置（带走/丢弃黄浦江/藏匿/留在现场被误导），去向合理且可被追查。
3. **留下什么痕迹？** 使用必然产生痕迹——弹壳与枪膛痕迹、枪伤入口出口、刀口形状、火药残留（近距射击留灼痕）、毒物残渣、装置残件。

**硬性标准**：
- 手法必须能在200字内说清，且以"民国常识 + 基本物理"可验证。
- **枪械边界**：手枪射程、装弹数、近距离射击的火药灼痕、弹壳抛落位置——是**可检验的物理事实**。不得出现"无声手枪步枪射程"式混搭；消音器在当时存在（"无声手枪"属特殊装备，须有来源交代）。
- **爆炸物验证**：炸弹需要引爆装置（雷管/定时器/引信）、炸药来源（TNT/硝铵/土制）、遗留残件与引爆方式互相印证。
- **机关/延时验证**：定时装置（钟表改装/线香/蜡烛/水漏/慢燃导火索）需要制作痕迹与工匠/技能来源；装置受潮、走时误差等自然故障约束，使用前后状态可被查验。
- **延时装置只有两类**：① 真正延时（定时装置/慢性毒/自燃引火物/燃尽触发）；② 心理延时（所有人误判死亡/离场时间，实际凶手当时就在场）。写延时必须先归类，再验证该类别的**时间精度**是否足以支撑死亡时间设定。

### 2.4 线索—推理映射（民国版）

**证据类型**（民国谍战本多类证）：
- **物证**：枪械/弹壳/子弹/刀/毒物残留/炸弹残件/密写工具/夹层信物
- **人证**：门房/佣人/巡捕/电车售票员/舞厅侍应/堂口眼线/报童的证词
- **书证**：电报底稿/密码本/密写信件/报纸/银行票据/巡捕房档案/户籍/通行证
- **口供**：嫌疑人供词（须与物证/书证交叉；卧底供词天然不可全信）
- **验状**：法医/医生/仵作检验记录（死因、伤痕、弹道——见附录D）
- **电讯**：截获电文/电台记录/监听笔记/电报局记录（民国谍战特有，见§3.7）

**线索三级**：
- **事实线索（F）**：直接陈述、无需推断即可采信（电文原文、报纸刊登、验尸记录、电报时间戳）。注意：事实线索"内容"可信，但"解读"仍可被误导（电文原文可信，但其**密码本与密钥**仍待破解）。
- **推断线索（I）**：需结合设定/常识推断（弹道角度、密写显影、发报手癖识别、行程核算）。
- **误导线索（R）**：指向伪解答（假情报、被栽赃的电文、伪装的现场），**必须在后期可被推翻或解释**，不能不了了之。

**民国谍战证据的局限（必须主动处理）**：
- **验尸技术有限**：无DNA、无精确毒理检验、血型只能排除不能认定；法医可判大体死因（枪/刀/勒/毒），但慢性毒、心疾猝死可能被误判——"以病掩毒"合法，但误判的暴露必须有线索。
- **指纹应用简陋**：大城市巡捕房有指纹采集，但无自动比对——指纹是线索但"比对需要原始档案"。
- **照片有但有局限**：证件照/报纸照片存在，但拍摄条件差、胶卷需暗房冲洗——"看不清脸"是时代现实，也可被利用。
- **身份无统一体系**：民国无全国统一身份证（沦陷区有良民证/身份证），化名/假证泛滥——**身份识别必须靠"可检验锚点"**（旧识、伤疤、口音、照片比对、指纹档案），而非"证件齐全"。

**推理价值标注**：每条线索在创作时应标注——它单独证明什么？与哪条线索组合证明什么？为**排除**哪个可能性服务？无推理价值的线索不该出现（纯氛围线除外，且需控制数量）。

**链式推导要求**：
- 从"初始线索集"到"真凶"至少存在一条 **≥3 步的逻辑链**。
- 关键推理链的**每一步至少2条独立线索支撑**。
- 链的每一步都必须"可被反驳"且"存在反驳线索"——否则该步骤是霸王推理（单方面认定、不可检验）。

### 2.5 唯一性判定与完整排除法（民国版）

在指认真凶之前，所有"他杀外可能"必须先被排除，且每个被排除项都要有**至少一条明确的排除线索**：

| 须排除的可能性       | 民国排除线索示例                                       |
| -------------------- | ------------------------------------------------------ |
| 自杀                 | 遗书笔迹比对、现场无自伤工具、枪伤角度不符（他杀多有接触性/近距离特征需核验）、腕部无火药残留 |
| 意外                 | 现场无意外触发条件（坠楼却无坠楼姿态、误食却无中毒对象） |
| 病亡                 | 法医检验死因明确为他杀（非病非猝死）                   |
| 无死亡（假死/替身）  | 身份识别锚点确认尸体身份（照片/旧识/伤疤/指纹）、后续有该人未死的行为矛盾 |
| 外部闯入者作案       | 门房/巡捕/出入登记/监控类记录排除外来者、封闭场景设定   |
| 合谋 / 帮凶          | 涉案人员信息边界清楚、行动窗口逐一排查（如交通员"恰好"不在场） |
| 死亡时间被伪造       | 计时源交叉验证（钟表/电报/报纸/时刻表/目击）           |
| **情报方作案**       | 排除"敌方机构远程策划"——现场行动必须由在场者完成或具备遥控/委托路径 |
| **卧底/双面作案**    | 身份识别锚点确认行动者真实身份；双面者的"行动轨迹"与其每一重身份都须核对 |

**唯一性检验**：给定全部线索，是否**只有一套**六要素自洽？若存在第二套同样自洽的解释，剧本就有逻辑漏洞——除非它是设计好的"伪解答"，而伪解答必须有反证线索（§3.9）。

### 2.6 反证检验流程（真相定型后必做）

把"真相"当作敌人，模拟最刁钻的玩家从六个角度攻击：

| 攻击角度       | 攻击问题                                                   | 被攻击即漏洞的情形                                     |
| -------------- | ---------------------------------------------------------- | ------------------------------------------------------ |
| **时间攻击**   | 凶手在X时刻做了Y，有没有任何证据/矛盾能推翻？              | 时间线上存在不可调和、无法解释的冲突                   |
| **物理攻击**   | 手法每一步真的可行吗？枪/毒/炸弹/机关是否违背物理或时代技术？ | 枪械射程失真、无声枪无来源、炸弹引信超时代、轻功式行动 |
| **信息来源攻击** | 凶手作案所需的"关键信息"（死者位置、时机、密码本、现场布局、钥匙）从哪得知？ | 凶手不该知道却必须知道，且无获取渠道线索（如密码本在军统电讯处而凶手无接触） |
| **身份攻击**   | 凶手/卧底的"真实身份"能否被现有线索唯一锁定？伪装身份的行为能否掩盖真实身份的习惯？ | 身份识别锚点缺失、伪装身份"毫无破绽"（违反§3.3）     |
| **动机攻击**   | 换成"意外/自杀/病亡/情报误传/嫁祸"能否同样解释现场？        | 排除项缺线索，真相无法唯一化                           |
| **公平性攻击** | 玩家在游戏中能否获得推导真相所需的**一切**信息（含密码学/机构知识）？ | 关键信息在复盘时才补充、或依赖玩家自带民国知识         |

**修正策略**：漏洞无法用"补一句话"解决时，**宁可改动设定**（改手法/改时间/改角色信息/改时代档位/改机构设定），也不要保留逻辑漏洞。

### 2.7 时代要素排查（民国谍战的"科技排查"）

创作民国谍战剧本，必须**先明确本世界的"证据能力边界"**——有哪些手段、没有哪些手段，且不得混用。与古风"不得假装有现代科技"、现代本格"必须主动处理科技"都不同，民国谍战的关键词是**"半可用"**：每项科技都存在，但都受时代限制。

| 时代要素 | 民国形态                                   | 对诡计的约束                                     | 可利用的破绽                                         |
| -------- | ------------------------------------------ | ------------------------------------------------ | ---------------------------------------------------- |
| **计时** | 钟表/车站大钟/广播报时/教堂钟/汽笛         | 时间精度中等，底层无表，钟表可被调               | 调钟、停表、误认钟声、时刻表与实际行动不符           |
| **验尸** | 法医/西医（大城）与仵作（乡野）并存         | 只能判大体死因，毒理/微量分析极有限              | 慢性毒难查、血型只能排除、仵作与法医结论分歧         |
| **身份** | 化名/证件/良民证/照片/指纹（简陋）/旧识     | 无统一身份证，真伪难辨                           | 假证、顶替、双面、照片年代不符、旧识"认不出"         |
| **门禁** | 公寓门房/洋房佣人/巡捕/会馆/堂口眼线        | 密室难但非不可能                                 | 钥匙复制、翻窗、跳板、夜半无人值守、跨区绕行         |
| **通讯** | 电报/无线电台/电话（人工总机）/书信/报纸    | 信息有延迟，总机可监听，电报有底稿               | 电报时间戳、总机接线员窃听、密写、电报伪造           |
| **交通** | 黄包车/电车/公共汽车/汽车/火车/轮船         | 夜行受限（电车收车/渡轮停航），时刻表是硬约束   | 时刻表核算、换乘、黄包车"恰好"不在、汽车无牌         |
| **监视** | 盯梢/尾随/巡捕巡逻/堂口眼线/巡警查夜        | 无监控，取证靠人眼与记录                         | 盲区、雨夜看不清、眼线被收买、巡逻簿被改             |
| **取证** | 电报底稿/密码本/报纸/银行票据/巡捕房档案/底片 | 书面与电讯记录是硬证据                           | 档案被烧、底片被换、密码本被调、票据被改             |
| **武器** | 手枪/冲锋枪/手榴弹/炸药/刀                  | 军火管制松散但有渠道约束                         | 弹壳弹道、军火来源、黑市交易、膛线痕迹               |
| **加密** | 电报码/密码本/密写/摩斯/死信箱/代号         | 信息可加密，破译是推理过程而非天降               | 密码本失窃/调换、密写显影、手癖识别、破译时效       |

**三条铁律**：
1. **不得出现超时代科技**：民国谍战本中不得出现监控摄像头、手机/对讲机、无人机、DNA鉴定、现代指纹数据库比对。**"半可用"是特点不是漏洞**——电话有人工总机（可窃听）、相机需暗房、无线电笨重需定时开机。
2. **必须主动处理时代局限**：验尸不万能、身份无统一体系、执法权碎片化、消息有延迟——这些局限要么被纳入推理，要么被明确交代失效理由。**不能"假装没有局限"**。
3. **机构/制度必须自洽**：军统、中统、地下党、76号、日本特高课、租界巡捕房的行为逻辑与权限边界要符合史实或自订明示；**"租界巡捕房像现代警方一样跨区查案"是硬伤**（§3.8）。

### 2.8 常见逻辑漏洞清单（民国谍战版避坑）

| 漏洞             | 表现                                                     | 规避方法                                         |
| ---------------- | -------------------------------------------------------- | ------------------------------------------------ |
| **科技穿越**     | 出现监控/手机/对讲机/无人机/DNA                        | 过时代要素排查表（§2.7）                        |
| **执法权混乱**   | 租界案像现代一样由"统一警方"查办                       | 明确管辖归属与跨区手续（§3.8）                  |
| **卧底无破绽**   | 双重身份完美无缺，无需任何验证                         | 提前暗示身世/旧识/习惯破绽（§3.3）              |
| **密码天降**     | 电文内容"直接给出"而不交代破译过程                     | 破译需要截获+密码本/密钥+语言特征线索（§3.7）   |
| **电台定位忽略** | 有电台收发却不考虑测向/监听/开机时间窗                 | 电台是双刃剑：开机即暴露位置窗口（§3.7）        |
| **枪械来源悬空** | 手枪/炸弹无军火渠道来源                               | 过"工具三问"，交代黑市/配发/缴获渠道（§2.3）    |
| **身份识别悬空** | 假证"天衣无缝"，或"一眼认出"远道之人                   | 靠旧识/伤疤/口音/照片/指纹核验（§3.3）          |
| **时间源混乱**   | 钟表/广播/时刻表互相对不上且无解释                     | 统一时间源+允许可解释偏差（§2.2）               |
| **情报来源不明** | 凶手知道死者位置/密码本内容却无获取渠道                 | 信息源头排查（§2.6信息来源攻击）                |
| **假情报无出处** | 栽赃用的电文/信件凭空出现                             | 假情报要有"伪造者+伪造工具+放置通道"线索（§3.8）|
| **验尸过度自信** | 法医精确到分钟的死亡时间/毒理鉴定                     | 法医只能粗判，死亡时间靠时间源交叉（§2.4）      |
| **知识依赖**     | 推理依赖玩家自带密码学/机构知识                       | 关键知识以设定说明/知识线索卡给出（ps_民国谍战 §5.6）       |
| **天降线索**     | 关键信息在真相揭晓时才首次出现                         | 线索前置、可搜证（§2.4）                        |
| **排除不完整**   | 忘了自杀/意外/病亡/假死/帮凶/外部闯入/情报方/双面等选项 | 过完整排除项清单（§2.5）                        |


## 三、核心诡计类型库（民国谍战适配）

### 3.1 密室杀人（民国版）

民国城市的密室载体与"公寓洋房、舞厅化妆间、银行金库、诊所病房、会馆厢房"密切相关。玻璃窗、老式门锁、门房、巡捕构成了民国密室的经典条件。

#### 密室的两大基本分类

| 类型                   | 说明                       | 关键特征                                   |
| ---------------------- | -------------------------- | ------------------------------------------ |
| **机械密室**（物理密室） | 通过机关、门锁装置实现密室 | 密室是真实的，凶手用物理手段完成       |
| **心理密室**（错觉密室） | 利用心理错觉制造密室假象   | 密室是假的——门实际没锁，只是让人以为锁了 |

#### 密室的形成者（剧本杀视角）

| 形成者         | 说明                                 | 在剧本杀中的实现                         |
| -------------- | ------------------------------------ | ---------------------------------------- |
| **凶手制造**   | 最常见的类型——凶手杀人后制造密室     | 凶手玩家需在搜证环节注意隐藏相关手法线索 |
| **死者制造**   | 自杀伪装成他杀，或死者无意制造密室   | 最终揭晓时需通过验尸证明是自杀           |
| **帮凶制造**   | 第三人在案发后无意或有意制造密室条件 | 该角色有独立动机（保护某人/制造混乱）    |
| **多人共同制造** | 多人各自的行为叠加形成密室假象       | 每个参与者都以为自己是"唯一做手脚的人"   |

#### 密室讲义分类索引（民国选型用）

| 编号 | 密室类型（卡尔分类简版）                           | 民国实现示例                                 | 剧本杀适用性 |
| ---- | -------------------------------------------------- | -------------------------------------------- | ------------ |
| 1    | 案件实为意外/自杀，被误认为他杀                    | 坠楼被伪造成推落、自缢被伪造成他杀勒死       | ★★★ 高      |
| 2    | 机械机关：杀人后自动上锁                           | 门锁被弹片/弹簧装置自锁、房门卡死            | ★★ 中       |
| 3    | 凶手作案时就在房间，事后混入人群或藏匿             | 藏身壁橱/阁楼/储物间，混入舞厅人群           | ★★★ 高      |
| 4    | 锁被做手脚（假锁/卡扣），实则任何人可开             | 门锁被细钢丝/卡片从门缝挑开，钥匙被复制       | ★★★ 高      |
| 5    | 用工具从外部或门下拨动门闩                         | 钢丝/铁片/卡片伸进门缝挑锁，玻璃窗从外扣紧   | ★★ 中       |
| 6    | 死者自己锁门（自杀或误锁）                         | 死者自缢/自杀前反锁、误触门锁               | ★★★ 高      |
| 7    | 伪装他杀的意外（利用现场布置误导死因）             | 伪造枪战现场掩盖意外/自杀                    | ★★★ 高      |

#### 密室杀人的动机（剧本杀适用）

| 动机                 | 说明                             | 对应的剧本设计                         |
| -------------------- | -------------------------------- | -------------------------------------- |
| **伪装自杀/意外**    | 让密室看起来是自杀或意外         | 验尸线索需揭示真正死因与表面不符       |
| **制造不在场证明**   | 让所有人以为死亡发生时无人能进出 | 时间线推理（时刻表/门房/巡捕）是关键   |
| **嫁祸给特定的人**   | 让某人有唯一"可能"作案的条件     | 嫁祸对象应有对应的自我辩护线索         |
| **制造恐怖氛围**     | 连环杀手的标志性手法             | 多起案件共享同一密室模式               |
| **掩盖真实手法或死亡时间** | 密室本身是烟雾弹             | 玩家需跳出密室思考"为什么要做密室"     |

**逻辑约束（重点）**：
1. 密室必须**"进、出、闭"三步都能解释**：凶手怎么进、怎么出、门锁怎么复原。
2. 心理密室必须交代**"锁被如何误认"**：是被卡片从外挑开、是钥匙被放回、是门框变形卡死——误认机制本身要有线索。
3. **民国门禁的现实**：公寓/洋房多有门房与佣人，出入有登记——"谁在何时进出"可查；夜半无人值守期、后门/侧门/防火梯是常见盲区。
4. 制造密室必须比"不制造密室"更有利：找不到合理动机时，用"伪装意外"或"制造恐慌"作为默认解释。

> **创作提示**：设计密室案时，顺序为——先问"凶手为什么要做密室"（动机）→ 再设计"怎么做的"（手法）→ 最后验证"怎么破除的"（破案线索）。**密室形成有解，破除也必须有解。**

### 3.2 不在场证明（民国版）

#### 在剧本杀中的典型形式

| 形式             | 说明                                   | 破解方向                               |
| ---------------- | -------------------------------------- | -------------------------------------- |
| **门房/巡捕作证** | 声称案发时在楼下见到/未见到某人进出   | 夜半眼疏、后门盲区、巡捕被收买         |
| **电车/火车/轮渡** | "我那时正在车上/船上"               | 时刻表核算、换乘、中途下车（逃票）     |
| **打麻将/舞厅作证** | 多人证明在某处打牌/跳舞               | 共犯作伪证/缺三缺一/中途离场           |
| **电台/电报时间戳** | "我那时正在发报"或"我收到了电报"     | 发报时间窗、代发、电文时间戳伪造       |
| **电话作证**     | "我那时接了电话，人在办公室"          | 人工总机接线员可证明接线时间与地点     |
| **汽车/黄包车**  | "我坐车走的，不可能赶回来"            | 无牌车、抄近路、司机被买通、车速核算   |

#### 常见的"不在场证明破绽"类型

1. **时刻谎称**——证人被误导/收买，以为在某时看到了某人
2. **替身诡计**——有人冒充嫌疑人出现在别处（化名/易容/同伙顶替）
3. **记录伪造**——电报时间戳、报纸、巡捕房巡逻簿、银行票据被改动
4. **交通错觉**——看似不可能的往返其实可行（换乘/抄近路/黄包车/夜间汽车）
5. **共犯伪证**——两人或多人合谋提供虚假证词（帮派成员/舞厅同伙互相作证）

#### 在剧本杀中设计不在场证明

**关键原则**：每个角色（包括真凶）都应有不在场证明。真凶的不在场证明必须"看起来合理但存在破绽"——且**破绽必须有线索**，而不是"天衣无缝"或"靠运气看穿"。

| 角色类型       | 不在场证明设计                                               |
| -------------- | ------------------------------------------------------------ |
| **真凶**       | 看似合理但有细微破绽的证明（如"我一直在打电话"——但总机记录显示挂线时间不对，或事后接线员能作证） |
| **其他嫌疑人** | 有真实的/部分真实的不在场证明，但各有隐瞒的理由（如"那夜我在赌场躲债所以不想说"） |
| **目击者**     | 可能错误地确认了时间——不是故意的，是雨夜/灯影/记忆偏差     |

**逻辑约束**：不在场证明的破绽必须**指向可搜证的位置**（电报局底稿、电车售票本、巡捕房巡逻簿、总机记录、公寓出入登记），玩家通过搜证+交叉对比可发现，而非依赖某角色"突然想起"。

### 3.3 身份诡计（卧底/双面/顶替/易容/化名）

> **民国谍战本的身份诡计是"全家桶"**：既有古风式的易容/顶替，又有谍战特有的**卧底、双面间谍、多重身份、化名与假证**。身份真假是民国谍战本最核心的推理维度之一——"破凶案"之前往往要先"破身份案"。

#### 剧本杀中可用的身份诡计

| 类型             | 说明                                   | 实现方式                                         |
| ---------------- | -------------------------------------- | ------------------------------------------------ |
| **卧底**         | 以某机构公开身份为掩护，实际为敌方/己方服务 | 提前暗示身世履历疑点、旧识"认不出"、行为与身份不符 |
| **双面间谍**     | 同一人同时为两方/三方服务              | 多套档案、多方接头对象、行动轨迹需与每一重身份都核对 |
| **顶替身份**     | 冒用死者/失踪者/他人的身份与证件       | 证件照片年代、旧识反应、履历无法印证             |
| **化名/代号**    | 公开用化名，真实身份被隐藏              | 代号在电文/报纸/档案中出现的次数与场合            |
| **易容/乔装**    | 以化妆/假须/假发/服饰改变容貌          | 提前铺垫化妆用品、身形/声音/旧伤是破绽           |
| **伪造证件**     | 假通行证/假身份证/假良民证              | 证件防伪（钢印/照片/纸质）、签发机构核查          |
| **性别混淆**     | 女扮男/男扮女（民国谍战常见）          | 通过"从不宽衣""嗓音""身形习惯"细节矛盾揭示        |
| **一人分饰两角** | 同一个人以两个身份在不同场合出现       | 两个"身份"从不同时在场，玩家拼凑时间线发现        |

#### 逻辑约束（重点）

1. **提前暗示原则**：诡计成立所需的事实（存在某个未被证实身份的成员、某人证件照片年代不符、某人从不让人细看、家族/机构有过顶替先例）必须在**游戏早期**有线索。
2. **置换后行为一致**：伪装身份的行为细节必须与**真实身份**（而非伪装身份）吻合——真实的性别/年龄/职业习惯/旧伤/口音是"无法完全伪装"的破绽，正是玩家的发现路径。**卧底再老练，也有"下班后"的真实习惯**（语言习惯、饮食习惯、对特定事物的反应）。
3. **身份识别锚点**：剧本中必须存在至少一条**不可伪造的身份识别线索**——旧识（认识你真面目的人）、伤疤/胎记（验尸/体检可查）、照片（底片年代）、指纹档案（巡捕房/机构留存）、身世履历（可被核验的过往）。**民国无统一身份证，"证件齐全"不是锚点，可被核验的过往才是。**
4. **一人分饰多角**：必须保证"各身份从不同时在场"——用时间线核对每个"出场"时刻，任一时刻被两名独立角色同时目击即诡计破产。双面间谍的行动轨迹必须同时"对得起"其每一重身份的公开义务。
5. **卧底的动机边界**：卧底杀人的动机来自**真实任务**（组织命令/保护上线/灭口），而非公开身份的利益——动机×身份互检时须按真实身份计算。

### 3.4 无面尸诡计（民国版）

> **定义**：尸体面部被毁/枪击毁容/烧焦/溺水肿胀/坠楼变形，身份无法直接辨认，"死者是谁"成为第一道谜题。

#### 在剧本杀中的典型运用

| 步骤         | 游戏内实现                                | 设计要点                                        |
| ------------ | ----------------------------------------- | ----------------------------------------------- |
| **误导阶段** | 现场发现尸体+遗留物品→玩家推断死者是A     | 遗留物品必须明显指向A（A的怀表/名片/证件/西装） |
| **发现矛盾** | 角色A的"目击"与尸体情况不匹配→触发怀疑    | A声称在某处看到谁/什么，与尸体状态冲突          |
| **真相揭示** | 线索显示尸体实际上是B                     | 通过照片比对/旧识认尸/伤疤/指纹档案/血型排除揭示 |

#### 经典结构变体

| 变体             | 说明                           | 剧本杀适用                                 |
| ---------------- | ------------------------------ | ------------------------------------------ |
| **尸体是替身**   | 凶手杀了无关人士冒充特定死者   | 需要凶手有接触"替身"的渠道和机会           |
| **尸体数量错误** | 实际死亡人数与发现的尸体数不同 | 多具尸体需在不同场景发现，玩家需统计比对   |
| **死者还活着**   | 某角色假死                     | 该角色的"死亡"需有目击者，但验尸线索不完整 |
| **双面者假死**   | 卧底/双面者借"死亡"脱身或金蝉脱壳 | 假死者的身份档案/旧识/后续行动矛盾是破绽   |

#### 逻辑约束（重点）

1. **必须有一条明确可靠的"身份识别锚点"**——照片比对（底片）、旧识（家人/战友/同僚）、伤疤/胎记（验尸可见）、指纹档案（大城巡捕房有留存）、血型（只能排除不能认定）。民国无DNA，**锚点尤为关键**。
2. **"误认"必须有合理原因**：面部毁损、烧焦、无头、溺水肿胀、家属"拒绝细看"（如指认者另有目的）——否则玩家会质疑"为什么认错了"。
3. **识别线索的取得时机**：身份识别线索要在"误导阶段"之后、"真相揭晓"之前**可被搜证获得**，形成"先误导→再证伪→后锁定"的推理弧线。

### 3.5 暴风雪山庄模式（民国版）

#### 民国封闭空间载体

| 载体         | 封闭方式                                       | 适用诡计               |
| ------------ | ---------------------------------------------- | ---------------------- |
| **洋房/别墅** | 断电/大雨封路/电话被剪断/宅邸四周眼线         | 密室、连环杀人、身份   |
| **孤岛/公馆** | 渡轮停航/轮渡被凿/大雾封江                   | 身份诡计、无面尸       |
| **火车包厢** | 列车行进中、包厢隔断、到站不停                | 密室、时间诡计、身份   |
| **舞厅/酒楼** | 打烊后封闭、电闸被拉、出入口被堵              | 帮派、阵营、密室       |
| **巡捕房/牢房** | 囚禁、出入受限、记录在案                     | 审讯、排除法、卧底     |
| **日军据点/76号** | 宪兵警戒、出入需通行证、通讯被控              | 审讯、身份、无面尸     |
| **医院/诊所** | 病房封闭、消毒隔离、夜间人少                  | 毒药、身份、延时       |
| **商船/游轮** | 航行中、乘客身份混杂、电台与世隔绝            | 暴风雪山庄、密码、身份 |

#### 逻辑约束（重点）

1. **凶手必须始终在幸存者中**；随着命案发生，嫌疑人集合必须**单调收缩**——不能中途出现"新到达者"或"此前不在场者"被排除后又复活。民国载体下"新到达者"尤其要注意：轮船中途靠岸、火车到站、飞机降落都可能带入新人——**一旦封闭成立，就必须写死封闭条件**（渡轮停航、列车不停站、电话被剪）。
2. 每一起新的命案都要**收窄可能性**（排除法推进），而不是制造无关混乱。
3. 连环案件要么共享同一凶手逻辑（特征/模式/被害者关联），要么明确揭示"第二凶手"，两者都需线索支撑。
4. **通讯被控是封闭的关键**：民国封闭空间的通讯切断（电话被剪/电报局停办/电台被监听）既要交代"如何切断"，也要交代"为何无人修复"——否则是漏洞。

### 3.6 时间诡计与延时装置（民国版）

#### 在剧本杀中的典型形式

| 形式           | 说明                                     | 破解方向                             |
| -------------- | ---------------------------------------- | ------------------------------------ |
| **死亡时间伪造** | 通过验尸误导/环境干预让死亡时间提前或推后 | 法医记录+时间源（钟表/电报/报纸）比对 |
| **钟表误导**   | 挂钟/怀表被调、停表                     | 多个计时源读数矛盾、权威时间源对比   |
| **电报/报纸时间戳** | 电文拍发时间、报纸发行时间被利用        | 电报局底稿、报馆记录、送达时间核算   |
| **延时杀人**   | 凶手动手后延迟死亡，制造不在场证明       | 凶器/装置的延时机制线索             |

#### 民国延时手段

| 延时手段       | 原理                                   | 精度与注意                                             |
| -------------- | -------------------------------------- | ------------------------------------------------------ |
| **定时装置**   | 钟表改装/闹钟触发/定时雷管             | 需交代装置来源与改装者；走时误差存在                 |
| **慢燃引火**   | 导火索/浸油布条/线香引燃               | 受潮失效风险，需留装置残件线索                       |
| **慢性毒药**   | 小剂量累积/迟发毒物，延迟发作           | 发作窗口宽，是"不在场证明"的经典手段                 |
| **心理延时**   | 所有人误判死亡/离场时间，凶手当时就在场 | 利用看错钟表/误认身份/夜盲等误判                     |
| **汽车制造意外** | 刹不住/方向失灵伪装车祸                | 刹车痕迹、车辆检修记录、路面状况是可查的             |

#### 逻辑约束（重点）

1. **偏差必须有系统来源**（§2.2法则6）：谁调的钟、何时调、为何无人发现，都要有交代。
2. **延时必须归类并验精度**：真延时（定时装置/慢燃/慢性毒）or 心理延时（误判在场者）。真延时要验证时间精度能否支撑设定。
3. **死亡时间伪造必须有验尸与时间源依据**：用什么手段误导了验尸结论（环境保温/降温、胃内容物做手脚），该手段本身要留下可被发现的痕迹；钟表/电报/报纸等独立时间源要交叉核验。
4. **民国时间源是中立的**：钟表可调、电报有时间戳、报纸有发行时间、时刻表是硬约束——时间诡计要"利用"这些而非"无视"这些。

### 3.7 密码与情报诡计（民国特色）

> 密码与情报是民国谍战本最富特色的手段板块，也是其**逻辑严谨性的核心考验**：破译必须是**过程**而非天降答案，情报流转必须**留痕**且**有窗口**。

#### 电报与密码诡计

| 诡计             | 实现                                     | 逻辑约束                                                     |
| ---------------- | ---------------------------------------- | ------------------------------------------------------------ |
| **密电破译**     | 截获的电文需破译，破译依赖密码本/密钥/语言特征 | 破译需线索支撑（截获电文+密码本线索+频率统计/电码本）；破译结果必须能在剧本内被玩家重现 |
| **密码本失窃/调换** | 密码本被窃、被换、被伪造               | 谁能接触密码本、失窃时间窗、被换后的"新旧不符"矛盾           |
| **电文时间戳**   | 电文拍发时间、送达时间、破译时间之差     | 电报局底稿/送报记录；时间差必须与行动窗口吻合                |
| **报务员手癖**   | 资深监听员凭发报节奏（"手癖"）识别发报人 | 手癖是个人印记，类比"笔迹"，需铺垫"某人发报习惯独特"的设定线索 |
| **电台测向**     | 无线电测向三角定位发报地点               | 测向需设备与时间；发报时间窗内"谁在某处"即嫌疑              |
| **代发/伪造电文** | 他人代发、伪造电文栽赃                 | 代发需权限/委托；伪造需密码本+电文格式知识；底稿留痕          |

#### 密写与隐写诡计

| 载体           | 原理                                     | 显影/破绽线索                                 |
| -------------- | ---------------------------------------- | -------------------------------------------- |
| **米汤密写**   | 淀粉水写字，干后透明                     | 碘酒熏显蓝黑；米粒淀粉残留                 |
| **牛奶/柠檬汁** | 有机物写字，干后透明                     | 加热焦化显色（烛火/熨斗）                 |
| **明矾/硫酸亚铁** | 化学试剂写字                           | 特定化学显影液；试剂来源线索               |
| **书页隐写**   | 在书/报纸上以点画/页码/字序约定信息     | 需"约定"设定线索（点页/划线/留白方式）     |
| **夹层/信物**  | 假书、夹层箱底、表壳/怀表夹层藏信       | 夹层需"可被发现"的打开方式或破损痕迹       |
| **收信人暗号**  | 以"寻人启事""征婚"等形式登报传递暗语     | 报纸版面/日期/措辞与约定对应               |

#### 死信箱与接头诡计

| 诡计           | 实现                                     | 逻辑约束                                                     |
| -------------- | ---------------------------------------- | ------------------------------------------------------------ |
| **死信箱交接** | 在约定地点无人交接（树洞/墙缝/墓碑后）   | 交接有时间窗与暗号标记（粉笔痕/报纸卷法）；**谁能看见交接**是关键排除项 |
| **接头暗号**   | 暗号对答（第一句/第二句）、手势、报纸位置 | 暗号错了即"接头人不对"；**顶替接头人是常见诡计**（需旧识/照片/暗号双向验证） |
| **单线联系**   | 交通员只认上线、上下线互不相识           | 链条断裂点=推理突破口；单线设计的"信息边界"必须清晰         |

#### 情报流转的逻辑闭环（创作时必建）

**一条情报从"源头"到"凶手"必须回答**：
1. **源头**：情报最初从哪获得（截获/窃取/内线/破译）？
2. **载体**：用什么传递（电报/密写/死信箱/交通员/当面）？
3. **窗口**：在哪个时间窗传递/收发（电台定时开机、死信箱约定时间）？
4. **留痕**：传递过程留下什么痕迹（电报底稿、报纸版面、粉笔标记、目击）？
5. **代价**：谁在传递/破译中暴露了什么（发报暴露位置、密写试剂来源、接头人现身）？

> **自检问题**：如果情报的"源头/载体/窗口/留痕/代价"任何一环说不清，就是"凶手不该知道却必须知道"的信息来源漏洞（§2.6）。**情报不是背景板，情报流转本身就是证据链。**

### 3.8 帮派与机构斗争（民国特色）

> 帮派与谍战机构是民国谍战本的**动机库、机会场与阻力源**。其推理价值在于：**帮派规矩与机构权限决定"谁能进"、"谁不敢查"、"谁受益"**。

#### 帮派载体

| 载体         | 冲突内核                         | 典型诡计                   |
| ------------ | -------------------------------- | -------------------------- |
| **码头**     | 地盘争夺、工会、走私             | 栽赃、灭口、替身           |
| **烟馆/赌场** | 经济命脉、供奉、堂口分成         | 毒杀、密室、收买           |
| **香堂/拜师** | 帮规、辈分、门下争位             | 身份诡计、动机（以下犯上） |
| **商会/公馆** | 买办、黑白勾结、政商勾结         | 权谋、假情报、灭口         |

#### 谍战机构载体

| 机构         | 权限边界（可用于推理）                             | 典型诡计                   |
| ------------ | -------------------------------------------------- | -------------------------- |
| **军统**     | 戴笠系统的特工机构，配电台、行动组，锄奸/暗杀     | 暗杀、密码破译、审讯       |
| **中统**     | 党务调查系统，重"党政"案件，与军统争权            | 渗透、档案、策反           |
| **中共地下党** | 单线联系、秘密电台、锄奸队、上下线互不相识         | 死信箱、接头、身份         |
| **76号（汪伪）** | 上海日伪特工总部，对抗军统锄奸、破坏地下工作     | 审讯、跟踪、反锄奸         |
| **日本特高课/宪兵** | 情报、镇压抗日、测向监听                         | 测向、密码、严刑           |
| **租界巡捕房** | 工部局/公董局警察，只管租界内、受治外法权约束     | 管辖真空、华捕系统、政治部 |

#### 租界管辖权诡计（民国谍战特有）

**核心设定**：上海分**公共租界、法租界、华界**三块，另有日占区。各自的警察/特工管不了对方的地盘——**"凶案发生在哪块地界，就由谁立案"**是硬规则。

| 管辖结构               | 对推理的影响                                           |
| ---------------------- | ------------------------------------------------------ |
| **尸体跨区**           | 尸体被从法租界移至华界/公共租界，立案机构与调查方向随之改变 |
| **治外法权**           | 外国人/特定身份者犯罪，由领事法庭或本方机构处理，中国警察无权过问 |
| **管辖真空**           | 交界处、码头、租界边缘案件归属不明——凶手可"利用混乱" |
| **机构争抢**           | 军统/中统/76号/巡捕房都想抢或推案件——谁"抢案"、谁"甩案"本身就是线索 |
| **引渡/移交**          | 嫌疑人跨区即需移交手续，手续间隙=逃亡/灭口窗口         |

#### 栽赃手法与逻辑约束

| 栽赃手法       | 实现                                     | 逻辑约束                                                     |
| -------------- | ---------------------------------------- | ------------------------------------------------------------ |
| **预置凶器**   | 把凶器藏入嫁祸对象处                   | 需有"凶手如何取得/放置凶器"的通道线索（钥匙、门房配合）     |
| **伪造电文/密信** | 伪造电报底稿/密写信件指向某人          | 需有"电文格式/密码本/笔迹可仿"的铺垫与伪造工具线索           |
| **假情报**     | 故意放出错误情报引导调查方向           | 假情报要有"放料人+放料渠道+收料人"的完整链条；反向排查即破绽 |
| **买通人证**   | 收买门房/巡捕/堂口眼线作伪证           | 需有金钱往来、威胁把柄等"买通"线索                           |
| **布置伪现场** | 伪造枪战/入室/仇杀现场                 | 伪现场与真实痕迹的矛盾点即破绽                               |

**逻辑约束（重点）**：
1. **栽赃要有"栽赃通道"线索**：嫁祸对象身上的凶器/电文，凶手是如何取得的？无通道的栽赃是凭空指控。
2. **机构权限是推理素材**：谁能调档、谁能抓人、谁有权审——"某机构该查却没查""某机构不该查却抢着查"都是线索。
3. **帮派规矩要自洽**：码头"谁说了算"、堂口"背叛的下场"——帮派行为有规则可循，不是随机暴力。
4. **机构利益豁免的处理**：权势可使人"不敢查"——这是动机与阻力的来源，但不能成为逻辑漏洞。玩家仍应能凭线索指向真凶，只是剧本内角色可能因权势而犹豫（这是戏剧张力，不是逻辑豁免）。

### 3.9 误导与伪解答工程（民国版）

**红鲱鱼设计原则**：

| 原则         | 说明                                         |
| ------------ | -------------------------------------------- |
| **有独立价值** | 即使不指向真凶，也揭示了某个角色的秘密或动机 |
| **合理存在**   | 不是凭空出现——与该角色的行为/背景一致        |
| **可被推翻**   | 后续有线索可推翻该误导，而不是"不了了之"     |
| **不过度集中** | 不要把大部分误导线索集中在同一个非真凶角色上 |

**民国谍战常见误导源**：
- **假情报/反向误导**：机构放出的假电文、故意泄漏的假消息——先引导玩家往错误方向查，再用链条反向排查拉回。
- **政治斗争误判**：让玩家以为死者死于党派斗争，实际是私人恩怨/灭口/情杀。
- **帮派仇杀传闻**：死者"仇家遍布"误导外部帮派作案，实际内部作案。
- **身份误认**：化名/顶替让玩家认定"死者/凶手是某人"，实际另有其人（§3.3、§3.4）。
- **电文破译歧义**：密电破译出"多个解释"，误导玩家——破译歧义需有语言/电码依据，且最终以其他线索收束。

**伪解答设计**：一个表面上能解释所有线索的"假真相"。要求：
- 伪解答必须能**暂时覆盖**绝大多数线索；
- 伪解答必须有**至少一条反证线索**，且该线索在游戏后期可被搜证获得；
- 伪解答被推翻的瞬间 = "恍然大悟"时刻。

**逻辑约束**：伪解答数量建议 **1–2 个**。每个伪解答的推翻线索要与真凶推理链**共用线索、互相咬合**，而非另起炉灶。

#### 误导的进阶形态：前提错误型

> **最高明的误导不是让玩家"想错答案"，而是让玩家"一开始就想错了问题"。** 一旦"死者是谁""凶手是哪个阵营""这封电文是谁发的"这一前提错误，所有后续推理都失去根基。

典型：**无面尸 + 身份误认**（§3.4）、**假电文误导阵营归属**（§3.8）、**伪解答依赖错误前提**（如"现场是密室"这个前提本身错了）。破绽点在于：推翻前提的那条线索（如"死者其实是B"、"这封电文是伪造的"）必须是**玩家可主动质疑、可搜证验证**的。


## 四、经典案例解析（逻辑严谨性视角）

以下案例解析侧重于"这个诡计**在逻辑上为什么成立**"以及"如何转化为剧本杀设计"，供创作时参考。解析基于各作品公开的剧情要点与剧本杀复盘，不涉及不必要剧透。

### 4.1 案例一：《风声》——封闭空间 + 身份锁定 + 排除法

| 项目     | 内容                             |
| -------- | -------------------------------- |
| **作者** | 麦家（原著）/ 高群书、陈国富（电影） |
| **类型** | 谍战 / 密室 / 身份 / 阵营        |

**设定**：汪伪政府破获抗日团体秘密电台，密电内容泄露。日伪怀疑潜伏的"老鬼"就在五名嫌疑人中，遂将其囚禁于封闭的裘庄，靠破译密电、审讯、试探、心理战锁定"老鬼"。

**逻辑上为什么成立**：
- **封闭空间使嫌疑人集合固定**（暴风雪山庄，§3.5）——排除法得以推进。
- **信息源是破局关键**：密电内容只有少数人知道（§3.7情报流转闭环）——"谁能接触密码本/电台"即锁定范围。
- **发报时间窗口是硬约束**：电台开机时间、密电发出时间与在场者核对（§3.7电台测向/开机窗口）。
- **身份诡计**：老鬼以公开身份潜伏（§3.3）——排除法+信息比对准确定位。

**剧本杀转化**：

| 作品中的实现                     | 在剧本杀中的转化                                             |
| -------------------------------- | ------------------------------------------------------------ |
| 五人被囚，逐一排查             | 固定嫌疑人集合，玩家各自隐瞒身份，同时要找出卧底             |
| 破译密电获取情报               | 电文作为核心线索，破译需要玩家组合密码本/语言特征线索         |
| 审讯与试探                       | 私聊/公聊阶段互相试探，证词交叉比对                          |
| 发报时间与测向                   | 时间线推理：发报时段内"谁恰好独处"                           |

**可借鉴的剧本杀元素**：
- **固定嫌疑人 + 排除法**：五人必有一"老鬼"，排除推进是主结构。
- **电文破译作为推理过程**：破译不是天降，需要线索组合。
- **隐藏身份 + 找卧底双线**：玩家既要保身份，又要找卧底。

### 4.2 案例二：《暗算》——密码破译与信息源排查

| 项目     | 内容                             |
| -------- | -------------------------------- |
| **作者** | 麦家                             |
| **类型** | 谍战 / 密码破译 / 机构           |

**设定**：分"听风"（无线电侦听，凭听觉辨识别频率与敌方报务员）、"看风"（密码破译）、"捕风"（保密局内部抓卧底）。

**逻辑上为什么成立**：
- **侦听依赖"个人印记"**：资深侦听员凭发报节奏（"手癖"）识别发报人——声音/发报特征是个人印记，类比笔迹（§3.7手癖识别）。
- **破译是推理过程**：破译依赖截获电文+密码本/密钥+语言特征（频率统计/电码本），不是凭空"看懂"（§3.7）。
- **抓卧底靠信息源排查**：谁能接触密码本、谁在发报时间有行动能力（§2.6信息来源攻击）。

**剧本杀转化**：

| 作品中的实现                   | 在剧本杀中的转化                                       |
| ------------------------------ | ------------------------------------------------------ |
| 侦听员识别发报"手癖"         | 设定线索：某人"发报习惯独特"被监听员识别               |
| 密码破译                       | 破译需要组合电文+密码本+语言特征线索，玩家可重现破译   |
| 保密局内部抓卧底               | 固定机构场景（会议室/电报房），靠时间线+信息源锁定     |

**可借鉴的剧本杀元素**：
- **破译必须可重现**：给出破译所需全部线索，让玩家"自己破出来"。
- **手癖识别**：发报/字迹/声音的个人印记作为身份线索。
- **信息源排查**：谁接触过什么资料，是排除法的骨架。

### 4.3 案例三：《潜伏》——双重身份的时间线与信息窗口

| 项目     | 内容                             |
| -------- | -------------------------------- |
| **类型** | 谍战 / 电视剧                     |
| **核心亮点** | 长期潜伏 + 双重身份 + 电台/死信箱情报传递 |

**设定**：余则成以军统天津站特工身份为掩护，实际是中共地下党员，长期潜伏，通过电台、死信箱、交通员传递情报。

**逻辑上为什么成立**：
- **双重身份的行为一致性**（§3.3）：公开身份与真实身份的日常必须"无缝"，但习惯/履历有破绽可寻。
- **电台收发是时间窗硬约束**：发报时间、频率、测向风险——"发报时段内谁恰好独处"即嫌疑（§3.7）。
- **情报传递留痕**：死信箱交接、交通员单线联系、暗号——传递链条可查（§3.7）。
- **身份维护需核验**：伪造履历经不起旧识/档案核对——"老照片、旧识、口音"是破绽（§3.3）。

**剧本杀转化**：

| 作品中的实现                 | 在剧本杀中的转化                                     |
| ---------------------------- | ---------------------------------------------------- |
| 双重身份隐藏于机构           | 玩家角色带双重身份任务，需隐藏又要完成任务           |
| 电台定时开机                 | 时间线：发报时段谁独处、谁"有事"                   |
| 死信箱/交通员传递           | 情报流转线索：交接点、暗号、目击                     |
| 身份经不起核验               | 旧识重逢、照片、档案核对作为身份破绽                 |

**可借鉴的剧本杀元素**：
- **双重身份本**：玩家身负隐藏任务，同时参与推理。
- **情报窗口推理**：发报/交接时段是时间线的关键锚点。
- **身份破绽可搜证**：旧照片、档案、旧识证词。

### 4.4 案例四：《悬崖》——身份伪装的代价与破绽

| 项目     | 内容                             |
| -------- | -------------------------------- |
| **类型** | 谍战 / 电视剧                     |
| **核心亮点** | 卧底身份的长线经营与暴露风险       |

**设定**：周乙以伪满警察厅人员身份潜伏，长期经营公开身份，靠电台与单线联系传递情报，暴露风险来自"无法抹去的过去"与"旧识重逢"。

**逻辑上为什么成立**：
- **身份伪装有代价**：换身份、迁居、旧识重逢都可能暴露——**"认识你真面目的人"是最大的变量**（§3.3身份识别锚点）。
- **单线联系的信息边界**：上下线互不相识，链条断裂即暴露（§3.7单线联系）。
- **情报交换的时机**：电台开机、交接时间的巧合即嫌疑。

**剧本杀转化**：

| 作品中的实现                     | 在剧本杀中的转化                                 |
| -------------------------------- | ------------------------------------------------ |
| 旧识重逢暴露身份               | "某人认出某人"的目击线索作为身份破绽             |
| 单线联系链条                   | 情报链条断裂点=推理突破口                       |
| 身份经营的长线细节             | 角色卡中的习惯、履历、人际往来细节可被搜证核验   |

**可借鉴的剧本杀元素**：
- **旧识证词**：认识真面目的人是最强身份线索。
- **链条断裂**：情报传递链条每环可查，断点即破绽。
- **长线细节**：习惯/口音/饮食等细节破绽。

### 4.5 案例五：《伪装者》——多重身份的家族谍战

| 项目     | 内容                             |
| -------- | -------------------------------- |
| **类型** | 谍战 / 电视剧                     |
| **核心亮点** | 明家三兄弟多重身份 + 家族情感     |

**设定**：明家三兄弟各有身份（军统/地下党/汪伪多重身份交织），在同一场合不同身份相遇，家族亲情与任务冲突。

**逻辑上为什么成立**：
- **多重身份的行为脚本**：同一人切换身份时，言行举止须符合对应身份的"脚本"——切换必有理由与破绽（§3.3）。
- **身份在场校验**：一人分饰多角，每个身份的"出场时刻"都要与时间线自洽——**任一时刻被独立目击即破产**（§3.3）。
- **家族关系是双刃剑**：既是掩护（"一家人不可能互相怀疑"），也是破绽（最了解你的人是家人）。

**剧本杀转化**：

| 作品中的实现                     | 在剧本杀中的转化                                 |
| -------------------------------- | ------------------------------------------------ |
| 多重身份在同场相遇             | 多重身份角色需在每个场景自洽，玩家靠时间线还原   |
| 家族掩护与破绽                 | 人物关系网既是线索网也是误导源                   |
| 身份切换的理由                 | 每个身份切换都要有"为什么现在切换"的动机与机会   |

**可借鉴的剧本杀元素**：
- **多重身份角色**：同一玩家/角色多个身份，推理复杂度高。
- **关系网线索**：家族/同事/上下级关系本身就是证据网。
- **身份切换自洽**：每个身份的出场时刻严格校验。

### 4.6 案例六：《色戒》——身份错位与行动暴露

| 项目     | 内容                             |
| -------- | -------------------------------- |
| **类型** | 谍战 / 电影（李安导演）           |
| **核心亮点** | 假身份渗透 + 暗杀行动 + 情感冲突   |

**设定**：王佳芝以"麦太太"身份接近易先生实施暗杀，假身份"细节破绽"（不熟悉贵妇社交、编造经历无法印证）与情感冲突导致暴露。

**逻辑上为什么成立**：
- **假身份的细节破绽**（§3.3）：编造经历经不起核验、社交细节不熟、方言错误——身份暴露的线索路径。
- **行动窗口与撤退路线**：暗杀的时机、现场、撤退——行动的每一步都需通道（§2.6物理/机会攻击）。
- **情感与任务的冲突**：人性变量——既是戏剧张力，也是"行动为何偏差"的解释。

**剧本杀转化**：

| 作品中的实现                   | 在剧本杀中的转化                                     |
| ------------------------------ | ---------------------------------------------------- |
| 假身份细节破绽               | 身份核验线索：方言、习惯、旧识证词、编造经历查证     |
| 暗杀窗口与撤退               | 行动时间线：谁在暗杀时段有通道                     |
| 情感冲突                     | 角色任务与情感的张力，影响行动选择（阵营本常用）     |

**可借鉴的剧本杀元素**：
- **假身份破绽可搜证**：编造经历、社交细节、方言错误是暴露路径。
- **行动通道推理**：暗杀/下毒的通道（机会×时机）。
- **阵营与情感**：角色个人任务影响推理与投票。

### 4.7 案例七：剧本杀阵营本（《孤城》《谍影·重庆迷雾》《兵临城下》）

| 项目     | 内容                                   |
| -------- | -------------------------------------- |
| **类型** | 民国谍战/抗战阵营机制本                 |
| **代表** | 《孤城》《谍影·重庆迷雾》《兵临城下》 |

**特点**：阵营对抗（国/共/日/帮派/平民）、身份隐藏、私聊交易、机制（物资/枪/情报/投票）。

**逻辑注意（阵营本的严谨性）**：
- **身份暴露要有"可验证信息"**：判断谁是卧底/间谍，需文本/实物证据（电文、信件、接头暗号、物资流向），而非纯"猜"（§3.7）。
- **私聊获取的情报需留痕**：交易/接头需有记录（纸条、账册、电报），否则私聊情报无法在复盘时被验证。
- **机制与推理的平衡**：机制（物资/枪/暗杀）要能服务于身份与动机的推理，而不是纯游戏规则。

**可借鉴的剧本杀元素**：

| 借鉴点         | 说明                                     |
| -------------- | ---------------------------------------- |
| **阵营对抗**   | 玩家分属阵营，各有目的，投票/行动受阵营影响 |
| **身份隐藏**   | 卧底/双面的隐藏与揭示                   |
| **私聊交易**   | 情报与物资的交换，须留痕可验证           |

## 七、逻辑自检清单（民国谍战版）

### 7.1 逻辑闭环检查
- [ ] 六要素（死因/手段/时机/机会/动机/身份）两两互检无矛盾
- [ ] 死因与现场表现一致（无"枪伤却是病亡""毒死却无来源"类矛盾）
- [ ] 凶手作案所需的关键信息均有获取渠道（密码本、钥匙、死者的位置、现场布局）
- [ ] 存在完整排除项（自杀/意外/病亡/假死/外部闯入/合谋/时间伪造/情报方/双面均被排除且各有线索）

### 7.2 时间线检查（民国计时）
- [ ] 钟表/广播/电报时间戳/时刻表换算统一，偏差有系统来源
- [ ] 主时间线物理自洽，所有记录/证词/巡捕房档案可叠加
- [ ] 火车/电车/轮渡时刻表核算与角色声称相符
- [ ] 每个角色有时间线，空白时段有解释（独处即嫌疑窗口）
- [ ] 任一证言至少与一条独立信息源交叉验证（门房×售票员×电报局×巡捕房）
- [ ] 电台开机/交接时间窗与在场者核对
- [ ] 夜间目击有照明/灯影来源交代，无"漆黑看清"硬伤

### 7.3 物理可行性检查（民国器物）
- [ ] 手法200字内可描述清楚
- [ ] 工具三问全部通过（来源/去向/痕迹），枪械有军火渠道、炸弹有引爆装置
- [ ] 弹道/弹壳/火药残留与枪支匹配
- [ ] 延时装置已归类（真延时/心理延时）且精度验证通过
- [ ] 密室"进、出、闭"三向都有解；门房/后门/防火梯盲区已处理
- [ ] 无超时代科技（监控/手机/DNA）；"半可用"科技局限已处理

### 7.4 线索公平性检查
- [ ] 所有关键线索在游戏过程中可被搜证获得（无天降线索）
- [ ] 关键推理链≥3步，每步≥2条独立线索支撑
- [ ] 每条线索标注了推理价值（无推理价值的线索已删除或转纯氛围）
- [ ] 身份诡计有提前暗示，且存在至少一条不可伪造的身份识别锚点
- [ ] 破译（密码/密写）所需线索全部给出，玩家可重现破译
- [ ] 每条误导线索有收束（可被推翻或有解释），假情报有完整链条
- [ ] 推理所需民国谍战知识已写入剧本（知识自包含，ps_民国谍战 §5.6）

### 7.5 唯一性检查
- [ ] 给定全部线索，只有一套六要素自洽
- [ ] 伪解答（若有）能被明确反证线索推翻
- [ ] 排除法穷举了所有"他杀外可能"（含情报方/双面/替身）
- [ ] 合谋/帮凶/单线联系的信息边界清晰（谁、何时、知道多少）

- [ ] 档位（写实/虚构/戏说）已定且全程守约

### 民国谍战本格核心公式

```
逻辑严谨的民国谍战剧本 = 时代要素自洽 + 六要素闭环 + 自洽时间线 + 物理可行手法 + 身份自洽 + 情报流转闭环 + 可推导线索链 + 唯一真相 + 完整排除法 + 知识自包含
```

### 剧本创作优先级（逻辑先行）

1. **先设计真相与诡计**——这是本格推理的灵魂
2. **再过逻辑框架**——六要素闭环、时间线、物理可行性、时代要素排查（本库第二章）
3. **再设计身份与情报线**——卧底/化名/双面的身份自洽，情报流转的闭环（§3.3、§3.7）
4. **再设计角色和动机**——角色为案件服务，动机与身份、机构权限互检
5. **再反向设计线索链**——从真相反推，建"线索链总表"，确保推理路径完整且公平
6. **最后设计分幕与氛围**——知识自包含，信息流速合理，玩家体验顺畅


## 附录：民国谍战专业知识速查（创作调用）

> 供创作时直接引用，保证密码、机构、器物、检验等细节**真实可信**。使用时须结合§2.7时代要素排查，确认与所选档位一致。

### A. 密码学基础（民国）

**中文电报码**：汉字以四位数编码（中文电码本/标准电码），电文以数字串形式传输。明码电文（如普通商务电报）人人可译；密码电文在此基础上再做规则变换。

**摩斯电码（Morse）**：点（短）/划（长）组合，用手键/自动键拍发。**报务员发报有个人"手癖"**（键速节奏、间隔习惯、起始动作），资深监听员可凭此识别发报人——类比"笔迹"，是极强的身份线索（《暗算》"听风"的依据）。

**密码体系分层**：
- **密码本（codebook）**：电报码数字再转译成无规律密语，双方各持一本——**密码本失窃/调换是重大事件**，接触者是排查对象。
- **换字规则**：移码（数字整体加减固定值）、换字表（替代）、纵横棋格（Polybius方格类）——规则即密钥。
- **一密一用/滚动码**：一次一密则不可破，滚动码（周期性换密钥）有规律可循——**破译需要截获足够数量的电文**。

**破译方法（给玩家的推理过程，非黑箱）**：
- 截获电文（电台监听/电报局截留）→ 判明语种与编码 → 频率统计（数字/字的出现频率与语言特征比对）→ 找出换字规律/密码本 → 解出明文。
- **破译的时效**：破译需要时间，情报的"破译时间差"本身是推理要素（敌人破译你电文的窗口=你的暴露窗口）。

**密写（隐形墨水）**：
- 淀粉/米汤水 → 碘酒熏显蓝黑色
- 牛奶/柠檬汁/洋葱汁 → 加热（烛火/熨斗）焦化显色
- 明矾水 → 浸水或加热显色
- 稀硫酸 → 加热碳化显黑（须防蚀纸）
- **显影手段本身是线索**：谁有试剂、谁有加热工具、谁被发现在"熏信纸"。

**隐写（Steganography）**：
- 报纸"寻人启事""征婚"栏暗语（版面/日期/措辞与约定对应）
- 书页以点画/页码/字序约定信息
- 信件行文挖字、藏头、藏尾
- 夹层：表壳、怀表底、假书、箱底夹层

**死信箱（Dead Drop）**：无人交接点（树洞/墙缝/墓碑后/邮筒夹层），交接有**时间窗与暗号标记**（粉笔痕、报纸卷法、花盆位置）——标记出现=有交接，标记异常=被破坏/被盯上。**谁能看见交接点，是排查死信箱的起点**。

**接头**：暗号对答（第一句/第二句既定）、手势、报纸拿法——**暗号错了即"接头人不对"**；顶替接头人是常见诡计，需暗号+旧识/照片双向验证。

**无线电台**：
- 定时联络（每天固定时段开机）——**开机时间窗**内"谁在某处"即嫌疑。
- **测向（DF）**：三角定位锁定发报位置——电台开机即暴露位置，专业机构会监听测向。
- 电台藏匿与自毁：便携电台笨重，藏匿处需被搜出；自毁装置/密码本烧毁是常见操作（烧毁的残页是线索）。

**关键制度要点**：
- **治外法权（领事裁判权）**：租界内洋人犯罪由中国领事法庭/本国机构审理，中国警察无权拘押洋人——**"洋人凶手"是管辖难题**（也常被凶手利用）。
- **引渡/移交**：嫌疑人跨区需移交手续，手续间隙=逃亡/灭口窗口。
- **华界警察/宪兵/保安队**：华界（中国自管区）由华界警局管辖，与租界互不管辖。
- **帮派行规**：拜师入堂（香堂）、辈分次序、码头地盘、"摆平"（调解纠纷）、"欺师灭祖"为第一大忌——帮派行为有规则。

### D. 民国法医检验速查

**体系并存**：民国时期大城市（上海/北平/南京）由**法医/西医医生**做尸体检验，公共租界由巡捕房安排英法医生；华界与乡野仍多用**仵作**（宋代方法）——**两套体系的结果可能分歧，可制造"验尸结论矛盾"的诡计**。

**检验能力（可用的证据）**：
- 大体死因：枪伤（入口/出口、射距近有火药灼痕）、刀伤（创口形状、深度）、勒/缢（索沟特征）、溺（肺水肿、水草）、毒（症状推断、气味）
- 弹道：枪伤入口出口、子弹留存、弹道方向推断（射击角度）
- 指纹：可采集（粉/熏显），但无自动比对——比对需原始指纹档案
- 血型：ABO血型（1901年发现），租界/大城市有应用——**只能排除不能认定**（O型血者众）
- 尸温/尸僵/尸斑：粗略估计死亡时间（误差以小时计，须与时间源交叉）

**检验局限（必须主动处理）**：
- 无DNA、无微量物证广泛分析
- 毒理检验极有限：砒霜类可粗测（银针/铜盘法，同古风银钗局限），乌头/断肠草等难检出
- 慢性毒/心疾猝死可能被误判为病死——"以病掩毒"合法，误判暴露需线索（药渣、病历、症状细节）
- 死亡时间只能粗糙判断，**精确死亡时间须靠时间源交叉**（钟表/电报/报纸/目击/时刻表）
- 身份识别：靠照片/旧识/伤疤/指纹档案/血型排除，无DNA
